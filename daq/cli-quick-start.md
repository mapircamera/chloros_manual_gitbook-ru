# CLI Краткое руководство по началу работы (pool-*)

Поставляемый в комплекте `chloros-cli` управляет датчиками сбора данных (DAQ) с помощью семейства команд **`daq pool-*`** — «тонкие» клиенты HTTP, которые управляют датчиком через постоянный пул датчиков бэкэнда Chloros. Бэкенд управляет транспортом, поэтому графический интерфейс, скрипт CLI и скрипт SDK используют один активный дескриптор, а не борются за порт. Все, что нужно клиенту, доступно через `pool-*`: подключение, потоковая передача, запись откалиброванных файлов `.daq` и замена профилей капсюлей.

`pool-*` также является **единственным** интерфейсом DAQ в выпущенных сборках. `chloros-cli daq --help` выводит список подкоманд `pool-*`, и вызов подкоманды DAQ, напрямую взаимодействующей с аппаратным обеспечением, в поставляемой сборке приводит к завершению работы с явной ошибкой, в которой указывается отсутствующий пакет и предлагается вернуться к `pool-*` — ничто не завершается без ошибки. (Команды прямого доступа к аппаратному обеспечению запускаются только из чек-аута исходного кода MAPIR; `pip install chloros-sdk` их также не предоставляет.)

***

## Необходимые условия

* **Должен работать бэкенд Chloros** — команды `pool-*` являются клиентами HTTP, а не драйверами оборудования. На Windows запустите настольное приложение Chloros (оно запускает бэкенд). На Linux/Jetson без монитора включите службу: `sudo systemctl enable --now chloros-backend.service`.
* **Вход в систему на Chloros+ (платный тариф)**: сначала запустите `chloros-cli login`. Проверка выполняется на стороне сервера — без входа в систему команды завершаются с ошибкой `401 AUTH_REQUIRED`; на бесплатном (Iron) тарифе — с ошибкой `403 PLAN_UPGRADE_REQUIRED`.
* По умолчанию команды нацелены на `http://127.0.0.1:5000`; семейство `daq pool-*` учитывает переменную среды `CHLOROS_BACKEND_URL`, если ваш бэкенд работает в другом месте.

***

## Пятиминутная сессия

```bash
# 1. Connect a sensor into the backend pool (pick the line matching your model)
chloros-cli daq pool-connect                                  # smart-detect any DAQ
chloros-cli daq pool-connect --port COM3                      # DAQ-U on a specific COM port
chloros-cli daq pool-connect --mac AA:BB:CC:DD:EE:FF          # DAQ-M by BLE MAC
chloros-cli daq pool-connect --eth-host daq-e-def330.local    # DAQ-E by hostname (reliable)

# 2. List the pool — this shows the sensor_id used by every command below
chloros-cli daq pool-list

# 3. Read the most recent calibrated spectrum frame (add --json for scripting)
chloros-cli daq pool-latest --sensor-id daq-e-def330 --json

# 4. Record a calibrated .daq file for 60 seconds
chloros-cli daq pool-record --sensor-id daq-e-def330 --duration 60 \
  --device-name "field-A"

# 5. Release the sensor when done
chloros-cli daq pool-disconnect --sensor-id daq-e-def330
```

***

## `pool-connect` — открыть датчик в пуле

| Вариант | Значение |
| --- | --- |
| `daq pool-connect` | Интеллектуальный поиск: найти любой DAQ на этом компьютере. |
| `daq pool-connect --port PORT` | DAQ-U на определённом последовательном порте (например, `COM3`, `/dev/ttyUSB0`). |
| `daq pool-connect --ble` | DAQ-M по BLE, автоматическое сканирование MAC-адресов. |
| `daq pool-connect --mac MAC` | DAQ-M с известным MAC-адресом BLE (подразумевает `--ble`). |
| `daq pool-connect --eth-host HOST` | DAQ-E по известному имени хоста или IP-адресу — **надежный путь**. |
| `daq pool-connect --eth` | DAQ-E с автоматическим обнаружением (mDNS, с резервным использованием ARP). См. предупреждение ниже. |

Флаги настройки, все необязательные:

| Флаг | Значение |
| --- | --- |
| `--integration-time MS` / `-t MS` | Время интеграции, задаваемое вручную, в миллисекундах. |
| `--frame-avg N` / `-f N` | Количество кадров, усредняемых для каждого отчёта спектра. |
| `--no-ae` | Отключить автоматическую экспозицию (по умолчанию включена). |
| `--no-stream` | Подключиться без запуска потока (возобновить позже с помощью `pool-stream --start`). |
| `--cap-id CAP` | Профиль коррекции капа; по умолчанию для бэкенда используется `sunshine_cosine`. См. [`pool-set-cap`](#pool-set-cap-declare-the-fitted-cap). |

{% hint style="warning" %}
**Предостережение относительно автоматического обнаружения `--eth`.** На хосте с несколькими сетевыми интерфейсами (более одного активного сетевого интерфейса) *первый* вызов `pool-connect --eth` после загрузки может завершиться безрезультатно, даже если датчик исправен — процесс обнаружения может пропустить интерфейс датчика, пока кэш ARP не загрузится. Если команда `--eth` ничего не обнаружит, повторите попытку или полностью пропустите обнаружение, используя команду `--eth-host <ip-or-hostname>`, которая является надёжным способом на машинах с несколькими сетевыми интерфейсами. Имя хоста DAQ-E — `daq-e-<id>.local` (например, `daq-e-def330.local`); можно использовать и простой IP-адрес.
{% endhint %}

## `pool-list` — просмотр подключённых устройств

Отображает все датчики в пуле бэкэнда, включая `sensor_id`, который требуется для выполнения всех остальных команд:

| Модель | Формат `sensor_id` | Пример |
| --- | --- | --- |
| DAQ-U / DAQ-M | 5-октатный с дефисами | `CB-7C-A8-2E-5F` |
| DAQ-E | `daq-e-<6 hex digits>` | `daq-e-def330` |

## `pool-latest` — чтение спектральных фреймов

```bash
chloros-cli daq pool-latest --sensor-id daq-e-def330 --recent 10 --json
```

Возвращает самый последний кадр или самые последние `--recent N` кадры; `--json` выводит машиночитаемый вывод для использования в скриптах. Кадры представляют собой радиометрически откалиброванную спектральную освещённость (Вт/м²/нм) на сетке из 135 точек в диапазоне 340–1010 нм с уже примененным профилем крышки датчика. Для получения количественных значений интенсивности излучения необходимо усреднить данные как минимум за 15 секунд — это особенность прибора, а не дефект.

## `pool-stream` — приостановить или возобновить потоковую передачу

```bash
chloros-cli daq pool-stream --sensor-id daq-e-def330 --stop    # pause
chloros-cli daq pool-stream --sensor-id daq-e-def330 --start   # resume
```

## `pool-record` — запись файла `.daq`

```bash
chloros-cli daq pool-record --sensor-id daq-e-def330 --duration 150 \
  --output ~/Documents/spectra --device-name "rooftop-A"
chloros-cli daq pool-record --sensor-id daq-e-def330 --stop
```

| Флаг | По умолчанию | Значение |
| --- | --- | --- |
| `--duration SEC` / `-d SEC` | `0` | Продолжительность записи в секундах; `0` означает, что запись будет продолжаться до тех пор, пока не будет выдан приказ `--stop`. |
| `--output DIR` / `-o DIR` | `~/Documents/DAQ Live View/` | Каталог вывода, определяемый **на компьютере, на котором запущен бэкенд**. |
| `--device-name NAME` | — | Метка, сохраняемая вместе с записью. |
| `--stop` | — | Остановить текущую запись. |

{% hint style="info" %}
Запись происходит на бэкенде, поэтому файл `.daq` попадает в файловую систему **компьютера, на котором работает бэкенд** — по умолчанию в каталог `~/Documents/DAQ Live View/`, а не обязательно туда, где вы запустили CLI. Имена файлов включают идентификатор датчика и временную метку.
{% endhint %}

## `pool-set-cap` — указание установленной крышки

```bash
chloros-cli daq pool-set-cap --sensor-id daq-e-def330 --cap-id sunshine_cosine
```

Идентификатор колпачка выбирает измерённый на заводе профиль коррекции, применяемый к каждому спектру, и он **должен соответствовать колпачку, физически установленному на датчике** — ни датчик, ни программное обеспечение не могут самостоятельно обнаружить колпачок, и выбор фиксируется в каждом файле `.daq`. По умолчанию везде используется `sunshine_cosine` (каждый DAQ поставляется с установленной крышкой косинусного корректора Sunshine, обеспечивающей по конструкции ослабление примерно в 12 раз — незаявленная замена крышки приводит к некорректной коррекции спектров примерно на этот коэффициент).

| `--cap-id` | Доступно на |
| --- | --- |
| `sunshine_cosine` (по умолчанию) | DAQ-U, DAQ-M, DAQ-E |
| `fov_15`, `fov_45`, `fov_90` | DAQ-U, DAQ-E |
| `fov_30`, `fov_60` | Только DAQ-U |
| `none` | Только DAQ-E — см. примечание |

Идентификатор крышки, не входящий в набор датчика, отклоняется при подключении с явной ошибкой. `none` (DAQ-E) означает, что крышка физически снята — при этом по-прежнему применяется заводской геометрический профиль для утопленного стеклянного рассеивателя DAQ-E, поэтому это не является «no-op», а DAQ-E без крышки представляет собой лабораторную конфигурацию, а не поддерживаемую полевую конфигурацию. («Голый» датчик DAQ-U является полностью «голым» и не требует никакого профиля коррекции; датчик DAQ-M используется со своим колпачком Sunshine.)

## `pool-disconnect` — освобождение датчиков

```bash
chloros-cli daq pool-disconnect --sensor-id daq-e-def330   # one sensor
chloros-cli daq pool-disconnect --all                      # everything in the pool
```

## Сводка команд

| Команда | Назначение |
| --- | --- |
| `daq pool-connect [--port P \| --ble \| --mac M \| --eth \| --eth-host H] [-t MS] [-f N] [--no-ae] [--no-stream] [--cap-id CAP]` | Открыть датчик в пуле бэкэнда. |
| `daq pool-list` | Показать все датчики в пуле с их `sensor_id`. |
| `daq pool-latest --sensor-id ID [--recent N] [--json]` | N последних откалиброванных спектральных кадров. |
| `daq pool-stream --sensor-id ID [--start \| --stop]` | Возобновление / приостановка потоковой передачи. |
| `daq pool-record --sensor-id ID [-d SEC] [-o DIR] [--device-name NAME] [--stop]` | Запуск / остановка записи `.daq` (на стороне бэкенда). |
| `daq pool-set-cap --sensor-id ID --cap-id CAP` | Смена профиля коррекции ограничителя во время работы. |
| `daq pool-disconnect --sensor-id ID [--all]` | Отключение одного датчика или всех датчиков. |

## Устранение неполадок при первом подключении DAQ-E

1. У DAQ-E нет светодиодного индикатора состояния — проверьте наличие питания по индикатору PoE/link на коммутаторе или порте инжектора и подождите несколько секунд после включения питания, чтобы устройство загрузилось и подключилось к сети.
2. Серверная машина должна находиться в **том же доменном пространстве**, что и датчик — mDNS не проходит через маршрутизаторы.
3. На Windows при первом запуске подтвердите запрос брандмауэра Defender (mDNS — UDP 5353, данные DAQ-E — UDP 5002, PTP — UDP 319/320).
4. Все еще нет ответа от `--eth`? Используйте `--eth-host` с именем хоста устройства (`daq-e-<id>.local`) или IP-адресом — это более надежный способ, особенно на хостах с несколькими IP-адресами.
