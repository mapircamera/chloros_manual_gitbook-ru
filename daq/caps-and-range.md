# Профили колпачков и откалиброванный диапазон

> Сами крышки — какие из них поставляются с какими датчиками, как они устанавливаются и каковы их оптические характеристики — описаны в **[руководстве пользователя DAQ](https://mapir.gitbook.io/daq)**. На этой странице рассматривается *указание* установленной крышки в Chloros
, что и обеспечивает правильность коррекции.

Заводская радиометрическая калибровка каждого светового датчика DAQ описывает *сам датчик без крышки*. Физическая крышка, установленная над рассеивателем, изменяет спектр света, улавливаемого датчиком, поэтому Chloros
применяет **профиль коррекции крышки**, измеренный на заводе, поверх пакета калибровочных данных. Указание правильного колпачка является частью получения откалиброванных данных — на этой странице описано, какие колпачки существуют для каждой модели, как их указывать и каков фактический откалиброванный спектральный диапазон датчика.

## Наличие колпачков по моделям

| Профиль колпачка (`cap_id`) | Физический колпачок | DAQ-U | DAQ-M | DAQ-E |
| --- | --- | --- | --- | --- |
| `sunshine_cosine` | Насадка с косинус-корректором для солнечного света (**установлена по умолчанию на всех моделях**) | Да | Да | Да |
| `fov_15` / `fov_45` / `fov_90` | Конусы, ограничивающие поле зрения (15° / 45° / 90°) | Да | — | Да |
| `fov_30` / `fov_60` | Конусы, ограничивающие поле зрения (30° / 60°) | Да | — | — |
| `none` | Без установленного колпачка | — | — | Да |

Примечания по конкретным моделям:

* **DAQ-M имеет один профиль колпачка: `sunshine_cosine`.** «Базовая версия плюс колпачок Sunshine» — это определение продукта, и базовая версия DAQ-M не требует геометрического профиля.
* **Базовая версия DAQ-U является полностью «базовой»** — она вообще не требует геометрического профиля, поэтому для неё не существует профиля `none`.
* **`none` на DAQ-E НЕ является пустой операцией.** Утопленный диффузор DAQ-E, покрытый стеклом, имеет собственную реальную геометрическую поправку, поэтому «без колпачка» само по себе является измеряемым профилем на этой модели.
* **Сам по себе датчик DAQ-E не может измерять прямое солнечное излучение при любом угле высоты** — колпачок Sunshine является стандартной конфигурацией для полевых условий. Не планируйте работу на открытом воздухе с использованием датчика DAQ-E без колпачка.

В настройках каждого датчика в графическом интерфейсе (значок шестеренки на вкладке «Световые датчики») в раскрывающемся списке **Колпачок** для моделей DAQ-U и DAQ-M также доступен вариант «Нет (открытый датчик)» — на этих двух моделях «открытый» просто означает, что коррекция с учетом колпачка не применяется, как указано выше. Выбирайте этот вариант только в том случае, если колпачок физически снят.

## Указание наличия колпачка — и почему это важно

**Указанный код `cap_id` должен соответствовать колпачку, физически установленному на датчике.** Ни датчик, ни программное обеспечение не могут определить установленный колпачок. Указание колпачка влияет на два аспекта:

1. **Коррекция в реальном времени**, применяемая к каждому спектру.
2. **Метка колпачка, записываемая в каждую запись `.daq`**, на которую полагается последующая обработка данных отражения.

Крышка Sunshine **по замыслу**ослабляет сигнал примерно**в 12 раз**, поэтому запись с указанием неверной крышки приводит к искажению масштаба спектров примерно на этот коэффициент. Незамедлительно указывайте смену крышки.

### Настройка крышки

Графический интерфейс: вкладка «Датчики освещенности» → значок шестеренки в строке датчика → раскрывающийся список **«Крышка»**. По умолчанию для всех моделей установлен `sunshine_cosine` — это предполагаемое значение (модели DAQ-U, DAQ-M и DAQ-E поставляются без конденсатора, и в записи указывается, что конденсатор предполагался, пока вы не выберете конкретный), и этот выбор сохраняется в проекте.

По умолчанию бэкенд использует значение `sunshine_cosine`, если ничего не передано.

Для опытных пользователей: профили поставляются в составе установки Chloros
под именем `daq/cap_profiles/<u|m|e>/<cap_id>.json` и могут быть переопределены для каждого пользователя с помощью `~/.chloros/daq_cap_profiles/<u|m|e>/<cap_id>.json`.

Помимо ограничений, датчики, которые никогда не подвергались повторной калибровке, автоматически получают небольшую корректировку тёмного смещения, рассчитанную на основе данных всего парка устройств — без каких-либо действий со стороны пользователя.

## DAQ-E-S: фиксированный диффузор и наклон

**DAQ-E-S** — это DAQ-E с двумя отличиями, имеющими значение для Chloros
. Всё остальное (обнаружение, подключение, PTP, запись, настройки устройства) работает точно так же, как и для DAQ-E.

* **Его диффузор является постоянным, поэтому коррекция с помощью колпачков не требуется.** Диффузор был установлен на устройстве во время заводской калибровки, поэтому калибровка уже отражает истинную интенсивность нисходящего излучения. Chloros
не применяет к нему профиль ограничения, независимо от запроса: профиль с соответствующим именем игнорируется с выводом сообщения, в записях указывается, что ограничение взято из модели, и предупреждение о предполагаемом ограничении для него никогда не срабатывает. В разделе «Настройки проекта» → «Датчик освещенности DAQ» в его строке не указан никакой предел, и переопределение предела на уровне всего проекта на него не распространяется. Не применяйте предел к его данным вручную: в противном случае показания коррекции «Sunshine» будут примерно в 11 раз выше фактических.
* **Он оснащён 3-осевым акселерометром.** Косинусная характеристика диффузора действительна только при его горизонтальном положении, поэтому наклоненный датчик сообщает неверное значение интенсивности излучения без каких-либо других симптомов. Поэтому каждое значение DAQ-E-S содержит данные о наклоне, крене и тангаже, а запись `.daq`, полученная с одного датчика, сохраняет их рядом с каждым спектром (`imu_tilt_deg`, `imu_roll_deg`, `imu_pitch_deg`, …), что позволяет отличить облако от сбитого с уровня крепления.

Информацию о каждом поле ориентации и о том, как сообщается о сбое в потоке данных ориентации, см. в [Справочнике по DAQ-E-S в CLI
](../reference/cli-reference.md#daq-e-s--fixed-diffuser-and-tilt-sensor).

## Характеристики солнцезащитного колпачка (конфигурация для использования на открытом воздухе)

Цифры, на которых можно основывать процедуры:

| Характеристика | Значение |
| --- | --- |
| Поле зрения | 180° полусферическое |
| Погрешность косинусной характеристики | ≤ ±4 % при угле падения до 60°; ≤ ±4,5 % при угле падения до 70° |
| Предел для низкого положения Солнца | Не рекомендуется при угле возвышения Солнца ниже ~15° |
| Ослабление | ~12× (по конструкции) |
| Повторяемость при повторной установке колпачка | ≈ 1,5 % |
| Количественное значение интенсивности излучения | Среднее значение по **≥ 15 с** измерений (характеристика прибора, не является дефектом) |

Для любого количественного значения интенсивности излучения — включая данные о коэффициенте отражения — следует использовать среднее значение по результатам измерений в течение не менее 15 секунд, а не отдельный кадр.

## Калиброванный спектральный диапазон

| Характеристика | Значение |
| --- | --- |
| Спектральная дискретизация | 340–1010 нм с шагом 5 нм (135 точек) |
| Радиометрически откалиброванный диапазон | **~374–974 нм** (ограничение, налагаемое программным обеспечением) |

Датчик передаёт данные по всей сетке 340–1010 нм, но радиометрический коэффициент усиления, прослеживаемый до NIST, охватывает диапазон ~374–974 нм. Chloros
**отказывается от деления по абсолютному коэффициенту отражения** для любого диапазона камеры, у которого менее половины спектрального веса находится в пределах этого диапазона, сообщая о причине пропуска `dls-uncalibrated-band-<nm>` вместо выдачи некалиброванного результата. Среди поставляемых моделей камер только фильтр F988 выходит за пределы этого диапазона; для него вместо этого используется рабочий процесс с панелью отражения — см. [Рабочие процессы с панелью отражения](reflectance.md).

Информацию о моделях датчиков, транспортных средствах и идентификаторах датчиков см. в [Обзоре DAQ](README.md). О том, как используется отметка ограничения (cap stamp) во время обработки, см. в разделе [Запись и формат .daq](recording.md).
