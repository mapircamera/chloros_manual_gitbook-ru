# Характеристики колпачков и откалиброванный диапазон

> Информация о самих колпачках — о том, какой колпачок поставляется с каким датчиком, как они устанавливаются и каковы их оптические характеристики — приведена в **[руководстве пользователя DAQ](https://mapir.gitbook.io/daq)**. На этой странице рассматривается *указание* установленной крышки в Chloros, что обеспечивает правильность коррекции.

Заводская радиометрическая калибровка каждого светового датчика DAQ описывает *голый* датчик. Физическая крышка, установленная над рассеивателем, изменяет состав света, собираемого датчиком, поэтому Chloros применяет **профиль коррекции крышки**, измеренный на заводе, поверх пакета калибровочных данных. Указание правильного колпачка является частью получения откалиброванных данных — на этой странице описано, какие колпачки существуют для каждой модели, как их указывать и каков фактический откалиброванный спектральный диапазон датчика.

## Наличие колпачков по моделям

| Профиль колпачка (`cap_id`) | Физический колпачок | DAQ-U | DAQ-M | DAQ-E |
| --- | --- | --- | --- | --- |
| `sunshine_cosine` | Насадка с косинусной коррекцией солнечного света (**по умолчанию на всех моделях**) | Да | Да | Да |
| `fov_15` / `fov_45` / `fov_90` | Конусы, ограничивающие поле зрения (15° / 45° / 90°) | Да | — | Да |
| `fov_30` / `fov_60` | Конусы, ограничивающие поле зрения (30° / 60°) | Да | — | — |
| `none` | Без установленного колпачка | — | — | Да |

Примечания по конкретным моделям:

* **DAQ-M имеет один профиль колпачка: `sunshine_cosine`.** «Базовая версия плюс колпачок Sunshine» — это определение продукта, а для базовой версии DAQ-M профиль геометрии не требуется.
* **Базовая версия DAQ-U является полностью базовой** — для неё профиль геометрии не требуется вообще, поэтому для неё не существует профиля `none`.
* **Профиль `none` на DAQ-E НЕ является пустым.** Утопленный диффузор DAQ-E, покрытый стеклом, имеет собственную реальную геометрическую поправку, поэтому «без колпачка» само по себе является измеренным профилем для этой модели.
* **Сам по себе датчик DAQ-E не может измерять прямой солнечный свет при любом угле высоты** — колпачок Sunshine является стандартной конфигурацией для полевых условий. Не планируйте работу на открытом воздухе с датчиком DAQ-E без колпачка.

В настройках каждого датчика в графическом интерфейсе (значок шестеренки на вкладке «Световые датчики») в раскрывающемся списке **Колпачок** для моделей DAQ-U и DAQ-M также доступен вариант «Нет (открытый датчик)» — на этих двух моделях «открытый» просто означает, что коррекция с учетом колпачка не применяется, как указано выше. Выбирайте этот вариант только в том случае, если колпачок физически снят.

## Указание наличия колпачка — и почему это важно

**Указанный код `cap_id` должен соответствовать колпачку, физически установленному на датчике.** Ни датчик, ни программное обеспечение не могут определить установленный колпачок. Указание колпачка влияет на два аспекта:

1. **Коррекция в реальном времени**, применяемая к каждому спектру.
2. **Метаданные о колпачке, записываемые в каждую запись `.daq`**, на которые полагается последующая обработка данных отраженного излучения.

Крышка Sunshine **по замыслу**ослабляет сигнал примерно в**12 раз**, поэтому запись с указанием неверной крышки приводит к искажению масштаба спектров примерно на этот коэффициент. Незамедлительно указывайте смену крышки.

### Настройка крышки

Графический интерфейс: вкладка «Датчики освещенности» → значок шестеренки в строке датчика → раскрывающийся список **«Крышка»**. По умолчанию для всех моделей установлен `sunshine_cosine` (все датчики DAQ поставляются с установленным косинус-корректором), и этот выбор сохраняется в проекте.

<!-- SCREENSHOT-NEEDED: DAQ tab per-sensor settings modal (gear icon) scrolled to the Cap dropdown, open to show the per-model choices with "Sunshine (cosine corrector)" selected. Use a connected DAQ-E so the Hostname/Firmware/PTP rows are also visible above it. -->

CLI (бэкенд должен быть запущен):

```bash
# Declare at connect time
chloros-cli daq pool-connect --eth-host daq-e-def330.local --cap-id sunshine_cosine

# Swap at runtime (after physically changing the cap)
chloros-cli daq pool-set-cap --sensor-id daq-e-def330 --cap-id fov_45
```

CLI синтаксически поддерживает полный список `cap_id` (`{none, fov_15, fov_30, fov_45, fov_60, fov_90, sunshine_cosine}`); каждый профиль проверяется на соответствие модели датчика при подключении, поэтому недоступный идентификатор конденсатора (например, идентификатор, предназначенный только для E, на DAQ-U) приводит к явной ошибке, а не к некорректной корректировке. По умолчанию бэкенд использует `sunshine_cosine`, если ничего не передано.

Python SDK Примечание: `cap_id` **не** является регулятором SDK — `connect_daq_sensor()` / `DAQSensorSession` не предоставляют доступ к параметрам конденсатора. Выберите ограничение с помощью приведённых выше команд CLI или раскрывающегося списка в графическом интерфейсе; см. [Справочник по SDK](../reference/sdk-reference.md).

Для опытных пользователей: профили поставляются в составе установки Chloros в `daq/cap_profiles/<u|m|e>/<cap_id>.json` и могут быть переопределены для каждого пользователя в `~/.chloros/daq_cap_profiles/<u|m|e>/<cap_id>.json`.

Помимо ограничений, датчики, которые никогда не подвергались повторной калибровке, автоматически получают небольшую корректировку тёмного смещения, полученную на основе данных всего парка оборудования — без участия пользователя.

## Характеристики ограничителя солнечного света (конфигурация для улицы)

Цифры, на которых можно основывать рабочие процедуры:

| Характеристика | Значение |
| --- | --- |
| Поле зрения | 180° полусферическое |
| Погрешность косинусной характеристики | ≤ ±4 % при угле падения до 60°; ≤ ±4,5 % при угле падения до 70° |
| Предел при низком положении солнца | Не рекомендуется при угле возвышения солнца ниже ~15° |
| Ослабление | ~12× (по конструкции) |
| Повторяемость повторной установки колпачка | ≈ 1,5 % |
| Количественное значение инсоляции | Среднее значение по **≥ 15 с** измерений (характеристика прибора, не является дефектом) |

Для любого количественного значения инсоляции — включая данные о коэффициенте отражения — следует использовать среднее значение по результатам измерений в течение не менее 15 секунд, а не отдельный кадр.

## Калиброванный спектральный диапазон

| Характеристика | Значение |
| --- | --- |
| Спектральная дискретизация | 340–1010 нм с шагом 5 нм (135 точек) |
| Радиометрически калиброванный диапазон | **~374–974 нм** (ограничение, налагаемое программным обеспечением) |

Датчик передаёт данные по всей сетке 340–1010 нм, но радиометрический коэффициент усиления, прослеживаемый до NIST, охватывает диапазон ~374–974 нм. Chloros **отказывается от деления по абсолютному коэффициенту отражения** для любого диапазона камеры, у которого менее половины спектрального веса находится в пределах этого диапазона, сообщая причину пропуска `dls-uncalibrated-band-<nm>` вместо выдачи некалиброванного результата. Среди поставляемых моделей камер только фильтр F988 выходит за пределы этого диапазона; для него вместо этого используется рабочий процесс с панелью отражательной способности — см. [Рабочие процессы с панелью отражательной способности](reflectance.md).

Информацию о моделях датчиков, транспортных средствах и идентификаторах датчиков см. в [обзоре DAQ](README.md). О том, как используется отметка предельного значения во время обработки, см. в разделе [Запись и формат .daq](recording.md).
