# Световые датчики DAQ

> **Ищете информацию об оборудовании?**Сведения о самих датчиках — моделях, способах крепления, крышках, разъемах, питании и приложении SCANNER — приведены в**[руководстве пользователя DAQ](https://mapir.gitbook.io/daq)**. В этой главе рассматривается их использование, начиная с Chloros.

Световые датчики **DAQ**, описанные в MAPIR, измеряют освещённость окружающей среды в виде радиометрически откалиброванных спектров. В Chloros они выполняют две функции:

* **Автономный спектральный прибор** — графики спектра в реальном времени, колориметрические данные и записи `.daq` — всё это доступно на [вкладке «Световые датчики»](gui.md), [CLI](cli-quick-start.md) или Python SDK.
* **Источник нисходящего излучения для расчета коэффициента отражения** — во время обработки модуль Chloros интерполирует показания `.daq` по каждойметку времени экспозиции и использует измеренную интенсивность нисходящего излучения для преобразования яркости камеры в коэффициент отражения (`--reflectance-source daq`); для откалиброванных диапазонов не требуется панель в кадре.

## Три модели, один формат данных

| Модель | Транспорт | Обнаружение |
| --- | --- | --- |
| **DAQ-U** | USB (последовательный) | сканирование последовательного порта |
| **DAQ-M** | Bluetooth Low Energy | сканирование BLE по имени |
| **DAQ-E** | Ethernet (IPv4, питание по PoE) | mDNS `_daq-e._tcp` (имя хоста `daq-e-<id>.local`) |

Все три устройства используют один и тот же протокол связи и предоставляют идентичные данные:

* **135-точечный спектр от 340 до 1010 нм с шагом 5 нм**, а также тристимульные координаты CIE XYZ в каждом кадре.
* **Радиометрически откалиброванная спектральная освещённость в Вт/м²/нм** — заводская калибровка каждого устройства (а также его активный профиль коррекции крышки) применяется до того, как данные дойдут до вас.
* Одинаковый **формат записи `.daq`** (файл SQLite). Последующая обработка данных одинакова независимо от того, какой транспортный протокол сформировал файл.

Транспортные стеки (USB-последовательный, BLE, mDNS/zeroconf) входят в состав бэкэнда Chloros — для взаимодействия с любой из этих трёх моделей через графический интерфейс или с помощью команд `pool-*` в CLI ничего устанавливать не нужно.

***

## Калиброванный диапазон: 340–1010 нм (сообщаемый), ~374–974 нм (калиброванный)

Датчик сообщает о полной сетке 340–1010 нм, но радиометрический коэффициент усиления, прослеживаемый до NIST, охватывает примерно **374–974 нм**. Chloros отклоняет деление по абсолютному коэффициенту отражения для любого диапазона камеры, у которого менее половины спектрального веса находится в пределах этого откалиброванного диапазона; пропущенный диапазон указывается с причиной пропуска `dls-uncalibrated-band-<nm>`.

Среди поставляемых моделей фильтров LATTICE это касается только **F988**:

Отражательная способность F988 калибруется с помощью панели отражательной способности в поле зрения: диапазон выходит за пределы калиброванного диапазона светового датчика DAQ, поэтому Chloros применяет ваши последние данные с панели и сохраняет их между наблюдениями панели.

Если данные сбора F988 обрабатываются при наличии только данных DAQ, Chloros отклоняет коэффициент отражения на основе DAQ для данного диапазона с причиной пропуска `dls-uncalibrated-band-988` — [рабочий процесс с панелью отражения](../calibration-targets.md) является поддерживаемым способом для F988.

## Идентификаторы датчиков

Каждый DAQ сообщает стабильный идентификатор датчика. Его формат зависит от модели:

| Модель | Формат ID | Пример |
| --- | --- | --- |
| DAQ-U | 5 октетов с дефисами | `CB-7C-A8-2E-5F` |
| DAQ-M | 5-октетовый с дефисами | `CB-74-02-30-6B` |
| DAQ-E | `daq-e-<6 hex digits>` | `daq-e-def330` |

Идентификатор датчика:

* вносится в каждый файл `.daq`, который он записывает,
* используется ключом Chloros для получения пакета заводской калибровки данного устройства,
* значением, которое вы передаете в `--sensor-id` в командах CLI и `pool-*`, а также
* для DAQ-E — также его имя хоста mDNS (`daq-e-def330.local`) — значение, которое принимает `--eth-host`.

## Заводская калибровка и облако

Каждое устройство DAQ проходит индивидуальную заводскую калибровку с использованием радиометрической цепочки, прослеживаемой до NIST, а Chloros загружает пакет калибровки для каждого устройства, связанный с его идентификатором датчика. Отчет о калибровке для каждого устройства (PDF) можно скачать в настройках датчика на [вкладке «Световые датчики»](gui.md).

{% hint style="warning" %}
**Для калибровки моделей DAQ-U и DAQ-M требуется доступ к облачному хранилищу.**Ни одна из этих моделей не хранит данные на борту: их заводские калибровочные наборы находятся в облачном хранилище MAPIR и загружаются по идентификатору датчика (затем кэшируются локально). Chloros требует подключения к Интернету для передачи откалиброванных данных в Вт/м²/нм с DAQ-U или DAQ-M.**DAQ-E является исключением** — он хранит данные калибровки на самом устройстве.

## Куда сохраняются записи

| Поверхность | Место назначения по умолчанию для `.daq` |
| --- | --- |
| Графический интерфейс — вкладка «Световые датчики» | `<project folder>/light_sensor/` (готовые записи автоматически добавляются в проект) |
| CLI — `daq pool-record` | `~/Documents/DAQ Live View/` на компьютере, на котором работает бэкенд |

Каждое имя файла `.daq` содержит идентификатор датчика и временную метку.
