# Световые датчики DAQ

> **Ищете информацию об оборудовании?**Сведения о самих датчиках — моделях, способах крепления, крышках, разъемах, питании и приложении SCANNER — приведены в**[руководстве пользователя DAQ](https://mapir.gitbook.io/daq)**. В этой главе рассматривается их использование в программе Chloros. Световые датчики**DAQ** от

MAPIR измеряют освещённость окружающей среды в виде радиометрически откалиброванных спектров. В Chloros они выполняют две функции:

* **Автономный спектральный прибор** — графики спектра в реальном времени, колориметрические данные и записи `.daq` — всё это доступно на [вкладке «Световые датчики»](gui.md), [CLI](cli-quick-start.md) или Python SDK.
* **Источник нисходящего излучения для расчета коэффициента отражения** — во время обработки Chloros интерполирует ваши показания `.daq` по временной метке экспозиции каждого снимка и использует измеренное нисходящее излучение для преобразования яркости камеры в коэффициент отражения (`--reflectance-source daq`); для откалиброванных диапазонов не требуется панель в кадре.

## Три модели, один формат данных

| Модель | Транспорт | Обнаружение |
| --- | --- | --- |
| **DAQ-U** | USB (последовательный) | сканирование последовательного порта |
| **DAQ-M** | Bluetooth Low Energy | сканирование BLE по имени |
| **DAQ-E** | Ethernet (IPv4, питание по PoE) | mDNS `_daq-e._tcp` (имя хоста `daq-e-<id>.local`) |

**DAQ-E-S (новое в версии 1.3.0).** DAQ-E с постоянным рассеивателем и датчиком наклона. В списке Chloros он указан как `DAQ-E-S` и работает точно так же, как DAQ-E, за исключением того, что не требует коррекции капа, а каждое показание содержит данные о наклоне, крене и тангаже устройства. См. [DAQ-E-S: фиксированный диффузор и наклон](caps-and-range.md#daq-e-s-fixed-diffuser-and-tilt).

Все три устройства используют один и тот же протокол связи и предоставляют идентичные данные:

* **135-точечный спектр в диапазоне от 340 до 1010 нм с шагом 5 нм**, а также тристимульные значения CIE XYZ в каждом кадре.
* **Радиометрически откалиброванная спектральная освещённость в Вт/м²/нм** — заводской калибровочный набор каждого прибора (а также его активный профиль коррекции колпачка) применяется до того, как данные поступают к вам.
* Одинаковый **формат записи `.daq`** (файл SQLite). Последующая обработка данных одинакова независимо от того, какой транспортный протокол сформировал файл.

Транспортные стеки (последовательный USB, BLE, mDNS/zeroconf) встроены в бэкэнд Chloros — не требуется ничего устанавливать для взаимодействия с любой из трёх моделей через графический интерфейс или команды `pool-*` в CLI.

## Калиброванный диапазон: заявленный 340–1010 нм, калиброванный ~374–974 нм

Датчик передаёт данные по всей сетке 340–1010 нм, но радиометрический коэффициент усиления, отслеживаемый по стандартам NIST, охватывает примерно **374–974 нм**. Chloros отклоняет деление по абсолютному коэффициенту отражения для любого диапазона камеры, у которого менее половины спектрального веса находится внутри этого откалиброванного диапазона; пропущенный диапазон указывается с причиной пропуска `dls-uncalibrated-band-<nm>`.

Среди поставляемых моделей фильтров LATTICE это касается только **F988**:

Отражательная способность F988 калибруется с использованием панели отражательной способности в поле зрения: диапазон лежит за пределами калиброванного диапазона светового датчика DAQ, поэтому Chloros применяет ваши последние данные с панели и сохраняет их между измерениями панели.

Если данные сбора F988 обрабатываются при наличии только данных DAQ, Chloros отклоняет коэффициент отражения на основе DAQ для этого диапазона с причиной пропуска `dls-uncalibrated-band-988` — [рабочий процесс с панелью отражательной способности](../calibration-targets.md) является поддерживаемым способом для F988.

## Идентификаторы датчиков

Каждый DAQ сообщает стабильный идентификатор датчика. Его формат зависит от модели:

| Модель | Формат ID | Пример |
| --- | --- | --- |
| DAQ-U | 5-октетовый с дефисами | `CB-7C-A8-2E-5F` |
| DAQ-M | 5-октетовый с дефисами | `CB-74-02-30-6B` |
| DAQ-E | `daq-e-<6 hex digits>` | `daq-e-def330` |

Идентификатор датчика:

* вносится в каждый файл `.daq`, который он записывает,
* используется в качестве ключа программой Chloros для получения пакета заводской калибровки данного устройства,
* значением, которое вы передаете в `--sensor-id` в командах CLI, и
* для DAQ-E — также его имя хоста mDNS (`daq-e-def330.local`) — значение, которое принимает `--eth-host`.

## Заводская калибровка и облако

Каждое устройство DAQ проходит индивидуальную заводскую калибровку с использованием радиометрической цепочки, прослеживаемой до NIST, а Chloros загружает пакет калибровочных данных для каждого устройства, привязанный к его идентификатору датчика. Отчет о калибровке для каждого устройства (PDF) можно скачать в настройках датчика на [вкладке «Световые датчики»](gui.md).

{% hint style="warning" %}
**Для калибровки устройств DAQ-U и DAQ-M требуется доступ к облаку.**Ни одна из моделей не хранит данные на борту: их заводские пакеты калибровки находятся в облаке MAPIR и загружаются по идентификатору датчика (затем кэшируются локально). Chloros требует подключения к Интернету для передачи откалиброванных данных в единицах Вт/м²/нм с DAQ-U или DAQ-M.**DAQ-E является исключением** — он хранит данные калибровки на самом устройстве.
{% endhint %}

## Куда сохраняются записи

| Поверхность | Место назначения по умолчанию `.daq` |
| --- | --- |
| Графический интерфейс — вкладка «Световые датчики» | `<project folder>/light_sensor/` (готовые записи автоматически добавляются в проект) |
| CLI — `daq pool-record` | `~/Documents/DAQ Live View/` на компьютере, на котором запущен бэкенд (относительный путь `-o` определяется относительно папки, в которой была запущена команда, если бэкенд находится на том же компьютере) |

Каждое имя файла `.daq` содержит идентификатор датчика и временную метку.
