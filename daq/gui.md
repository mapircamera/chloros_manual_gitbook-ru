# Вкладка «DAQ» в Chloros

Вкладка «DAQ» — обозначенная как **«Световые датчики»** на боковой панели Chloros — представляет собой панель управления в режиме реального времени для [световых датчиков DAQ-U, DAQ-M и DAQ-E](README.md): подключайте датчики через любой канал передачи данных, наблюдайте за откалиброванными спектрами в режиме реального времени, вычисляйте коэффициент отражения в реальном времени по паре датчиков и записывайте файлы `.daq` прямо в ваш проект.

Вкладка становится доступной после завершения запуска бэкэнда Chloros. Данные для графиков на вкладке поступают от службы DAQ Chloros через активное соединение, которое автоматически восстанавливается (с интервалом повторной попытки 2–10 с) в случае прерывания; пока служба недоступна, в строке «Статус» датчика отображается надпись **«Нет сервера»**.

Макет представляет собой **боковую панель датчиков**(по одной строке на каждый подключённый датчик) и**область графиков** (по одному графику на датчик или группу).

## Подключение датчика

Нажмите **«Подключить датчик»** в верхней части боковой панели. Диалоговое окно подключения откроется в основной области (или в виде накладки при добавлении другого датчика — в этом случае появляется кнопка «Отмена»).

| Элемент управления | Поведение |
| --- | --- |
| **Тип устройства** | `DAQ-U (USB)` (по умолчанию), `DAQ-M (Bluetooth)` или `DAQ-E (Ethernet)`. Переключение запускает повторное сканирование для вновь выбранного транспорта. |
| **Порт / Устройство BLE / Имя хоста / IP** | Отображает обнаруженные устройства в формате `device - description`; автоматически выбирается первая запись, распознанная как датчик. Во время сканирования отображаются `Scanning...` (USB), `Scanning (N)...` с 8-секундным обратным отсчётом (BLE) или `Discovering ethernet sensors (N)...` с 5-секундным обратным отсчётом (Ethernet). При отсутствии результатов отображаются записи `No ports` / `No BLE devices` / `No ethernet sensors found`. |
| **↻ Обновить** | Немедленно повторяет сканирование выбранного канала передачи данных (отключено во время сканирования BLE/Ethernet). |
| **Подключиться** | Становится доступной после выбора устройства; во время установления соединения название меняется на `Connecting...`. |

Поиск работает только **пока диалоговое окно подключения отображается на экране** и повторяется каждые 15 секунд только для выбранного канала связи — простое открытие вкладки не запускает сканирование. В случае сбоя в диалоговом окне отображается сообщение: *«Подключение не удалось. Попробуйте отключить и снова подключить датчик, затем нажмите «Подключиться» ещё раз».*

Боковая панель открывается автоматически при подключении первого датчика.

{% hint style="info" %}
**DAQ-E не отображается?** У DAQ-E нет светодиодного индикатора состояния — проверьте индикатор PoE/соединения на коммутаторе или порту инжектора, к которому он подключен, и подождите несколько секунд после включения питания, чтобы устройство загрузилось. Устройство Chloros должно находиться в одном домене широковещания (mDNS не проходит через маршрутизаторы). На Windows примите запрос брандмауэра Defender при первом привязывании Chloros своих многоадресных сокетов (mDNS UDP 5353, данные DAQ-E UDP 5002, PTP UDP 319/320). Два устройства DAQ-E в одной локальной сети обнаруживаются отдельно, каждое под своим собственным именем хоста `daq-e-<id>.local`.
{% endhint %}

## Боковая панель датчиков

Каждому подключенному датчику отводится отдельная строка (плюс одна строка на каждую группу «Окружающая среда + Объект»). Порядок строк можно изменять перетаскиванием, при этом их порядок также влияет на расположение панелей диаграмм. Щелкните по строке, чтобы сделать этот датчик/эту группу активной диаграммой в списке.

| Элемент | Значение |
| --- | --- |
| Цветная левая граница | Цвет графика датчика. |
| Значок транспорта | `DAQ-U` / `DAQ-M` / `DAQ-E` или зелёный значок `REF` для группы отражательной способности «Ambient+Object». |
| Название устройства | По умолчанию — серийный номер датчика (его постоянный идентификатор для калибровки, имена файлов `.daq` и сопоставления при импорте); пользовательские названия сохраняются для каждого проекта. |
| Иконка **«Калибровано»** (зелёная) | Отображается, когда загружен заводской пакет калибровки датчика, т. е. спектры представлены в единицах Вт/м²/нм. |
| Иконка **Доступно обновление** (янтарная, только для DAQ-E) | Текущая версия прошивки устарела по сравнению с образом, входящим в состав данной сборки Chloros. Во время обновления отображается текущий прогресс (`Flashing… N%`, `Restarting sensor…`, затем `Updated X → Y` или `Failed`). |
| Глаз | Включает или выключает отображение данного датчика на графике. |
| Шестеренка | Открывает модальное окно настроек для отдельного датчика (ниже). |
| ✕ (красный) | Отключает датчик или удаляет группу «Окружающая среда + Объект». |

Над строками расположены две кнопки:

* **Подключить датчик** — открывает диалоговое окно подключения (во время работы переименовывается в `Connecting...`).
* **Записать всё / Остановить всё**— запускает или останавливает запись `.daq` на**всех**подключённых датчиках. Требуется наличие хотя бы одного датчика**и открытого проекта** (всплывающая подсказка: «Откройте проект для записи»); кнопка становится красной, пока идёт любая запись.

В пустом состоянии отображается надпись «Датчики не подключены».

## Настройки для каждого датчика (модальное окно с иконкой шестеренки)

Открывается с помощью иконки шестеренки в строке датчика. Содержание в порядке:

* **Строки информации** — Тип устройства (DAQ-U/M/E), Подключение (`Serial (USB)` / `Bluetooth` / `Ethernet`), порт (COM-порт, адрес BLE или хост) и последовательный порт.
* **Отчёт о калибровке: загрузить** — загружает сертификат калибровки данного устройства, прослеживаемый до NIST (PDF), и открывает его в вашем просмотрщике PDF. Доступно после определения серийного номера; сертификат кэшируется при первом подключении.
* **Название устройства** — нажмите на значок карандаша, чтобы переименовать; сохраняется для каждого проекта.
* **Цвет линии графика** — палитра цветов; сохраняется для каждого проекта.
* **Время интегрирования (мс)**— ползунок + число,**1–500 мс**, по умолчанию**32 мс**. Отключено, если функция AE включена.
* **Среднее количество кадров**— ползунок + число,**1–50 кадров**, по умолчанию**20**.
* **AE: ВКЛ./ВЫКЛ.**— переключатель автоматической экспозиции;**по умолчанию ВКЛ.** при подключении. Выключите его, чтобы установить время интеграции вручную.
* **Остановить трансляцию / Начать трансляцию** — приостановить или возобновить прямую трансляцию.
* **Запись / Остановить запись** — запись с датчика `.daq` (требуется открытый проект).
* **Cap** — профиль коррекции капа (следующий раздел).
* **Строки с информацией в реальном времени** — время интеграции (мс), FPS, количество отсчётов, запись (красный `REC` или `Off`) и статус (`Streaming` / `Paused` / `SATURATED` / `No Server`).

### Только для DAQ-E: строки «Сеть», «Прошивка» и «PTP»

* **Имя хоста / IP** — текущий адрес устройства.
* **Прошивка** — текущая версия прошивки, а также ячейка действия:<version\>

кнопка</version\>

**Обновить до \<version\>** появляется, когда данная сборка Chloros содержит более новый образ прошивки DAQ-E. Обновление передается по сети примерно за 30 секунд; датчик автоматически перезапускается и подключается заново, а в случае прерывания передачи текущая прошивка остаётся неизменной. Ход обновления отображается в режиме реального времени (`Flashing… N%` → `Restarting sensor…` → `Updated X → Y`), а при актуальном состоянии ячейка отображает значение `Up to date`.
* **Синхронизация PTP** — текущее состояние PTP (переходит в режим `unknown`). Прошивка DAQ-E версии 1.2.0 и выше участвует в стандарте IEEE 1588 PTPv2 в качестве часового генератора, работающего только в режиме ведомого устройства; бэкенд хоста Chloros является PTP-грандмастером, и все устройства DAQ-E и камеры LATTICE в локальной сети работают в качестве его ведомых устройств в домене 0, поддерживая отклонение временных меток в пределах примерно 1 мс.

Для группы «Ambient+Object» в модальном окне оборудования отображаются только исходные датчики группы, название устройства и цвет линии графика.

### Выбор крышки

Выпадающий список **Крышка** указывает Chloros, какая физическая крышка установлена на диффузоре датчика, и применяет к каждому спектру профиль коррекции, измеренный на заводе для этой крышки. Варианты выбора зависят от модели:

| Модель | Варианты крышки |
| --- | --- |
| DAQ-U | Без крышки (открытый датчик), FOV 15°, FOV 30°, FOV 45°, FOV 60°, FOV 90°, Sunshine (косинусный корректор) |
| DAQ-M | Нет (открытый датчик), Sunshine (косинусный корректор) |
| DAQ-E | Нет (открытый датчик), FOV 15°, FOV 45°, FOV 90°, Sunshine (косинусный корректор) |

**По умолчанию для всех моделей установлен режим «Sunshine» (косинусный корректор)** — компания MAPIR поставляет каждый DAQ с установленным колпачком «Sunshine», и это является стандартной конфигурацией для использования на открытом воздухе: полусферический обзор 180° с погрешностью косинуса ≤ ±4 % в диапазоне до 60° и ≤ ±4,5 % в диапазоне до 70° (не рекомендуется при угле возвышения Солнца ниже ~15°), с заложенным в конструкцию коэффициентом ослабления (~12×). Ваш выбор сохраняется в проекте.

{% hint style="warning" %}
**Выбор колпачка должен соответствовать установленному физическому колпачку.**Ни датчик, ни программное обеспечение не могут определить, какой именно колпачок установлен. Выбор определяет как коррекцию в реальном времени, так и метку, записываемую в каждый файл `.daq` — при ослаблении колпачка Sunshine ~12× незаявленная смена колпачка приводит к некорректной коррекции спектров примерно на этот коэффициент. (Снятие и повторная установка одного и того же колпачка приводит к погрешности около 1,5 %.) Выбирайте**«None» (голый датчик)** только в том случае, если крышка физически снята; на DAQ-E даже при выборе «None» по-прежнему применяется заводской геометрический профиль для его утопленного стеклянного рассеивателя — это не «no-op» — а DAQ-E без крышки представляет собой лабораторную конфигурацию, а не поддерживаемую полевую конфигурацию.
{% endhint %}

{% hint style="info" %}
Обновление по сравнению с более ранней инструкцией: переключатель «Установлен диффузор Sunshine» на стороне браузера, присутствовавший в версии 1.1.0, исчез. Управление крышкой теперь осуществляется с помощью профиля крышки для каждого датчика, применяемого на стороне сервера.
{% endhint %}

## Область диаграмм

На фиксированной верхней панели расположены **переключатель между списком и сеткой**и ползунок**масштабирования диаграммы** (размер ячейки 200–2000 пикселей). Режим просмотра автоматически переключается в сетку, если имеется более одной группы диаграмм, и обратно в список, если их одна или меньше. Режим просмотра и размер диаграммы сохраняются для каждого проекта.**Спектральный график** для каждого датчика отображает:

* **Ось X** — длина волны (нм). Сетка датчика составляет 340–1010 нм с шагом 5 нм (135 точек), интерполированная до 1 нм для отображения.
* **Ось Y** — мощность (Вт/м²), с автоматическим префиксом СИ (м/мк/н), выбираемым на основе пикового значения. Спектры представляют собой радиометрически откалиброванную спектральную освещённость (Вт/м²/нм) на всех трёх транспортных средствах.
* Радужная спектральная заливка под одной кривой; данные от нескольких датчиков на одном графике накладываются в виде цветных линий с приглушённой заливкой.
* **Наведение курсора**— вертикальный курсор с указанием длины волны и значения по каждому датчику;**перетаскивание** для изменения масштаба (при увеличении появляется кнопка уменьшения масштаба).
* Кнопка **+** (только в режиме сетки) для добавления датчика на этот график или создания группы (см. ниже).
* Название устройства выровнено по центру вверху, а до поступления первого кадра отображается индикатор загрузки.

**Насыщенность** не отображается на самом графике: насыщенный датчик отображается красным текстом статуса `SATURATED` и красной строкой `Saturated: Yes` в таблице данных в реальном времени. Чтобы сбросить насыщение, уменьшите время интегрирования или снова включите автоэкспозицию (AE).

## Таблица данных в реальном времени (режим просмотра списка)

Под графиком в режиме просмотра списка, обновляется каждые 500 мс:

* **Все модели**: Образец цвета света (sRGB по CIE XYZ), Насыщенность (Да/Нет), CIE 1931 X/Y/Z, Хроматичность x/y, CIE u′/v′, CCT (K), CRI (Ra), Доминирующая длина волны (нм), пиковая длина волны (нм), чистота возбуждения, Duv, CIE L\*/a\*/b\* и Манселл H/V/C.
* **Только откалиброванные датчики**(любой из моделей DAQ-U / DAQ-M / DAQ-E после загрузки заводского пакета калибровки — об этом свидетельствует зелёная метка**«Откалиброван»** в строке датчика): Общая мощность (Вт/м²), Фотопический люкс (лкс), скотопический люкс (лкс), соотношение S/P, PPFD плюс PPFD Red/Green/Blue (мкмоль/м²/с), а также оптические интенсивности излучения — S-конус, меланопический, родопический, M-конус, L-конус (все в Вт/м²).

## Группы коэффициентов отражения (Окружающее освещение + Объект)

Два подключенных датчика можно объединить для отображения отражательной способности в реальном времени — без использования камеры:

1. В режиме просмотра сетки нажмите **+**на плитке графика и выберите**Объединить окружающее освещение + объект**.
2. Выберите датчик **Источник окружающего света**и датчик**Сканер объекта**(два разных датчика), затем нажмите**Создать**.

Chloros вычисляет R(λ) = объект(λ) / окружающее освещение(λ) для каждой длины волны на основе двух потоков данных в реальном времени (0, если окружающее освещение ≤ 0). Название группы зависит от класса калибровки датчиков:

* Оба датчика откалиброваны (пакет загружен) → **«Кажущаяся отражательная способность»**.
* Хотя бы один датчик не откалиброван → **«Относительное отражение»**.

Группа отображается в виде зелёной строки `REF` на боковой панели и в виде отдельного графика (радужная заливка, значения при наведении курсора с точностью до 4 знаков после запятой, масштабирование перетаскиванием).

Меню **+**также предлагает пункт**Добавить новый датчик** с тремя вариантами размещения: *Объединить новый датчик* (добавить к этому графику), *Переместить существующий датчик сюда* или *Просмотреть новый датчик* (отдельный график).

### Таблица индексов растительности

В режиме просмотра списка под графиком группы отражательной способности расположена таблица индексов растительности, рассчитанная на основе данных отражательной способности в реальном времени в центрах полос **синий 450 / зелёный 550 / красный 670 / NIR 800 нм** (значения с точностью до 4 знаков после запятой, `---`, если расчет невозможен; наведите курсор на название индекса, чтобы увидеть его полное название):

* **Отображаются всегда** (независимо от масштаба, для любой комбинации датчиков): NDVI, GNDVI, ENDVI, WDRVI, GRVI, CVI, GCI, MSR.
* **Только если оба датчика откалиброваны по мощности** (загружены оба набора): EVI, SAVI, OSAVI, GSAVI, GOSAVI, MSAVI2, RDVI, TDVI, LAI, NLI, MNLI, FCI, GEMI

## Запись файлов `.daq`

* Для записи требуется **открытый проект** — в противном случае кнопки «Записать всё» (на боковой панели) и «Запись» для каждого датчика будут отключены.
* Файлы записываются в папку **`<project folder>/light_sensor/`**; имена файлов содержат идентификатор датчика и временную метку, а название устройства сохраняется вместе с записью.
* При остановке записи (кнопка «Остановить», «Остановить всё», или отключение во время записи), готовый файл `.daq` **автоматически добавляется в открытый проект** — он появляется в списке файлов проекта без ручного добавления, готовый к использованию в качестве данных о нисходящем излучении для [обработки коэффициента отражения](README.md).
* Во время записи в строках реального времени модального окна настроек отображается красный индикатор `REC`.

Для получения количественных значений интенсивности излучения необходимо усреднять данные за период не менее 15 секунд — это характеристика прибора, а не дефект

## Расположение нескольких датчиков и сохранение настроек проекта

* Объединяйте несколько датчиков на одном графике (общие оси), сохраняйте отдельные графики (автоматическая сетка), перемещайте датчики между графиками, перетаскивайте и изменяйте порядок строк/плиток, а также скрывайте отдельные датчики с помощью переключателя в виде глаза.
* Для каждого проекта Chloros сохраняются: названия устройств, цвета графиков, размер диаграмм, режим просмотра и настройки каждого датчика (время интегрирования, усреднение кадров, состояние AE, выбор ограничителя).
* **При повторном открытии проекта датчики подключаются автоматически** по адресу — COM-порт для DAQ-U, устройство BLE для DAQ-M, имя хоста mDNS для DAQ-E (распознаётся даже при смене IP-адреса устройства) — и повторно применяет сохранённые для каждого датчика профиль крышки, усреднение кадров, состояние AE и вручную заданное время интеграции.***

## Сопряжение камеры (DLS)

Сопрягать нечего. В отличие от рабочих процессов DLS для дронов, в которых датчик освещенности привязывается к камере заранее, Chloros сопоставляет данные DAQ с изображениями на последующем этапе: во время импорта/обработки показания `.daq` интерполируются по временной метке экспозиции каждого снимка. Ведите запись с помощью любого подключенного датчика (`.daq` автоматически добавляется в проект), и при обработке коэффициента отражения будут найдены правильные показания по времени — см. [Датчики освещенности DAQ](README.md), чтобы узнать, как используются данные о нисходящем излучении.</version\>
