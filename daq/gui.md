# Вкладка «DAQ» в Chloros

Вкладка «DAQ» — обозначенная как **Световые датчики** на боковой панели Chloros — представляет собой панель управления в режиме реального времени для [световых датчиков DAQ-U, DAQ-M и DAQ-E](README.md): подключайте датчики через любой канал передачи данных, наблюдайте за откалиброванными спектрами в режиме реального времени, рассчитывайте коэффициент отражения в реальном времени по паре датчиков и записывайте файлы `.daq` прямо в ваш проект.

Вкладка становится доступной после завершения запуска бэкенда Chloros. Данные для графиков на вкладке поступают от службы DAQ Chloros через активное соединение, которое автоматически восстанавливается (с задержкой 2–10 с) в случае прерывания; пока служба недоступна, в строке «Status» датчика отображается надпись **No Server**.

Макет состоит из **боковой панели датчиков**(одна строка на каждый подключённый датчик) и**области графиков** (одна плитка графика на каждый датчик или группу).

## Подключение датчика

Нажмите **«Подключить датчик»** в верхней части боковой панели. В основной области откроется диалоговое окно подключения (или в виде накладки при добавлении ещё одного датчика — в этом случае появляется кнопка «Отмена»).

| Элемент управления | Поведение |
| --- | --- |
| **Тип устройства** | `DAQ-U (USB)` (по умолчанию), `DAQ-M (Bluetooth)` или `DAQ-E (Ethernet)`. Переключение запускает повторное сканирование для вновь выбранного транспорта. |
| **Порт / Устройство BLE / Имя хоста / IP** | Отображает обнаруженные устройства в формате `device - description`; автоматически выбирается первая запись, распознанная как датчик. Во время сканирования отображаются `Scanning...` (USB), `Scanning (N)...` с 8-секундным обратным отсчётом (BLE) или `Discovering ethernet sensors (N)...` с 5-секундным обратным отсчётом (Ethernet). При отсутствии результатов отображаются записи `No ports` / `No BLE devices` / `No ethernet sensors found`. |
| **↻ Обновить** | Немедленно повторяет сканирование выбранного канала передачи данных (отключено во время сканирования BLE/Ethernet). |
| **Подключить датчик** | Становится доступной после выбора устройства; во время установления соединения обозначение меняется на `Connecting...`. |

Поиск работает только **пока на экране открыто диалоговое окно подключения** и повторяется каждые 15 секунд только для выбранного канала связи — простое открытие вкладки не запускает сканирование. В случае сбоя в диалоговом окне отображается сообщение: *«Подключение не удалось. Попробуйте отключить и снова подключить датчик, затем нажмите «Подключить» ещё раз».*

Боковая панель открывается автоматически при подключении первого датчика.

{% hint style="info" %}
**DAQ-E не отображается?**У DAQ-E нет светодиодного индикатора состояния — проверьте индикатор PoE/соединения на коммутаторе или порту инжектора, к которому он подключен, и подождите несколько секунд после включения питания, чтобы устройство загрузилось. Устройство Chloros должно находиться в том же домене широковещания (mDNS не проходит через маршрутизаторы). Правило брандмауэра**«Chloros Backend (UDP-In)»** в программе установки пропускает mDNS (UDP 5353), данные DAQ-E (UDP 5002) и PTP (UDP 319/320); в брандмауэре стороннего производителя необходимо разрешить те же порты. Два устройства DAQ-E в одной локальной сети обнаруживаются отдельно, каждое под своим собственным именем хоста `daq-e-<id>.local`.
{% endhint %}

## Боковая панель датчиков

Каждому подключенному датчику отводится отдельная строка (плюс одна строка на каждую группу «Окружающая среда + Объект»). Порядок строк можно изменять перетаскиванием, при этом их порядок также влияет на расположение фрагментов графика. Щелкните строку, чтобы сделать этот датчик/группу активным графиком в списке.

| Элемент | Значение |
| --- | --- |
| Цветная левая граница | Цвет графика датчика. |
| Значок транспорта | `DAQ-U` / `DAQ-M` / `DAQ-E` или зелёный значок `REF` для группы отражательной способности «Ambient+Object». |
| Название устройства | По умолчанию — серийный номер датчика (его постоянный идентификатор для калибровки, имена файлов `.daq` и сопоставления при импорте); пользовательские названия сохраняются для каждого проекта. |
| Иконка **«Калибровано»** (зелёная) | Отображается, когда загружен заводской пакет калибровки датчика, т. е. спектры представлены в единицах Вт/м²/нм. |
| Иконка **Доступно обновление** (янтарная, только для DAQ-E) | Текущая версия прошивки устарела по сравнению с образом, входящим в состав данной сборки Chloros

. Во время обновления отображается текущий прогресс (`Flashing… N%`, `Restarting sensor…`, затем `Updated X → Y` или `Failed`). |
| Глаз | Включает/выключает отображение данного датчика на графике. |
| Шестеренка | Открывает модальное окно настроек для данного датчика (ниже). |
| ✕ (красный) | Отключает датчик или удаляет группу «Окружающая среда + Объект». |

Над строками расположены две кнопки:

* **Подключить датчик** — открывает диалоговое окно подключения (во время работы переименовывается в `Connecting...`).
* **Запись всего / Остановить всё**— запускает или останавливает запись `.daq` на**каждом**подключённом датчике. Требуется наличие хотя бы одного датчика**и открытого проекта** (всплывающая подсказка: «Откройте проект для записи»); кнопка становится красной, пока идет любая запись.

В пустом состоянии отображается надпись «Датчики не подключены».

## Настройки для каждого датчика (модальное окно с шестеренкой)

Открывается с помощью значка шестеренки в строке датчика. Содержание в порядке:

* **Строки информации** — Тип устройства (DAQ-U/M/E), Подключение (`Serial (USB)` / `Bluetooth` / `Ethernet`), порт (COM-порт, адрес BLE или хост) и последовательный порт.
* **Отчет о калибровке: загрузить** — загружает сертификат калибровки данного устройства, прослеживаемый до NIST (PDF), и открывает его в программе просмотра PDF. Доступно после того, как известен серийный номер; сертификат кэшируется при первом подключении.
* **Имя устройства** — нажмите на значок карандаша, чтобы переименовать; сохраняется для каждого проекта.
* **Цвет линии графика** — образец цвета; сохраняется для каждого проекта.
* **Время интеграции (мс)**— ползунок + число,**1–500 мс**, по умолчанию**32 мс**. Отключено, когда AE включен.
* **Среднее по кадру**— ползунок + число,**1–50 кадров**, по умолчанию**20**.
* **AE: ВКЛ./ВЫКЛ.**— переключатель автоматической экспозиции;**по умолчанию ВКЛ.** при подключении. Выключите его, чтобы установить время интеграции вручную.
* **Остановить трансляцию / Начать трансляцию** — приостановить или возобновить прямую трансляцию.
* **Запись / Остановить запись** — запись данных с датчика `.daq` (требуется открытый проект).
* **Cap** — профиль коррекции капа (следующий раздел).
* **Строки с информацией в реальном времени** — время интеграции (мс), FPS, количество отсчётов, запись (красный цвет `REC` или `Off`) и статус (`Streaming` / `Paused` / `SATURATED` / `No Server`).

### Только для DAQ-E: строки «Сеть», «Прошивка» и «PTP»

* **Имя хоста / IP** — текущий адрес устройства.
* **Прошивка** — текущая версия прошивки, а также ячейка действия:<version\>

кнопка</version\>

**«Обновить до \<version\>

»** появляется, если данная сборка Chloros

содержит более новый образ прошивки DAQ-E. Обновление передается по сети примерно за 30 секунд; датчик автоматически перезапускается и повторно подключается, а в случае прерывания передачи текущая прошивка остаётся неизменной. Ход обновления отображается в реальном времени (`Flashing… N%` → `Restarting sensor…` → `Updated X → Y`), а в ячейке отображается значение `Up to date`, когда обновление завершено.
* **Синхронизация PTP** — текущее состояние PTP (при сбое возвращается к `unknown`). Прошивка DAQ-E версии 1.2.0+ участвует в стандарте IEEE 1588 PTPv2 в качестве часового генератора, работающего только в режиме ведомого устройства; бэкенд хоста Chloros

является главным генератором PTP, и все устройства DAQ-E и камеры LATTICE в локальной сети работают в качестве подчиненных устройств в домене 0, поддерживая точность временных меток в пределах примерно 1 мс.
* **Сеть**— адрес, по которому работает устройство, и способ его получения (DHCP, локальный по каналу или статический), а также сохраненная настройка, которая применяется после перезапуска.**Изменить…**открывает форму:**Автоматически (DHCP)**или**Статический IP**с указанием IP-адреса, маски подсети и опционального шлюза.**Применить и перезапустить** сохраняет настройки, перезапускает датчик и повторно подключает его. Статический адрес за пределами сети этого компьютера отклоняется, поскольку Chloros

не смог установить связь с датчиком после перезапуска; в этом случае появляется окно, позволяющее всё же разрешить это для компьютера, который будет переадресован или маршрутизирован в эту сеть. **Поток при включении**определяет, начинает ли датчик передачу данных сразу после включения питания, до подключения какого-либо программного обеспечения.**«Перезапустить датчик»** перезапускает его и повторно подключает с текущими настройками. Перезапуск запрещен во время записи данных датчиком. Новое в версии 1.3.0.

Для группы «Ambient+Object» в модальном окне с шестеренкой отображаются только исходные датчики группы, **Название устройства**и**Цвет линии графика**.

### Выбор крышки

Выпадающий список **Крышка** указывает Chloros

, какая физическая крышка установлена на диффузоре датчика, и применяет к каждому спектру профиль коррекции, измеренный на заводе для данной крышки. Варианты выбора зависят от модели:

| Модель | Варианты крышки |
| --- | --- |
| DAQ-U | Нет (открытый датчик), FOV 15°, FOV 30°, FOV 45°, FOV 60°, FOV 90°, Sunshine (косинусный корректор) |
| DAQ-M | Без крышки (открытый датчик), «Sunshine» (косинусный корректор) |
| DAQ-E | Без крышки (открытый датчик), FOV 15°, FOV 45°, FOV 90°, «Sunshine» (косинусный корректор) |

**По умолчанию для всех моделей установлен режим «Sunshine» (косинусный корректор)** — компания MAPIR

поставляет каждый DAQ с установленным колпачком «Sunshine», и это является стандартной конфигурацией для использования на открытом воздухе: полусферический обзор 180° с погрешностью косинуса ≤ ±4 % в диапазоне до 60° и ≤ ±4,5 % в диапазоне до 70° (не рекомендуется при угле возвышения Солнца ниже ~15°), с заложенным в конструкцию ослаблением сигнала (~12×). Ваш выбор сохраняется в проекте.

{% hint style="warning" %}
**Выбор крышки должен соответствовать установленной крышке.**Ни датчик, ни программное обеспечение не могут определить, какая крышка установлена. Этот выбор определяет как коррекцию в режиме реального времени, так и метку, записываемую в каждый файл `.daq` — учитывая ослабление ~12× у крышки Sunshine, незаявленная смена крышки приводит к некорректной коррекции спектров примерно на этот коэффициент. (Снятие и повторная установка той же крышки приводит к погрешности около 1,5 %.) Выбирайте**«Нет» (голый датчик)** только в том случае, если крышка физически снята; на DAQ-E вариант «None» по-прежнему применяет заводской геометрический профиль для его утопленного стеклянного диффузора — это не пустая операция — а DAQ-E без насадки представляет собой лабораторную конфигурацию, а не поддерживаемую полевую конфигурацию.
{% endhint %}

{% hint style="info" %}
Обновление по сравнению с предыдущим руководством: переключатель «Sunshine Diffuser Installed» на стороне браузера, присутствовавший в версии 1.1.0, исчез. Управление крышками теперь осуществляется с помощью профиля крышки для каждого датчика, применяемого на стороне сервера.
{% endhint %}

## Область диаграмм

В верхней фиксированной панели расположены **переключатель между списком и сеткой**и ползунок**масштабирования графика** (размер ячейки 200–2000 пикселей). При наличии более одной группы графиков вид автоматически переключается на сетку, а при наличии одной или менее групп — обратно на список. Режим просмотра и размер диаграммы сохраняются для каждого проекта.**Спектральная диаграмма** для каждого датчика отображает:

* **Ось X** — длина волны (нм). Сетка датчика составляет 340–1010 нм с шагом 5 нм (135 точек), интерполированная до 1 нм для отображения.
* **Ось Y**— для откалиброванного датчика (зелёная иконка**«Откалиброван»**),**Мощность (Вт/м²/нм)**— радиометрически откалиброванная спектральная освещённость для всех трёх типов переноса — с автоматическим префиксом системы СИ (м/мк/н), выбираемым по пику. Датчик, пакет калибровки которого не загружен, отображает свои необработанные показания как**Интенсивность (импульсы)** без масштабирования. Когда на одном графике накладываются оба типа данных, мощность отображается по левой оси, а отсчёты — по правой.
* Радужная спектральная заливка под одной кривой; данные от нескольких датчиков на одном графике накладываются в виде цветных линий с приглушённой заливкой.
* **Наведение курсора**— вертикальный курсор с указанием длины волны и значения для каждого датчика (Вт/м²/нм для откалиброванного датчика, в остальных случаях — общее количество импульсов);**перетаскивание** для изменения масштаба (при увеличении масштаба появляется кнопка уменьшения).
* Кнопка **+** (только в режиме сетки) для добавления датчика на этот график или создания группы (см. ниже).
* Название устройства, выровненное по центру вверху, и индикатор загрузки до поступления первого кадра.

**Насыщенность** не отображается на самом графике: насыщенный датчик отображается красным текстом статуса `SATURATED` и красной строкой `Saturated: Yes` в таблице данных в реальном времени. Чтобы сбросить насыщенность, уменьшите время интегрирования или снова включите AE.

## Группы отражательной способности (Окружающий свет + Объект)

Два подключенных датчика можно объединить для отображения отражательной способности в реальном времени — без использования камеры:

1. В режиме просмотра сетки нажмите **+**на плитке диаграммы и выберите**Объединить окружающий свет + объект**.
2. Выберите датчик **Источник окружающего света**и датчик**Сканер объекта**(два разных датчика), затем нажмите**Создать**.

Chloros

вычисляет R(λ) = объект(λ) / окружающий свет(λ) для каждой длины волны на основе двух потоков данных в реальном времени (0, если окружающий свет ≤ 0). Метка группы зависит от класса калибровки датчиков:

* Оба датчика откалиброваны (пакет загружен) → **«Кажущаяся отражательная способность»**.
* Хотя бы один датчик не откалиброван → **«Относительная отражательная способность»**.

## Запись файлов `.daq`

* Для записи требуется **открытый проект** — в противном случае кнопки «Записать всё» (на боковой панели) и «Запись» для каждого датчика будут отключены.
* Файлы записываются в папку **`<project folder>/light_sensor/`**; имена файлов содержат идентификатор датчика и временную метку, а название устройства сохраняется вместе с записью.
* Когда запись останавливается («Остановить», «Остановить всё» или разрыв соединения во время записи), готовый файл `.daq` **автоматически добавляется в открытый проект** — он появляется в списке файлов проекта без ручного добавления, готовый к использованию в качестве данных о нисходящем излучении для [обработки коэффициента отражения](README.md).
* Во время записи в строках реального времени модального окна настроек отображается красный индикатор `REC`.

Для получения количественных значений интенсивности излучения необходимо усреднять данные за период не менее 15 секунд — это характеристика прибора, а не его неисправность.

## Расположение нескольких датчиков и сохранение настроек проекта

* Объединяйте несколько датчиков на одном графике (общие оси), сохраняйте отдельные графики (автоматическая сетка), перемещайте датчики между графиками, перетаскивайте и изменяйте порядок строк/плиток, а также скрывайте отдельные датчики с помощью переключателя в виде глаза.
* Для каждого проекта Chloros

сохраняет: названия устройств, цвета графиков, размер диаграммы, режим просмотра и настройки каждого датчика (время интеграции, усреднение кадров, состояние AE, выбор крышки).
* **При повторном открытии проекта датчики подключаются автоматически** по адресу — COM-порт для DAQ-U, устройство BLE для DAQ-M, имя хоста mDNS для DAQ-E (определяется даже при смене IP-адреса устройства) — и повторно применяет сохраненные для каждого датчика профиль крышки, усреднение кадров, состояние AE и вручную заданное время интеграции.***

## Сопряжение камеры (DLS)

Сопрягать нечего. В отличие от рабочих процессов DLS с использованием дронов, в которых датчик освещённости привязывается к камере заранее, Chloros

сопоставляет данные DAQ с изображениями на последующем этапе: при импорте/обработке показания `.daq` интерполируются по временной метке экспозиции каждого снимка. Сделайте запись с помощью любого подключенного датчика (`.daq` автоматически попадает в проект), и при обработке коэффициента отражения будут найдены правильные показания по времени — см. [Датчики освещенности DAQ](README.md), чтобы узнать, как используются данные о нисходящем излучении. Для **реальных**снимков LATTICE выберите датчик в раскрывающемся списке**Light Sensor** на вкладке «Cameras»; тогда при каждой съемке сохраняются использованные показания, сопоставленные только с камерами этой конкретной съемки (см. [Рабочие процессы с отраженным излучением](reflectance.md)).</version\>
