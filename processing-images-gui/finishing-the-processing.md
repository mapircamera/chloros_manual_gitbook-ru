## Индикация завершения обработки

После успешного завершения обработки вы увидите несколько индикаторов:

* ✅ **Индикатор выполнения**: достигает 100% завершения
* ✅ **Журнал отладки**: отображает сообщение «Обработка завершена»
* ✅ **Кнопка «Пуск»**: снова становится активной (готова к следующему запуску обработки)
* ✅ **Выходные файлы**: все обработанные изображения сохранены в подпапке модели камеры***

## Просмотр обработанных изображений

### Быстрый просмотр в проводнике

**Встроенный просмотр Windows:**

1. Перейдите в подпапку модели камеры
2. Выберите файл изображения
3. Предварительный просмотр отобразится в панели просмотра Windows Explorer
4. Используйте клавиши со стрелками для просмотра изображений

### Предварительный просмотр во внешних программах просмотра изображений

**Рекомендуемые программы просмотра:*** **QGIS** — бесплатное программное обеспечение для работы с ГИС (лучше всего подходит для геореференцированного мультиспектрального анализа)
* **IrfanView** — быстрая и легкая программа просмотра изображений (поддерживает TIFF)
* **Adobe Photoshop** — профессиональное редактирование (поддержка формата TIFF)
* **GIMP** — бесплатная альтернатива Photoshop
* **Windows Photos** — базовый просмотр (может не поддерживать 16-битный формат TIFF)

### Предварительный просмотр в Chloros Image Viewer

Используйте встроенный Image Viewer Chloros для расширенной визуализации:

1. Щелкните миниатюру изображения в файловом браузере
2. Изображение откроется в основной области предварительного просмотра
3. Щелкните вкладку **Image Viewer** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> в левой боковой панели
4. Используйте [Index/LUT Sandbox](../image-viewer-gui/index-lut-sandbox.md) для интерактивного анализа

См. [Просмотрщик изображений](../image-viewer-gui/opening-an-image-full-screen.md) для получения подробных инструкций.

## Распространенные проблемы с выводом и их решения

### Проблема: отсутствуют выходные файлы

**Возможные причины:**

* Файлы не соответствовали критериям обработки
* Изображения только для целевой аудитории (исключены из экспорта)
* Не хватило места на диске во время экспорта
* Повреждение файлов во время обработки

**Решения:**

1. Проверьте журнал отладки на наличие сообщений о пропуске/ошибках
2. Убедитесь, что на диске было достаточно места
3. Подсчитайте файлы: количество должно совпадать с (исходное количество - количество целевых файлов) × (индексы + 1)
4. Повторно импортируйте и обработайте отсутствующие файлы

### Проблема: темные или светлые края (виньетирование по-прежнему видно)

**Возможные причины:**

* Коррекция виньетирования отключена
* Камера/объектив отсутствуют в базе данных профилей Chloros
* Чрезмерное виньетирование, превышающее возможности коррекции

**Решения:**

1. Убедитесь, что коррекция виньетирования включена в настройках проекта
2. Проверьте, правильно ли определена модель камеры
3. Обратитесь в службу поддержки MAPIR, если виньетирование сохраняется

### Проблема: Неверные цвета или значения

**Возможные причины:**

* Не обнаружено калибровочных мишеней
* Выбрана неверная модель калибровочной мишени
* Калибровка по отражательной способности отключена
* Низкое качество изображений мишеней

**Решения:**

1. Убедитесь, что калибровка по отражательной способности включена
2. Проверьте сообщения «Цель найдена» в журнале отладки
3. Проверьте качество изображений мишеней
4. Повторите обработку с отмеченными правильными мишенями

### Проблема: Значения NDVI кажутся неправильными

**Ожидаемые диапазоны NDVI:*** **Вода, камни, почва**: от -0,1 до 0,2
* **Редкая/нездоровая растительность**: от 0,2 до 0,4
* **Умеренная растительность**: от 0,4 до 0,6
* **Здоровая, густая растительность**: от 0,6 до 0,9**Если значения выходят за пределы этих диапазонов:**

1. Убедитесь, что была применена калибровка отражательной способности
2. Убедитесь, что был включен журнал датчика освещенности
3. Проверьте, были ли обнаружены калибровочные мишени
4. Убедитесь, что была определена правильная модель камеры
5. Проверьте время и условия съемки целевого изображения

## Использование обработанных изображений

### Для фотограмметрии / создания ортомозаики

**Рекомендуемый рабочий процесс:**

1.**Импортируйте откалиброванные изображения отражательной способности** в программное обеспечение для фотограмметрии:
   * Pix4Dmapper
   * Agisoft Metashape
   * DroneDeploy
   * WebODM
2. **Сохраняйте метаданные EXIF**: убедитесь, что данные GPS сохранены для геотаггирования
3. **Калиброванные рабочие процессы**: используйте изображения отражательной способности для обеспечения научной точности
4. **Обработайте индексные мозаики**: Создайте ортомозаики NDVI из отдельных индексных изображений
5. **Экспорт геореференцированных GeoTIFF**: Для использования в приложениях ГИС

### Для ГИС-анализа

**Рекомендуемый рабочий процесс:**

1.**Загрузите в QGIS, ArcGIS или аналогичную программу**

2.**Используйте 16-битные TIFF** изображения отражения для многополосного анализа
3. **Используйте индексные изображения** (NDVI, NDRE) в качестве готовых к использованию слоев растительности
4. **Растровый калькулятор**: объединяйте полосы для пользовательского анализа
5. **Экспорт**: создание карт классификации, обнаружение изменений, карты состояния растительности

### Для прямого анализа / отчетности

**Рекомендуемый рабочий процесс:**

1.**Используйте индексные изображения с цветами LUT** для визуальных отчетов
2. **Извлечение статистики**: среднее значение NDVI по полю/участку
3. **Временные ряды**: сравнивайте индексы по нескольким сеансам
4. **Создавайте отчеты**: включайте карты, статистику и визуализации***

## Последующие циклы обработки

### Повторное использование настроек проекта

Если в будущем предстоит обработка похожих наборов данных:

1. **Сохраните шаблон проекта** (если это еще не сделано)
2. **Создайте новый проект**, используя сохраненный шаблон
3. **Импортируйте новые изображения**

4.**Обработайте**с идентичными настройками для обеспечения согласованности

### Пакетная обработка нескольких сессий

Для нескольких сессий/наборов данных:**Вариант 1: GUI — несколько проектов**

* Создайте отдельный проект для каждой сессии
* Используйте единые настройки шаблона
* Обрабатывайте по одному за раз

**Вариант 2: Chloros CLI (только Chloros+)**

* Автоматизируйте пакетную обработку
* Обрабатывайте несколько папок с помощью скриптов
* См. [Документацию по CLI](../CLI.md)

**Вариант 3: Python SDK (только для Chloros+)**

* Программное управление
* Интеграция с конвейерами анализа
* См. [Документация по API](../api-python-sdk.md)

## Устранение неполадок при постобработке

### Повторная обработка с другими настройками

Если результаты не удовлетворительны:

1. Сохраните исходные изображения (никогда не удаляйте)
2. Откройте тот же проект в Chloros
3. Настройте параметры на панели «Настройки проекта»
4. Выполните обработку заново — результаты перезапишут предыдущие

### Обработка поднабора изображений

Чтобы переобработать только определенные изображения:

1. Создайте новый проект
2. Импортируйте только те изображения, которые требуют переобработки
3. Используйте тот же шаблон настроек
4. Обработайте меньший набор данных
