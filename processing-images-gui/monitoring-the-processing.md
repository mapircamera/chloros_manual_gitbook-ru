# Мониторинг обработки

После запуска обработки Chloros предоставляет несколько способов отслеживать ход работы, проверять наличие проблем и понимать, что происходит с вашим набором данных. На этой странице объясняется, как отслеживать ход обработки и интерпретировать информацию, предоставляемую Chloros.

## Обзор индикатора хода выполнения

Индикатор хода выполнения в верхнем заголовке показывает статус обработки в реальном времени и процент выполнения.

### Индикатор хода выполнения в бесплатном режиме

Для пользователей без лицензии Chloros+:

**2-этапное отображение хода выполнения:**

1.**Обнаружение мишеней** — поиск калибровочных мишеней на изображениях
2. **Обработка** — применение корректировок и экспорт**Индикатор выполнения показывает:**

* Общий процент выполнения (0–100%)
* Название текущего этапа
* Простую визуализацию в виде горизонтальной полосы

### Индикатор выполнения Chloros+

Для пользователей с лицензией Chloros+:

**4-этапное отображение прогресса:**

1.**Обнаружение** — поиск калибровочных мишеней
2. **Анализ** — изучение изображений и подготовка конвейера
3. **Калибровка** — применение корректировок виньетирования и отражения
4. **Экспорт** — сохранение обработанных файлов**Интерактивные функции:*** **Наведите курсор** на индикатор выполнения, чтобы увидеть развернутую панель с 4 этапами
* **Щелкните** по индикатору выполнения, чтобы зафиксировать/закрепить развернутую панель
* **Щелкните еще раз**, чтобы отменить фиксацию и автоматическое скрытие при уходе курсора
* Каждый этап показывает индивидуальный прогресс (0–100%)

***

## Понимание каждого этапа обработки

{% hint style="info" %}
**Архитектура конвейера**: Эти 4 этапа графического интерфейса пользователя соответствуют [4-потоковому конвейеру обработки](../processing-architecture/processing-pipeline.md). В системах с ускорением на GPU поток 3 (калибровка) использует преимущества [динамической адаптации вычислений](../processing-architecture/dynamic-compute-adaptation.md), которая оптимизирует обработку для вашего конкретного оборудования.
{% endhint %}

### Этап 1: Обнаружение (обнаружение целей)

**Что происходит:**

* Chloros сканирует изображения, отмеченные флажком «Цель»
* Алгоритмы компьютерного зрения идентифицируют 4 панели калибровки
* Из каждой панели извлекаются значения отражательной способности
* Записываются временные метки целей для правильного планирования калибровки

**Продолжительность:**

* С отмеченными целями: 10–60 секунд
* Без отмеченных целей: 5–30+ минут (сканируются все изображения)

**Индикатор прогресса:**

* Обнаружение: 0% → 100%
* Количество отсканированных изображений
* Количество найденных целей

**На что следует обратить внимание:**

* Должно завершиться быстро, если цели правильно помечены
* Если занимает слишком много времени, цели, возможно, не помечены
* Проверьте журнал отладки на наличие сообщений «Цель найдена»

### Этап 2: Анализ

**Что происходит:**

* Чтение метаданных EXIF изображения (временные метки, настройки экспозиции)
* Определение стратегии калибровки на основе временных меток целей
* Организация очереди обработки изображений
* Подготовка рабочих процессов для параллельной обработки (только Chloros+)

**Продолжительность:** 5–30 секунд**Индикатор прогресса:**

* Анализ: 0% → 100%
* Быстрая стадия, обычно завершается быстро

**На что следует обратить внимание:**

* Процесс должен проходить плавно, без пауз
* Предупреждения об отсутствующих метаданных появятся в журнале отладки

### Этап 3: Калибровка

**Что происходит:*** **Дебайеризация**: преобразование RAW-матрицы Байера в 3 канала
* **Коррекция виньетирования**: устранение затемнения по краям объектива
* **Калибровка отражения**: нормализация по заданным значениям
* **Расчет индексов**: вычисление мультиспектральных индексов
* Обработка каждого изображения по полной цепочке

**Продолжительность:** большая часть общего времени обработки (60–80%)**Индикатор прогресса:**

* Калибровка: 0% → 100%
* Обрабатывается текущее изображение
* Обработанные изображения / Всего изображений

**Поведение при обработке:*** **Свободный режим**: Обрабатывает по одному изображению последовательно
* **Режим Chloros+**: Обрабатывает до 16 изображений одновременно
* **Ускорение на GPU**: Значительно ускоряет этот этап**На что следует обратить внимание:**

* Стабильное продвижение по количеству изображений
* Проверка журнала отладки на наличие сообщений о завершении обработки каждого изображения
* Предупреждения о проблемах с качеством изображения или калибровкой

### Этап 4: Экспорт

**Что происходит:**

* Запись откалиброванных изображений на диск в выбранном формате
* Экспорт мультиспектральных индексных изображений с цветами LUT
* Создание подпапок моделей камер
* Сохранение исходных имен файлов с соответствующими суффиксами

**Продолжительность:** 10–20 % от общего времени обработки**Индикатор прогресса:**

* Экспорт: 0 % → 100 %
* Запись файлов
* Формат экспорта и место назначения

**На что следует обратить внимание:**

* Предупреждения о нехватке места на диске
* Ошибки записи файлов
* Завершение всех настроенных выходов

## Вкладка «Журнал отладки»

Журнал отладки содержит подробную информацию о ходе обработки и любых возникших проблемах.

### Доступ к журналу отладки

1. Нажмите значок **Журнал отладки** <img src="../.gitbook/assets/icon_log.JPG" alt="" data-size="line"> на левой боковой панели
2. Откроется панель журнала, отображающая сообщения об обработке в режиме реального времени
3. Панель прокручивается автоматически, чтобы отобразить последние сообщения

### Понимание сообщений журнала

#### Информационные сообщения (белый/серый)

Обычные обновления обработки:

```
[INFO] Processing started
[INFO] Target detected in IMG_0015.RAW - 4 panels found
[INFO] Calibrating IMG_0234.RAW
[INFO] Exported NDVI image: IMG_0234_NDVI.tif
[INFO] Processing complete
```

#### Предупреждающие сообщения (желтый)

Некритические проблемы, не приводящие к остановке обработки:

```
[WARN] No GPS data found in IMG_0145.RAW
[WARN] Target image timestamp gap > 30 minutes
[WARN] Low contrast in calibration panel - results may vary
```

**Действие:** Просмотрите предупреждения после завершения обработки, но не прерывайте ее

#### Сообщения об ошибках (Red)

Критические проблемы, которые могут привести к сбою обработки:

```
[ERROR] Cannot write file - disk full
[ERROR] Corrupted image file: IMG_0299.RAW
[ERROR] No targets detected - enable reflectance calibration or mark target images
```

**Действие:** Остановите обработку, устраните ошибку, перезапустите

### Общие сообщения журнала

| Сообщение                          | Значение                                | Необходимые действия                                         |
| -------------------------------- | -------------------------------------- | ----------------------------------------------------- |
| «Цель обнаружена в \[имя файла]» | Цель калибровки найдена успешно  | Нет — нормально                                         |
| «Обработка изображения X из Y»        | Обновление текущего прогресса                | Нет — нормально                                         |
| «Цели не найдены»               | Цели калибровки не обнаружены        | Отметить целевые изображения или отключить калибровку по отражению |
| «Недостаточно места на диске»        | Недостаточно места для вывода          | Освободите место на диске                                    |
| «Пропуск поврежденного файла»        | Файл изображения поврежден                  | Снова скопируйте файл с SD-карты                             |
| «Данные PPK применены»               | Применены поправки GPS из файла .daq | Нет — нормально                                         |

### Копирование данных журнала

Чтобы скопировать журнал для устранения неполадок или обращения в службу поддержки:

1. Откройте панель «Журнал отладки»
2. Нажмите кнопку **«Копировать журнал»** (или щелкните правой кнопкой мыши → «Выделить все»)
3. Вставьте в текстовый файл или электронное письмо
4. При необходимости отправьте в службу поддержки MAPIR

## Мониторинг системных ресурсов

### Использование ЦП

**Свободный режим:**

* 1 ядро ЦП на ~100%
* Остальные ядра находятся в режиме ожидания или доступны
* Система остается отзывчивой

**Параллельный режим Chloros+:**

* Несколько ядер на 80–100% (до 16 ядер)
* Высокая общая загрузка ЦП
* Система может работать с меньшей отзывчивостью

**Для мониторинга:**

* Windows Диспетчер задач (Ctrl+Shift+Esc)
* Вкладка «Производительность» → раздел «ЦП»
* Найдите процессы «Chloros» или «chloros-backend»

### Использование памяти (RAM)

**Типичное использование:**

* Небольшие проекты (&lt; 100 изображений): 2–4 ГБ
* Средние проекты (100–500 изображений): 4–8 ГБ
* Крупные проекты (500+ изображений): 8–16 ГБ
* Параллельный режим Chloros+ использует больше ОЗУ

**Если памяти мало:**

* Обрабатывайте меньшие партии
* Закройте другие приложения
* Увеличьте объем ОЗУ, если регулярно обрабатываете большие наборы данных

### Использование GPU (Chloros+ с CUDA)

Когда включено ускорение на GPU:

* GPU NVIDIA показывает высокую загрузку (60–90%)
* Использование VRAM увеличивается (требуется 4 ГБ+ VRAM)
* Этап калибровки проходит значительно быстрее

**Для мониторинга:**

* Значок NVIDIA в системном трее
* Диспетчер задач → Производительность → Графический процессор
* GPU-Z или аналогичный инструмент мониторинга

### Ввод-вывод диска

**Чего ожидать:**

* Высокая скорость чтения с диска на этапе анализа
* Высокая скорость записи на диск на этапе экспорта
* SSD значительно быстрее, чем HDD

**Совет по повышению производительности:**

* По возможности используйте SSD для папки проекта
* Избегайте сетевых дисков для больших наборов данных
* Убедитесь, что диск не заполнен почти до предела (это влияет на скорость записи)

## Обнаружение проблем во время обработки

### Предупреждающие признаки

**Процесс замирает (без изменений более 5 минут):**

* Проверьте журнал отладки на наличие ошибок
* Проверьте наличие свободного места на диске
* Проверьте в диспетчере задач, запущен ли процесс Chloros

**Часто появляются сообщения об ошибках:**

* Остановите обработку и просмотрите ошибки
* Распространенные причины: нехватка места на диске, поврежденные файлы, проблемы с памятью
* См. раздел «Устранение неполадок» ниже

**Система перестает отвечать:**

* Параллельный режим Chloros+ использует слишком много ресурсов
* Рассмотрите возможность уменьшения количества одновременно выполняемых задач или модернизации оборудования
* Свободный режим менее ресурсоемкий

### Когда следует остановить обработку

Остановите обработку, если вы видите:

* ❌ Ошибки «Диск заполнен» или «Невозможно записать файл»
* ❌ Повторяющиеся ошибки повреждения файлов изображений
* ❌ Система полностью зависла (не отвечает)
* ❌ Осознали, что были настроены неправильные параметры
* ❌ Импортированы неправильные изображения

**Как остановить:**

1. Нажмите**кнопку «Стоп/Отмена»** (заменяет кнопку «Старт»)
2. Обработка останавливается, прогресс теряется
3. Устраните проблемы и начните сначала

***

## Устранение неполадок во время обработки

### Обработка идет очень медленно

**Возможные причины:**

* Неотмеченные целевые изображения (сканирование всех изображений)
* Использование HDD вместо SSD
* Недостаток системных ресурсов
* Настроенно слишком много индексов
* Доступ к сетевому диску

**Решения:**

1. Если только что запустили и находитесь на этапе обнаружения: отмените, отметьте целевые изображения, перезапустите
2. На будущее: используйте SSD, уменьшите количество индексов, обновите оборудование
3. Рассмотрите возможность использования CLI для пакетной обработки больших наборов данных

### Предупреждения о «месте на диске»

**Решения:**

1. Немедленно освободите место на диске
2. Переместите проект на диск с большим объемом свободного места
3. Уменьшите количество индексов для экспорта
4. Используйте формат JPG вместо TIFF (файлы меньшего размера)

### Частые сообщения о «поврежденных файлах»

**Решения:**

1. Перекопируйте изображения с SD-карты, чтобы убедиться в их целостности
2. Проверьте SD-карту на наличие ошибок
3. Удалите поврежденные файлы из проекта
4. Продолжите обработку оставшихся изображений

### Перегрев системы / ограничение производительности

**Решения:**

1. Обеспечьте достаточную вентиляцию
2. Очистите вентиляционные отверстия компьютера от пыли
3. Уменьшите нагрузку на систему (используйте режим Free вместо Chloros+)
4. Выполняйте обработку в более прохладные часы дня

***

## Уведомление о завершении обработки

По завершении обработки:

* Индикатор выполнения достигает 100%
* В журнале отладки появляется сообщение **«Обработка завершена»**
* Кнопка «Пуск» снова становится активной
* Все выходные файлы находятся в подпапке модели камеры

***

## Следующие шаги

После завершения обработки:

1. **Проверьте результаты** — см. [Завершение обработки](finishing-the-processing.md)
2. **Проверьте папку с результатами** — убедитесь, что все файлы экспортированы правильно
3. **Просмотрите журнал отладки** — проверьте наличие предупреждений или ошибок
4. **Просмотрите обработанные изображения** — используйте просмотрщик изображений или внешнее программное обеспечение

Информацию о просмотре и использовании обработанных результатов см. в разделе [Завершение обработки](finishing-the-processing.md).
