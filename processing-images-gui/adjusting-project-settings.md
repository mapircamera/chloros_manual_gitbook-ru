# Настройка параметров проекта

Перед обработкой изображений важно настроить параметры проекта в соответствии с требованиями вашего рабочего процесса. Панель «Настройки проекта» <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> панель настроек проекта обеспечивает полный контроль над калибровкой, параметрами обработки, мультиспектральными индексами и форматами экспорта.

## Доступ к настройкам проекта

1. Откройте проект в Chloros
2. Нажмите на значок **Настройки проекта** <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> на левой боковой панели
3. На панели «Настройки проекта» отобразятся все параметры конфигурации

{% hint style="info" %}
**Настройки сохраняются автоматически** вместе с проектом. При повторном открытии проекта все настройки восстанавливаются.
{% endhint %}

***

## Быстрая настройка для типичных рабочих процессов

### Настройки по умолчанию (рекомендуется для большинства пользователей)

Для типичных рабочих процессов с камерами MAPIR и Survey3 хорошо подходят настройки по умолчанию:

* ✅ **Коррекция виньетирования**: Включено
* ✅ **Калибровка отражательной способности**: Включено (требуются изображения мишеней MAPIR)
* ✅ **Метод дебайеризации**: Стандартный (быстрый, среднее качество)
* ✅ **Формат экспорта**: TIFF (16-бит)

Просто импортируйте изображения и начните обработку с этими настройками по умолчанию.

## Обзор настроек проекта

Панель «Настройки проекта» разделена на несколько категорий. Ниже приводится краткое описание каждого раздела. Полную документацию см. в разделе [Настройки проекта](../project-settings/project-settings.md).

### Обнаружение мишеней

Управляет тем, как Chloros идентифицирует калибровочные мишени на ваших изображениях.

**Ключевые настройки:*** **Минимальная площадь калибровочной выборки**: пороговое значение размера для обнаружения мишеней (по умолчанию: 25 пикселей)
* **Минимальная кластеризация мишеней**: пороговое значение сходства для группировки областей мишеней (по умолчанию: 60)**Когда следует корректировать:**

* Увеличьте площадь выборки, если возникают ложные обнаружения
* Уменьшите, если цели не обнаруживаются
* Настройте кластеризацию, если цели разбиваются на несколько обнаружений

### Обработка

Основные параметры обработки изображений и калибровки.

**Ключевые настройки:*** **Коррекция виньетирования**: Компенсирует затемнение по краям объектива ✅ Рекомендуется
* **Калибровка отражения**: Нормализует значения с помощью калибровочных мишеней ✅ Рекомендуется
* **Метод дебайеризации**: Алгоритм преобразования RAW в 3-канальный мультиспектральный формат
* **Минимальный интервал повторной калибровки**: Время между использованием калибровочных мишеней (0 = использовать все)**Расширенные настройки:*** **Смещение часового пояса датчика освещенности**: Для синхронизации времени PPK (по умолчанию: 0)
* **Применить корректировки PPK**: Использует данные GPS/контактных точек экспозиции из файлов .daq
* **Контактные точки экспозиции 1/2**: Назначает камеры контактным точкам экспозиции для конфигураций с двумя камерами

### Метод дебайеризации

В настоящее время в Chloros мы предлагаем 2 метода дебайеризации:

#### Стандартный (быстрый, среднее качество)

Стандартный метод дебайеризации работает быстро, но при этом появляется цветовой шум, что приводит к менее точным и более зашумленным изображениям.

#### С учетом текстуры (медленно, высочайшее качество) \[Только в Chloros+]

Метод с учетом текстуры использует высококачественный алгоритм дебайеризации с учетом краев в сочетании с моделью шумоподавления на основе ИИ/машинного обучения, которая удаляет практически весь шум дебайеризации. Для работы модели с учетом текстуры требуется память графического процессора (VRAM). Мы рекомендуем использовать ее, если у вас доступно более 4 ГБ VRAM, для более быстрой обработки.

### Индекс (мультиспектральные индексы)

Настройте, какие растительные индексы следует рассчитывать и экспортировать.

**Как добавить индексы:**

1. Нажмите кнопку**«Добавить индекс»**

2. Выберите индекс из раскрывающегося меню (NDVI, NDRE, GNDVI и т. д.)
3. Настройте параметры визуализации (цвета LUT, диапазоны значений)
4. Добавьте несколько индексов по мере необходимости

**Популярные индексы:*** **NDVI**: Общее состояние растительности (наиболее распространенный)
* **NDRE**: Раннее обнаружение стресса с RedEdge
* **GNDVI**: Чувствителен к концентрации хлорофилла
* **OSAVI**: Хорошо работает с видимой почвой
* **EVI**: Области с высоким индексом листовой поверхности (LAI)**Пользовательские формулы (только для Chloros+):**

* Создание пользовательских формул мультиспектральных индексов
* Использование математических операций с полосами для всех каналов изображения
* Сохранение пользовательских формул для повторного использования

Все доступные индексы и формулы см. в разделе [Формулы мультиспектральных индексов](../project-settings/multispectral-index-formulas.md).

### Экспорт

Управление форматом и качеством выходного файла.

**Доступные форматы:*** **TIFF (16-бит)**: Рекомендуется для ГИС и научного анализа (диапазон 0–65 535)
* **TIFF (32-бит, проценты)**: Значения отражательной способности с плавающей запятой (диапазон 0,0–1,0)
* **PNG (8-бит)**: сжатие без потерь для визуализации (диапазон 0–255)
* **JPG (8-бит)**: файлы минимального размера, сжатие с потерями (диапазон 0–255)***

## Сохранение и загрузка настроек

### Сохранение шаблона проекта

Создавайте повторно используемые шаблоны для обеспечения единообразных рабочих процессов:

1. Настройте все необходимые параметры на панели «Настройки проекта»
2. Прокрутите вниз до раздела **«Сохранить шаблон проекта»**

3. Введите описательное имя шаблона (например, «Survey3N\_RGN\_Agriculture»)
4. Нажмите значок сохранения

**Преимущества:**

* Применение одинаковых настроек к нескольким проектам
* Обмен конфигурациями с членами команды
* Обеспечение согласованности при повторных опросах

### Загрузка шаблона в новый проект

При создании нового проекта:

1. Выберите **«Новый проект»** в главном меню
2. Выберите опцию **«Загрузить из шаблона»**

3. Выберите сохраненный шаблон
4. Все настройки применяются автоматически

### Рабочий каталог

Настройка **«Папка для сохранения проекта»** определяет, где по умолчанию создаются новые проекты:

* **Местоположение по умолчанию**: `C:\Users\[Username]\Chloros Projects`
* **Изменить местоположение**: нажмите значок редактирования и выберите новую папку
* **Когда менять**:
  * Сетевой диск для совместной работы в команде
  * Другой диск с большим объемом памяти
  * Упорядоченная структура папок по годам/клиентам

## Настройка PPK (Post-Processed Kinematic)

При использовании регистраторов данных MAPIR с GPS для точной геолокации:

### Необходимые условия

* DAQ MAPIR с модулем GPS (GNSS)
* Файл журнала .daq с записями о контактах экспозиции
* Камера, подключенная к контактам экспозиции DAQ во время сеанса съемки

### Шаги настройки

1. Поместите файл журнала .daq в папку проекта
2. В настройках проекта установите флажок **«Применить поправки PPK»**

3. При необходимости установите**«Смещение часового пояса датчика освещенности»** (по умолчанию: 0 для UTC)
4. Назначьте камеры контактам экспозиции:
   * **Одна камера**: автоматически назначается контакту 1
   * **Две камеры**: вручную назначьте каждую камеру соответствующему контакту**Назначение контактов экспозиции:*** **Контакт экспозиции 1**: выберите модель камеры из выпадающего списка
* **Контакт экспозиции 2**: выберите вторую камеру или «Не использовать»
* Одна и та же камера не может быть назначена на оба контакта

{% hint style="warning" %}
**Важно**: контакты экспозиции должны быть правильно назначены соответствующим камерам. Неправильное назначение приведет к неверным данным геолокации.
{% endhint %}

## Расширенные сценарии

### Проекты с несколькими камерами

При обработке изображений с нескольких камер MAPIR в одном проекте:

1. Chloros автоматически определяет модель каждой камеры
2. Каждая камера получает соответствующий профиль обработки
3. PPK: вручную назначьте каждой камере правильный контакт экспозиции
4. Все камеры используют один и тот же формат экспорта и индексы

**Пример**: Survey3W RGN + Survey3N OCN установка с двумя камерами

### Замедленная съемка или съемки в разные даты

Для повторных съемок одной и той же области в течение времени:

1. Создайте шаблон со стандартными настройками
2. Используйте одинаковую настройку калибровочной мишени в каждой сессии
3. Обрабатывайте каждую дату как отдельный проект
4. Используйте одинаковые настройки для получения сопоставимых результатов
5. Экспортируйте в одном формате для временного анализа

### Большие наборы данных

Для проектов с большим количеством изображений (500+):

* Рассмотрите возможность разбиения на более мелкие проекты по дате или области
* Используйте параллельную обработку Chloros+ для получения результатов быстрее
* Рассмотрите использование CLI или API для автоматизации пакетной обработки
* Настройте минимальный интервал повторной калибровки, чтобы сократить время обнаружения мишеней

## Проверка настроек

Перед началом обработки проверьте следующие ключевые настройки:

* [ ] Модель камеры правильно определена в файловом браузере
* [ ] Включена коррекция виньетирования
* [ ] Включена калибровка по отражательной способности
* [ ] Импортировано как минимум одно изображение калибровочной мишени
* [ ] Добавлены нужные мультиспектральные индексы
* [ ] Выбран формат экспорта, подходящий для вашего рабочего процесса
* [ ] Настроены параметры PPK (при использовании файлов .daq с событиями экспозиции)
