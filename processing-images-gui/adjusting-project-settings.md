# Настройка параметров проекта

Перед обработкой изображений важно настроить параметры проекта в соответствии с требованиями вашего рабочего процесса. Панель «Настройки проекта» (<img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line">) обеспечивает полный контроль над калибровкой, параметрами обработки, мультиспектральными индексами и форматами экспорта.

## Доступ к настройкам проекта

1. Откройте проект в Chloros
2. Нажмите на значок **«Настройки проекта»** <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> на левой боковой панели
3. На панели «Настройки проекта» отобразятся все параметры конфигурации

<figure><img src="../.gitbook/assets/image (28).png" alt=""><figcaption><p>Панель «Настройки проекта» — отображение, обнаружение целей и обработка</p></figcaption></figure>{% hint style="info" %}
**Настройки сохраняются автоматически** вместе с проектом. При повторном открытии проекта все настройки восстанавливаются.
{% endhint %}

## Быстрая настройка для типичных рабочих процессов

### Настройки по умолчанию (рекомендуются для большинства пользователей)

Настройки по умолчанию хорошо подходят для типичных рабочих процессов Survey3 и LATTICE:

* ✅ **Коррекция виньетирования**: Включена
* ✅ **Калибровка отражательной способности / баланс белого**: Включена (используются мишени MAPIR и/или данные светового датчика DAQ)
* ✅ **Метод дебайеризации**: Стандартный (быстрый, среднее качество)
* ✅ **Формат экспорта**: TIFF (16-битный)
* ✅ **Все результаты экспорта**: Включено (LATTICE автоматически выводит результаты дебайеризации, предварительного просмотра, яркости и отражательной способности)

Просто импортируйте свои изображения и начните обработку с этими настройками по умолчанию.

## Обзор настроек проекта

Панель «Настройки проекта» состоит из приведённых ниже разделов. Два дополнительных раздела — **DAQ Light Sensor**и**Array Alignment** — появляются автоматически, если ваш проект содержит соответствующие файлы. Полную документацию см. в разделе [Настройки проекта](../project-settings/project-settings.md).

### Отображение

* **Разрешение миниатюр изображений**: разрешение миниатюр в сетке изображений. Варианты:**По умолчанию (512 пикс.)**,**1024 пикс.**,**2048 пикс.**,**Полное разрешение**. Только для отображения — никогда не влияет на обработку. Более высокие значения обеспечивают более четкое изображение при увеличении, но загружаются медленнее.

### Обнаружение целей

Управляет тем, как Chloros идентифицирует калибровочные цели на ваших изображениях.

**Ключевые настройки:*** **Минимальная площадь калибровочной выборки (px)**: пороговое значение размера для обнаружения мишеней (по умолчанию:**25**, диапазон 0–10000)
* **Минимальная степень кластеризации мишеней (0–100)**: Пороговое значение сходства для группировки областей мишеней (по умолчанию:**60**)**Когда следует корректировать:**

* Увеличьте площадь выборки, если возникают ложные обнаружения
* Уменьшите, если мишени не обнаруживаются
* Отрегулируйте кластеризацию, если мишени разбиваются на несколько обнаружений

{% hint style="info" %}
Эти настройки недоступны (затенены), если отключена функция **«Калибровка отражательной способности / баланс белого»** — при её отключении обнаружение целей вообще не выполняется.
{% endhint %}

### Обработка

Основные параметры обработки изображений и калибровки.

**Ключевые настройки:*** **Коррекция виньетирования**: компенсирует затемнение по краям объектива ✅ Рекомендуется
* **Калибровка отражательной способности / баланс белого**: калибрует изображения с использованием обнаруженных мишеней (Survey3) и/или данных светового датчика DAQ (LATTICE) ✅ Рекомендуется
* **Метод дебайеризации**: алгоритм преобразования RAW-файлов в 3-канальный мультиспектральный формат
* **Минимальный интервал повторной калибровки**: минимальное время в секундах между использованием калибровочных мишеней (по умолчанию:**0** = использовать все, диапазон 0–3600)**Некалиброванные резервные продукты:**Если кадр не может быть откалиброван по отражательной способности (мишени нет или калибровка отключена), он экспортируется в виде одного из двух резервных продуктов —**на каждый запуск приходится ровно один из этой пары**, выбираемый переключателем коррекции виньетирования:

* **Экспорт характеристик датчика**: записывает `Sensor_Response_Images` — используется, когда коррекция виньетирования**выключена*** **Экспорт с коррекцией виньетирования**: записывает файл `Vignette_Corrected_Images` — используется, когда коррекция виньетирования**включена**Флажок, который не используется, затенены. Снятие отметки с активного флажка полностью останавливает запись этого файла.**Продукты экспорта LATTICE** (отображаются для каждого проекта; они применяются к снимкам LATTICE):

* **Экспорт с дебайеризацией**: изображение с линейной дебайеризацией (`Debayered_Images`). Применимо к RGB и мультиспектральным модулям.
* **Экспорт предварительного просмотра**: изображение предварительного просмотра (`Preview_Images`). Для RGB: баланс белого (источник освещения DAQ, если доступен, в противном случае — «серый мир») + гамма; для мультиспектральных модулей: растяжение в ложных цветах.
* **Экспорт яркости**: спектральная яркость типа float32 (`Radiance_Images`, Вт/м²/ср/нм). Только для мультиспектральных модулей — не применимо к мастер-файлам RGB.
* ****Экспорт коэффициента отражения**: коэффициент отражения типа uint16 (`Reflectance_Calibrated_Images`, DN 32768 = ρ 1,0), если кадр покрыт нисходящим сигналом `.daq` или целевым объектом внутри кадра. Только для мультиспектральных модулей.

Все четыре параметра **включены по умолчанию**— один импортированный необработанный кадр LATTICE распределяется по всем включенным и применимым продуктам за один проход обработки. Флажок**«Экспорт коэффициента отражения»** отключен, если калибровка коэффициента отражения выключена. Параметры, которые невозможно изменить из-за состояния вышестоящего переключателя, всегда отображаются серыми с всплывающей подсказкой, указывающей название переключателя, который необходимо изменить.**Расширенные настройки:*** **Смещение часового пояса датчика освещенности**: количество часов относительно UTC для синхронизации времени датчика освещенности (по умолчанию: 0, диапазон от −12 до +12)
* **Применять поправки PPK**: использует данные GPS/контактов экспозиции из файлов `.daq` (по умолчанию: выключено)
* **Контакты экспозиции 1/2**: назначает камеры контактам экспозиции для конфигураций с двумя камерами

{% hint style="info" %}
**Уровень входных данных LATTICE устанавливается автоматически.** Захваченные данные LATTICE содержат информацию об уровне обработки в метаданных XMP, и обработка всегда начинается с необработанного кадра — в графическом интерфейсе пользователя настраивать ничего не нужно. (Флаг CLI `--input-level` существует в качестве средства переопределения для опытных пользователей в случае съёмок с утраченными метаданными; см. [Справочник по CLI](../reference/cli-reference.md).)
{% endhint %}

### Метод дебайеризации

В настоящее время в Chloros доступны 2 метода дебайеризации:

#### Стандартный (быстрый, среднее качество)

Стандартный дебайеризатор работает быстро, но при этом возникает цветовой шум, что приводит к менее точным и более зашумленным изображениям.

#### С учётом текстур (медленно, наивысшее качество) \[Только в Chloros+]

Метод «С учётом текстур» использует высококачественный алгоритм дебайеринга с учетом краёв в сочетании с моделью удаления шума на основе ИИ/машинного обучения, которая устраняет практически весь шум, возникающий при дебайеринге. Для работы модели требуется память графического процессора (VRAM): при **7 ГБ или более VRAM** она может обрабатывать несколько изображений одновременно; при объёме памяти менее 7 ГБ она обрабатывает по одному изображению за раз (заметно медленнее). См. [Динамическая адаптация вычислений](../processing-architecture/dynamic-compute-adaptation.md).

{% hint style="info" %}
**При съёмке LATTICE всегда используется стандартная демозаика.** Модели Texture Aware, обученной на данных LATTICE, не существует, поэтому этот параметр не предлагается для снимков LATTICE — однако снимки Survey3 в том же проекте всё ещё могут использовать эту функцию.
{% endhint %}

### Индексы (мультиспектральные индексы)

Настройте, какие растительные индексы следует рассчитывать и экспортировать. В раскрывающемся списке графического интерфейса доступно **27 предустановленных формул индексов**.**Как добавить индексы:**

1. Нажмите кнопку**«Добавить индекс»**

2. Выберите индекс из выпадающего меню (NDVI, NDRE, GNDVI и т. д.)
3. Настройте параметры визуализации (цвета LUT, диапазоны значений)
4. Добавьте несколько индексов по мере необходимости

**Популярные индексы:*** **NDVI**: общее состояние растительности (наиболее распространённый)
* **NDRE**: раннее выявление стресса в сочетании с RedEdge
* **GNDVI**: чувствительный к концентрации хлорофилла
* **OSAVI**: Хорошо работает при видимой почве
* **EVI**: Регионы с высоким индексом листовой поверхности (LAI)**Пользовательские формулы:**

* Создавайте собственные формулы мультиспектральных индексов с помощью математических операций над всеми каналами изображения
* Сохраняйте пользовательские формулы для повторного использования
* Пользовательские формулы — это функция Chloros+; доступность зависит от уровня вашего тарифного плана

Список всех доступных индексов и формул — включая информацию о том, какие названия доступны только в графическом интерфейсе, а какие также работают в CLI/SDK — см. в разделе [Формулы мультиспектральных индексов](../project-settings/multispectral-index-formulas.md).

### Экспорт

Управляет форматом выходного файла.

**Доступные форматы**(параметр:**Формат откалиброванного изображения**, по умолчанию**TIFF (16-битный)**):

* **TIFF (16-бит)**: рекомендуется для ГИС и научного анализа
* **TIFF (32-бит, в процентах)**: значения с плавающей запятой
* **PNG (8-бит)**: сжатие без потерь для визуализации
* **JPG (8-бит)**: файлы наименьшего размера, сжатие с потерями

Результаты записываются в папку проекта, сгруппированные по камерам и форматам: `<project>/<camera>/<format>/<Product>_Images/`. Значения яркости **всегда** записываются в формате float32 в папку `tiff32` независимо от данного параметра. Экспортированные файлы сохраняют исходное имя файла — папка идентифицирует продукт. Полное дерево выходных файлов см. в разделе [Завершение обработки](finishing-the-processing.md).

{% hint style="warning" %}
**Чтение значений коэффициента отражения**: значение DN, означающее ρ = 1,0, зависит от исходной камеры — LATTICE использует 32768 (отмечено в XMP как `Chloros:PixelScale`), Survey3 использует 65535. Считывайте значение тега, а не принимайте его за постоянную величину. См. [Форматы выходных изображений](../output-image-formats.md).
{% endhint %}

### Датчик освещенности DAQ

В этом разделе перечислены все файлы DAQ по нисходящему излучению (`.daq` / `.csv`) в вашем проекте — по одной строке на файл — с указанием модели датчика, имени файла и **ограничения** диффузора, действующего для данного файла.

* **Переопределение коэффициента (все файлы)**: единый раскрывающийся список для всего проекта.**Авто**(по умолчанию) использует записанный коэффициент каждого файла — если ничего не записано, предполагается солнечное излучение, поскольку все DAQ-файлы MAPIR поставляются с корректором солнечного излучения. Выбор значения**cap**переопределяет все файлы: исходные записи корректируются с его помощью, а записи, уже содержащие значение**cap**, пересчитываются (записанная коррекция отменяется, применяется выбранное значение**cap**).
* В строках отображаются предупреждения, если записанное ограничение было принято по умолчанию концентратором, а не подтверждено оператором, а также если для выбранного ограничения отсутствует профиль для данной модели устройства (в этом случае переопределение для данного файла не допускается).

Записи DAQ, сделанные на вкладке «Световые датчики», автоматически добавляются в открытый проект, а импортированные файлы `.daq` / `.csv` появляются здесь сразу после добавления.

При создании нового проекта:

2. Выберите шаблон проекта в дополнительном окне выбора шаблонов
3. Все настройки из шаблона применяются автоматически

### Рабочий каталог

Настройка **«Рабочий каталог»** определяет, где по умолчанию создаются новые проекты:

* **Местоположение по умолчанию**: `C:\Users\[Username]\Chloros Projects`
* **Изменить местоположение**: нажмите значок редактирования и выберите новую папку
* **Совместно с CLI**: `chloros-cli` использует ту же настройку папки проектов по умолчанию
* **Когда менять**:
  * Сетевой диск для совместной работы в команде
  * Другой диск с большим объёмом памяти
  * Упорядоченная структура папок по годам/клиентам

## Настройка PPK (Post-Processed Kinematic)

При использовании регистраторов данных MAPIR с GPS для точной геолокации:

### Необходимые условия

* Регистратор данных MAPIR с модулем GPS (GNSS)
* Файл журнала .daq с записями о контактах экспозиции
* Камера, подключённая к контактам экспозиции регистратора данных во время сеанса съёмки

### Этапы настройки

1. Поместите файл журнала .daq в папку проекта
2. В настройках проекта установите флажок **«Применять поправки PPK»**

3. При необходимости установите значение**«Смещение часового пояса датчика освещенности»** (по умолчанию: 0 для UTC)
4. Назначьте камеры выводам экспозиции:
   * **Одна камера**: автоматически назначается выводу 1
   * **Две камеры**: вручную назначьте каждую камеру соответствующему выводу**Назначение выводов экспозиции:*** **Контакт экспозиции 1**: выберите модель камеры из выпадающего списка
* **Контакт экспозиции 2**: выберите вторую камеру или «Не использовать»
* Одну и ту же камеру нельзя назначить на оба контакта

{% hint style="warning" %}
**Важно**: Контакты экспозиции должны быть правильно назначены соответствующим камерам. Неправильное назначение приведёт к получению неверных данных геолокации.
{% endhint %}

## Расширенные сценарии

### Проекты с несколькими камерами

При обработке изображений с нескольких камер MAPIR в одном проекте:

1. Chloros автоматически определяет модель каждой камеры (как Survey3, так и LATTICE)
2. Каждой камере назначаются соответствующие профили обработки, и для каждой камеры создаётся собственное дерево папок выходных данных
3. PPK: вручную назначьте каждой камере Survey3 правильный контакт экспозиции
4. Все камеры используют один и тот же формат экспорта и индексы

**Примеры**: Survey3W, RGN + Survey3N, OCN — установка с двумя камерами, или массив LATTICE, сочетающий ведущую камеру RGB с узкополосными модулями

### Замедленная съемка или съемки в разные даты

Для повторных съемок одного и того же участка в течение определенного периода времени:

1. Создайте шаблон со стандартными настройками
2. Используйте одинаковую конфигурацию калибровочных мишеней в каждой сессии
3. Обрабатывайте данные каждой даты как отдельный проект
4. Используйте идентичные настройки для получения сопоставимых результатов
5. Экспортируйте данные в одном формате для временного анализа

### Крупные наборы данных

Для проектов с большим количеством изображений (500+):

* Рассмотрите возможность разбиения на более мелкие проекты по дате или территории
* Используйте параллельную обработку Chloros+ для ускорения получения результатов
* Рассмотрите возможность использования CLI или API для автоматизации пакетной обработки
* Настройте минимальный интервал повторной калибровки, чтобы сократить время обнаружения целей
