# Настройка параметров проекта

Перед обработкой изображений важно настроить параметры проекта в соответствии с требованиями вашего рабочего процесса. Панель «Настройки проекта» <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> обеспечивает полный контроль над калибровкой, параметрами обработки, мультиспектральными индексами и форматами экспорта.

## Доступ к настройкам проекта

1. Откройте проект в программе Chloros
2. Нажмите на значок **«Настройки проекта»** <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> на левой боковой панели
3. На панели «Настройки проекта» отобразятся все параметры конфигурации

<figure><img src="../.gitbook/assets/image (28).png" alt=""><figcaption><p>Панель «Настройки проекта» — отображение, обнаружение целей и обработка</p></figcaption></figure>

{% hint style="info" %}
**Настройки сохраняются автоматически** вместе с проектом. При повторном открытии проекта все настройки восстанавливаются.
{% endhint %}

***

## Быстрая настройка для типичных рабочих процессов

### Настройки по умолчанию (рекомендуются для большинства пользователей)

Настройки по умолчанию хорошо подходят для типичных рабочих процессов с использованием Survey3
и LATTICE:

* ✅ **Коррекция виньетирования**: Включено
* ✅ **Калибровка отражательной способности / баланс белого**: Включено (использует мишени MAPIR
и/или данные светового датчика DAQ)
* ✅ **Метод дебайеризации**: Стандартный (быстрый, среднее качество)
* ✅ **Формат экспорта**: TIFF
(16-бит) (TIFF
(8-бит) для проектов, полностью использующих 8-битное разрешение)
* ✅ **Все экспортные продукты**: Включено (LATTICE автоматически сохраняет результаты дебайеризации, предварительный просмотр, радианцию и отражательную способность)

Просто импортируйте изображения и начните обработку с этими настройками по умолчанию.

## Обзор настроек проекта

Панель «Настройки проекта» состоит из приведённых ниже разделов. Два дополнительных раздела — **Световой датчик DAQ**и**Выравнивание массива** — появляются автоматически, если ваш проект содержит соответствующие файлы. Полную документацию см. в разделе [Настройки проекта](../project-settings/project-settings.md).

### Отображение

* **Разрешение миниатюр изображений**: разрешение миниатюр в сетке изображений. Варианты:**По умолчанию (512 пикселей)**,**1024 пикселя**,**2048 пикселей**,**Полное разрешение**. Этот параметр влияет только на отображение — он никогда не влияет на обработку. Более высокие значения обеспечивают более четкое изображение при увеличении, но загружаются медленнее.

### Обнаружение целей

Управляет тем, как Chloros
идентифицирует калибровочные цели на ваших изображениях.

**Ключевые настройки:*** **Минимальная площадь калибровочной выборки (px)**: пороговое значение размера для обнаружения целей (по умолчанию:**25**, диапазон 0–10000)
* **Минимальный коэффициент кластеризации целей (0–100)**: пороговое значение сходства для группировки областей целей (по умолчанию:**60**)**Когда следует настраивать:**

* Увеличьте площадь выборки, если возникают ложные обнаружения
* Уменьшите, если цели не обнаруживаются
* Настройте кластеризацию, если цели разбиваются на несколько обнаружений

{% hint style="info" %}
Эти настройки затенены, если отключена функция **«Калибровка отражательной способности / баланс белого»** — при её отключении обнаружение целей вообще не выполняется.
{% endhint %}

### Обработка

Основные параметры обработки изображений и калибровки.

**Ключевые настройки:*** **Коррекция виньетирования**: компенсирует затемнение по краям объектива ✅ Рекомендуется
* **Калибровка отражательной способности / баланс белого**: калибрует изображения с использованием обнаруженных мишеней (Survey3
) и/или данных светового датчика DAQ (LATTICE) ✅ Рекомендуется
* **Метод дебайеризации**: алгоритм преобразования RAW в 3-канальный мультиспектральный формат
* **Минимальный интервал повторной калибровки**: минимальное время в секундах между использованием калибровочных мишеней (по умолчанию:**0** = использовать все, диапазон 0–3600)**Некалиброванные резервные продукты:**Когда кадр не может быть откалиброван по отражательной способности (нет доступной мишени или калибровка отключена), он экспортируется в виде одного из двух резервных продуктов —**на каждый прогон приходится ровно один из этой пары**, выбираемый переключателем коррекции виньетирования:

* **Экспорт характеристик датчика**: записывает `Sensor_Response_Images` — используется, когда коррекция виньетирования**выключена*** **Экспорт с коррекцией виньетирования**: записывает `Vignette_Corrected_Images` — используется, когда коррекция виньетирования**включена**Флажок, который не используется, затенен. Снятие флажка с активного параметра полностью останавливает запись этого файла.**Результаты экспорта LATTICE** (отображаются для каждого проекта; относятся к снимкам, полученным с помощью LATTICE):

* **Экспорт с дебайеризацией**: линейное изображение без байеров (`Debayered_Images`): удалено тёмное смещение калибровочного набора, затем выполнена демозаика, без плоского поля или размикширования — тот же файл, который сохраняется при съёмке на уровне без байеров — в исходной ориентации датчика. Применимо к модулям RGB
и мультиспектральным модулям.
* **Экспорт предварительного просмотра**: изображение предварительного просмотра (`Preview_Images`). RGB
= баланс белого (источник освещения DAQ, если доступен, в противном случае — «серый мир») + гамма; мультиспектральный = растяжение в ложных цветах.
* **Экспорт яркости**: спектральная яркость типа float32 (`Radiance_Images`, Вт/м²/ср/нм). Только для мультиспектральных модулей — не применимо к мастер-файлам RGB
.
* **Экспорт коэффициента отражения**: коэффициент отражения типа uint16 (`Reflectance_Calibrated_Images`, DN 32768 = ρ 1,0), если показание нисходящего излучения `.daq` или цель внутри кадра охватывает весь кадр. Только для мультиспектральных модулей.

Все четыре параметра **включены по умолчанию**— один импортированный необработанный кадр LATTICE распределяется по всем включённым и применимым продуктам за один проход обработки. Флажок**«Экспорт коэффициента отражения»** затеняется, если калибровка коэффициента отражения отключена. Параметры, которые невозможно установить из-за положения родительского переключателя, всегда отображаются серыми с всплывающей подсказкой, указывающей название переключателя, который необходимо изменить.**Расширенные настройки:*** **Смещение часового пояса датчика освещенности**: количество часов относительно UTC для синхронизации времени датчика освещенности (по умолчанию: 0, диапазон от −12 до +12)
* **Применять поправки PPK**: использует данные GPS/экспозиционных контактов из файлов `.daq` (по умолчанию: выключено)
* **Экспозиционные контакты 1/2**: назначает камеры экспозиционным контактам для конфигураций с двумя камерами

{% hint style="info" %}
**Уровень входных данных LATTICE устанавливается автоматически.** Снимки LATTICE содержат информацию об уровне обработки в метаданных XMP, и обработка всегда начинается с необработанного кадра — в графическом интерфейсе пользователя настраивать ничего не нужно. (Флаг CLI
`--input-level` предназначен для опытных пользователей в качестве переопределения настроек при захватах с утраченными метаданными; см. [Справочник по CLI
](../reference/cli-reference.md).)
{% endhint %}

### Метод дебайеризации

В настоящее время в Chloros
доступны 2 метода дебайеризации:

#### Стандартный (быстрый, среднее качество)

Стандартный дебайеризатор работает быстро, но при этом возникает цветовой шум, что приводит к менее точным и более зашумленным изображениям.

#### С учётом текстуры (медленно, высочайшее качество) \[Только в Chloros
+]

Метод «С учётом текстуры» использует высококачественный алгоритм дебайеризации с учётом краёв в сочетании с моделью удаления шума на основе ИИ/машинного обучения, которая устраняет практически весь шум, возникающий при дебайеризации. Для работы модели требуется память графического процессора (VRAM): при **7 ГБ или более VRAM** она может обрабатывать несколько изображений одновременно; при объёме памяти менее 7 ГБ она обрабатывает по одному изображению за раз (заметно медленнее). См. [Динамическая адаптация вычислений](../processing-architecture/dynamic-compute-adaptation.md).

{% hint style="info" %}
**При съёмке LATTICE всегда используется стандартная демозаика.** Модели Texture Aware, обученной на данных LATTICE, не существует, поэтому этот параметр не предлагается для снимков LATTICE — однако снимки Survey3
в том же проекте по-прежнему могут использовать эту функцию.
{% endhint %}

Настройте, какие растительные индексы следует рассчитывать и экспортировать. В раскрывающемся списке графического интерфейса доступно **27 предустановленных формул индексов**.**Как добавить индексы:**

1. Нажмите кнопку**«Добавить индекс»**

2. Выберите индекс из раскрывающегося меню (NDVI
, NDRE
, GNDVI
и т. д.)
3. Настройте параметры визуализации (цвета LUT, диапазоны значений)
4. Добавьте несколько индексов по мере необходимости

**Популярные индексы:*** **NDVI**: общее состояние растительности (наиболее распространённый)

**Пользовательские формулы:**

* Сохраняйте пользовательские формулы для повторного использования
* Пользовательские формулы — это функция Chloros
+; их доступность зависит от уровня вашего тарифного плана

### Экспорт

Управляет форматом выходного файла.

**Доступные форматы**(параметр:**Формат откалиброванного изображения**, по умолчанию**TIFF
(16-бит)**):

* **TIFF
(16-бит)**: рекомендуется для ГИС и научного анализа
* **TIFF
(8-bit)**: 8-битный TIFF
* **TIFF
(32-bit, Percent)**: значения с плавающей запятой
* **PNG
(8-bit)**: сжатие без потерь для визуализации
* **JPG (8-bit)**: файлы наименьшего размера, сжатие с потерями

В списке указано, какие форматы могут иметь изображения проекта: Chloros
не увеличивает разрядность. Для всех 8-битных изображений доступны только форматы TIFF
(8-бит), PNG
(8-бит) и JPG (8-бит), а по умолчанию используется формат TIFF
(8-бит). В смешанном проекте каждый снимок экспортируется с собственной глубиной или ниже. Данные о яркости сохраняются в формате 32-битного числа с плавающей запятой.

Результаты записываются в папку проекта, сгруппированные по камерам и форматам: `<project>/<camera>/<format>/<Product>_Images/`. Данные Radiance **всегда** записываются в формате float32 в папку `tiff32`, независимо от данной настройки. Экспортированные файлы сохраняют имя исходного файла — папка идентифицирует продукт. При экспорте мультиспектральных данных LATTICE также могут записываться маски ограничения по пикселям в папку `clamp_masks/`, расположенную рядом с папками продуктов. См. раздел [Завершение обработки](finishing-the-processing.md) для ознакомления с полной структурой выходных файлов.

{% hint style="warning" %}
**Чтение значений коэффициента отражения**: значение DN, при котором ρ = 1,0, зависит от исходной камеры — LATTICE использует 32768 (указано в XMP-файле `Chloros:PixelScale`), а Survey3
— 65535. Считывайте значение тега, а не принимайте его за постоянную величину. См. [Форматы выходных изображений](../output-image-formats.md).
{% endhint %}

### Датчик освещенности DAQ

В этом разделе перечислены все файлы DAQ с нисходящим освещением (`.daq` / `.csv`) в вашем проекте, по одной строке на файл, с указанием модели датчика, имени файла и **ограничения** диффузора , действующую для данного файла.

* **Переопределение крышки (все файлы)**: единый раскрывающийся список для всего проекта.**Авто** (по умолчанию) использует записанное для каждого файла значение предела — если ничего не записано, предполагается солнечный свет, но DAQ-U, DAQ-M и DAQ-E поставляются без предела, и Chloros
не может определить, что было подобрано, поэтому при обработке выдается предупреждение о предполагаемом пределе: выберите тот предел, который был подобран. Выбор предела переопределяет значения для всех файлов, кроме файлов DAQ-E-S, диффузор которого является частью его калибровки: исходные записи корректируются с его учётом, а записи, уже содержащие предел, переоцениваются (записанная коррекция отменяется, применяется выбранный предел).
* В строках отображаются предупреждения, если записанный коэффициент соответствовал предполагаемому значению по умолчанию концентратора, а не был подтвержден оператором, а также если для выбранного коэффициента отсутствует профиль для данной модели устройства (в этом случае переопределение для данного файла отклоняется).

Записи DAQ, сделанные на вкладке «Световые датчики», автоматически добавляются в открытый проект, а импортированные файлы `.daq` / `.csv` появляются здесь сразу после добавления.

Этот раздел появляется **только** в том случае, если хотя бы одно изображение в проекте содержит преобразование для выравнивания модулей, которое массивы LATTICE наносят при съемке (`Chloros:Alignment*` XMP). ## Сохранение и загрузка настроек

### Сохранение шаблона проекта

Создавайте повторно используемые шаблоны для обеспечения единообразных рабочих процессов:

1. Настройте все необходимые параметры на панели «Настройки проекта»
2. Прокрутите вниз до раздела **«Сохранить шаблон проекта»**

3. Введите описательное имя шаблона (например, «Survey3N

\_RGN\_Agriculture»)
4. Нажмите значок сохранения

**Преимущества:**

* Применение одинаковых настроек к нескольким проектам
* Обмен конфигурациями с членами команды
* Обеспечение единообразия при повторных съемках

### Загрузка шаблона в новый проект

При создании нового проекта:

1. Выберите **«Новый проект»** в главном меню
2. Выберите шаблон проекта в дополнительном окне выбора шаблонов
3. Все настройки из шаблона применяются автоматически

### Рабочий каталог

Настройка **«Рабочий каталог»** определяет, где по умолчанию создаются новые проекты:

* **Местоположение по умолчанию**: `Documents\MAPIR\Chloros Projects` в папке «Документы» Windows

(обычно `C:\Users\[Username]\Documents\MAPIR\Chloros Projects`; она следует за папкой «Документы», если OneDrive или роуминг-профиль перемещают её)
* **Изменить расположение**: нажмите значок редактирования и выберите новую папку
* **Совместное использование с CLI**: `chloros-cli` использует ту же настройку папки проекта по умолчанию
* **Используйте короткие пути в Windows**: если не включена поддержка длинных путей в Windows

, папка проекта, длина пути к которой превышает примерно 130 символов, будет отклонена перед обработкой — см. [Запуск обработки](starting-the-processing.md#the-project-folder-is-too-deep-for-this-computer)
* **Когда следует изменить**:
  * Сетевой диск для совместной работы в команде
  * Другой диск с большим объёмом памяти
  * Упорядоченная структура папок по годам/клиентам

## Настройка PPK (Post-Processed Kinematic)

При использовании регистраторов данных MAPIR

с GPS для точной геолокации:

### Необходимые условия

* Регистратор данных MAPIR

с модулем GPS (GNSS)
* Файл журнала .daq с записями о контактах экспозиции
* Камера, подключённая к контактам экспозиции регистратора данных во время сеанса съёмки

### Этапы настройки

1. Поместите файл журнала .daq в папку проекта
2. В настройках проекта установите флажок **«Применять поправки PPK»**

3. При необходимости установите значение**«Смещение часового пояса датчика освещённости»** (по умолчанию: 0 для UTC)
4. Назначьте камеры контактам экспозиции:
   * **Одна камера**: автоматически назначается контакту 1
   * **Две камеры**: вручную назначьте каждую камеру соответствующему контакту**Назначение контактов экспозиции:*** **Контакт экспозиции 1**: выберите модель камеры из раскрывающегося списка
* **Контакт экспозиции 2**: выберите вторую камеру или «Не использовать»
* Одну и ту же камеру нельзя назначить на оба контакта

{% hint style="warning" %}
**Важно**: Контакты экспозиции должны быть правильно назначены соответствующим камерам. Неправильное назначение приведёт к получению неверных данных геолокации.
{% endhint %}

## Расширенные сценарии

### Проекты с несколькими камерами

При обработке изображений с нескольких камер MAPIR

в одном проекте:

1. Chloros

автоматически определяет модель каждой камеры (как Survey3

, так и LATTICE)
2. Каждая камера получает соответствующие профили обработки, а также собственное дерево выходных папок
3. PPK: вручную присвойте каждой камере Survey3

правильный контакт экспозиции
4. Все камеры используют одинаковый формат экспорта и индексы

**Примеры**: двухкамерная установка Survey3W

RGN

+ Survey3N

OCN

или массив LATTICE, сочетающий основную камеру RGB

с узкополосными модулями

### Таймлапс или съемки в разные даты

Для повторных съемок одного и того же участка в течение определенного периода времени:

1. Создайте шаблон со стандартными настройками
2. Используйте одинаковую конфигурацию калибровочных мишеней в каждой сессии
3. Обрабатывайте данные каждой даты как отдельный проект
4. Используйте идентичные настройки для получения сопоставимых результатов
5. Экспортируйте данные в одном формате для временного анализа

### Крупные наборы данных

Для проектов с большим количеством изображений (500+):

* Рассмотрите возможность разбиения на более мелкие проекты по дате или области
* Используйте параллельную обработку в Chloros

+ для ускорения получения результатов
* Рассмотрите возможность использования CLI

или API

для автоматизации пакетной обработки
* Настройте минимальный интервал повторной калибровки, чтобы сократить время обнаружения мишеней
