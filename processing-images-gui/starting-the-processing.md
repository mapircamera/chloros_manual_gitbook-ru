# Запуск обработки

После импорта изображений, маркировки калибровочных мишеней и настройки параметров проекта вы готовы приступить к обработке. На этой странице приведены инструкции по запуску конвейера обработки Chloros.

## Контрольный список перед обработкой

Прежде чем нажать кнопку «Пуск», убедитесь, что всё готово:

* [ ] **Файлы импортированы** — все изображения отображаются в обозревателе файлов
* [ ] **Изображения-мишени отмечены** — в столбце «Мишени» отмечены калибровочные изображения (или импортирована запись `.daq` для LATTICE)
* [ ] **Модели камер определены** — в столбце «Модель камеры» указаны правильные камеры
* [ ] **Настройки сконфигурированы** — настройки проекта проверены и скорректированы
* [ ] **Индексы выбраны** — добавлены нужные мультиспектральные индексы (при необходимости)
* [ ] **Формат экспорта выбран** — выбран формат вывода, подходящий для вашего рабочего процесса

{% hint style="info" %}
**Совет**: Перед обработкой просмотрите несколько изображений в файловом браузере, чтобы убедиться, что они загрузились правильно.
{% endhint %}

***

## Запуск обработки

### Найдите кнопку «Пуск»

Кнопка «Пуск/Воспроизведение» расположена в верхней панели заголовка Chloros:

* Расположение: вверху по центру окна
* Значок: **Кнопка «Воспроизведение/Пуск»** <img src="../.gitbook/assets/image (2) (1) (1).png" alt="" data-size="line">
* Состояние: кнопка активна (светящаяся), когда система готова к обработке

### Нажмите, чтобы начать

1. Нажмите **кнопку «Воспроизведение/Старт»** в верхней панели заголовка
2. Обработка начнётся немедленно
3. Во время обработки кнопка превращается в кнопку **«Стоп»**

4. Индикатор выполнения обновляется, отображая статус обработки

{% hint style="success" %}
**Обработка запущена**: после нажатия Chloros автоматически выполняет все этапы обработки — обнаружение объекта, дебайеринг, калибровку, расчёт индекса и экспорт. Программа автоматически определяет, является ли ваш проект Survey3, LATTICE или их комбинацией, и применяет к каждой камере соответствующий конвейер обработки.
{% endhint %}

## Описание режимов обработки

Chloros работает в двух различных режимах обработки в зависимости от вашей лицензии:

### Бесплатный режим (последовательная обработка)

**Доступен всем пользователям**

**Принцип работы:**

* Обрабатывает изображения по одному, последовательно
* Однопоточная работа
* Меньшее потребление памяти

**Индикатор выполнения показывает 2 этапа:**

1.**Обнаружение мишеней** — сканирование в поисках калибровочных мишеней
2. **Обработка** — применение калибровки и экспорт изображений**Время обработки:**

* Значительно медленнее, чем в параллельном режиме Chloros+
* Подходит для небольших и средних наборов данных (&lt; 200 изображений)

### Режим Chloros+ (параллельная обработка)

**Требуется лицензия Chloros+**

**Принцип работы:**

* Одновременная обработка нескольких изображений с использованием [4-потокового конвейера обработки](../processing-architecture/processing-pipeline.md)
* [Динамическая адаптация вычислений](../processing-architecture/dynamic-compute-adaptation.md) автоматически выбирает оптимальную стратегию для вашего оборудования при запуске
* Ускорение на GPU (CUDA) с помощью графических карт NVIDIA (настольные ПК и Jetson)
* **Количество рабочих процессов адаптируется к аппаратному обеспечению**: стратегии с использованием GPU запускают**от 1 до 4 параллельных рабочих процессов** (масштабируются в зависимости от объёма VRAM — на Jetson с небольшим объёмом памяти запускается 1, а на настольном GPU с объёмом 12 ГБ и более — до 4); системы, использующие только CPU, запускают по одному рабочему процессу на каждое физическое ядро, минус один**Индикатор выполнения отображает 4 этапа** (соответствующие 4 потокам конвейера):

1. **Обнаружение** (поток 1) — поиск объектов калибровки
2. **Анализ** (поток 2) — изучение метаданных изображения и вычисление калибровки
3. **Калибровка** (поток 3) — дебейеринг, коррекция виньетирования, калибровка, вычисление индекса
4. **Экспорт** (поток 4) — сохранение обработанных изображений и индексов**Взаимодействие с индикатором выполнения:*** **Наведите курсор мыши** на индикатор, чтобы увидеть подробную раскрывающуюся панель с 4 этапами
* **Щелкните** по индикатору выполнения, чтобы зафиксировать раскрывающуюся панель на месте
* **Щелкните ещё раз**, чтобы отменить фиксацию и скрыть панель**Время обработки:**

* Значительно быстрее, чем в бесплатном режиме
* Ускорение на GPU ещё больше повышает скорость

{% hint style="info" %}
**Chloros+ Скорость**: Параллельная обработка может быть в 5–10 раз быстрее, чем последовательный режим, при работе с большими наборами данных. Проект из 500 изображений, обработка которого в бесплатном режиме занимает 2 часа, с Chloros+ может завершиться за 15–20 минут.
{% endhint %}

## Что происходит во время обработки

### Этап 1: Обнаружение мишеней

**Что делает Chloros:**

* Сканирует изображения, отмеченные в столбце «Мишень» (все изображения, если ни одно не отмечено)
* Идентифицирует калибровочные панели на каждой мишени
* Извлекает значения коэффициентов отражения с панелей мишеней
* Записывает временные метки мишеней для планирования калибровки

**Продолжительность:** 1–30 секунд (с отмеченными мишенями), 5–30+ минут (без отметок)

### Этап 2: Дебайеризация (Преобразование RAW)

**Что делает Chloros:**

* Преобразует данные RAW с матрицей Байера в полноценные 3-канальные изображения (монохромные модули LATTICE остаются однополосными — для них дебайеринг пропускается с соответствующей записью в журнале)
* Применяет выбранный алгоритм демозаики
* Сохраняет максимальное качество изображения и детали

**Продолжительность:** Зависит от количества изображений и скорости ЦП/ГП

### Этап 3: Калибровка

**Что делает Chloros:*** **Коррекция виньетирования**: устраняет затемнение по краям изображения
* **Калибровка отражательной способности**: нормализует значения с использованием эталонных значений отражательной способности и/или данных о нисходящем излучении, полученных системой сбора данных (DAQ)
* Применяет коррекции ко всем диапазонам/каналам
* Использует соответствующий калибровочный эталон для каждого изображения на основе временной метки

**Продолжительность:** Основная часть времени обработки

### Этап 4: Расчёт индексов

**Что делает Chloros:**

* Вычисляет настроенные мультиспектральные индексы (NDVI, NDRE и т. д.)
* Применяет математические операции с полосами к откалиброванным изображениям
* Генерирует индексные изображения для каждого выбранного индекса

**Продолжительность:** Несколько секунд на каждое изображение

### Этап 5: Экспорт

**Что делает Chloros:**

* Сохраняет обработанные изображения в выбранном формате
* **Расширенный вывод LATTICE**: каждый необработанный кадр LATTICE экспортируется как все включённые продукты за один проход — с удалением байеров, предварительный просмотр, яркость (всегда float32), отражательная способность
* Записывает файлы в дерево выходных данных проекта: `<project>/<camera>/<format>/<Product>_Images/`
* **Сохраняет исходное имя файла** — папка идентифицирует продукт, суффикс не добавляется**Продолжительность:** Зависит от формата экспорта и размера файла***

## Поведение при обработке

### Автоматический конвейер обработки

После запуска весь конвейер работает автоматически:

* Взаимодействие с пользователем не требуется
* Все настроенные этапы выполняются последовательно
* Информация о ходе обработки отображается в режиме реального времени
* Экспортированные файлы записываются на диск по мере завершения — вы можете открывать готовые результаты, пока процесс продолжается

### Нагрузка на компьютер во время обработки

**Свободный режим:**

* Относительно низкая загрузка ЦП (однопоточный режим)
* Компьютер продолжает нормально реагировать на другие задачи
* Можно безопасно свернуть окно Chloros и работать в других приложениях

**Параллельный режим Chloros+:**

* Высокая загрузка ЦП во всем пуле рабочих процессов стратегии
* При ускорении на GPU: высокая загрузка GPU
* Во время обработки компьютер может работать с задержками
* Старайтесь не запускать другие задачи, интенсивно использующие ЦП

{% hint style="warning" %}
**Совет по повышению производительности**: для достижения максимальной производительности Chloros+ закройте другие приложения и позвольте Chloros использовать все системные ресурсы.
{% endhint %}

### Обработку нельзя приостановить (но остановка выполняется корректно)

* После запуска обработку нельзя приостановить и возобновить позже
* Нажатие кнопки **«Стоп»** полностью останавливает запуск с первого нажатия
* Продукты, уже экспортированные до остановки, остаются на диске
* Остановленный запуск точно отражает, что было выполнено (см. строки `[RUN-SUMMARY]` в журнале)
* При запуске нового цикла обработка начинается с самого начала

**Совет по планированию:** для очень крупных проектов рекомендуется рассматривать возможность пакетной обработки или использования CLI для лучшего контроля.***

## Мониторинг обработки

Во время выполнения обработки вы можете:

* **Наблюдать за индикатором выполнения** — просматривать общий процент выполнения
* **Просматривать текущий этап** — «Обнаружение», «Анализ», «Калибровка» или «Экспорт»
* **Просматривать вкладку «Журнал»** — просматривать подробные сообщения и предупреждения об обработке
* **Просматривать готовые изображения** — файлы экспорта появляются на диске в процессе обработки

Подробную информацию о мониторинге см. в разделе [Мониторинг обработки](monitoring-the-processing.md).

## Остановка обработки

Если вам необходимо остановить обработку:

### Как остановить

1. Найдите **кнопку «Остановить»** (во время обработки она заменяет кнопку «Пуск»)
2. Нажмите её один раз — на полосе отобразится надпись **«Остановка...»**, пока завершается обработка текущего изображения
3. Цикл завершается в состоянии окончательной остановки, а в журнале выводится точный отчет `[RUN-SUMMARY]` о том, что было выполнено

### Когда следует остановить

**Уважительные причины для остановки:**

* Обнаружено, что использовались неверные настройки
* Забыли отметить целевые изображения
* Импортированы не те изображения
* Система работает слишком медленно или не отвечает

**После остановки:**

* Результаты, экспортированные до остановки, остаются на диске
* Проверьте и устраните любые проблемы, при необходимости скорректируйте настройки
* Перезапустите обработку — цикл начнётся с начала

## Оценка времени обработки

Фактическое время обработки значительно варьируется в зависимости от:

* Количества изображений
* Разрешения изображений
* Формата входных данных (RAW или JPG)
* Режима обработки (Free или Chloros+)
* Скорости процессора и количества ядер
* Наличие графического процессора (только Chloros+)
* Количество рассчитываемых индексов
* Количество включенных продуктов экспорта (LATTICE)

### Приблизительные оценки (Chloros+, изображения 12 МП, современный процессор)

| Количество изображений | Бесплатный режим | Chloros+ (ЦП) | Chloros+ (графический процессор) |
| ----------- | --------- | -------------- | -------------- |
| 50 изображений   | 15–20 мин | 5–8 мин        | 3–5 мин        |
| 100 изображений  | 30–40 мин | 10–15 мин      | 5–8 мин        |
| 200 изображений  | 1–1,5 ч | 20–30 мин      | 10–15 мин      |
| 500 изображений  | 2–3 часа   | 45–60 мин      | 20–30 мин      |
| 1000 изображений | 4–6 часов   | 1,5–2 часа      | 40–60 мин      |

{% hint style="info" %}
**Первый запуск**: Первоначальная обработка может занять больше времени, поскольку Chloros создаёт кэши и профили. Последующая обработка аналогичных наборов данных будет проходить быстрее.
{% endhint %}

## Распространённые проблемы при запуске

### Кнопка «Пуск» отключена (затенена)

**Возможные причины:**

* Изображения не импортированы
* Бэкенд не полностью запущен
* Предыдущая обработка всё ещё выполняется
* Проект не полностью загружен

**Решения:**

1. Дождитесь полной инициализации бэкенда (проверьте значок в главном меню)
2. Убедитесь, что изображения импортированы в файловый браузер
3. Перезапустите Chloros, если кнопка по-прежнему отключена
4. Проверьте журнал отладки на наличие сообщений об ошибках

### Обработка запускается, но сразу же завершается сбоем

**Возможные причины:**

* В проекте нет допустимых изображений
* Поврежденные файлы изображений
* Недостаточно места на диске
* Недостаточно оперативной памяти (RAM)

**Решения:**

1. Проверьте журнал отладки <img src="../.gitbook/assets/icon_log.JPG" alt="" data-size="line"> на наличие сообщений об ошибках
2. Убедитесь в наличии свободного места на диске
3. Попробуйте обработать меньший набор изображений
4. Убедитесь, что изображения не повреждены

### Запуск завершился, но изображения не записаны

Запуск, в ходе которого запрашивались продукты на основе изображений, но ни один из них не был записан, рассматривается как **сбой, а не успех** — об этом громко сообщает Chloros:

* В журнале графического интерфейса выводится сообщение `[RUN-SUMMARY]`, указывающее на вероятную причину — изображения не импортированы, цель не обнаружена или все запрошенные продукты были пропущены как неприменимые (например, запрос на радианцию/отражательную способность с камер, поддерживающих только RGB)
* Эквивалент CLI (`chloros-cli process`) выводит сообщение `Processing finished but wrote no image products.` и **завершается с ненулевым кодом**, что позволяет скриптам обнаружить эту ошибку
* Намеренный запуск только с метаданными (все экспортные продукты отключены, индексы отсутствуют) всё равно считается успешным

См. [справочник по CLI](../reference/cli-reference.md#a-run-that-writes-no-images-fails) для полного описания семантики.

### Предупреждение «Цели не обнаружены»

**Возможные причины:**

* Забыли пометить изображения-цели
* Изображения-цели не содержат видимых целей
* Слишком строгие настройки обнаружения целей

**Решения:**

1. Ознакомьтесь с разделом [Выбор изображений с целями](choosing-target-images.md)
2. Отметьте соответствующие изображения в столбце «Цель»
3. Убедитесь, что цели видны на отмеченных изображениях
4. При необходимости скорректируйте настройки обнаружения целей

## Советы по успешной обработке

### Перед началом

1. **Сначала проведите тестирование на небольшом поднаборе** — обработайте 10–20 изображений для проверки настроек
2. **Проверьте доступное место на диске** — убедитесь, что свободного места в 2–3 раза больше, чем размер набора данных (больше, если включены все продукты LATTICE)
3. **Закройте ненужные приложения** — освободите системные ресурсы
4. **Проверьте изображения целей** — просмотрите помеченные цели, чтобы убедиться в качестве
5. **Сохраните проект** — проект сохраняется автоматически, но рекомендуется сохранять его вручную

### Во время обработки

1. **Избегайте перехода системы в спящий режим** — отключите режимы энергосбережения
2. **Держите Chloros на переднем плане** — или, по крайней мере, видимым на панели задач
3. **Периодически следите за ходом обработки** — проверяйте наличие предупреждений или ошибок
4. **Не запускайте другие ресурсоемкие приложения** — особенно при работе Chloros+ в параллельном режиме

### Chloros+ — ускорение на GPU

При использовании ускорения на GPU NVIDIA:

1. Обновите драйверы NVIDIA до последней версии
2. Убедитесь, что графический процессор имеет 4 ГБ и более видеопамяти (7 ГБ и более для одновременного дебайеринга с поддержкой текстур)
3. Закройте приложения, интенсивно использующие графический процессор (игры, программы для редактирования видео)
4. Контролируйте температуру графического процессора (обеспечьте надлежащее охлаждение)
