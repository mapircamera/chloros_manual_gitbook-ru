# Запуск обработки

После импорта изображений, маркировки калибровочных мишеней и настройки параметров проекта вы готовы приступить к обработке. На этой странице приведены инструкции по запуску конвейера обработки Chloros.

## Контрольный список перед началом обработки

Перед тем как нажать кнопку «Старт», убедитесь, что все готово:

* [ ] **Файлы импортированы** — все изображения отображаются в файловом браузере
* [ ] **Целевые изображения отмечены** — в столбце «Цель» отмечены изображения для калибровки
* [ ] **Модели камер определены** — в столбце «Модель камеры» указаны правильные камеры
* [ ] **Настройки сконфигурированы** — настройки проекта проверены и скорректированы
* [ ] **Выбраны индексы** — добавлены нужные мультиспектральные индексы (при необходимости)
* [ ] **Выбран формат экспорта** — выбран формат вывода, подходящий для вашего рабочего процесса

{% hint style="info" %}
**Совет**: Просмотрите несколько изображений в браузере файлов, чтобы убедиться, что они загрузились правильно, перед началом обработки.
{% endhint %}

## Запуск обработки

### Найдите кнопку «Старт»

Кнопка «Старт/Воспроизведение» расположена в верхней панели заголовка Chloros:

* Положение: вверху по центру окна
* Значок: **Кнопка «Воспроизведение/Старт»** <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line">
* Статус: кнопка активна (светится), когда готова к обработке

### Нажмите, чтобы начать

1. Нажмите **кнопку «Воспроизведение/Старт»** в верхней панели заголовка
2. Обработка начинается немедленно
3. Во время обработки кнопка становится неактивной (затемняется)
4. Индикатор выполнения обновляется, отображая статус обработки

{% hint style="success" %}
**Обработка начата**: После нажатия Chloros автоматически выполняет все этапы обработки — обнаружение объекта, дебайеринг, калибровку, расчет индекса и экспорт.
{% endhint %}

## Понимание режимов обработки

Chloros работает в двух различных режимах обработки в зависимости от вашей лицензии:

### Бесплатный режим (последовательная обработка)

**Доступно для всех пользователей**

**Как это работает:**

* Обрабатывает изображения по одному, последовательно
* Однопоточная работа
* Меньшее использование памяти

**Индикатор выполнения показывает 2 этапа:**

1.**Обнаружение мишеней** — сканирование в поисках калибровочных мишеней
2. **Обработка** — применение калибровки и экспорт изображений**Время обработки:**

* Намного медленнее, чем в параллельном режиме Chloros+
* Подходит для небольших и средних наборов данных (&lt; 200 изображений)

### Режим Chloros+ (параллельная обработка)

**Требуется лицензия Chloros+**

**Как это работает:**

* Одновременная обработка нескольких изображений с использованием [4-поточного конвейера обработки](../processing-architecture/processing-pipeline.md)
* [Динамическая адаптация вычислений](../processing-architecture/dynamic-compute-adaptation.md) автоматически выбирает оптимальную стратегию для вашего оборудования
* Ускорение на GPU (CUDA) с помощью видеокарт NVIDIA (настольные ПК и Jetson)
* Масштабируется от Jetson Nano (1 рабочий процесс) до настольного ПК с GPU объемом 12 ГБ и более (3–4 рабочих процесса)

**Индикатор выполнения показывает 4 этапа** (соответствующие 4 потокам конвейера):

1. **Обнаружение** (поток 1) — поиск объектов калибровки
2. **Анализ** (поток 2) — изучение метаданных изображения и вычисление калибровки
3. **Калибровка** (поток 3) — дебайеринг на GPU, коррекция виньетирования, вычисление индекса
4. **Экспорт** (поток 4) — сохранение обработанных изображений и индексов**Взаимодействие с индикатором выполнения:*** **Наведите курсор мыши** на индикатор, чтобы увидеть подробную раскрывающуюся панель с 4 этапами
* **Щелкните** по индикатору выполнения, чтобы зафиксировать раскрывающуюся панель на месте
* **Щелкните еще раз**, чтобы разблокировать и скрыть панель**Время обработки:**

* Значительно быстрее, чем в бесплатном режиме
* Масштабируется в зависимости от количества ядер процессора
* Ускорение на GPU еще больше повышает скорость

{% hint style="info" %}
**Chloros+ Скорость**: Параллельная обработка может быть в 5–10 раз быстрее, чем последовательный режим, для больших наборов данных. Проект из 500 изображений, который занимает 2 часа в бесплатном режиме, может быть завершен за 15–20 минут с Chloros+.
{% endhint %}

## Что происходит во время обработки

### Этап 1: Обнаружение мишеней

**Что делает Chloros:**

* Сканирует отмеченные изображения мишеней (или все изображения, если ни одно не отмечено)
* Идентифицирует 4 калибровочных панели в каждой мишени
* Извлекает значения отражения из панелей мишеней
* Записывает временные метки мишеней для планирования калибровки

**Продолжительность:** 1–30 секунд (с отмеченными целями), 5–30+ минут (без отмеченных целей)

### Этап 2: Дебайеринг (преобразование RAW)

**Что делает Chloros:**

* Преобразует данные RAW в формате Байера в полные изображения RGB
* Применяет высококачественный алгоритм демозаикирования
* Сохраняет максимальное качество и детали изображения

**Продолжительность:** Зависит от количества изображений и скорости процессора

### Этап 3: Калибровка

**Что делает Chloros:*** **Коррекция виньетирования**: устраняет затемнение по краям изображения
* **Калибровка отражательной способности**: нормализует с использованием эталонных значений отражательной способности
* Применяет коррекции ко всем полосам/каналам
* Использует соответствующий калибровочный эталон для каждого изображения на основе временной метки

**Продолжительность:** большая часть времени обработки

### Этап 4: Расчет индексов

**Что делает Chloros:**

* Рассчитывает настроенные мультиспектральные индексы (NDVI, NDRE и т. д.)
* Применяет математические операции с диапазонами к откалиброванным изображениям
* Генерирует индексные изображения для каждого выбранного индекса

**Продолжительность:** Несколько секунд на каждое изображение

### Этап 5: Экспорт

**Что делает Chloros:**

* Сохраняет откалиброванные изображения в выбранном формате
* Экспортирует индексные изображения с настроенными цветами LUT
* Записывает файлы в подпапки моделей камер
* Сохраняет исходные имена файлов с суффиксами

**Продолжительность:** Зависит от формата экспорта и размера файла***

## Поведение при обработке

### Автоматический конвейер обработки

После запуска весь конвейер работает автоматически:

* Взаимодействие с пользователем не требуется
* Все настроенные шаги выполняются последовательно
* Отображение хода выполнения в режиме реального времени

### Использование ресурсов компьютера во время обработки

**Свободный режим:**

* Относительно низкая загрузка ЦП (однопоточный режим)
* Компьютер остается отзывчивым для других задач
* Можно безопасно свернуть Chloros и работать в других приложениях

**Chloros+ Параллельный режим:**

* Высокая загрузка ЦП (многопоточный режим, до 16 ядер)
* С ускорением на GPU: высокая загрузка GPU
* Во время обработки компьютер может реагировать медленнее
* Избегайте запуска других задач, интенсивно использующих процессор

{% hint style="warning" %}
**Совет по производительности**: Для достижения максимальной производительности Chloros+ закройте другие приложения и позвольте Chloros использовать все системные ресурсы.
{% endhint %}

### Обработку нельзя приостановить

**Важные ограничения:**

* После запуска обработку нельзя приостановить
* Вы можете отменить обработку, но прогресс будет утрачен
* Частичные результаты не сохраняются
* В случае отмены необходимо начать сначала

**Совет по планированию:** Для очень больших проектов рассмотрите возможность обработки партиями или использования CLI для лучшего контроля.***

## Мониторинг обработки

Во время выполнения обработки вы можете:

* **Наблюдать за индикатором выполнения** — просматривать общий процент выполнения
* **Просматривать текущий этап** — «Обнаружение», «Анализ», «Калибровка» или «Экспорт»
* **Просматривать вкладку журнала** — просматривать подробные сообщения и предупреждения об обработке
* **Просматривать готовые изображения** — некоторые файлы экспорта могут появляться во время обработки

Подробную информацию о мониторинге см. в разделе [Мониторинг обработки](monitoring-the-processing.md).

## Отмена обработки

Если вам нужно остановить обработку:

### Как отменить

1. Найдите **кнопку «Стоп/Отмена»** (заменяет кнопку «Старт» во время обработки)
2. Нажмите кнопку «Стоп»
3. Обработка немедленно останавливается
4. Неполные результаты отбрасываются

### Когда отменять

**Допустимые причины для отмены:**

* Осознание того, что были использованы неверные настройки
* Забыли отметить целевые изображения
* Импортированы неверные изображения
* Система работает слишком медленно или не отвечает

**После отмены:**

* Проверьте и исправьте любые проблемы
* Настройте параметры по мере необходимости
* Перезапустите обработку с начала
* Для оптимальной работы полностью закройте Chloros и перезапустите

{% hint style="warning" %}
**Отсутствие частичных результатов**: Отмена приводит к удалению всего прогресса. Chloros не сохраняет частично обработанные изображения.
{% endhint %}

## Оценка времени обработки

Фактическое время обработки сильно зависит от:

* Количества изображений
* Разрешения изображений
* Входного формата (RAW или JPG)
* Режима обработки (Free или Chloros+)
* Скорости процессора и количества ядер
* Наличия графического процессора (только для Chloros+)
* Количество индексаций, подлежащих расчету
* Сложность формата экспорта

### Приблизительные оценки (Chloros+, изображения 12 Мп, современный процессор)

| Количество изображений | Бесплатный режим | Chloros+ (CPU) | Chloros+ (GPU) |
| ----------- | --------- | -------------- | -------------- |
| 50 изображений   | 15–20 мин | 5–8 мин        | 3–5 мин        |
| 100 изображений  | 30–40 мин | 10–15 мин      | 5–8 мин        |
| 200 изображений  | 1–1,5 ч | 20–30 мин      | 10–15 мин      |
| 500 изображений  | 2–3 ч   | 45–60 мин      | 20–30 мин      |
| 1000 изображений | 4–6 ч   | 1,5–2 ч      | 40–60 мин      |

{% hint style="info" %}
**Первый запуск**: Первоначальная обработка может занять больше времени, так как Chloros создает кэши и профили. Последующая обработка аналогичных наборов данных будет проходить быстрее.
{% endhint %}

## Распространенные проблемы при запуске

### Кнопка «Пуск» отключена (затенена)

**Возможные причины:**

* Изображения не импортированы
* Бэкэнд не полностью запущен
* Предыдущая обработка все еще выполняется
* Проект не полностью загружен

**Решения:**

1. Подождите, пока бэкэнд полностью инициализируется (проверьте значок в главном меню)
2. Убедитесь, что изображения импортированы в файловом браузере
3. Перезапустите Chloros, если кнопка остается неактивной
4. Проверьте журнал отладки на наличие сообщений об ошибках

### Обработка запускается, но сразу же завершается сбоем

**Возможные причины:**

* В проекте нет допустимых изображений
* Поврежденные файлы изображений
* Недостаточно места на диске
* Недостаточно памяти (RAM)

**Решения:**

1. Проверьте журнал отладки <img src="../.gitbook/assets/icon_log.JPG" alt="" data-size="line"> на наличие сообщений об ошибках
2. Проверьте доступное место на диске
3. Попробуйте обработать меньший набор изображений
4. Убедитесь, что изображения не повреждены

### Предупреждение «Цели не обнаружены»

**Возможные причины:**

* Забыли отметить целевые изображения
* Целевые изображения не содержат видимых целей
* Слишком строгие настройки обнаружения целей

**Решения:**

1. Ознакомьтесь с разделом [Выбор целевых изображений](choosing-target-images.md)
2. Отметьте соответствующие изображения в столбце «Цель»
3. Убедитесь, что цели видны на отмеченных изображениях
4. При необходимости настройте параметры обнаружения целей

## Советы для успешной обработки

### Перед началом

1. **Сначала проведите тестирование на небольшом поднаборе** — обработайте 10–20 изображений для проверки настроек
2. **Проверьте доступное место на диске** — убедитесь, что свободного места в 2–3 раза больше, чем размер набора данных
3. **Закройте ненужные приложения** — освободите системные ресурсы
4. **Проверьте целевые изображения** — просмотрите отмеченные цели, чтобы убедиться в их качестве
5. **Сохраните проект** — проект сохраняется автоматически, но рекомендуется сохранять его вручную

### Во время обработки

1. **Избегайте перехода системы в спящий режим** — отключите режимы энергосбережения
2. **Держите Chloros на переднем плане** — или, по крайней мере, видимым на панели задач
3. **Периодически следите за ходом работы** — проверяйте наличие предупреждений или ошибок
4. **Не запускайте другие ресурсоемкие приложения** — особенно в параллельном режиме Chloros+

### Ускорение на GPU в Chloros+

При использовании ускорения на GPU NVIDIA:

1. Обновите драйверы NVIDIA до последней версии
2. Убедитесь, что GPU имеет 4 ГБ и более видеопамяти
3. Закройте приложения, интенсивно использующие графический процессор (игры, редактирование видео)
4. Контролируйте температуру графического процессора (обеспечьте адекватное охлаждение)
