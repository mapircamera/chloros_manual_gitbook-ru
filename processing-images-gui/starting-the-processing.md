# Запуск обработки

После импорта изображений, маркировки калибровочных мишеней и настройки параметров проекта вы готовы приступить к обработке. На этой странице приведены инструкции по запуску конвейера обработки Chloros.

## Контрольный список перед началом обработки

Прежде чем нажать кнопку «Start», убедитесь, что всё готово:

* [ ] **Файлы импортированы** — все изображения отображаются в браузере файлов
* [ ] **Целевые изображения отмечены** — в столбце «Цель» отмечены калибровочные изображения (или импортирована запись `.daq` для LATTICE)
* [ ] **Модели камер определены** — в столбце «Модель камеры» указаны правильные камеры
* [ ] **Настройки сконфигурированы** — настройки проекта проверены и скорректированы
* [ ] **Индексы выбраны** — добавлены нужные мультиспектральные индексы (при необходимости)
* [ ] **Выбран формат экспорта** — выбран формат вывода, подходящий для вашего рабочего процесса

{% hint style="info" %}
**Совет**: Перед обработкой просмотрите несколько изображений в браузере файлов, чтобы убедиться, что они загрузились правильно.
{% endhint %}

***

## Запуск обработки

### Найдите кнопку «Пуск»

Кнопка «Пуск/Воспроизведение» расположена в верхней панели заголовка программы Chloros:

* Расположение: вверху по центру окна
* Значок: **Кнопка «Пуск/Воспроизведение»** <img src="../.gitbook/assets/image (2) (1) (1).png" alt="" data-size="line">
* Состояние: кнопка активна (светящаяся), когда программа готова к обработке

### Нажмите, чтобы начать

1. Нажмите **кнопку «Воспроизведение/Старт»** в верхней панели заголовка
2. Обработка начнётся немедленно
3. Во время обработки кнопка превращается в кнопку **«Стоп»**

4. Индикатор прогресса обновляется, отображая статус обработки

{% hint style="success" %}
**Обработка начата**: После нажатия кнопки Chloros автоматически выполняет все этапы обработки — обнаружение целей, дебейеринг, калибровку, расчёт индекса и экспорт. Программа автоматически определяет, является ли ваш проект Survey3, LATTICE или их комбинацией, и применяет соответствующий конвейер обработки к каждой камере.
{% endhint %}

## Описание режимов обработки

Chloros работает в двух различных режимах обработки в зависимости от вашей лицензии:

### Бесплатный режим (последовательная обработка)

**Доступно всем пользователям**

**Как это работает:**

* Обрабатывает изображения по одному, последовательно
* Однопоточная работа
* Меньшее потребление памяти

**Индикатор выполнения показывает 2 этапа:**

1.**Обнаружение мишеней** — сканирование в поисках калибровочных мишеней
2. **Обработка** — применение калибровки и экспорт изображений**Время обработки:**

* Значительно медленнее, чем в параллельном режиме Chloros+
* Подходит для небольших и средних наборов данных (< 200 изображений)

### Режим Chloros+ (параллельная обработка)

**Требуется лицензия Chloros+**

**Как это работает:**

* Одновременная обработка нескольких изображений с использованием [4-потокового конвейера обработки](../processing-architecture/processing-pipeline.md)
* [Динамическая адаптация вычислений](../processing-architecture/dynamic-compute-adaptation.md) автоматически выбирает оптимальную стратегию для вашего оборудования при запуске
* Ускорение на GPU (CUDA) с помощью видеокарт NVIDIA
* **Количество рабочих процессов адаптируется к аппаратному обеспечению**: стратегии с использованием GPU запускают**2–4 параллельных рабочих процесса** (масштабируются в зависимости от объёма VRAM — 3 на GPU с объёмом 2–12 ГБ, от 2 до 4 на GPU с объёмом 12 ГБ и более); Системы, использующие только ЦП, запускают по одному рабочему процессу на каждое физическое ядро, за вычетом одного**Индикатор выполнения отображает 4 этапа** (соответствующие 4 потокам конвейера):

1. **Обнаружение** (поток 1) — поиск объектов калибровки
2. **Анализ** (поток 2) — изучение метаданных изображения и вычисление калибровки
3. **Калибровка** (поток 3) — дебейеринг, коррекция виньетирования, калибровка, вычисление индекса
4. **Экспорт** (поток 4) — сохранение обработанных изображений и индексов**Взаимодействие с индикатором прогресса:*** **Наведите курсор мыши** на индикатор, чтобы увидеть подробную раскрывающуюся панель с 4 этапами
* **Щелкните** по индикатору прогресса, чтобы зафиксировать раскрывающуюся панель на месте
* **Щелкните ещё раз**, чтобы отменить фиксацию и скрыть панель**Время обработки:**

* Значительно быстрее, чем в бесплатном режиме
* Ускорение на GPU ещё больше повышает скорость

{% hint style="info" %}
**Скорость Chloros+**: Параллельная обработка может быть в 5–10 раз быстрее, чем последовательный режим, при работе с большими наборами данных. Проект из 500 изображений, обработка которого в бесплатном режиме занимает 2 часа, с Chloros+ может быть завершён за 15–20 минут.
{% endhint %}

## Что происходит во время обработки

### Этап 1: Обнаружение целей

**Что делает Chloros:**

* Сканирует изображения, отмеченные вами в столбце «Цель» (все изображения, если ни одно не отмечено)
* Идентифицирует калибровочные панели в каждой цели
* Извлекает значения коэффициентов отражения из панелей целей
* Записывает временные метки целей для планирования калибровки

**Продолжительность:** 1–30 секунд (с отмеченными целями), 5–30+ минут (без отметок)

### Этап 2: Дебайеринг (преобразование RAW)

**Что делает Chloros:**

* Преобразует данные RAW в формате Байера в полноценные 3-канальные изображения (монохромные модули LATTICE остаются однополосными — для них дебайеринг пропускается с соответствующей записью в журнале)
* Применяет выбранный алгоритм демозаики
* Сохраняет максимальное качество изображения и детали

**Продолжительность:** Зависит от количества изображений и скорости ЦП/ГП

### Этап 3: Калибровка

**Что делает Chloros:*** **Коррекция виньетирования**: Устраняет затемнение по краям изображения
* **Калибровка отражательной способности**: нормализует с использованием целевых значений отражательной способности и/или данных о нисходящем излучении, полученных системой сбора данных (DAQ)
* Применяет корректировки ко всем полосам/каналам
* Использует соответствующий калибровочный эталон для каждого изображения на основе временной метки

**Продолжительность:** большая часть времени обработки

### Этап 4: Расчёт индексов

**Что делает Chloros:**

* Рассчитывает настроенные мультиспектральные индексы (NDVI, NDRE и т. д.)
* Применяет математические операции с диапазонами к откалиброванным изображениям
* Генерирует индексные изображения для каждого выбранного индекса

**Продолжительность:** Несколько секунд на каждое изображение

### Этап 5: Экспорт

**Что делает Chloros:**

* Сохраняет обработанные изображения в выбранном формате
* **LATTICE fan-out**: каждый необработанный кадр LATTICE экспортируется как все включённые продукты за один проход — с устранением байеровского фильтра, предварительный просмотр, радианс (всегда float32), отражательная способность
* Записывает файлы в выходную структуру проекта: `<project>/<camera>/<format>/<Product>_Images/`
* **Сохраняет исходное имя файла** — папка идентифицирует продукт, суффикс не добавляется**Продолжительность:** зависит от формата экспорта и размера файла***

## Поведение при обработке

### Автоматический конвейер обработки

После запуска весь конвейер работает автоматически:

* Взаимодействие с пользователем не требуется
* Все настроенные этапы выполняются последовательно
* Отображение хода выполнения в режиме реального времени
* Экспортированные файлы записываются на диск по мере их завершения — вы можете открывать готовые результаты, пока процесс продолжается

### Нагрузка на компьютер во время обработки

**Режим «Free»:**

* Относительно низкая загрузка ЦП (однопоточный режим)
* Компьютер продолжает нормально реагировать на другие задачи
* Можно безопасно свернуть Chloros и работать в других приложениях

**Параллельный режим Chloros+:**

* Высокая загрузка ЦП во всем пуле рабочих процессов стратегии
* При ускорении на GPU: высокая загрузка GPU
* Во время обработки компьютер может реагировать медленнее
* Старайтесь не запускать другие задачи, интенсивно использующие ресурсы ЦП

{% hint style="warning" %}
**Совет по повышению производительности**: Для достижения максимальной производительности Chloros+ закройте другие приложения и позвольте Chloros использовать все системные ресурсы.
{% endhint %}

### Обработку нельзя приостановить (но остановка происходит корректно)

* После запуска обработку нельзя приостановить и возобновить позже
* Нажатие кнопки **«Стоп»** полностью останавливает выполнение с первого нажатия
* Результаты, уже экспортированные до остановки, остаются на диске
* Остановленная обработка точно отражает, что было выполнено (см. строки `[RUN-SUMMARY]` в журнале)
* При запуске нового цикла обработка начинается с самого начала

**Совет по планированию:** для очень крупных проектов рекомендуется рассматривать возможность пакетной обработки или использования командной строки (CLI) для более эффективного управления.

## Мониторинг обработки

Во время выполнения обработки вы можете:

* **Наблюдать за индикатором выполнения** — просматривать общий процент выполнения
* **Просматривать текущий этап** — «Обнаружение», «Анализ», «Калибровка» или «Экспорт»
* **Проверять вкладку «Журнал»** — просматривать подробные сообщения и предупреждения об обработке
* **Просматривать готовые изображения** — файлы экспорта появляются на диске в процессе обработки

Подробную информацию о мониторинге см. в разделе [Мониторинг обработки](monitoring-the-processing.md).

## Остановка обработки

Если вам нужно остановить обработку:

### Как остановить

1. Найдите **кнопку «Стоп»** (во время обработки она заменяет кнопку «Пуск»)
2. Нажмите её один раз — на полосе отобразится надпись **«Остановка...»**, пока завершается обработка текущего изображения
3. Цикл завершится в состоянии окончательной остановки, а в журнале будет выведена точная информация `[RUN-SUMMARY]` о том, что было выполнено

### Когда следует остановить

**Веские причины для остановки:**

* Обнаружено, что использовались неверные настройки
* Забыли пометить целевые изображения
* Импортированы не те изображения
* Система работает слишком медленно или не отвечает

**После остановки:**

* Результаты, экспортированные до остановки, остаются на диске
* Проверьте и устраните все проблемы, при необходимости скорректируйте настройки
* Перезапустите обработку — запуск начнётся с самого начала

## Оценка времени обработки

Фактическое время обработки значительно варьируется в зависимости от:

* Количества изображений
* Разрешения изображений
* Формата входных данных (RAW или JPG)
* Режима обработки (Free или Chloros+)
* Скорости процессора и количества ядер
* Наличия графического процессора (только для Chloros+)
* Количества индекса, подлежащего расчёту
* Количества включённых продуктов экспорта (LATTICE)

### Приблизительные оценки (Chloros+, изображения 12 МП, современный процессор)

| Количество изображений | Бесплатный режим | Chloros+ (ЦП) | Chloros+ (графический процессор) |
| ----------- | --------- | -------------- | -------------- |
| 50 изображений   | 15–20 мин | 5–8 мин        | 3–5 мин        |
| 100 изображений  | 30–40 мин | 10–15 мин      | 5–8 мин        |
| 200 изображений  | 1–1,5 ч | 20–30 мин      | 10–15 мин      |
| 500 изображений  | 2–3 ч   | 45–60 мин      | 20–30 мин      |
| 1000 изображений | 4–6 ч   | 1,5–2 ч      | 40–60 мин      |

{% hint style="info" %}
**Первый запуск**: Первоначальная обработка может занять больше времени, так как Chloros создаёт кэши и профили. Последующая обработка аналогичных наборов данных будет проходить быстрее.
{% endhint %}

## Распространённые проблемы при запуске

### Кнопка «Пуск» отключена (затенена)

**Возможные причины:**

* Изображения не импортированы
* Бэкенд не запущен полностью
* Предыдущая обработка ещё выполняется
* Проект не загружен полностью

**Решения:**

1. Дождитесь полной инициализации бэкэнда (проверьте значок в главном меню)
2. Убедитесь, что изображения импортированы в файловый браузер
3. Перезапустите Chloros, если кнопка по-прежнему отключена
4. Проверьте журнал отладки на наличие сообщений об ошибках

### Обработка запускается, но сразу же завершается сбоем

**Возможные причины:**

* В проекте нет допустимых изображений
* Поврежденные файлы изображений
* Недостаточно места на диске
* Недостаточно оперативной памяти (RAM)

**Решения:**

1. Проверьте журнал отладки <img src="../.gitbook/assets/icon_log.JPG" alt="" data-size="line"> на наличие сообщений об ошибках
2. Проверьте наличие свободного места на диске
3. Попробуйте обработать меньший набор изображений
4. Убедитесь, что изображения не повреждены

### Запуск завершается, но изображения не записываются

Запуск, в ходе которого запрашивались изображения, но ни одно из них не было записано, рассматривается как **сбой, а не успех** — Chloros явно сообщает об этом:

* В журнале графического интерфейса выводятся подсказки `[RUN-SUMMARY]`, указывающие на вероятную причину — изображения не импортированы, цель не обнаружена или все запрошенные продукты были пропущены как неприменимые (например, запрос на радианцию/отражательную способность с камер, поддерживающих только формат RGB)
* Эквивалент в CLI (`chloros-cli process`) выводит сообщение `Processing finished but wrote no image products.` и **завершается с ненулевым кодом**, что позволяет скриптам обнаружить эту ошибку
* Намеренный запуск, предусматривающий вывод только метаданных (все экспортные продукты отключены, индексы отсутствуют), по-прежнему считается успешным

Полную семантику см. в [справочнике по CLI](../reference/cli-reference.md#a-run-that-writes-no-images-fails).

### Папка проекта находится слишком глубоко в иерархии для данного компьютера

**Только для Windows, нововведение версии 1.3.0.** В Windows по умолчанию отключены длинные пути, и длина любого пути к файлу не может превышать 260 символов. Продукты Chloros располагаются примерно на 130 символов ниже папки проекта, поэтому папка проекта, расположенная глубже, не сможет получить свои продукты. Вместо того чтобы запускаться и ничего не записывать, Chloros теперь проверяет перед началом обработки:

* Нажатие кнопки «Пуск» не запускает выполнение: индикатор выполнения показывает причину, а в журнале отладки отображается код `[PROCESS] refused: The project folder is too deep for this computer…`. В сообщении указывается длина папки проекта и максимальная допустимая длина папки проекта.
* Создание или открытие проекта в папке, расположенной слишком глубоко даже для собственных файлов проекта, также не допускается. В окне сообщения указывается причина, наибольшая допустимая длина папки проекта и инструкции по включению поддержки длинных путей; при этом ничего не создаётся и не открывается; в журнале отладки это регистрируется как `[PROJECT] refused: …`. Дублирование проекта под более длинным именем также может привести к превышению ограничения: копия создается, но не открывается, и в том же сообщении указывается причина.

**Решения:**

1. Храните проекты в папке с более коротким именем — измените**Рабочий каталог** в [Настройках проекта](../project-settings/project-settings.md) и создайте проект заново, или
2. Включите поддержку длинных путей в Windows и перезапустите Chloros: запустите установщик Chloros заново с установленным флажком **Включить длинные пути Windows** (он установлен по умолчанию) или воспользуйтесь групповой политикой: *Конфигурация компьютера > Административные шаблоны > Система > Файловая система > Включить длинные пути Win32*.

### Предупреждение «Цели не обнаружены»

**Возможные причины:**

* Забыли пометить целевые изображения
* Целевые изображения не содержат видимых целей
* Слишком строгие настройки обнаружения целей

**Решения:**

1. Ознакомьтесь с разделом [Выбор целевых изображений](choosing-target-images.md)
2. Отметьте соответствующие изображения в столбце «Цель»
3. Убедитесь, что цели видны на отмеченных изображениях
4. При необходимости настройте параметры обнаружения целей

## Советы по успешной обработке

### Перед началом

1. **Сначала проведите тестирование на небольшом поднаборе** — обработайте 10–20 изображений для проверки настроек
2. **Проверьте доступное место на диске** — убедитесь, что свободного места в 2–3 раза больше размера набора данных (больше, если включены все продукты LATTICE)
3. **Закройте ненужные приложения** — освободите системные ресурсы
4. **Проверьте изображения с целями** — просмотрите отмеченные цели, чтобы убедиться в качестве
5. **Сохраните проект** — проект сохраняется автоматически, но рекомендуется сохранять его вручную

### Во время обработки

1. **Избегайте перехода системы в спящий режим** — отключите режимы энергосбережения
2. **Держите Chloros на переднем плане** — или, по крайней мере, видимым на панели задач
3. **Периодически следите за ходом обработки** — проверяйте наличие предупреждений или ошибок
4. **Не запускайте другие ресурсоемкие приложения** — особенно при работе Chloros+ в параллельном режиме

### Ускорение Chloros+ с помощью графического процессора

При использовании ускорения с помощью графического процессора NVIDIA:

1. Обновите драйверы NVIDIA до последней версии
2. Убедитесь, что графический процессор имеет 4 ГБ и более видеопамяти (7 ГБ и более для одновременного дебайеринга с поддержкой текстур)
3. Закройте приложения, интенсивно использующие графический процессор (игры, редактирование видео)
4. Контролируйте температуру графического процессора (обеспечьте надлежащее охлаждение)
