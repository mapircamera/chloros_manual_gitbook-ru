# Выбор изображений с эталонами

Отметка изображений, содержащих калибровочные эталоны, позволяет программе Chloros точно определить, где их искать. Если в столбце «Target» отмечено хотя бы одно изображение, программа Chloros сканирует **только отмеченные изображения** — таким образом, отметка эталонов позволяет как ускорить обработку, так и предотвратить ошибочное распознавание съемочных снимков в качестве эталонов.

## Зачем помечать целевые изображения?

### Пометка управляет процессом сканирования

Когда вы отмечаете в столбце «Цель» определённые изображения:

* Chloros сканирует на наличие целей только отмеченные изображения
* Обнаружение целей происходит гораздо быстрее
* Изображения съёмки не могут привести к ложным обнаружениям целей

Если **ни одно** изображение не отмечено, программа «Chloros» переходит к сканированию всех изображений в проекте:

* Алгоритмы обнаружения целей запускаются на каждом изображении
* Сотни или тысячи изображений проверяются без необходимости
* Обработка занимает значительно больше времени, особенно при работе с большими наборами данных

{% hint style="success" %}
**Повышение скорости**: отметка 2–3 изображений с целями в наборе из 500 изображений может сократить время обнаружения целей с более чем 30 минут до менее 1 минуты.
{% endhint %}

***

## Как помечать изображения целей

### Шаг 1: Определите изображения целей

Просмотрите импортированные изображения в браузере файлов и определите, какие из них содержат калибровочные цели.

**Типичные сценарии:*** **Цель до съемки**: снята до начала сеанса
* **Мишень после съемки**: снята после завершения сеанса
* **Мишени в поле**: мишени, размещённые в пределах зоны съёмки
* **Несколько мишеней**: 2–3 изображения мишеней на сеанс (рекомендуется)

### Шаг 2: Проверьте столбец «Мишень» <img src="../.gitbook/assets/image (33).png" alt="" data-size="original">

Для каждого изображения, содержащего калибровочную мишень:

1. Найдите изображение в таблице «Обзор файлов»
2. Найдите столбец **«Мишень»** (крайний правый столбец)
3. Установите флажок в столбце «Мишень» для этого изображения
4. Повторите для всех изображений, содержащих мишени

### Шаг 3: Проверьте свой выбор

Перед обработкой дважды проверьте:

* [ ] Все изображения с калибровочными мишенями отмечены
* [ ] Ни одно изображение, не содержащее мишени, не отмечено по ошибке
* [ ] Мишени хорошо видны на отмеченных изображениях

## LATTICE: Мишени не обязательны при записи данными с DAQ

Для мультиспектральных камер LATTICE мишень калибровки в кадре является **одним из двух** возможных эталонов отражательной способности:

* **Мишень в кадре**: когда изображение с отмеченной мишенью проходит контроль качества (QA) в системе «Chloros», мишень становится**абсолютным эталоном отражательной способности** для окружающих её изображений.
* **Нисходящее излучение DAQ**: если мишени нет (или она не прошла проверку QA), программа «Chloros» вместо этого вычисляет коэффициент отражения на основе интенсивности нисходящего излучения, регистрируемой световым датчиком DAQ (ρ = π·L/E). Если запись с `.daq` или DAQ-M `.csv` охватывает ваши снимки, вы получаете откалиброванное коэффициент отражения**без каких-либо изображений мишеней**.

Это автоматическое поведение является по умолчанию. В файле CLI / SDK это соответствует параметру `--reflectance-source auto`; вы также можете принудительно установить `target` (строгий режим — без подстановки данных с DAQ) или `daq` (авторитет DAQ). См. [Справочник по CLI](../reference/cli-reference.md#per-product-export-toggles-lattice-multispectral).

**Геометрии целей LATTICE**: помимо классического обнаружения панелей, используемого для Survey3, обработка LATTICE поддерживает**цели с маркировкой ArUco**,**цели с фиксированными областями интереса (ROI)**и**полосковые цели**, настраиваемые для каждого проекта. Сканы**измеренного** коэффициента отражения мишени для каждого устройства могут быть предоставлены по серийному номеру (CLI: `--target-reflectance-dir`, по одному `<serial>.csv` на каждое устройство), с номинальными спектрами T3/T4P в качестве резервного варианта.

{% hint style="info" %}
**Модуль F988**: отражательная способность F988 калибруется с помощью панели отражения на месте съемки: данная полоса лежит за пределами откалиброванного диапазона датчика освещенности DAQ, поэтому Chloros использует ваши самые последние данные съемки панели и сохраняет их между очередными съемками панели. Если модуль F988 обрабатывается только с использованием DAQ, Chloros отклоняет коэффициент отражения на основе данных DAQ для этого диапазона (причина пропуска `dls-uncalibrated-band-988`) — поддерживаемым способом является рабочий процесс с использованием панели.
{% endhint %}

## Рекомендации по съемке целевых изображений

### Рекомендации по съемке целевых изображений

**Время съемки:**

* Снимайте целевые изображения непосредственно перед началом сеанса съемки и на протяжении всего сеанса
* При тех же условиях освещения, что и для датчика освещенности DAQ
* В идеале снимайте изображения мишени как можно чаще для достижения наилучших результатов. В противном случае данные датчика освещенности будут использоваться для корректировки калибровки с течением времени.

**Положение камеры:**

* Держите камеру над мишенью так, чтобы она была центрирована и занимала около 40–60 % центра изображения.
* Удерживайте камеру параллельно поверхности объекта или в направлении надира

**Освещение:**

* Используйте такое же окружающее освещение, как и для датчика освещенности системы сбора данных (DAQ)
* Избегайте появления теней на поверхности объекта
* Не заслоняйте источник света своим телом, транспортным средством или растительностью
* Пасмурная погода обеспечивает наиболее стабильные результаты

**Состояние объекта:**

* Панели мишени должны быть чистыми и сухими.
* Все панели мишени (например, все 4 на T4) должны быть хорошо видны и не заслонены.
* По возможности располагайте мишени перпендикулярно источнику света или в надирной точке относительно него.

### Сколько снимков мишени?

**Минимум:**1 изображение мишени за сеанс.**Рекомендуется:** 3–5 изображений мишени за сеанс.**Рекомендуемый график:**

* 3–5 снимков, сделанных вскоре после начала записи датчиком освещенности
* Для достижения наилучших результатов поворачивайте камеру между съемками
* Дополнительно: периодически в середине сеанса, если условия освещения постоянно меняются

## Работа с несколькими камерами

### Конфигурации с двумя камерами

При одновременном использовании двух камер MAPIR (например, Survey3W RGN + Survey3N OCN):

1. Снимайте изображения мишени **обеими камерами** одновременно
2. Используйте **один и тот же физический объект** для обеих камер
3. Отметьте изображения объекта для **обоих типов камер** в файловом браузере
4. Программа «Chloros» будет использовать соответствующие объекты для калибровки каждой камеры

### Колонка «Модель камеры»

Колонка **«Модель камеры»** помогает определить, какие изображения были получены с какой камеры:

* Survey3W\_RGN
* Survey3N\_OCN
* LATT-M3M-L41-F550
* LATT-M3C-L87-FRGN
* и т. д.

Используйте этот столбец, чтобы убедиться, что вы пометили мишени для каждого типа камеры в вашем проекте.

## Настройки обнаружения целей

### Регулировка чувствительности обнаружения

Если «Chloros» не обнаруживает ваши цели правильно, отрегулируйте следующие настройки в [Настройках проекта](adjusting-project-settings.md):**Минимальная площадь калибровочной выборки (px):*** **По умолчанию**: 25 пикселей
* **Увеличьте**, если возникают ложные срабатывания на мелких артефактах
* **Уменьшите**, если цели не обнаруживаются**Минимальный коэффициент кластеризации целей (0–100):*** **По умолчанию**: 60
* **Увеличьте**, если цели разбиваются на несколько обнаружений
* **Уменьшите**, если цели с вариациями цвета не обнаруживаются полностью

{% hint style="info" %}
**Совет по CLI**: `chloros-cli process` поддерживает те же регуляторы (`--min-target-size`, `--target-clustering`), а его флаг `--target`/`--targets` помечает всю входную папку как «только для панели целей». См. [Справочник по CLI](../reference/cli-reference.md).
{% endhint %}

## Распространённые проблемы с целевыми изображениями

### Проблема: цели не обнаружены

**Возможные причины:**

* Изображения мишеней не отмечены в файловом браузере
* Мишень занимает слишком маленькую часть кадра (&lt; 30 % изображения)
* Плохое освещение (тени, блики)
* Слишком строгие настройки обнаружения мишеней

**Решения:**

1. Убедитесь, что для нужных изображений установлен флажок в столбце «Мишень»
2. Проверьте качество изображений целей в предварительном просмотре
3. Если качество низкое, повторно сфотографируйте цели
4. При необходимости скорректируйте настройки обнаружения целей

### Проблема: ложные обнаружения целей

**Возможные причины:**

* Белые здания, транспортные средства или растительный покров принимаются за цели
* Яркие участки в растительности
* Слишком низкая чувствительность обнаружения

**Решения:**

1. Отмечайте только изображения реальных целей — сканируются только отмеченные изображения
2. Увеличьте минимальную площадь калибровочной выборки
3. Увеличьте минимальное значение кластеризации целей
4. Убедитесь, что на изображениях целей видна только цель (минимальное количество помех на фоне)

## Контрольный список для проверки

Перед началом обработки проверьте выбор изображений целей:

* [ ] По крайней мере 1 изображение цели отмечено за сеанс (или, для LATTICE, запись `.daq`/`.csv`, охватывающая сеанс)
* [ ] Флажки в столбце «Цель» установлены для всех изображений целей
* [ ] Изображения целей сняты в тот же период времени, что и обследование
* [ ] Цели четко видны в предварительном просмотре при нажатии
* [ ] Все калибровочные панели видны на каждом изображении цели
* [ ] На целях нет теней или препятствий
* [ ] Для системы с двумя камерами: цели отмечены для обоих типов камер

## Обработка без целей

### LATTICE: с записью DAQ

Если световой датчик DAQ регистрировал интенсивность нисходящего излучения во время съёмок LATTICE, цели не требуются:

1. Импортируйте файл `.daq` (или DAQ-M `.csv`) с изображениями
2. Оставьте столбец «Мишень» неотмеченным
3. Коэффициент отражения рассчитывается автоматически на основе данных о нисходящем излучении, полученных с DAQ
4. Для расчета яркости никогда не требуется ни целевой точки, ни данных DAQ — она определяется исключительно на основе заводской радиометрической калибровки камеры

### Обработка без каких-либо эталонных данных

Вы также можете выполнять обработку без целевых точек и без данных DAQ:

1. Оставьте все флажки в столбце «Целевая точка» неотмеченными
2. **Отключите** «Калибровка отражательной способности / баланс белого» в настройках проекта — в этом случае обнаружение целей будет полностью пропущено
3. Коррекция виньетирования по-прежнему будет применяться
4. Результирующие данные не будут калиброваны по абсолютной отражательной способности (мультиспектральный формат LATTICE по-прежнему экспортирует продукты с удаленным байерированием, предварительный просмотр и интенсивность излучения)

{% hint style="warning" %}
**Не рекомендуется для научной работы сSurvey3**: без калибровки отражательной способности значения пикселей Survey3 представляют собой лишь относительную яркость, а не научные измерения отражательной способности. Для получения точных и воспроизводимых результатов используйте калибровочные мишени (или, в случае LATTICE, световой датчик DAQ).
{% endhint %}
