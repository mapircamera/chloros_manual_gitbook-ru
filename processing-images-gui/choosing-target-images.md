# Выбор изображений с калибровочными мишенями

Пометка изображений, содержащих калибровочные мишени, является важнейшим этапом, который значительно ускоряет работу конвейера обработки Chloros. Заранее выбрав изображения с мишенями, вы избавляете Chloros от необходимости сканировать каждое изображение в вашем наборе данных в поисках калибровочных мишеней.

## Зачем помечать изображения с мишенями?

### Скорость обработки

Без маркировки целевых изображений Chloros должен:

* Просканировать каждое изображение в вашем проекте
* Запустить алгоритмы обнаружения целей на каждом изображении
* Проверить сотни или тысячи изображений без необходимости

**Результат**: Обработка может занять значительно больше времени, особенно для больших наборов данных.

### С маркированными целевыми изображениями

Когда вы отмечаете столбец «Цель» для определенных изображений:

* Chloros сканирует на наличие целей только отмеченные изображения
* Обнаружение целей завершается гораздо быстрее
* Общее время обработки значительно сокращается

{% hint style="success" %}
**Повышение скорости**: Отметка 2–3 целевых изображений в наборе данных из 500 изображений может сократить время обнаружения целей с 30+ минут до менее 1 минуты.
{% endhint %}

***

## Как пометить изображения целей

### Шаг 1: Определите изображения целей

Просмотрите импортированные изображения в файловом браузере и определите, какие из них содержат калибровочные цели.

**Типичные сценарии:*** **Цель до съемки**: снята до начала сеанса
* **Цель после съемки**: снята после завершения сеанса
* **Цели в поле**: цели, размещенные в пределах области съемки
* **Несколько целей**: 2–3 изображения целей на сеанс (рекомендуется)

### Шаг 2: Проверьте столбец «Цель»

Для каждого изображения, содержащего калибровочную цель:

1. Найдите изображение в таблице файлового браузера
2. Найдите столбец **«Цель»** (крайний правый столбец)
3. Установите флажок в столбце «Цель» для этого изображения
4. Повторите для всех изображений, содержащих цели

### Шаг 3: Проверьте свой выбор

Перед обработкой дважды проверьте:

* [ ] Все изображения с калибровочными мишенями отмечены
* [ ] Ни одно изображение, не содержащее мишени, не отмечено случайно
* [ ] Мишени четко видны на отмеченных изображениях

## Рекомендации по работе с изображениями мишеней

### Рекомендации по съемке мишеней

**Время:**

* Снимайте изображения мишеней непосредственно перед началом и в течение всей сессии съемки
* При тех же условиях освещения, что и для датчика освещенности DAQ
* Для достижения наилучших результатов, в идеале, снимайте изображения мишеней как можно чаще. В противном случае данные датчика освещенности будут использоваться для корректировки калибровки с течением времени.

**Положение камеры:**

* Держите камеру над мишенью так, чтобы она была по центру и занимала около 40–60 % центра изображения.
* Держите камеру параллельно поверхности мишени или под углом 90° к ней

**Освещение:**

* Такое же окружающее освещение, как у вашего светового датчика DAQ
* Избегайте теней на поверхностях мишеней
* Не закрывайте источник света своим телом, транспортным средством или растительностью
* Пасмурная погода обеспечивает наиболее стабильные результаты

**Состояние мишени:**

* Держите панели мишени чистыми и сухими
* Все 4 панели должны быть хорошо видны и не заслонены
* По возможности, мишени должны располагаться перпендикулярно/надирно по отношению к источнику света

### Сколько изображений мишени?

**Минимум:**1 изображение цели за сеанс.**Рекомендуется:** 3–5 изображений цели за сеанс.**Рекомендуемый график:**

* 3–5 изображений, снятых вскоре после начала записи датчиком освещенности
* Для достижения наилучших результатов поворачивайте камеру между съемками
* Дополнительно: периодически в середине сеанса, если условия освещения постоянно меняются

## Работа с несколькими камерами

### Настройки с двумя камерами

При одновременном использовании двух камер MAPIR (например, Survey3W RGN + Survey3N OCN):

1. Снимите изображения мишени **обеими камерами** одновременно
2. Используйте **одну и ту же физическую мишень** для обеих камер
3. Отметьте изображения мишени для **обоих типов камер** в файловом браузере
4. Chloros будет использовать соответствующие мишени для калибровки каждой камеры

### Колонка «Модель камеры»

Колонка **«Модель камеры»** помогает определить, какие изображения были получены с какой камеры:

* Survey3W\_RGN
* Survey3N\_OCN
* Survey3W\_RGB
* и т. д.

Используйте этот столбец, чтобы убедиться, что вы отметили цели для каждого типа камеры в вашем проекте.

## Настройки обнаружения целей

### Регулировка чувствительности обнаружения

Если Chloros не обнаруживает ваши цели правильно, отрегулируйте эти настройки в [Настройках проекта](adjusting-project-settings.md):**Минимальная площадь калибровочной выборки:*** **По умолчанию**: 25 пикселей
* **Увеличьте**, если возникают ложные обнаружения на мелких артефактах
* **Уменьшите**, если цели не обнаруживаются**Минимальное кластерирование целей:*** **По умолчанию**: 60
* **Увеличьте**, если цели разбиваются на несколько обнаружений
* **Уменьшите**, если цели с цветовыми вариациями не обнаруживаются полностью***

## Распространенные проблемы с изображениями целей

### Проблема: цели не обнаружены

**Возможные причины:**

* Изображения целей не отмечены в файловом браузере
* Цель слишком мала в кадре (&lt; 30% изображения)
* Плохое освещение (тени, блики)
* Слишком строгие настройки обнаружения целей

**Решения:**

1. Убедитесь, что в столбце «Цель» отмечены правильные изображения
2. Проверьте качество изображения цели в предварительном просмотре
3. Повторно снимите цели, если качество плохое
4. При необходимости настройте параметры обнаружения целей

### Проблема: ложные обнаружения целей

**Возможные причины:**

* Белые здания, транспортные средства или растительный покров, принятые за цели
* Яркие участки в растительности
* Слишком низкая чувствительность обнаружения

**Решения:**

1. Отметьте только изображения реальных целей, чтобы ограничить область обнаружения
2. Увеличьте минимальную площадь калибровочной выборки
3. Увеличьте минимальное значение кластеризации целей
4. Убедитесь, что на изображениях целей видна только цель (минимальное количество посторонних объектов на фоне)

## Контрольный список для проверки

Перед началом обработки проверьте выбор изображений целей:

* [ ] Отмечено не менее 1 изображения цели за сеанс
* [ ] Флажки в столбце «Цель» установлены для всех изображений целей
* [ ] Изображения целей сняты в тот же период, что и съемка
* [ ] Цели четко видны в предварительном просмотре при нажатии
* [ ] Все 4 панели калибровки видны на каждом изображении цели
* [ ] На целях нет теней или препятствий
* [ ] Для двухкамерной системы: цели отмечены для обоих типов камер

## Обработка без целей

### Обработка без калибровочных целей

Хотя это не рекомендуется для научной работы, вы можете выполнять обработку без целей:

1. Оставьте все флажки в столбце «Цель» не установленными
2. **Отключите** «Калибровку отражательной способности» в настройках проекта
3. Коррекция виньетирования по-прежнему будет применяться
4. Результат не будет откалиброван на абсолютную отражательную способность

{% hint style="warning" %}
**Не рекомендуется**: без калибровки отражательной способности значения пикселей отражают только относительную яркость, а не научные измерения отражательной способности. Для получения точных и воспроизводимых результатов используйте калибровочные мишени.
{% endhint %}
