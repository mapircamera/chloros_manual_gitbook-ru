# Добавление файлов в проект

После того как вы создали или открыли проект в Chloros, следующим шагом будет добавление мультиспектральных изображений для начала обработки. Вкладка «Обзор файлов» (<img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line">) упрощает импорт изображений и управление набором данных.

## Доступ к «Обзору файлов»

1. Откройте или создайте проект в Chloros
2. Нажмите на значок **«Обзор файлов»** <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> на левой боковой панели
3. На панели «Обзор файлов» отобразится список файлов вашего проекта

{% hint style="info" %}
**Поддерживаемые типы файлов**:

* **Survey3W / Survey3N**: пары файлов RAW+JPG и изображения в формате JPG (рекомендуется формат RAW+JPG)
* **LATTICE**: записи в формате `.tif` / `.tiff` — сделанные с помощью программы управления камерой Chloros или концентратора LATTICE
* **Данные датчиков освещенности**: записи `.daq` (DAQ-U/M/E) и журналы нисходящего излучения DAQ-M `.csv` — импортируются вместе с изображениями для калибровки коэффициента отражения
{% endhint %}

***

## Добавление изображений в проект

Существует два основных способа добавления изображений в проект:

### Способ 1: Добавление файлов

Используйте этот вариант для импорта отдельных файлов изображений или небольшого набора файлов.

1. Нажмите кнопку **«Добавить файлы»** <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> в верхней части панели «Обзор файлов»
2. Перейдите в папку, содержащую ваши изображения
3. Выберите один или несколько файлов изображений (удерживайте клавишу **Ctrl** для выбора нескольких файлов)
4. Нажмите **«Открыть»**, чтобы импортировать выбранные файлы

### Способ 2: Добавить папку

Используйте этот вариант, чтобы импортировать все изображения из папки за один раз. В одном диалоговом окне можно выбрать **несколько папок**.

1. Нажмите кнопку **«Добавить папку»** <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> в верхней части панели «Обзор файлов»
2. Перейдите к папке (папкам), содержащей изображения сеанса съемки, и выберите её (их)
3. Нажмите **«Выбрать папку»**, чтобы импортировать все поддерживаемые изображения

{% hint style="info" %}
**О файлах, которые не удалось загрузить, выдается сообщение.** Если папка содержит файлы, которые Chloros распознает, но не может загрузить, вы увидите предупреждение — изображения не исчезают из сетки незаметно.
{% endhint %}

## Импорт папок с данными LATTICE Capture

Данные LATTICE Capture сохраняются в **одной подпапке на каждый уровень экспорта** — например, `raw/`, `debayered/`, `radiance/`, `reflectance/`, `preview/` — с соответствующим файлом нисходящего потока `.daq` в корневой папке:

```
output/
├── raw/           capture_<timestamp>_SN<serial>_raw.tif
├── debayered/     capture_<timestamp>_SN<serial>_debayered.tif
├── preview/       capture_<timestamp>_SN<serial>_display.tif
└── *.daq          the downwelling reading matched to the capture
```

**Укажите папку в корневой папке снимков** (`output/` выше). Если выбранная папка сама по себе не содержит изображений, но имеет вложенные папки, Chloros автоматически переходит в них — вложенные папки данного уровня и корневая папка `.daq` загружаются за один раз.**Как импортируются снимки:*** Каждый снимок импортируется как **одно изображение**, сгруппированное по снимку (а не по одной записи на каждый уровень). Остальные уровни одного и того же снимка отображаются как режимы просмотра этого единственного изображения.
* **Обработка всегда начинается с исходного кадра.** Остальные уровни доступны для просмотра, но через конвейер проходит только `raw` — повторная обработка уже обработанного результата привела бы к двойному применению коррекций, поэтому Chloros отклоняется. Повторно импортированный экспорт никогда не может занять слот необработанных данных съёмки.
* Папка съёмки, сохранённая **без** необработанных данных, импортируется и отображается нормально, но обработка пропускает её и фиксирует это в журнале. (Флаг CLI `--input-level` может принудительно задать точку входа для этого случая — см. [Справочник по CLI](../reference/cli-reference.md#what-a-captures-folder-looks-like).)**Сеансы концентратора LATTICE** импортируются таким же образом: укажите в поле «Добавить папку» папку сеанса, скопированную с концентратора (она содержит `raw/` и `previews/`), вместе с любым журналом DAQ-M `.csv`. Если калибровка камеры или DAQ ещё не сохранена в кэше вашего компьютера, Chloros автоматически загрузит её по серийному номеру при импорте (требуется однократное подключение к Интернету).***

## Понимание таблицы файлового браузера

После импорта изображения отображаются в таблице со следующими столбцами:

### Имя файла

* Исходное имя файла с камеры
* Сохраняет соглашение об именовании камеры (например, IMG\_0001.RAW или capture\_20260816\_101500\_SN213800234\_raw.tif)

### Временная метка

* Дата и время съемки изображения
* Извлечено из метаданных EXIF изображения
* Используется для сопоставления световых датчиков, синхронизации PPK и планирования работы калибровочных мишеней

### Модель камеры

* Автоматически определённая конфигурация камеры и фильтра
* Примеры Survey3: Survey3W\_RGN, Survey3N\_OCN, Survey3W\_RGB
* Примеры LATTICE: LATT-M3M-L41-F550, LATT-M3C-L87-FRGN
* Используется для применения правильных профилей обработки

### Колонка «Мишени» (флажок)

* Установите этот флажок для изображений, содержащих калибровочные мишени
* Если отмечено хотя бы одно изображение, **поиск мишеней проводится только в отмеченных изображениях*** Подробности см. в разделе [Выбор изображений с мишенями](choosing-target-images.md)

### Просмотр метаданных изображения

Нажатие кнопки переключения в правом верхнем углу над таблицей отображает метаданные выбранного изображения в области сетки изображений.

## Файлы датчиков освещённости в вашем проекте

* Файлы `.daq` и `.csv` отображаются в списке файлового браузера, но не являются изображениями, на которые можно нажать — они предоставляют данные о нисходящей интенсивности излучения для калибровки коэффициента отражения.
* Каждый импортированный файл `.daq`/`.csv` отображается в разделе **Настройки проекта → Датчик освещенности DAQ**, где можно проверить, какая поправка на диффузорный колпачок применяется к каждому файлу. См. [Настройка параметров проекта](adjusting-project-settings.md).
* Записи, сделанные на вкладке **Датчики освещенности**, автоматически добавляются в открытый проект — ручной импорт не требуется.***

## Управление файлами в проекте

### Удаление файлов

Чтобы удалить ненужные изображения из проекта:

1. Выберите одно или несколько изображений в таблице «Обзор файлов»
2. Нажмите кнопку **«Удалить выбранное»** <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line">
3. Подтвердите удаление (файлы не удаляются с диска, а лишь исключаются из проекта)

### Сортировка и фильтрация

* **Сортировка по столбцу**: щелкните любой заголовок столбца, чтобы отсортировать изображения
* **Сортировка по временной метке**: удобно для упорядочивания хронологических последовательностей снимков
* **Фильтр по модели камеры**: сгруппируйте изображения по типу камеры, если используете несколько камер***

## Предварительный просмотр изображений

### Просмотр изображения в полном размере

Щелкните любую миниатюру изображения в обозревателе файлов, чтобы отобразить его в основной области предварительного просмотра:

1. Изображение появляется в центральной панели предварительного просмотра
2. Используйте элементы управления масштабированием для просмотра деталей изображения
3. Перемещайтесь между изображениями с помощью клавиш со стрелками

### Быстрая навигация

* **Предыдущее изображение**: щелкните стрелку влево или нажмите клавишу ←
* **Следующее изображение**: щелкните стрелку вправо или нажмите клавишу →
* **Увеличение/уменьшение**: используйте колесико мыши или кнопки масштабирования
* **Панорамирование**: щелкните и перетащите курсор по изображению при увеличенном масштабе***

## Работа с дубликатами файлов

Chloros автоматически обнаруживает и игнорирует дубликаты файлов:

* Файлы с одинаковыми именами пропускаются
* Предотвращает случайную двойную обработку
* При обнаружении дубликатов отображается предупреждающее сообщение

{% hint style="warning" %}
**Важно**: Не переименовывайте и не изменяйте исходные файлы изображений перед импортом. Для правильной обработки Chloros использует исходные имена файлов и метаданные.
{% endhint %}

***

## Наборы данных с изображениями, снятыми разными камерами

Если ваш проект содержит изображения, снятые несколькими камерами MAPIR:

1. Chloros автоматически определяет модель каждой камеры — Survey3, LATTICE или смешанный тип
2. Каждый тип камеры обрабатывается с использованием соответствующего профиля калибровки
3. В браузере файлов модель камеры отображается в столбце «Модель камеры»
4. При обработке для каждой камеры создается собственное дерево выходных папок

**Примеры сценариев**: конфигурация с двумя камерами Survey3W и RGN + Survey3N и OCN, или массив LATTICE с главной камерой RGB и несколькими узкополосными модулями***

## Рекомендации

### Подготовка перед импортом

* Храните изображения калибровочных мишеней в той же папке, что и съёмочные изображения
* Храните файлы световых датчиков `.daq` / `.csv` каждой сессии съёмки вместе с изображениями этой сессии
* Сохраняйте исходную структуру папок с камеры/SD-карты/концентратора
* Не смешивайте наборы данных из разных сеансов в одном проекте

### Именование файлов

* Сохраняйте исходные имена файлов камеры (IMG\_0001.RAW, capture\_... и т. д.)
* Не переименовывайте файлы перед импортом
* Исходные имена содержат важные метаданные

### Изображения калибровочных мишеней

* Всегда включайте 1–2 изображения калибровочных мишеней на сеанс (Survey3; для LATTICE их может заменить запись DAQ — см. [Выбор изображений мишеней](choosing-target-images.md))
* Снимайте эталоны до и после сеанса съемки
* Располагайте эталоны в тех же условиях освещения, что и область съемки
* Помечайте изображения эталонов с помощью флажка «Эталон»

## Распространённые проблемы и их решения

### Изображения не отображаются после импорта

**Возможные причины:**

* Неподдерживаемый формат файла (см. список поддерживаемых типов в верхней части этой страницы)
* Изображения получены с камер, не относящихся к серии MAPIR (см. [Поддерживаемые камеры](../supported-cameras.md))
* Повреждение файлов или неполная передача с SD-карты

**Решение**: Убедитесь в совместимости формата файла и модели камеры, а также проверьте предупреждение о загрузке файлов, чтобы определить, какие именно файлы не удалось загрузить

### Модель камеры не распознана

**Возможные причины:**

* Измененные метаданные EXIF
* Изображения, отредактированные во внешнем программном обеспечении
* Неполная передача файлов

**Решение**: Повторно импортируйте исходные, немодифицированные файлы с камеры/карты SD

### Отсутствуют временные метки

**Возможные причины:**

* Неправильно настроены часы камеры
* Данные EXIF удалены внешним программным обеспечением

**Решение**: Убедитесь, что настройки времени на камере были правильными во время съемки

### При повторном открытии проекта сообщается об отсутствующих файлах

Если исходные файлы были перемещены или удалены с момента последнего открытия проекта, сообщение Chloros укажет, **какие** именно файлы отсутствуют, вместо того чтобы открывать пустую сетку. Восстановите файлы по их исходным путям или удалите отсутствующие записи и повторно импортируйте их.***

## Дальнейшие действия

После импорта файлов:

1. **Просмотрите список файлов** — убедитесь, что все изображения загрузились правильно
2. **Проверьте модели камер** — убедитесь в правильном распознавании камер
3. **Отметьте целевые изображения** — см. [Выбор целевых изображений](choosing-target-images.md)
4. **Настройте параметры** — настройте параметры обработки в [Настройках проекта](adjusting-project-settings.md)
5. **Запустите обработку** — см. раздел [Запуск обработки](starting-the-processing.md)

Подробную информацию о настройке проекта см. в разделе [Настройка параметров проекта](adjusting-project-settings.md).
