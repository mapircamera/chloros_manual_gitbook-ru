# Добавление файлов в проект

После того как вы создали или открыли проект в Chloros, следующим шагом будет добавление мультиспектральных изображений для начала обработки. Вкладка «Обзор файлов»<img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> позволяет легко импортировать изображения и управлять набором данных.

## Доступ к файловому браузеру

1. Откройте или создайте проект в Chloros
2. Нажмите на значок **Файловый браузер** <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> на левой боковой панели
3. На панели «Обзор файлов» отобразится список файлов вашего проекта

{% hint style="info" %}
**Поддерживаемые типы файлов**: Chloros поддерживает файлы изображений в форматах RAW+JPG и JPG, полученные с камер MAPIR, Survey3W и Survey3N. Рекомендуется использовать только файлы RAW+JPG.
{% endhint %}

***

## Добавление изображений в проект

Существует два основных способа добавления изображений в проект:

### Способ 1: Добавить файлы

Используйте этот вариант для импорта отдельных файлов изображений или небольшого набора файлов.

1. Нажмите кнопку **«Добавить файлы»** <img src="../.gitbook/assets/image.png" alt="" data-size="line"> в верхней части панели «Обзор файлов»
2. Перейдите в папку, содержащую ваши изображения
3. Выберите один или несколько файлов изображений (удерживайте клавишу **Ctrl**, чтобы выбрать несколько файлов)
4. Нажмите **«Открыть»**, чтобы импортировать выбранные файлы

### Способ 2: Добавить папку

Используйте этот вариант, чтобы импортировать все изображения из папки сразу.

1. Нажмите кнопку **«Добавить папку»** <img src="../.gitbook/assets/image (1).png" alt="" data-size="line"> в верхней части панели «Обзор файлов»
2. Перейдите к папке, содержащей изображения сеанса съемки, и выберите ее
3. Нажмите **«Выбрать папку»**, чтобы импортировать все поддерживаемые изображения из этой папки***

## Понимание таблицы «Обзор файлов»

После импорта изображения отображаются в таблице со следующими столбцами:

### Имя файла

* Исходное имя файла с камеры
* Сохраняет соглашение об именовании камеры (например, IMG\_0001.RAW)

### Временная метка

* Дата и время съемки изображения
* Извлечено из метаданных EXIF изображения
* Используется для синхронизации PPK и обнаружения калибровочных мишеней

### Модель камеры

* Автоматически определённая конфигурация камеры и фильтра
* Примеры: Survey3W\_RGN, Survey3N\_OCN, Survey3W\_RGB
* Используется для применения правильных профилей обработки

### Столбец «Мишень» (флажок)

* Установите этот флажок для изображений, содержащих калибровочные мишени
* Значительно ускоряет обнаружение мишеней во время обработки
* Подробности см. в разделе [Выбор изображений-мишеней](choosing-target-images.md)

### Просмотр метаданных изображения

Нажатие кнопки переключения в правом верхнем углу над таблицей отображает метаданные выбранного изображения в области сетки изображений.

## Управление файлами в проекте

### Удаление файлов

Чтобы удалить ненужные изображения из проекта:

1. Выберите одно или несколько изображений в таблице файлового браузера
2. Нажмите кнопку **«Удалить выбранное»** <img src="../.gitbook/assets/image (2).png" alt="" data-size="line"> .
3. Подтвердите удаление (файлы не удаляются с диска, а только из проекта).

### Сортировка и фильтрация

* **Сортировка по столбцу**: нажмите на заголовок любого столбца, чтобы отсортировать изображения.
* **Сортировка по временной метке**: полезно для упорядочивания хронологических последовательностей снимков.
* **Фильтр по модели камеры**: сгруппируйте изображения по типу камеры, если используете несколько камер.***

## Предварительный просмотр изображений

### Просмотр полного изображения

Щелкните любую миниатюру изображения в браузере файлов, чтобы отобразить его в основной области предварительного просмотра:

1. Изображение появляется в центральной панели предварительного просмотра
2. Используйте элементы управления масштабированием для просмотра деталей изображения
3. Перемещайтесь между изображениями с помощью клавиш со стрелками

### Быстрая навигация

* **Предыдущее изображение**: щелкните стрелку влево или нажмите клавишу ←
* **Следующее изображение**: щелкните стрелку вправо или нажмите клавишу →
* **Увеличение/уменьшение**: используйте колесико мыши или кнопки масштабирования
* **Панорамирование**: щелкните и перетащите изображение при увеличении***

## Работа с дубликатами файлов

Chloros автоматически обнаруживает и игнорирует дубликаты файлов:

* Файлы с одинаковыми именами пропускаются
* Предотвращает случайную двойную обработку
* При обнаружении дубликатов отображается предупреждающее сообщение

{% hint style="warning" %}
**Важно**: Не переименовывайте и не изменяйте исходные файлы изображений перед импортом. Chloros использует исходные имена файлов и метаданные для правильной обработки.
{% endhint %}

***

## Наборы данных с изображениями с разных камер

Если ваш проект содержит изображения с нескольких камер MAPIR:

1. Chloros автоматически определяет модель каждой камеры
2. Каждый тип камеры обрабатывается с использованием соответствующего профиля калибровки
3. В файловом браузере модель камеры отображается в столбце «Модель камеры»
4. При обработке для каждого типа камеры применяются правильные настройки

**Пример сценария**: Survey3W RGN + Survey3N OCN — конфигурация с двумя камерами***

## Рекомендации

### Организация перед импортом

* Храните изображения калибровочных мишеней в той же папке, что и изображения съемки
* Сохраняйте исходную структуру папок с камеры/SD-карты
* Не смешивайте наборы данных из разных сеансов в одном проекте

### Именование файлов

* Сохраняйте исходные имена файлов камеры (IMG\_0001.RAW и т. д.)
* Не переименовывайте файлы перед импортом
* Исходные имена содержат важные метаданные

### Изображения калибровочных мишеней

* Всегда включайте 1–2 изображения калибровочных мишеней на сеанс
* Снимайте мишени до и после сеанса съемки
* Размещайте мишени в тех же условиях освещения, что и область съемки
* Помечайте изображения мишеней с помощью флажка «Target» (Мишень), чтобы ускорить обработку

## Распространенные проблемы и решения

### Изображения не отображаются после импорта

**Возможные причины:**

* Неподдерживаемый формат файла (только RAW+JPG и JPG с камер MAPIR)
* Изображения получены с камер, отличных от MAPIR (см. [Поддерживаемые камеры](../supported-cameras.md))
* Повреждение файла или неполная передача с SD-карты

**Решение**: Проверьте совместимость формата файла и модели камеры

### Модель камеры не обнаружена

**Возможные причины:**

* Измененные метаданные EXIF
* Изображения отредактированы во внешнем программном обеспечении
* Неполная передача файлов

**Решение**: Повторно импортируйте исходные, немодифицированные файлы с камеры/SD-карты

### Отсутствуют временные метки

**Возможные причины:**

* Неправильно настроены часы камеры
* Данные EXIF удалены внешним программным обеспечением

**Решение**: Убедитесь, что настройки времени камеры были правильными во время съемки***

## Следующие шаги

После импорта файлов:

1. **Просмотрите список файлов** — убедитесь, что все изображения загрузились правильно
2. **Проверьте модели камер** — убедитесь, что камеры определены правильно
3. **Отметьте целевые изображения** — см. [Выбор целевых изображений](choosing-target-images.md)
4. **Настройте параметры** — настройте параметры обработки в [Настройках проекта](adjusting-project-settings.md)
5. **Начните обработку** — см. [Запуск обработки](starting-the-processing.md)

Подробную информацию о настройке проекта см. в разделе [Настройка параметров проекта](adjusting-project-settings.md).
