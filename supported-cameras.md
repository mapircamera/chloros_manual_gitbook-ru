# Поддерживаемые камеры

Chloros обрабатывает изображения с двух семейств камер MAPIR на **всех платформах** (Windows, Linux amd64 и Linux arm64/Jetson):

* **Survey3** — камеры Survey3W (с широким углом) и Survey3N (с узким углом). Входные данные: `RAW+JPG`.
* **LATTICE**— мультиспектральные камерные модули M3C и M3M. Входные данные: снимки `.tif`/`.tiff`. Камерами LATTICE также можно**управлять в режиме реального времени** из Chloros — через вкладку «Камеры» графического интерфейса пользователя (Windows) или `chloros-cli lattice` / Python и SDK (Windows и Linux) — включая синхронизированные массивы из нескольких камер. См. [руководство LATTICE](lattice/).

Конвейер обработки также принимает входные файлы формата `.dng`.

Линейка LATTICE представляет собой модульную систему мультиспектральных камер, построенную на базе датчика Sony IMX265 с глобальным затвором (3,1 Мп, размер пикселя 3,45 мкм). Каждая камера хранит свой идентификатор в виде строки модели:

```
<sensor>-<lens>-F<filter>        e.g.  M3C-L41-FRGN,  M3M-L87-F550
```

Chloros отображается с префиксом `LATT-` (например, `LATT-M3M-L41-F550`), и эта строка модели определяет все последующие параметры — профиль датчика, расположение полос и калибровка настраиваются автоматически; настраивать что-либо для каждой камеры не требуется. Номер объектива соответствует **горизонтальному углу обзора в градусах**: `L41` = узкий 41°, `L87` = широкий 87°.

Существует две конфигурации датчиков:

| Конфигурация | Датчик      | Тип фильтра                           | Диапазоны на камеру                                                        |
| ------------- | ----------- | ------------------------------------- | ----------------------------------------------------------------------- |
| **M3C**       | Цветная матрица Байера | Тройной полосовой фильтр                       | 3 спектральных диапазона за одну экспозицию                                 |
| **M3M**       | Монохромный  | Один узкополосный интерференционный фильтр | 1 откалиброванный диапазон — объединение нескольких камер M3M для расчёта индексов растительности |

### Варианты фильтров M3C (Байера)

| Фильтр | Диапазоны (название @ центр, нм / FWHM, нм)       |
| ------ | ---------------------------------------- |
| `FRGB` | Blue 475/30 · Green 550/30 · Red 625/30  |
| `FRGN` | Red 660/21 · Green 550/30 · NIR 850/30   |
| `FOCN` | Orange 615/21 · Cyan 490/38 · NIR 808/14 |
| `FNGB` | Blue 475/30 · Green 550/30 · NIR 850/30  |

† «Коэффициент отражения F988 калибруется с использованием панели отражения, находящейся в поле обзора: этот диапазон выходит за пределы калиброванного диапазона датчика освещенности DAQ, поэтому Chloros применяет ваши последние данные считывания с панели и сохраняет их до следующего считывания». См. [Калибровочные мишени](calibration-targets.md).
