# Поддерживаемые камеры.

Chloros обрабатывает изображения с двух семейств камер MAPIR на **всех платформах** (Windows, Linux amd64 и Linux arm64/Jetson):

* **Survey3** — камеры Survey3W (широкоугольные) и Survey3N (узкоугольные). Входные данные: `RAW+JPG`.
* **LATTICE**— мультиспектральные камерные модули M3C и M3M. Входные данные: снимки `.tif`/`.tiff`. Камерами LATTICE также можно**управлять в режиме реального времени** из Chloros — через вкладку «Камеры» графического интерфейса (Windows) или с помощью `chloros-cli lattice` / Python SDK (Windows и Linux) — включая синхронизированные массивы из нескольких камер. См. [руководство по LATTICE](lattice/).

Конвейер обработки также принимает входные файлы формата `.dng`.

Линейка LATTICE представляет собой модульную систему мультиспектральных камер, построенную на базе датчика Sony IMX265 с глобальным затвором (3,1 Мп, размер пикселя 3,45 мкм). Каждая камера хранит свой идентификатор в виде строки модели:

```
<sensor>-<lens>-F<filter>        e.g.  M3C-L41-FRGN,  M3M-L87-F550
```. Программа

Chloros отображает её с префиксом `LATT-` (например, `LATT-M3M-L41-F550`), и эта строка модели определяет все последующие параметры — профиль датчика, расположение полос и калибровка определяются автоматически; настраивать что-либо для каждой камеры отдельно не требуется. Номер объектива соответствует **горизонтальному углу обзора в градусах**: `L41` = узкий 41°, `L87` = широкий 87°.

Существует две конфигурации датчика:

| Конфигурация | Датчик      | Тип фильтра                           | Диапазоны на камеру                                                        |
| ------------- | ----------- | ------------------------------------- | ----------------------------------------------------------------------- |
| **M3C**       | Цветной (Байера) | Тройной полосовой                       | 3 спектральных диапазона за одну экспозицию                                 |
| **M3M**       | Монохромный  | Один узкополосный интерференционный фильтр | 1 откалиброванный диапазон — объединение нескольких камер M3M для расчёта растительных индексов |

### Варианты фильтров M3C (Байера)

| Фильтр | Диапазоны (название @ центр, нм / FWHM, нм)       |
| ------ | ---------------------------------------- |
| `FRGB` | Blue 475/30 · Green 550/30 · Red 625/30  |
| `FRGN` | Red 660/21 · Green 550/30 · NIR 850/30   |
| `FOCN` | Orange 618,4/46 · Cyan 494,1/40 · NIR 821,6/54 (измерено — см. ниже) |
| `FNGB` | Blue 475/30 · Green 550/30 · NIR 850/30  |

Для `FOCN` приведены **измеренные** значения полосы полумаксимума фильтра (Chloros 1.3.0 и более поздние версии; в более ранних версиях использовались значения из технического паспорта: 615/21 · 490/38 · 808/14). Названия полос остаются прежними: `Orange_615`, `Cyan_490` и `NIR_808`, а измеренные значения центра и ширины — это те данные, которые Chloros вносит в каждый откалиброванный экспорт.
