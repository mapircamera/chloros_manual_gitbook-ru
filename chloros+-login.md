# Вход в Chloros+

## Вход через графический интерфейс

Боковое меню пользователя <img src=".gitbook/assets/icon_user.JPG" alt="" data-size="line"> позволяет вам войти в свою учетную запись Chloros+ и получить доступ к дополнительным функциям.

**Вход в систему требуется выполнить только один раз на каждом компьютере.** Графический интерфейс, CLI, Python и SDK используют один и тот же кэшированный сеанс — вход через настольный графический интерфейс также активирует CLI и SDK на этом компьютере (и наоборот — через `chloros-cli login`).

## Уровни тарифных планов

| Тарифный план | `plan_id` | Тип |
| --- | --- | --- |
| Iron | `0` | Бесплатный |
| Copper | `1` | Платный (Chloros+) |
| Bronze | `2` | Платный (Chloros+) |
| Серебро | `3` | Платный (Chloros+) |
| Золотой | `4` | Платный (Chloros+) |

См. [тарифные планы и цены](https://cloud.mapir.camera/pricing), чтобы узнать, что включает в себя каждый платный тариф.

### Для доступа к CLI / SDK требуется платный тариф

Для доступа к CLI, Python и SDK требуется **любой платный тариф Chloros+ (Copper или выше)**. Это правило применяется**на стороне сервера** — каждый запрос CLI/SDK должен содержать как активную сессию, так и платный тарифный план:

| Статус HTTP | `error_code` | Значение | Решение |
| --- | --- | --- | --- |
| `401` | `AUTH_REQUIRED` | Не вошёл в систему на этом компьютере | `chloros-cli login <email> <password>` |
| `403` | `PLAN_UPGRADE_REQUIRED` | Вошли в систему, но уровень тарифного плана слишком низкий (бесплатный уровень «Iron») | Перейдите на любой платный тарифный план Chloros+ |

`chloros-cli status` остаётся доступным на бесплатном тарифе, поэтому вы всегда можете увидеть свой текущий тариф и причину отказа в доступе.

### Ограничения на количество подключённого оборудования для каждого тарифа

Каждый тариф ограничивает количество камер LATTICE и световых датчиков DAQ, которые можно подключить одновременно в режиме реального времени:

| Тариф | Камеры LATTICE | Световые датчики DAQ |
| --- | --- | --- |
| Iron (бесплатный / без входа в систему) | 4 | 2 |
| Copper / Bronze | 6 | 3 |
| Silver | 10 | 6 |
| Gold | 20 | 12 |

## Вход в CLI

Войдите в систему, используя свои учетные данные Chloros+, чтобы включить обработку CLI. В Linux (без графического интерфейса) это единственный способ активировать вашу лицензию.

**Синтаксис:**

```bash
chloros-cli login <email> <password>
```

{% hint style="info" %}
**Пользователи SDK**: Python SDK также предоставляет программный метод `logout()` для очистки кэшированных учетных данных. Подробности см. в [Справочнике по SDK](reference/sdk-reference.md).
{% endhint %}

**Пример:**

```powershell
chloros-cli login user@example.com 'MyP@ssw0rd123'
```

{% hint style="warning" %}
**Специальные символы**: Используйте одинарные кавычки для паролей, содержащих такие символы, как `$`, `!` или пробелы.
{% endhint %}

### Хранение учетных данных

Кэшированные учетные данные и настройки хранятся в папке `.chloros` в домашнем каталоге пользователя на **всех платформах**:

| Платформа | Путь к кэшу учетных данных |
| --- | --- |
| **Windows** | `%USERPROFILE%\.chloros\` |
| **Linux** | `~/.chloros/` |

### Истечение срока действия плана и льготный период для автономной работы

Дата истечения срока действия плана, отображаемая в графическом интерфейсе пользователя, указывает, когда ваша лицензия станет недействительной. Для ежемесячных подписок срок истекает в конце месяца; для годовых подписок — через год с момента начала подписки.

Chloros проверяет вашу лицензию в режиме онлайн, однако работа в автономном режиме поддерживается в течение льготного периода:

* Результаты успешных проверок на сервере кэшируются в течение **5 минут**, поэтому при нормальном использовании количество запросов на проверку лицензии минимально.
* Кэш подписанных, привязанных к конкретному компьютеру лицензий обеспечивает более длительные периоды автономной работы: **30 дней для месячных тарифных планов**и**до даты истечения срока действия подписки (не более 365 дней) для годовых тарифных планов**.
* По истечении льготного периода тариф переходит на бесплатный уровень «Iron» до тех пор, пока устройство не сможет хотя бы один раз подключиться к серверу лицензий; доступ возобновляется после следующей успешной проверки.

### Ограничение по количеству устройств

Каждый тариф Chloros+ предусматривает различное количество зарегистрированных устройств. Каждое устройство, на котором вы входите в систему с помощью учётной записи Chloros+, учитывается в общем количестве зарегистрированных устройств. Вы можете переименовать или удалить устройство на странице своей учётной записи MAPIR Cloud.
