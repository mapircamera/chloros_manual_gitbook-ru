# Вход в Chloros+

## Вход в Chloros и Chloros (браузер)

Боковое меню <img src=".gitbook/assets/icon_user.JPG" alt="" data-size="line"> боковое меню позволяет вам войти в свою учетную запись Chloros+ и разблокировать дополнительные функции.

После входа в систему будут отображены данные вашей учетной записи:

<figure><img src=".gitbook/assets/user_account.JPG" alt="" width="375"><figcaption></figcaption></figure>## Вход в CLI

Войдите с помощью учетных данных Chloros+, чтобы включить обработку CLI. В Linux (без графического интерфейса) это единственный способ активировать лицензию.

**Синтаксис:**

```bash
chloros-cli login <email> <password>
```

{% hint style="info" %}
**Пользователи SDK**: Python SDK также предоставляет программный метод `logout()` для очистки кэшированных учетных данных. Подробности см. в [документации по методу Python SDK](api-python-sdk.md#logout).
{% endhint %}

**Пример:**

```powershell
chloros-cli login user@example.com 'MyP@ssw0rd123'
```

{% hint style="warning" %}
**Специальные символы**: Используйте одинарные кавычки вокруг паролей, содержащих символы, такие как `$`, `!`, или пробелы.
{% endhint %}

**Вывод:**

<figure><img src=".gitbook/assets/cli login_w.JPG" alt=""><figcaption></figcaption></figure>### Хранение учетных данных

Кэшированные учетные данные хранятся в месте, зависящем от платформы:

| Платформа | Путь к кэшу учетных данных |
| --- | --- |
| **Windows** | `%APPDATA%\Chloros\cache\` |
| **Linux** | `~/.cache/chloros/` |

### Истечение срока действия плана

Срок истечения плана в графическом интерфейсе пользователя показывает, когда ваша лицензия станет недействительной. Для ежемесячных подписок срок истечения наступает в конце месяца. Для годовых подписок — через год после начала подписки. Для проверки лицензии требуется ежемесячное подключение к Интернету, с 30-дневным льготным периодом.

### Ограничение по устройствам

Каждый тарифный план Chloros+ предлагает разное количество зарегистрированных устройств. Каждое устройство, на котором вы входите в систему с помощью учетной записи Chloros+, будет учитываться в количестве ваших зарегистрированных устройств. Вы можете переименовать и удалить устройство на странице своей учетной записи MAPIR Cloud.
