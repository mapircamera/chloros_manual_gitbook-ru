# Вход в Chloros+

## Вход через графический интерфейс

Меню боковой панели пользователя <img src=".gitbook/assets/icon_user.JPG" alt="" data-size="line"> позволяет войти в свою учетную запись Chloros+ и получить доступ к дополнительным функциям.

**Входить нужно только один раз на каждом компьютере.** Графический интерфейс, командная строка (CLI) и SDK для Python используют одну и ту же кэшированную сессию — вход через графический интерфейс на рабочем столе также активирует командную строку и SDK на этом компьютере (и наоборот, через `chloros-cli login`).

## Уровни тарифных планов

| Тариф | `plan_id` | Тип |
| --- | --- | --- |
| Iron | `0` | Бесплатный |
| Copper | `1` | Платный (Chloros+) |
| Bronze | `2` | Платный (Chloros+) |
| Silver | `3` | Платный (Chloros+) |
| Золото | `4` | Платный (Chloros+) |

См. [тарифные планы и цены](https://cloud.mapir.camera/pricing), чтобы узнать, что включает в себя каждый платный тариф.

### Для доступа к CLI/SDK требуется платный тариф

Для доступа к CLI и Python SDK требуется **любой платный тариф Chloros+ (Copper или выше)**. Это требование обеспечивается**на стороне сервера** — каждый запрос CLI/SDK должен содержать как активную сессию, так и платный тариф:

| Статус HTTP | `error_code` | Значение | Решение |
| --- | --- | --- | --- |
| `401` | `AUTH_REQUIRED` | Не вошёл в систему на этом компьютере | `chloros-cli login <email> <password>` |
| `403` | `PLAN_UPGRADE_REQUIRED` | Вошли в систему, но уровень тарифного плана слишком низкий (бесплатный уровень «Iron») | Перейдите на любой платный тарифный план Chloros+ |

`chloros-cli status` остаётся доступным на бесплатном тарифе, поэтому вы всегда можете увидеть свой текущий тариф и причину отказа в доступе.

### Ограничения на количество подключённого оборудования для каждого тарифа

Каждый тариф ограничивает количество камер LATTICE и световых датчиков DAQ, которые можно подключить одновременно в режиме реального времени:

| Тариф | Камеры LATTICE | Световые датчики DAQ |
| --- | --- | --- |
| Iron (бесплатный / без входа в систему) | 4 | 2 |
| Copper / Bronze | 6 | 3 |
| Silver | 10 | 6 |
| Gold | 20 | 12 |

## Вход в CLI



Войдите с помощью своих учетных данных Chloros+, чтобы включить обработку через CLI. В Linux (без графического интерфейса) это единственный способ активировать лицензию.

**Синтаксис:**

```bash
chloros-cli login <email> <password>
```

{% hint style="info" %}
**Пользователи SDK**: Python SDK также предоставляет программный метод `logout()` для очистки кэшированных учетных данных. Подробности см. в [справочнике по SDK](reference/sdk-reference.md).
{% endhint %}

**Пример:**

```powershell
chloros-cli login user@example.com 'MyP@ssw0rd123'
```

{% hint style="warning" %}
**Специальные символы**: Используйте одинарные кавычки вокруг паролей, содержащих такие символы, как `$`, `!` или пробелы.
{% endhint %}

### Хранение учетных данных

Кэшированные учетные данные и конфигурация хранятся в папке `.chloros` в домашнем каталоге пользователя на **всех платформах**:

| Платформа | Путь к кэшу учетных данных |
| --- | --- |
| **Windows** | `%USERPROFILE%\.chloros\` |
| **Linux** | `~/.chloros/` |

Установка новой версии поверх существующей сохраняет ваши учетные данные в системе в Windows (установщик) и в Linux (папка `.deb`, включая `chloros-cli update`). Удаление Chloros — или удаление пакета для Linux — приводит к очистке кэшированных данных входа, поэтому после новой установки вам потребуется войти в систему заново.

### Истечение срока действия тарифного плана и льготный период для автономной работы

Срок истечения тарифного плана, указанный в графическом интерфейсе, показывает, когда ваша лицензия утратит действительность. Для ежемесячных подписок срок действия истекает в конце месяца; для годовых подписок — через год после начала подписки.

Программа Chloros проверяет вашу лицензию в режиме онлайн, но работа в автономном режиме поддерживается в течение льготного периода:

* Результаты успешных проверок на сервере сохраняются в кэше в течение **5 минут**, поэтому при нормальном использовании запросов на проверку лицензии происходит очень мало.
* Кэш подписанных, привязанных к конкретному компьютеру лицензий обеспечивает работу в автономном режиме в течение более длительных периодов: **30 дней для месячных тарифных планов**и**до даты истечения срока действия вашей подписки (не более 365 дней) для годовых тарифных планов**.
* По истечении льготного периода тариф переходит на бесплатный уровень «Iron» до тех пор, пока устройство не сможет хотя бы один раз подключиться к серверу лицензий; доступ возобновляется после следующей успешной проверки.

### Ограничение по количеству устройств

Каждый тарифный план Chloros+ предусматривает различное количество зарегистрированных устройств. Каждое устройство, на котором вы входите в систему с помощью учётной записи Chloros+, учитывается в общем количестве зарегистрированных устройств. Вы можете переименовывать и удалять устройства на странице своей учётной записи MAPIR Cloud.

Точное количество устройств, разрешенных для вашей учетной записи, указано на странице вашей учетной записи MAPIR Cloud. Выход из системы на устройстве надежно освобождает его слот, а устройство, которое уже зарегистрировано, всегда может войти в систему снова, даже если учетная запись достигла предельного количества устройств.
