1. Загрузите указанный выше файл .exe

3. Следуйте подсказкам мастера установки
4. Выберите каталог установки (по умолчанию: `C:\Program Files\Chloros\`)
5. На странице **«Выбор дополнительных задач»**оставьте отмеченными оба параметра**«Настройки системы»** (рекомендуется — см. ниже)
6. Завершите установку и запустите Chloros или Chloros CLI
7. Войдите в систему с помощью своей [учетной записи MAPIR Cloud Chloros+](https://cloud.mapir.camera/pricing) (или продолжайте работу с бесплатной версией)

**Параметры системных настроек** (оба отмечены по умолчанию):

| Параметр, как указано в установщике | Что он делает | Отказ от автоматической установки |
| --- | --- | --- |
| **Включить длинные пути в Windows** (позволяет размещать папки проектов глубже, чем 260 символов; рекомендуется) | Устанавливает значение 1 для общесистемного параметра Windows `LongPathsEnabled`. В Windows этот параметр по умолчанию отключен, и в этом случае длина пути к файлу не может превышать 260 символов; продукты Chloros располагаются примерно на 130 символов ниже папки проекта, поэтому при отключенной поддержке длинных путей создание папки проекта, расположенной глубже, будет невозможно. Начинает действовать для программ, запущенных после установки. Остается включенным после удаления программы, так как другие программы могут полагаться на эту настройку. | `/MERGETASKS="!longpaths"` |
| **Исключить бэкенд Chloros из сканирования Microsoft Defender** (значительно ускоряет захват изображений с камер; рекомендуется) | Добавляет исключение процесса Microsoft Defender для `chloros-backend.exe` в папке установки, благодаря чему защита в режиме реального времени не сканирует каждый файл, который записывает бэкенд, независимо от места записи. При высокой частоте захвата сканирование занимает около 30 % от частоты захвата (77,7 против 52,7 захватов в секунду при непрерывном захвате с 9 камер). Никакие другие программы не исключаются, и исключение удаляется при удалении программы. Если Defender отсутствует или заблокирован политикой, этот шаг завершается без ошибок, и установка продолжается. | `/MERGETASKS="!defenderexclusion"` |

При скрытой установке (`/SILENT` или `/VERYSILENT`) применяются оба параметра, если вы не отключите их с помощью указанного значения `/MERGETASKS`.

{% hint style="success" %}
Установщик один раз добавляет папку CLI (`C:\Program Files\Chloros\cli\`) в вашу систему `PATH` — при повторной установке или обновлении дубликат записи больше не добавляется, а дубликаты, добавленные предыдущими установщиками, удаляются. Откройте новый терминал после установки, чтобы использовать `chloros-cli`. Установщик также добавляет два правила брандмауэра Windows для бэкэнда в каждый сетевой профиль: **Chloros Backend (UDP-In)**— для потоков с камер, PTP, mDNS и потока данных DAQ-E, а также**Chloros Backend (TCP-In)**, ограниченное локальной подсетью, для обновления прошивки DAQ-E, при котором датчик подключается обратно к этому компьютеру для сбора изображения. Оба правила удаляются при удалении программы.
{% endhint %}

#### Linux amd64 (пакет .deb — CLI + бэкенд)

* **Тип файла**: .deb (пакет Debian/Ubuntu)
* **Архитектура**: x86_64 (amd64)

```bash
sudo apt install ./chloros_1.3.0_amd64.deb
chloros-cli --version     # Verify installation: "Chloros CLI 1.3.0"
```

#### Linux arm64 — NVIDIA Jetson (пакет .deb — CLI + бэкенд)

* **Тип файла**: .deb (JetPack 6)
* **Архитектура**: aarch64 (arm64)

```bash
sudo apt install ./chloros_1.3.0_arm64_jp6.deb
chloros-cli --version     # Verify installation: "Chloros CLI 1.3.0"
```

Используйте фактическое имя загруженного файла и сохраните `./`, чтобы `apt` установил именно этот файл, а не искал пакет по имени. Установите с помощью `apt install`, а не с помощью `dpkg -i`: apt также устанавливает зависимости Python SDK, которые пакет рекомендует, а не требует, а `dpkg -i` их пропускает. Начиная с версии 1.3.0 бэкенд и интерфейс командной строки (CLI) устанавливаются в распакованном виде под `/usr/lib/chloros/`, поэтому они запускаются без предварительной распаковки.

Пакет для Jetson использует сборку PyTorch с поддержкой CUDA из JetPack 6, поэтому обработка, включая встроенный дебайер Texture Aware, выполняется на графическом процессоре Jetson. Он использует библиотеки CUDA и cuDNN, устанавливаемые JetPack 6 (`sudo apt install nvidia-jetpack` на образе, где их нет).

См. [Установка в Linux](linux/linux-installation.md) для получения подробных инструкций по настройке и [Руководство по NVIDIA Jetson](linux/nvidia-jetson-guide.md) для рекомендаций, специфичных для Jetson.

#### Python SDK (все платформы)

Каждый установщик включает соответствующий пакет wheel `chloros_sdk`, поэтому версия SDK всегда соответствует установленному GUI/CLI/бэкенду. В Windows установщик автоматически устанавливает его в системный Python. В Linux `.deb` устанавливает SDK для самого системного `python3` (в `/usr/lib/python3/dist-packages`), поэтому `import chloros_sdk` работает сразу после установки, без pip и без подключения к сети. Только в виртуальную среду (virtualenv), которая не видит системные пакеты, необходимо установить входящий в комплект файл wheel:

```bash
pip install /usr/lib/chloros/sdk/chloros_sdk-*.whl
```

Для хостов, на которых установлен только pip (пакет Chloros не установлен; в этом случае SDK управляет бэкендом на другом компьютере), SDK также доступен на PyPI:

```bash
pip install chloros-sdk
```

Документацию см. в разделе [API: Python SDK](api-python-sdk.md) и в [Справочнике по SDK](reference/sdk-reference.md).

{% hint style="info" %}
**Пользователи Linux**: Пакет `.deb` устанавливает интерфейс командной строки (CLI), бэкэнд и SDK для Python. Для Linux нет графического интерфейса — все взаимодействие осуществляется через интерфейс командной строки или SDK.
{% endhint %}

## Помощь по установке

### Устранение неполадок

**Установка завершается с ошибкой:**

* Убедитесь, что у вас есть права администратора
* Временно отключите антивирусное ПО
* Убедитесь, что ваш компьютер соответствует минимальным системным требованиям

**Приложение не запускается (Windows):**

* Убедитесь, что установлена Windows 10/11 (64-разрядная версия)
* Обновите драйверы видеокарты
* Проверьте журнал событий Windows на наличие подробностей об ошибке
* Обратитесь в службу поддержки с журналами ошибок

**CLI не запускается (Linux):**

* Убедитесь, что пакет `.deb` установлен правильно: `dpkg -l | grep chloros`
* Проверьте права доступа: `sudo chmod +x /usr/bin/chloros-cli`
* Запустите диагностику: `chloros-cli selftest`
* Проверьте наличие недостающих библиотек: `ldd /usr/lib/chloros/backend/chloros-backend | grep "not found"` (начиная с версии 1.3.0, `/usr/lib/chloros/chloros-backend` представляет собой небольшой скрипт-запуска; сама программа находится в `/usr/lib/chloros/backend/`)

**Проблемы с активацией лицензии:**

* Убедитесь, что интернет-соединение активно
* Проверьте учетные данные на [https://cloud.mapir.camera](https://cloud.mapir.camera)
* Убедитесь, что брандмауэр не блокирует Chloros

* Подробные инструкции см. в разделе [Chloros+ Вход](chloros+-login.md)

## Обновления программного обеспечения

Chloros проверяет наличие обновлений, уведомляет о выходе новой версии и предоставляет ссылку на эту страницу загрузки — для обновления запустите новый подписанный установщик. Ваши настройки, проекты и данные для входа сохраняются после обновления. В Linux и на Jetson `chloros-cli update` проверяет наличие более новой версии и предлагает загрузить и установить соответствующую версию `.deb` (эта команда доступна только в Linux).
