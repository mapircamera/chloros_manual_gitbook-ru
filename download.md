#### Установщик Windows (графический интерфейс + CLI + бэкэнд)

* **Тип файла**: .exe (установщик Windows)**Шаги по установке:**

1. Загрузите указанный выше файл .exe
2. Дважды щелкните по установщику, чтобы начать установку
3. Следуйте инструкциям мастера установки
4. Выберите каталог установки (по умолчанию: `C:\Program Files\MAPIR\Chloros\`)
5. Завершите установку и запустите Chloros или Chloros CLI
6. Войдите в систему, используя свою [учетную запись MAPIR Cloud Chloros+](https://cloud.mapir.camera/pricing) (или продолжайте работу с бесплатной версией)

{% hint style="success" %}
Установщик автоматически добавляет `chloros-cli` в системную переменную PATH для доступа из командной строки.
{% endhint %}

#### Linux amd64 (пакет .deb — CLI + бэкенд)

* **Тип файла**: .deb (пакет Debian/Ubuntu)
* **Архитектура**: x86\_64 (amd64)

```bash
sudo dpkg -i chloros-amd64.deb
chloros-cli --version  # Verify installation
```

#### Linux arm64 — NVIDIA Jetson (пакет .deb — CLI + бэкенд)

* **Тип файла**: .deb (JetPack 6)
* **Архитектура**: aarch64 (arm64)

```bash
sudo dpkg -i chloros-arm64-jp6.deb
chloros-cli --version  # Verify installation
```

См. [Установка Linux](linux/linux-installation.md) для получения подробных инструкций по настройке и [Руководство по NVIDIA Jetson](linux/nvidia-jetson-guide.md) для получения рекомендаций, относящихся конкретно к Jetson.

#### Python SDK (все платформы)

Каждый установщик включает соответствующий пакет wheel `chloros_sdk`, поэтому версия SDK всегда соответствует установленному графическому интерфейсу (GUI)/CLI/бэкенду. В Windows установщик автоматически устанавливает его в вашу систему Python; в Linux установщик `.deb` помещает колесо в `/usr/lib/chloros/sdk/` и выводит команду установки:

```bash
pip install --user /usr/lib/chloros/sdk/chloros_sdk-*.whl
```

Для хостов, поддерживающих только pip (без установленного пакета Chloros), SDK также доступен на PyPI:

```bash
pip install chloros-sdk
```

См. [API : Python SDK](api-python-sdk.md) и [Справочник по SDK](reference/sdk-reference.md) для ознакомления с документацией.

{% hint style="info" %}
**Пользователи Linux**: Пакет `.deb` устанавливает CLI и бэкенд. У Linux нет графического интерфейса — всё взаимодействие осуществляется через CLI или SDK.
{% endhint %}

## Помощь по установке

### Устранение неполадок

**Установка завершается с ошибкой:**

* Убедитесь, что у вас есть права администратора
* Временно отключите антивирусное ПО
* Убедитесь, что ваш компьютер соответствует минимальным системным требованиям

**Приложение не запускается (Windows):**

* Убедитесь, что установлена версия Windows 10/11 (64-разрядная)
* Обновите драйверы графической карты
* Проверьте журнал событий Windows на наличие подробностей об ошибке
* Обратитесь в службу поддержки с журналами ошибок

**CLI не запускается (Linux):**

* Убедитесь, что пакет `.deb` установлен правильно: `dpkg -l | grep chloros`
* Проверьте права доступа: `sudo chmod +x /usr/bin/chloros-cli`
* Запустите диагностику: `chloros-cli selftest`
* Проверьте наличие отсутствующих библиотек: `ldd /usr/lib/chloros/chloros-backend | grep "not found"`

**Проблемы с активацией лицензии:**

* Убедитесь, что интернет-соединение активно
* Проверьте учетные данные на [https://cloud.mapir.camera](https://cloud.mapir.camera)
* Убедитесь, что брандмауэр не блокирует Chloros
* Подробные инструкции см. на странице [Chloros+ Вход](chloros+-login.md)

## Обновления программного обеспечения

Chloros проверяет наличие обновлений, уведомляет о выходе новой версии и предоставляет ссылку на эту страницу загрузки — для обновления запустите новый подписанный установщик. Ваши настройки и проекты сохраняются после обновления. В Linux и Jetson `chloros-cli update` проверяет наличие более новой версии и предлагает загрузить и установить соответствующий `.deb` (эта команда доступна только в Linux).
