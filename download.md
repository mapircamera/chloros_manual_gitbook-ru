#### Установщик Windows (GUI + CLI + бэкэнд)

* **Тип файла**: .exe (Установщик Windows)**Шаги по установке:**

1. Загрузите указанный выше файл .exe
2. Дважды щелкните по установщику, чтобы начать установку
3. Следуйте подсказкам мастера установки
4. Выберите каталог установки (по умолчанию: `C:\Program Files\[USER]\Chloros\`)
5. Завершите установку и запустите Chloros или Chloros CLI
6. Войдите в систему с помощью своей [учетной записи Cloud Chloros+](https://cloud.mapir.camera/pricing) (или продолжайте работу с бесплатной версией)

{% hint style="success" %}
Установщик автоматически добавляет `chloros-cli` в системный PATH для доступа из командной строки.
{% endhint %}

#### Linux amd64 (пакет .deb — CLI + бэкэнд)

* **Тип файла**: .deb (пакет Debian/Ubuntu)
* **Архитектура**: x86\_64 (amd64)

```bash
sudo dpkg -i chloros-amd64.deb
chloros-cli --version  # Verify installation
```

#### Linux arm64 — NVIDIA Jetson (пакет .deb — CLI + бэкэнд)

* **Тип файла**: .deb (JetPack 6)
* **Архитектура**: aarch64 (arm64)

```bash
sudo dpkg -i chloros-arm64-jp6.deb
chloros-cli --version  # Verify installation
```

См. [Установка Linux](linux/linux-installation.md) для получения подробных инструкций по настройке и [Руководство по NVIDIA Jetson](linux/nvidia-jetson-guide.md) для получения рекомендаций, относящихся конкретно к Jetson.

#### Python SDK (все платформы)

```bash
pip install chloros-sdk
```

См. [API : Python SDK](api-python-sdk.md) для ознакомления с документацией.

{% hint style="info" %}
**Пользователи Linux**: Пакет `.deb` устанавливает CLI и бэкэнд. Python SDK устанавливается отдельно через pip. Для Linux нет графического интерфейса — все взаимодействие осуществляется через CLI или SDK.
{% endhint %}

## Помощь по установке

### Устранение неполадок

**Установка завершается с ошибкой:**

* Убедитесь, что у вас есть права администратора
* Временно отключите антивирусное ПО
* Убедитесь, что ваш компьютер соответствует минимальным системным требованиям

**Приложение не запускается (Windows):**

* Убедитесь, что установлена Windows 10/11 (64-разрядная версия)
* Обновите драйверы графической карты
* Проверьте журнал событий Windows на наличие подробностей об ошибке
* Обратитесь в службу поддержки с журналами ошибок

**CLI не запускается (Linux):**

* Убедитесь, что пакет `.deb` установлен правильно: `dpkg -l | grep chloros`
* Проверьте права доступа: `sudo chmod +x /usr/bin/chloros-cli`
* Запустите диагностику: `chloros-cli selftest`
* Проверьте наличие недостающих библиотек: `ldd /usr/lib/chloros/chloros-backend | grep "not found"`

**Проблемы с активацией лицензии:**

* Убедитесь, что интернет-соединение активно
* Проверьте учетные данные на [https://cloud.mapir.camera](https://cloud.mapir.camera)
* Убедитесь, что брандмауэр не блокирует Chloros
* Подробные инструкции см. в разделе [Chloros+ Вход](chloros+-login.md)
