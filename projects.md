# Графический интерфейс: Проекты

Chloros позволяет создавать проекты, которые можно будет открыть в будущем. Проект представляет собой обычную папку (в папке «Project Folder»), содержащую:

* `project.json` — настройки проекта, список файлов и параметры отображения
* `cameras.json` — камеры и матрицы, подключённые во время работы с проектом, с их настройками
* `sensors.json` — датчики освещённости DAQ, подключённые во время работы с проектом, а также привязки «камера↔датчик»
* ваши снимки, записи `.daq` и папки с обработанными результатами

Собственного формата файлов проектов нет — папка и содержащиеся в ней файлы JSON и составляют проект, что также упрощает копирование, архивирование и перенос проектов с [CLI](CLI.md) или [Python SDK](api-python-sdk.md).

## Новый проект

<figure><img src=".gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>Выберите «Новый проект» в главном меню и введите уникальное имя для вашего проекта.

Если у вас сохранены какие-либо шаблоны проектов, под полем ввода имени появится раскрывающийся список **«Выбрать шаблон»** — выбор одного из них приведет к созданию нового проекта на основе настроек этого шаблона. Шаблоны сохраняются в разделе [Настройки проекта](project-settings/project-settings.md): введите название в поле «Сохранить название шаблона проекта» и нажмите значок сохранения.

## Открыть проект

<figure><img src=".gitbook/assets/v120-open-project.jpg" alt=""><figcaption><p>В разделе «Открыть проект» отображается список всех проектов в папке проектов, а внизу находится кнопка <strong>«Открыть папку проектов»</strong></p></figcaption></figure>Выберите «Открыть проект», чтобы увидеть список существующих проектов в папке проектов. Если проектов нет, второстепенное боковое меню не откроется. На приведенном выше снимке экрана вы можете увидеть несколько проектов, созданных с помощью графического интерфейса (t1, t2, t3). Проекты с именами в формате DATE\_TIME были созданы программой CLI с использованием схемы именования проектов по умолчанию. Щелчок по любому имени проекта приведет к его открытию.

Нажатие кнопки «Открыть папку проекта» открывает проводник вашего компьютера с путем к проекту. Вы можете настроить путь к проекту в [Настройках проекта](project-settings/project-settings.md).

Если какие-либо исходные файлы изображений проекта были перемещены или удалены с момента его последнего открытия, Chloros отобразит диалоговое окно со списком именно тех файлов, которых не хватает, вместо того, чтобы открывать пустую сетку.

## Дублировать проект

Доступно после открытия проекта. Выберите «Дублировать проект», чтобы скопировать текущий проект под новым именем — Chloros предложит следующее свободное имя (например, «MyProject (2)») — и дубликат откроется сразу же.

## Добавить файлы

После открытия проекта выберите «Добавить файлы» в главном меню, чтобы добавить отдельные файлы изображений в текущий проект. Эта функция аналогична функции добавления в файловом браузере, но для удобства доступна непосредственно из главного меню.

## Добавить папку

После открытия проекта выберите в главном меню пункт «Добавить папку», чтобы добавить папки с изображениями в текущий проект. Можно выбрать несколько папок за один раз. Дубликаты файлов игнорируются.

## Запуск / Остановка обработки

После добавления файлов в проект в главном меню становится доступным пункт «Запустить обработку». Это то же самое действие, что и нажатие кнопки «Воспроизвести/Запустить» в верхнем заголовке. Во время обработки пункт меню меняется на «Остановить обработку», чтобы вы могли приостановить конвейер.

## Подключение к камере / Подключение к датчику освещенности

В нижней части главного меню расположены два ярлыка для подключения оборудования, доступные как при открытом, так и при закрытом проекте:

* **Подключить к камере** — открывает [вкладку «Камеры»](lattice/) для подключения камеры или массива камер LATTICE.
* **Подключить датчик освещенности** — открывает вкладку [«Датчики освещенности»](daq/) для подключения датчика освещенности DAQ.

Подключение оборудования при открытом проекте приводит к сохранению его в проекте (см. ниже). Если проект не открыт, подключения действуют только в рамках текущей сессии.

{% hint style="info" %}
Пункты меню «Добавить файлы», «Добавить папку» и «Запустить/Остановить обработку» отображаются или становятся доступными только при открытом проекте и после добавления файлов. Они обеспечивают быстрый доступ к действиям, которые также доступны через боковую панель «Обзор файлов» и кнопки в заголовке.
{% endhint %}

## Проекты запоминают ваше оборудование

Новое в версии 1.2.0: проект сохраняет оборудование, подключенное в период его работы. Камеры и массивы (с настройками для каждой камеры, именами, цветами и расположением в сетке) сохраняются в файле `cameras.json`, а датчики освещенности (с именами, цветами и привязками к камерам) — в файле `sensors.json` — автоматически, по мере вашей работы.

Когда вы **вновь открываете** проект, файл Chloros не подключается к оборудованию сразу. Каждая половина проекта восстанавливает соединение при первом переходе на вкладку, к которой она относится:

* При открытии вкладки **Камеры** происходит повторное подключение сохраненных камер и матриц, а также повторное применение их сохраненных настроек.
* При открытии вкладки **Датчики освещенности** происходит повторное подключение сохраненных датчиков сбора данных (DAQ).

Таким образом, при открытии проекта только для просмотра или экспорта изображений камеры никогда не переходят в режим потоковой передачи. Если при открытии вкладки сохраненное устройство не удается найти, в диалоговом окне отображается информация о недоступных устройствах, чтобы вы могли повторно подключить или удалить их.

## Записи DAQ и файлы .daq в проекте

* Записи `.daq`, сделанные при открытом проекте (из вкладки «Световые датчики» или во время захвата), **автоматически добавляются в проект**.
* Импортированные файлы `.daq`, а также все записи проекта, перечислены в разделе **«Световые датчики DAQ»** в [Настройках проекта](project-settings/project-settings.md), причём для каждой записи указан свой профиль коррекции яркости.
* Во время обработки файлы `.daq` проекта обеспечивают освещение сверху для расчёта коэффициентов отражения — см. [Форматы выходных изображений](output-image-formats.md).

## Запуск сохраненного проекта без графического интерфейса

Сохраненный проект можно запустить без графического интерфейса:

* **CLI**: `chloros-cli project open / connect / capture / sensor / align / run` работает с путем к папке проекта — см. [Справочник по CLI](reference/cli-reference.md).
* **SDK**: `chloros_sdk.open_project(path)` возвращает дескриптор проекта; `connect_all()` переводит все сохраненные камеры и датчики в рабочий режим с сохраненными настройками — см. [Справочник по SDK](reference/sdk-reference.md).
