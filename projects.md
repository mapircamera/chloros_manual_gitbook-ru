# Графический интерфейс: Проекты. Программа

Chloros позволяет создавать проекты, которые можно будет открыть в будущем. Проект представляет собой обычную папку (расположенную в папке «Project Folder»), содержащую:

* `project.json` — настройки проекта, список файлов и параметры отображения
* `cameras.json` — камеры и матрицы, подключённые во время работы с проектом, с их настройками
* `sensors.json` — датчики освещённости DAQ, подключённые во время работы с проектом, а также привязки «камера↔датчик»
* ваши снимки, записи `.daq` и папки с обработанными результатами

Собственного формата файлов проектов нет — проект представляет собой папку и содержащиеся в ней файлы JSON, что также упрощает копирование, архивирование и управление проектами с помощью [CLI](CLI.md) или [Python SDK](api-python-sdk.md).

Если вы не измените это в [Настройках проекта](project-settings/project-settings.md), папка проекта будет `Documents\MAPIR\Chloros Projects` в папке «Документы» (`~/Documents/MAPIR/Chloros Projects` в Linux).

{% hint style="warning" %}
**Windows: используйте короткие имена папок проектов, если не включена поддержка длинных путей.**В Windows по умолчанию отключена поддержка длинных путей, и длина любого пути к файлу не может превышать 260 символов. Обработанные результаты хранятся на уровне примерно на 130 символов ниже папки проекта, поэтому, начиная с версии 1.3.0, Chloros отклоняет слишком глубокую папку проекта — при её создании, открытии или запуске обработки — вместо того, чтобы запускаться и ничего не записывать. В сообщении указывается самая длинная папка проекта, которая подходит. Используйте папку проекта с меньшим именем или включите поддержку длинных путей в Windows (параметр установщика**Включить длинные пути Windows**, отмеченный по умолчанию) и перезапустите Chloros. См. раздел [Запуск обработки](processing-images-gui/starting-the-processing.md#the-project-folder-is-too-deep-for-this-computer).
{% endhint %}

## Новый проект

<figure><img src=".gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>Выберите «Новый проект» в главном меню и введите уникальное имя для вашего проекта.

Если у вас сохранены какие-либо шаблоны проектов, под полем имени появится раскрывающийся список **Выбрать шаблон** — выбор одного из них запустит новый проект с настройками этого шаблона. Шаблоны сохраняются в разделе [Настройки проекта](project-settings/project-settings.md): введите имя в поле «Имя шаблона проекта» и нажмите значок сохранения.

## Открыть проект

<figure><img src=".gitbook/assets/v120-open-project.jpg" alt=""><figcaption><p>В списке «Открыть проект» отображаются все проекты в вашей папке проектов, а внизу находится кнопка <strong>Открыть папку проектов</strong></p></figcaption></figure>

Выберите «Открыть проект», чтобы увидеть список существующих проектов в папке проектов. Если проектов нет, второстепенное боковое меню не откроется. На фотографии выше вы можете увидеть несколько проектов, созданных с помощью графического интерфейса (t1, t2, t3). Проекты с именами в формате DATE\_TIME были созданы с помощью интерфейса командной строки (CLI) с использованием схемы именования проектов по умолчанию. Нажатие на любое имя проекта приведёт к его открытию.

Нажатие кнопки «Открыть папку проекта» открывает проводник вашего компьютера по пути к папке проекта. Вы можете настроить путь к проектам в [Настройках проекта](project-settings/project-settings.md).

Если какие-либо исходные файлы изображений проекта были перемещены или удалены с момента его последнего открытия, Chloros показывает диалоговое окно со списком именно тех файлов, которых не хватает, вместо того, чтобы открывать пустую сетку.

## Дублировать проект

Доступно после открытия проекта. Выберите «Дублировать проект», чтобы скопировать текущий проект под новым именем — Chloros предложит следующее свободное имя (например, «MyProject (2)») — и дубликат откроется сразу же.

## Добавить файлы

После открытия проекта выберите «Добавить файлы» в главном меню, чтобы добавить отдельные файлы изображений в текущий проект. Эта функция аналогична функции добавления в файловом браузере, но для удобства доступна непосредственно из главного меню.

## Добавить папку

После открытия проекта выберите в главном меню пункт «Добавить папку», чтобы добавить папки с изображениями в текущий проект. Можно выбрать несколько папок за один раз. Дубликаты файлов игнорируются.

## Запуск / Остановка обработки

После добавления файлов в проект в главном меню становится доступна команда «Запустить обработку». Это то же самое действие, что и нажатие кнопки «Воспроизвести/Запустить» в верхнем заголовке. Во время обработки пункт меню меняется на «Остановить обработку», чтобы вы могли приостановить конвейер.

## Подключение к камере / Подключение к датчику освещенности

В нижней части главного меню расположены два ярлыка для подключения оборудования, доступные как при открытом, так и при закрытом проекте:

* **Подключить к камере** — открывает [вкладку «Камеры»](lattice/) для подключения камеры или массива камер LATTICE.
* **Подключить датчик освещенности** — открывает [вкладку «Датчики освещенности»](daq/) для подключения датчика освещенности DAQ.

Подключение оборудования при открытом проекте сохраняет его в проекте (см. ниже). Без проекта подключения действуют только в рамках текущего сеанса.

{% hint style="info" %}
Пункты меню «Добавить файлы», «Добавить папку» и «Запустить/Остановить обработку» отображаются или становятся доступными только при открытом проекте и после добавления файлов. Они обеспечивают быстрый доступ к действиям, которые также доступны через боковую панель «Обзор файлов» и кнопки в верхней панели.
{% endhint %}

## Проекты запоминают ваше оборудование

Новое в версии 1.2.0: проект сохраняет информацию об оборудовании, подключенном в то время, пока он открыт. Камеры и массивы (с настройками для каждой камеры, именами, цветами и расположением в сетке) сохраняются в файле `cameras.json`, а датчики освещенности (с именами, цветами и привязками к камерам) — в файле `sensors.json` — автоматически, по мере вашей работы.

Когда вы **вновь открываете** проект, Chloros не подключается к оборудованию сразу. Каждая половина проекта восстанавливает соединение при первом переходе на вкладку, к которой она относится:

* При открытии вкладки **Камеры** восстанавливается соединение с сохраненными камерами и массивами и повторно применяются их сохраненные настройки.
* При открытии вкладки **Датчики освещенности**происходит повторное подключение сохраненных датчиков сбора данных (DAQ) и повторное применение их сохраненных настроек, включая насадку. Датчик, для которого в меню «Cap» выбран параметр**None (голый датчик)**, остаётся «голым». Проект, сохраненный более ранней версией Chloros, регистрировал «голый» датчик как отсутствие выбора, поэтому он восстанавливается с косинусной поправкой на солнечное излучение; установите для него значение «None» ещё раз и сохраните проект.

Таким образом, при открытии проекта только для просмотра или экспорта изображений камеры никогда не переходят в режим потоковой передачи. Если при открытии вкладки сохраненное устройство не удается найти, в диалоговом окне отображается список недоступных устройств, чтобы вы могли повторно подключить или удалить их.

## Записи DAQ и файлы .daq в проекте

* Записи `.daq`, сделанные при открытом проекте (на вкладке «Световые датчики» или во время захвата), **автоматически добавляются в проект**.
* Импортированные файлы `.daq`, а также все записи проекта, перечислены в разделе **«Световые датчики DAQ»** в [Настройках проекта](project-settings/project-settings.md), причём для каждой записи указан свой профиль коррекции яркости.
* Во время обработки файлы `.daq` проекта обеспечивают освещение сверху для расчёта коэффициентов отражения — см. [Форматы выходных изображений](output-image-formats.md).

## Запуск сохраненного проекта без графического интерфейса

Сохраненный проект можно запустить без графического интерфейса:

* **CLI**: `chloros-cli project open / connect / capture / sensor / align / run` работает с путем к папке проекта — см. [Справочник по CLI](reference/cli-reference.md).
* **Сборка SDK**: `chloros_sdk.open_project(path)` возвращает дескриптор проекта; `connect_all()` подключает все сохраненные камеры, массивы и датчики освещенности с их сохраненными настройками (датчики освещенности — через запущенный бэкенд Chloros) — см. [Справочник по SDK](reference/sdk-reference.md).
