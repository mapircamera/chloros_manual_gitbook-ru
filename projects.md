# Графический интерфейс: Проекты

Chloros позволяет создавать проекты, которые можно будет открыть в будущем.

## Новый проект

<figure><img src=".gitbook/assets/project_new.JPG" alt=""><figcaption></figcaption></figure>Выберите «Новый проект» в главном меню и введите уникальное имя для вашего проекта.

## Открыть проект

<figure><img src=".gitbook/assets/project_open.JPG" alt=""><figcaption></figcaption></figure>Выберите «Открыть проект», чтобы увидеть список существующих проектов в папке проектов. Если проектов нет, второстепенное боковое меню не откроется. На фотографии выше вы можете увидеть несколько проектов, созданных с помощью графического интерфейса (t1, t2, t3). Проекты DATE\_TIME были созданы программой CLI с использованием стандартной схемы именования проектов. Нажатие на любое имя проекта откроет его.

Нажатие кнопки «Открыть папку проекта» открывает проводник вашего компьютера по пути к проекту. Вы можете настроить путь к проекту в [Настройках проекта](project-settings/project-settings.md).

## Добавить файлы

После открытия проекта выберите «Добавить файлы» в главном меню, чтобы добавить отдельные файлы изображений в текущий проект. Эта функция аналогична функции добавления в файловом браузере, но для удобства доступна непосредственно из главного меню.

## Добавить папку

После открытия проекта выберите «Добавить папку» в главном меню, чтобы добавить всю папку с изображениями в текущий проект. Дубликаты файлов игнорируются.

## Запуск / Остановка обработки

После добавления файлов в проект в главном меню становится доступна опция «Запустить обработку». Это то же самое действие, что и нажатие кнопки «Воспроизвести/Запустить» в верхнем заголовке. Во время обработки пункт меню меняется на «Остановить обработку», чтобы вы могли приостановить конвейер.

{% hint style="info" %}
Пункты меню «Добавить файлы», «Добавить папку» и «Запустить/Остановить обработку» отображаются или становятся доступными только при открытом проекте и добавленных файлах. Они обеспечивают быстрый доступ к действиям, также доступным через боковую панель файлового браузера и кнопки в верхней панели.
{% endhint %}
