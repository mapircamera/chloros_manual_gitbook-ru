# Песочница для индексов/LUT

«Песочница для индексов/LUT» — это интерактивная рабочая область в программе просмотра изображений Chloros, которая позволяет в режиме реального времени экспериментировать с расчетом мультиспектральных индексов и визуализацией цветов. Этот мощный инструмент помогает тестировать различные индексы, уточнять диапазоны значений и создавать готовые к публикации визуализации без повторной обработки всего набора данных.

## Что такое «Песочница» для индексов/LUT?

### Назначение

«Песочница» предоставляет:

* **Расчет индексов в реальном времени** — мгновенное применение любого растительного индекса
* **Интерактивную настройку LUT** — точную настройку цветовых градиентов и диапазонов
* **Оптимизацию рабочего процесса** — определение оптимальных настроек перед пакетной обработкой

### Sandbox против обработки проекта

**Index/LUT Sandbox (интерактивный):**

* Одно изображение за раз
* Мгновенная обратная связь
* Экспериментальный и итеративный
* Без постоянных изменений в файлах
* Идеально подходит для изучения и тестирования

**Обработка проекта (пакетная):**

* Весь набор данных за раз
* Предварительно настроенные параметры
* Постоянные выходные файлы
* Требует много времени
* Лучше всего подходит, когда настройки окончательно определены

{% hint style="success" %}
**Оптимальный рабочий процесс**: используйте Sandbox для экспериментов и поиска оптимальных настроек индекса и LUT, а затем примените эти настройки во время обработки проекта ко всему вашему набору данных.
{% endhint %}

## Работа с песочницей для индекса/LUT

### Понимание предварительно рассчитанных индексов

В Chloros индексы можно применять во время обработки проекта. Чтобы определить, какие настройки индекса и LUT вы хотите применить к экспорту, проще всего использовать песочницу просмотрщика изображений.

Песочница позволяет:

* **Применять новые индексы и цветовые градиенты (LUT)** для визуализации данных
* **Настраивать параметры визуализации** в интерактивном режиме
* **Просматривать** уже рассчитанные индексные изображения
* **Проверять** значения пикселей на всех уровнях масштабирования

### Открытие песочницы

Доступ к песочнице индекса/LUT осуществляется на вкладке **Просмотрщик изображений** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> :

1. Щелкните изображение в сетке изображений файлового браузера, оно откроется на вкладке **Просмотрщик изображений**<img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 2. Щелкните вкладку**Просмотрщик изображений** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> , чтобы открыть левую всплывающую боковую панель, если она еще не открыта

### Выбор изображения для применения индекса/LUT

Для работы с индексом в песочнице Image Viewer <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> :

1. **Откройте изображение** из основной сетки изображений, щелкнув по нему
2. Затем откроется вкладка **Просмотрщик изображений** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> откроется
3. Нажмите на **выпадающий список «Слой»** (в правом верхнем углу просмотрщика)
4. Выберите слой из выпадающего списка:
   * RAW (Отражение)

### Применение индекса к изображению

Как только изображение будет отображаться в полноэкранном режиме и боковая панель **Просмотрщика изображений** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> :

1. Установите флажок «Индекс» в верхней части боковой панели
2. Выберите фильтр вашей камеры из раскрывающегося списка слева
3. Выберите нужную формулу индекса из раскрывающегося списка справа
4. Перетащите цветные кружки каналов фильтра в соответствующие места в формуле индекса ниже
5. Как только формула будет действительна, изображение обновится и покажет значения индекса
6. Перемещайте курсор мыши, чтобы увидеть значения в месте нахождения курсора
7. Увеличьте масштаб, чтобы увидеть отдельные пиксели и связанные с ними значения

Каждый индекс имеет определенный диапазон значений и значение:

#### Пример NDVI

```

Formula: (NIR - Red) / (NIR + Red)

For Survey3W RGN camera:
NIR = 850nm band
Red = 661nm band

Result range: -1.0 to +1.0
Typical vegetation: 0.4 to 0.9
Stressed vegetation: 0.2 to 0.4
Bare soil: 0.0 to 0.2
Water: -0.1 to 0.1
```

Полную документацию по формулам индексов см. в разделе [Формулы мультиспектральных индексов](../project-settings/multispectral-index-formulas.md).

## Работа с таблицами преобразования (LUT)

### Что такое LUT?

**Таблица преобразования (LUT)** сопоставляет числовые значения индексов с цветами для визуализации:

* **Входные данные**: значение пикселя индекса (например, NDVI 0,65)
* **Выходные данные**: цвет (например, ярко-зеленый)
* **Цель**: облегчить распознавание и интерпретацию закономерностей**LUT для оттенков серого и цветная LUT:**

* Оттенки серого: научный и нейтральный подход, отображает исходные данные
* Цветная LUT: интуитивная и эффектная, выделяет закономерности и различия

{% hint style="success" %}
**Возможности визуализации**: Применение цветной LUT к индексной картинке в оттенках серого значительно упрощает идентификацию узоров, аномалий и областей интереса с первого взгляда.
{% endhint %}

### Применение LUT к индексной картинке

Как только у вас появится индексная картинка, показывающая

1. Нажмите кнопку <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> кнопку «+Добавить LUT»
2. Выберите цветовой градиент
3. Настройте минимальную и максимальную точки обрезки
4. Настройте режим обрезки
5. Установите флажок «Индекс» в боковой панели **Просмотрщика изображений** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> , чтобы применить LUT

### Выбор цветового градиента

**Выбор градиента:**

1. На панели LUT найдите**цветную полосу градиента**

2. Наведите курсор мыши на нее, чтобы просмотреть доступные предустановки градиента
3. Выберите нужный градиент
4. Изображение **немедленно обновляется** с новыми цветами, когда флажок «Индекс» установлен

{% hint style="success" %}
**Рекомендации**: Для индексов растительности, таких как NDVI, градиент Red-Yellow-Green является наиболее интуитивным, поскольку соответствует естественным цветовым ассоциациям (зеленый = здоровый, желтый = умеренный, красный = подверженный стрессу).
{% endhint %}

### Настройка цветовых классов

**Элемент управления «Классы»**определяет, сколько дискретных цветовых шагов будет отображаться в вашем градиенте:**Варианты количества классов:*** **2–5 классов**: очень широкие категории, четко различимые зоны
* **6–10 классов**: сбалансированный, подходит для классификации
* **11–20 классов**: плавные градиенты, непрерывный вид
* **20+ классов**: почти непрерывный, максимальная плавность**Как настроить:**

1. На панели LUT найдите**квадраты с образцами цветов под полосой градиента**

2. Настройте количество классов, добавляя их с помощью кнопки «+»
3. Удалите количество классов, дважды щелкнув по образцу цвета
4. Градиент обновляется **в режиме реального времени** на изображении**Влияние на визуализацию:*** **Меньшее количество классов** (3–5): создает четкие зоны, упрощает классификацию, облегчает различение категорий
* **Среднее количество классов** (6–10): сбалансированный подход, подходит для большинства задач
* **Большее количество классов** (15–20): плавные переходы, детализированные вариации, фотографический вид**Когда использовать:*** **Небольшое количество классов (3–5)**: презентационные слайды, классификационные карты, простые отчеты
* **Среднее количество классов (6–10)**: общий анализ, сбалансированная детализация, стандартные отчеты
* **Большое количество классов (15–20)**: научный анализ, детальное исследование, результаты публикационного качества

### Точная настройка диапазонов значений

**Регуляторы диапазона значений**определяют, какие значения индекса сопоставляются с какими цветами в вашем градиенте:**Регуляторы диапазона на панели LUT:*** **Минимальное значение**: нижняя граница цветовой шкалы
* **Максимальное значение**: верхняя граница цветовой шкалы
* **Промежуточные значения**: автоматически распределяются между минимальным и максимальным значениями (на основе количества классов)

#### Настройка минимальных/максимальных значений

**Чтобы настроить диапазоны значений:**

1. На панели LUT найдите поля ввода**Min Value**и**Max Value**

2. Щелкните поле**Min Value**

3. Введите желаемое минимальное значение (например, `0.2`)
4. Нажмите **Enter** или щелкните за пределами поля
5. Повторите для поля **Максимальное значение** (например, `0.9`)
6. Визуализация **обновится немедленно**{% hint style="info" %}**Автоматическое масштабирование**: При первом применении LUT Chloros автоматически устанавливает минимальное и максимальное значения в соответствии с фактическим диапазоном данных на изображении. Затем вы можете сузить этот диапазон, чтобы сосредоточиться на конкретных диапазонах значений, представляющих интерес.
{% endhint %}

**Пример настройки диапазона NDVI:*** **Полный диапазон**: от `-1.0` до `1.0` (отображение всех возможных значений)
* **С акцентом на растительность**: от `0.2` до `0.9` (исключить голую почву и воду)
* **Только здоровая растительность**: от `0.5` до `0.9` (выделить только сильные растения)
* **Обнаружение стресса**: от `0.2` до `0.5` (выделить проблемные зоны)
* **Пользовательский диапазон**: настройте на основе наблюдаемых значений пикселей**Зачем настраивать диапазоны?*** **Увеличить контраст** в интересующей вас области
* **Исключить нерелевантные значения** (например, водоемы, голую почву)
* **Стандартизация визуализации** для нескольких изображений или дат
* **Выделение тонких различий** в узком диапазоне значений

### Обрезание значений, выходящих за пределы диапазона

Когда значения пикселей выходят за пределы заданного диапазона минимальных/максимальных значений, вы можете контролировать их отображение с помощью **режимов обрезания**.

#### **Доступные варианты режимов обрезания:**

#### 1. Минимальное и максимальное

* Пиксели **ниже минимального значения**→ отображаются с использованием**первого цвета** в градиенте (например, красного)
* Пиксели **выше максимального значения**→ отображаются с использованием**последнего цвета** в градиенте (например, зеленого)
* **Пример использования**: выделение экстремальных значений, отображение полного диапазона данных с насыщенными цветами на границах
* **Пример**: значения NDVI ниже 0,2 отображаются красным цветом, значения выше 0,9 — зеленым

#### 2. Прозрачный фон

* Пиксели **за пределами диапазона**становятся**полностью прозрачными*** Только пиксели **в пределах диапазона** отображают цветовой градиент
* **Применение**: наложение ГИС, выделение определенных диапазонов значений, выделение только интересующих областей
* **Пример**: отображение только значений NDVI от 0,4 до 0,7 в цвете, все остальное прозрачно

{% hint style="warning" %}
**Ограничение прозрачности**: прозрачные пиксели будут отображаться в просмотрщике как цвет фона. При экспорте во время обработки прозрачность сохраняется в формате PNG, но не в JPG.
{% endhint %}

#### 3. Фон индекса

* Пиксели **вне диапазона**отображаются в**оттенках серого** (показывая исходные значения индекса)
* Пиксели **в пределах диапазона**отображаются с**цветовым градиентом*** **Вариант использования**: Незаметная подсветка, сохранение контекста при выделении интересующих областей
* **Пример**: Цветовая подсветка стрессовой растительности (NDVI 0,3–0,5) при отображении здоровых областей в сером цвете

#### 4. Исходный фон

* Пиксели **за пределами диапазона**отображают**исходное мультиспектральное изображение*** Пиксели **в пределах диапазона**отображают**цветовой градиент*** **Вариант использования**: Наиболее интуитивный — сочетает естественный контекст изображения с аналитической цветовой накладкой
* **Пример**: Просмотр фактического вида поля/посевов с наложенными цветокодированными зонами стресса

### Выбор подходящего режима обрезки

| Режим обрезки              | Наилучшее применение                                   | Стиль визуализации          |
| -------------------------- | ------------------------------------------ | ---------------------------- |
| **Минимальный и максимальный**    | Полное отображение данных, научный анализ     | Все пиксели окрашены           |
| **Прозрачный фон** | Наложения ГИС, выделение определенных диапазонов    | Цвет в диапазоне, пустое пространство за пределами |
| **Индексный фон**       | Незаметное выделение, сохранение контекста данных  | Цвет в диапазоне, серый за пределами  |
| **Исходный фон**    | Отчеты, презентации, интуитивный анализ | Цвет в диапазоне, фотография за пределами |

### Создание пользовательских цветов LUT

Для полного контроля над визуализацией вы можете создавать **пользовательские цветовые градиенты**, редактируя отдельные цветовые остановки.**Чтобы создать пользовательский градиент:**

1. На панели LUT найдите**панель предварительного просмотра градиента**

2. Найдите**квадраты с образцами цветов** под градиентом
3. **Щелкните по цветовой остановке**, чтобы выбрать ее
4. Откроется **палитра цветов**

5. Выберите новый цвет с помощью:
   * **Цветового круга**: визуальный выбор цвета
   * **Ползунков RGB/HSV**: точное управление цветом
   * **Ввода шестнадцатеричного кода**: точная спецификация цвета (например, `#FF0000` для красного)
6. Щелкните за пределами палитры цветов, **чтобы применить новый цвет**

7. Градиент**обновится сразу** на изображении**Добавление или удаление цветовых остановок:*** **Добавить остановку**: щелкните значок «+», чтобы добавить новый образец в конец
* **Удалить остановку**: дважды щелкните квадрат цвета, чтобы удалить образец**Стратегии настройки:*** **Инвертировать градиент**: изменить порядок цветов, чтобы перевернуть значение (например, зеленый = низкий, красный = высокий)
* **Цвета бренда**: подобрать цветовую палитру вашей организации для отчетов
* **Подходит для людей с дальтонизмом**: использовать комбинации оранжевого и синего или фиолетового и желтого
* **Оптимизация для печати**: выбрать цвета, которые хорошо смотрятся как при цветной, так и при черно-белой печати
* **Многопороговый**: используйте разные цвета для определенных пороговых значений при классификации

{% hint style="info" %}
**Сохранение пользовательских градиентов**: пользовательские градиенты можно сохранять и использовать повторно. Нажмите значок сохранения на панели LUT, чтобы сохранить свои пользовательские цветовые схемы для будущего использования.
{% endhint %}

## Интерактивный рабочий процесс

### Обновления в реальном времени

Все настройки LUT в тестовой среде обновляют изображение **мгновенно и интерактивно**:

* **Переключение слоя** → Изображение меняется немедленно
* **Выбор градиента** → Цвета обновляются мгновенно
* **Настройка диапазона значений** → Контрастность меняется в реальном времени
* **Изменение классов** → Плавность градиента обновляется немедленно
* **Изменение обрезки** → Отображение фона меняется мгновенно
* **Редактирование цветов** → Пользовательский градиент применяется немедленно**Кнопка «Применить» не нужна** — все изменения происходят в режиме реального времени и интерактивно!

{% hint style="success" %}
**Обратная связь в реальном времени**: Мгновенная визуальная обратная связь позволяет быстро экспериментировать с различными настройками, пока вы не найдете оптимальную визуализацию для ваших аналитических задач.
{% endhint %}

### Рабочий процесс итеративной доработки

**Типичный рабочий процесс оптимизации LUT:**

1.**Выберите индексный слой** (например, RAW (Отражение))
2. **Примените индекс** — выберите фильтр камеры и формулу индекса, перетащите цветные кружки в соответствующие места в формуле индекса
3. **Примените градиент LUT** - Начните с пресета Red-Yellow-Green
4. **Проверьте значения пикселей** — перемещайте курсор, обратите внимание на диапазоны значений
5. **Настройте минимальное/максимальное значение** — сузьте диапазон, чтобы сосредоточиться на растительности (например, от 0,2 до 0,9)
6. **Выберите обрезку** — попробуйте «Original Background» для контекста
7. **Уточните цвета** — настройте градиент, если необходимо, для конкретного акцента
8. **Завершите настройки**— задокументируйте настройки и скопируйте их в «Project Settings» для обработки экспорта

### Проверка значений пикселей

Понимание фактических значений пикселей имеет решающее значение для установки эффективных диапазонов LUT:**Как проверить значения:**

1. Значения пикселей отображаются, когда на изображении**установлены флажки** «Индекс» или «Индекс» и «LUT».
2. **Наведите курсор** на разные области изображения
3. **Наблюдайте за значениями пикселей**, отображаемыми в легенде при наведении курсора
4. Увеличьте масштаб, чтобы увидеть отдельные пиксели, выделенные плавающим значением
5. **Запишите** диапазоны значений для различных объектов:
   * **Здоровая растительность**: например, NDVI 0,55–0,85
   * **Стрессовая растительность**: например, NDVI 0,30–0,50
   * **Голая почва**: например, NDVI 0,05–0,25
   * **Вода** (если присутствует): например, NDVI от -0,05 до 0,10**Использование значений пикселей для настройки диапазонов LUT:**После проверки значений пикселей настройте минимальное и максимальное значения LUT соответствующим образом:**Пример сценария:*** **Наблюдение**: Значения почвы = 0,05–0,25, Стресс = 0,25–0,50, Здоровое состояние = 0,50–0,85
* **Цель**: Визуализировать только здоровье растений (исключить почву)
* **Настройки LUT**: Мин. = `0.25`, Макс. = `0.85`
* **Обрезка**: «Исходный фон», чтобы увидеть почву в естественных цветах
* **Результат**: Цветовой градиент применяется только к растительности, почва отображается как на исходном изображении

{% hint style="info" %}
**Динамический диапазон**: Различные культуры, сезоны и стадии роста будут иметь разные диапазоны значений. Всегда проверяйте значения пикселей в вашем конкретном наборе данных перед настройкой диапазонов LUT.
{% endhint %}

## Пользовательские индексы (Chloros+)

### Создание формул пользовательских индексов

{% hint style="info" %}
**Где создавать**: Пользовательские индексы можно настроить в**Настройках проекта** перед обработкой, а также в боковой панели песочницы просмотрщика изображений.
{% endhint %}

**Чтобы создать пользовательский индекс:**

1.**Откройте «Настройки проекта»** (до начала обработки) или боковую панель «Песочницы» в Image Viewer
2. Перейдите к **раскрывающемуся списку «Формула индекса»**

3. Найдите опцию**«Пользовательский»** (необходимо войти в систему с лицензией Chloros+)
4. **Определите свою формулу**, используя переменные диапазонов:
   * Названия диапазонов: `NIR`, `Red`, `Green`, `Blue`, `RedEdge` и т. д.
   * Операторы: `+`, `-`, `*`, `/`, `^` (экспонента)
   * Функции: `sqrt()`, `abs()` и т. д. (если поддерживаются)
   * Скобки: `()` для определения порядка операций
5. **Назовите свой индекс** (например, «MyIndex» или «CustomNDVI»)
6. **Сохраните настройки**

**Примеры пользовательских формул:**

```

Modified NDVI with offset:
(NIR - Red) / (NIR + Red + 0.5)

Simple ratio:
NIR / Red

Complex multi-band:
(NIR - Red) / (NIR + Red - Blue)

Exponential index:
(NIR / Red) ^ 2
```

{% hint style="warning" %}
**Проверка формулы**: Убедитесь, что ваша формула использует полосы, доступные в вашей камере. Например, RedEdge доступна только на камерах с фильтром RedEdge.
{% endhint %}
