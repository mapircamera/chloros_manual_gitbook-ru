# Песочница «Index/LUT»

Песочница «Index/LUT» — это интерактивная рабочая область на боковой панели программы просмотра изображений Chloros. Вы выбираете формулу, привязываете к ней каналы вашей камеры, раскрашиваете изображение градиентом и настраиваете диапазон значений — и изображение обновляется в режиме реального времени по мере ваших действий. Начиная с версии 1.2.0 вы также можете **сохранять созданные настройки** как для одного изображения, так и для всего проекта, без повторной обработки.

## Для чего нужна «Песочница»

| «Песочница» Index/LUT (интерактивная)        | Обработка проекта (пакетная)       |
| -------------------------------------- | -------------------------------- |
| По одному изображению за раз, мгновенная обратная связь  | Весь набор данных за один прогон     |
| Экспериментальный и итеративный режим             | Предварительно настроенные параметры          |
| Рендеринг в режиме реального времени; сохранение только по запросу  | Всегда записывает готовые файлы      |
| Идеально подходит для поиска подходящих настроек | Лучше всего использовать, когда настройки окончательно определены |

{% hint style="success" %}
**Обычный рабочий процесс**: настраивайте в Sandbox, пока визуализация не будет соответствовать вашим ожиданиям, затем либо экспортируйте напрямую из Sandbox, либо скопируйте те же настройки индекса и LUT в [Настройки проекта](../project-settings/project-settings.md), чтобы при следующем прогоне обработки они были применены ко всем изображениям.
{% endhint %}

## Открытие Sandbox

1. Щелкните по изображению в сетке — оно откроется в полноэкранном режиме на вкладке **Image Viewer** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line">
2. Щелкните значок **Просмотрщика изображений** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line">, чтобы развернуть левую боковую панель, если она ещё не открыта
3. Выберите многополосный слой из раскрывающегося списка слоёв в правом верхнем углу — обычно выбирают **RAW (Отражательная способность)**, поскольку значения индекса, рассчитанные на основе откалиброванной отражательной способности, сопоставимы между изображениями

На боковой панели отображаются (сверху вниз):

* название изображения и модель камеры
* кнопка **Экспорт/Сохранение изображений** — появляется после установки флажка «Индекс» или «LUT»
* флажки **Индекс**и**LUT**
* панель настроек индекса
* панель **Значения курсора** с показаниями, гистограммой и регулятором GSD

{% hint style="warning" %}
**Недоступно для монохромных камер.** На однодиапазонном изображении LATTICE M3M оба флажка отключены, с подсказкой _«Недоступно для монохромных (M3M) датчиков» — многополосный индекс для одного диапазона не определен. Для вычисления индексов с камер M3M объедините две или более камер в выровненный многополосный стек и используйте движок индексов LATTICE.
{% endhint %}

## Применение индекса

1. Установите флажок **«Индекс»** в верхней части боковой панели
2. Выберите фильтр вашей камеры из выпадающего списка слева (`RGN`, `OCN`, `NGB`, `RGB`, `RE`, `NIR`)
3. Выберите формулу индекса из правого раскрывающегося списка — 27 встроенных формул, а также любые пользовательские формулы, которые вы сохранили
4. Формула отображается в виде математического выражения ниже, с пустым кружком в каждом слоте полосы. **Перетащите цветной кружок канала на ячейку**, чтобы привязать его
5. Как только все ячейки, используемые в формуле, будут привязаны, изображение обновится и покажет значения индекса
6. Наведите курсор на изображение, чтобы прочитать значения; панель **Значения курсора** добавит строку индекса со значением под курсором

Дважды щелкните привязанное поле, чтобы очистить его. Незавершённая формула — это нормальное состояние во время перетаскивания, а не ошибка: изображение просто не обновляется, пока формула не будет завершена.

Круги каналов имеют цветовую маркировку: красный = Red, зеленый = Green, синий = Blue, оранжевый = Orange, голубой = Cyan, фиолетовый = NIR, пурпурный = RE. Те же цвета используются для точек каналов и кривых гистограммы на панели «Значения курсора».

### Пример NDVI

```

Formula: (NIR - Red) / (NIR + Red)

For a Survey3W RGN camera:
  NIR = 850 nm band
  Red = 661 nm band

Result range:          -1.0 to +1.0
Typical vegetation:     0.4 to 0.9
Stressed vegetation:    0.2 to 0.4
Bare soil:              0.0 to 0.2
Water:                 -0.1 to 0.1
```

Полный справочник по формулам — все три списка предустановок и информация о том, какие имена где используются — см. в разделе [Формулы мультиспектральных индексов](../project-settings/multispectral-index-formulas.md).

### При установленном флажке «Индекс», но без таблицы LUT

Изображение рисуется в **оттенках серого**, растянутых между двумя пороговыми значениями. Это сделано намеренно: индекс-изображение представляет собой скалярные данные, и отображение в оттенках серого является его точным воспроизведением. Добавьте LUT, если хотите получить цветное изображение.***

## Работа с LUT (таблицами преобразования)**Таблица соответствий** сопоставляет значения индекса с цветами: входное значение NDVI 0,65, выходной — определённый оттенок зелёного. Она не изменяет данные — она изменяет способ их интерпретации.

### Добавление LUT

1. Нажмите кнопку **«+ Добавить LUT»** (<img src="../.gitbook/assets/image (1) (1) (1).png" alt="" data-size="line">) под формулой
2. Выберите цветовой градиент
3. Установите минимальное и максимальное значения отсечения
4. Выберите режим отсечения
5. Установите флажок **LUT** на боковой панели, чтобы применить его

Флажок LUT остаётся неактивным, пока таблица LUT не будет фактически настроена для индекса.

### Выбор цветового градиента

Наведите курсор на **полосу градиента**, чтобы открыть список предустановок — Chloros поставляется с**семью** предустановками градиентов:

| # | Градиент                            | Форма                                                               |
| - | ----------------------------------- | ------------------------------------------------------------------- |
| 1 | Red → Жёлтый → Green (**по умолчанию**)  | Расходящийся — соответствует обычному представлению о растительности: зелёный = здоровый |
| 2 | Фиолетовый → Жёлтый → Green             | Расходящийся, с чётко выраженным нижним диапазоном                                  |
| 3 | Коричневый → Белый → Blue                | Расходящийся вокруг светлой средней точки                                   |
| 4 | Чёрный → Пурпурный → Розовый → Бледно-жёлтый | Последовательная, от тёмного к светлому                                           |
| 5 | Red → Жёлтый → Blue                 | Расходящаяся вокруг светлой средней точки                                   |
| 6 | Фиолетовый → Blue → Green → Жёлтый      | Последовательно, от тёмного к светлому                                           |
| 7 | Orange → Белый → Пурпурный             | Расходится вокруг светлой средней точки                                   |

**Расходящийся**градиент помещает нейтральный цвет в середину окна, что хорошо воспринимается, когда средняя точка имеет определённое значение (пороговое значение, базовую дату).**Последовательный** градиент монотонно переходит от тёмного к светлому, что удобно для величин, у которых есть только «больше» и «меньше».

Каждая предустановка имеет семь цветовых точек. Щёлкните по предустановке, и изображение сразу обновится (если установлен флажок LUT).

### Редактирование цветовых остановок

Под полосой градиента находится ряд цветовых образцов, по одному на каждую остановку:

* **Изменить цвет**: щелкните образец, чтобы открыть палитру цветов (цветовое колесо, ползунки RGB/HSV или шестнадцатеричный код, например `#FF0000`)
* **Добавить остановку**: щелкните кнопку**+** в конце ряда — будет добавлена белая остановка
* **Удалить остановку**:**дважды щелкните** образец
* **Сохранить отредактированный градиент**: щелкните значок сохранения рядом с полосой градиента, чтобы добавить отредактированный градиент в список предустановок и иметь возможность выбрать его вновь

Градиент, настроенный вами для индекса, сохраняется вместе с этим индексом в настройках проекта, поэтому он сохраняется даже после закрытия и повторного открытия проекта.

**Меньшее количество точек**создает чётко разграниченные зоны, которые воспринимаются как классификация;**большее количество точек** создает плавные, почти фотографические переходы. От трёх до пяти точек подходят для презентационных слайдов и классификационных карт; от шести до десяти — для общего анализа; пятнадцать и более — для детального изучения и иллюстраций в публикациях.

### Настройка диапазона значений

Регулятор порогового значения представляет собой **ползунок с двумя ручками**, диапазон которого простирается от −1 до +1; на каждом конце имеется редактируемое текстовое поле для ввода точных значений, а также кнопка**AUTO**.

* Перетащите любой из ползунков или введите число в соответствующее поле и нажмите Enter
* **AUTO**устанавливает диапазон в пределах**2-го и 98-го процентилей** допустимых значений индекса изображения — это хорошая отправная точка, игнорирующая выбросы. Chloros адаптивно округляет результат: до 4 знаков после запятой для очень узкого диапазона, до 3 — для узкого, и до 2 — в остальных случаях
* Любая ручная настройка имеет приоритет над режимом AUTO, пока вы не нажмёте кнопку AUTO снова

Пример окон NDVI:

| Цель                                    | Мин.  | Макс. |
| --------------------------------------- | ---- | --- |
| Показать всё                         | −1,0 | 1,0 |
| Только растительность, исключить почву и воду | 0,2  | 0,9 |
| Только здоровая растительность                 | 0,5  | 0,9 |
| Выделить стресс                        | 0,2  | 0,5 |

Сужение диапазона повышает контрастность внутри интересующей вас области и выводит всё остальное за пределы диапазона — где **режим обрезки** определяет, что с ним произойдёт.***

## Режимы обрезки

Когда значение индекса пикселя выходит за пределы диапазона min/max, режим обрезки определяет, как он будет отображаться.

| Название раскрывающегося списка                  | Сохраненное значение      | Пиксели, выходящие за пределы диапазона, отображаются как                                                                                                |
| ------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Минимальное и максимальное** (по умолчанию) | `clip`            | Ближайший конечный цвет градиента — значения ниже минимального принимают первый цвет, значения выше максимального — последний |
| **Прозрачный фон**      | `transparent`     | Полностью прозрачный (реальный альфа-канал)                                                                                                  |
| **Индексный фон**| `indexColor`      | Оттенки серого, растянутые на**весь** индексный диапазон изображения, поэтому структура, выходящая за пределы диапазона, по-прежнему видна в сером                |
| **Исходный фон**         | `backgroundColor` | Само базовое изображение, поэтому цветовая накладка располагается поверх реальной сцены                                                |

| Режим                       | Лучше всего подходит для                               | Внешний вид                                      |
| -------------------------- | -------------------------------------- | ----------------------------------------- |
| **Минимальное и максимальное**      | Полное отображение данных, научный анализ | Каждый пиксель окрашен                      |
| **Прозрачный фон** | Наложения ГИС, выделение диапазона значений   | Цвет внутри окна, ничего снаружи |
| **Индексный фон**       | Выделение с сохранением контекста данных    | Цвет внутри, серый снаружи               |
| **Исходный фон**    | Отчёты и презентации              | Цвет внутри, фотография снаружи         |

{% hint style="info" %}
**Пиксели без данных всегда прозрачны, в любом режиме.** Пиксель, индекс которого не является конечным (деление на 0/0) или равен ровно −1,0 или +1,0 (индикаторы насыщенности, возникающие, когда один диапазон показывает ноль, а другой — нет), рассматривается как отсутствие данных, а не как экстремальное значение. Это позволяет исключить пересвеченные области и «мертвые» тени из цветовой шкалы, вместо того чтобы отображать их как самые крайние значения в кадре. То же правило определяет, какие пиксели используются для расчёта пороговых значений AUTO и гистограммы индексов, благодаря чему все три показателя совпадают.
{% endhint %}

Прозрачность сохраняется при экспорте в формате PNG. Её невозможно передать в формате JPG.

## Считывание значений во время настройки

Панель **Значения курсора** под панелью настроек служит измерительным инструментом для Sandbox:

* Наведите курсор на изображение и просмотрите исходные значения по каналам, а также значение индекса в отдельной строке
* Включите кнопку **INDEX** над гистограммой, чтобы увидеть распределение значений индекса в кадре: два порога обрезки будут отображаться в виде оранжевых пунктирных линий, а значение курсора — в виде белой линии; это самый быстрый способ выбрать окно, которое действительно содержит ваши данные
* Включите **CURSOR**, чтобы увидеть линии-маркеры на значениях под указателем
* Увеличьте масштаб свыше 60× (меньше, если задан размер блока GSD), чтобы выделить отдельные отображаемые пиксели с плавающим значением

Практическая инструкция:

1. Запишите значения над здоровой растительностью, стрессовой растительностью, голой почвой и водой
2. Посмотрите, где эти скопления находятся на гистограмме индекса
3. Установите минимальное и максимальное значения, чтобы охватить интересующее вас скопление
4. Выберите режим обрезки — _Original Background_ сохраняет видимость сцены вокруг него

## Экспорт из Sandbox

Всё вышеописанное является предварительным просмотром в режиме реального времени, пока вы не сохраните его. Кнопка **«Экспорт/Сохранение изображений»** в верхней части боковой панели открывает панель, которая выдвигается поверх боковой панели (а не закрывает изображение, так что вы по-прежнему можете видеть то, о чём принимаете решение).

<figure><img src="../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>### Параметры

| Параметр                          | Эффект                                                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Применить к текущему изображению**      | Сохраняет именно то изображение, которое отображается, с этими настройками                                                                                                |
| **Применить ко всем изображениям проекта** | Повторно применяет ту же конфигурацию ко всем изображениям в проекте. Изображения, не содержащие полос, необходимых для данного индекса, пропускаются и не рассматриваются как ошибки |
| **Градиентная шкала индекса/LUT**      | Также записывает отдельное изображение с легендой для каждого экспорта, с указанием диапазона значений                                                                     |
| **Гистограмма индекса**             | Также записывает отдельное изображение гистограммы для каждого экспорта, показывающее минимальное и максимальное значения данных, а также пороги клипирования                                               |

Если значение **Размер блока GSD** на вкладке изображения превышает 1, панель уведомит вас об этом перед подтверждением: при экспорте будет сохранено то, что вы видите на экране, включая усреднение по блокам. Сначала верните значение GSD к 1, если хотите получить полное разрешение.

### Куда сохраняются файлы

Каждый клик по кнопке **«Экспорт»**выделяет**новую, никогда не используемую повторно папку**:

```
<project folder>/Sandbox_Exports/<IndexName>_<Index|LUT>_<NNN>/
```

Примеры: `Sandbox_Exports/NDVI_LUT_001/`, затем `Sandbox_Exports/NDVI_LUT_002/` для следующего запуска. Нумерация формируется на основе сканирования того, что уже находится на диске, поэтому она сохраняется даже после перезапуска и удаления папок вручную. Ничто никогда не перезаписывается — весь смысл «песочницы» заключается в сравнении одной попытки с предыдущей.

Внутри папки, для каждого образа:

| Файл                                                   | Содержимое                                                   |
| ------------------------------------------------------ | ---------------------------------------------------------- |
| `<source name>_<IndexName>_<Index\|LUT>.png`           | Отображённое изображение, пиксель за пикселем то, что показывал просмотрщик |
| `<source name>_<IndexName>_<Index\|LUT>_legend.png`    | Вспомогательный файл с полосой градиента, если запрашивается                     |
| `<source name>_<IndexName>_<Index\|LUT>_histogram.png` | Вспомогательный файл с гистограммой индексов, если запрашивается                  |

Обе боковые панели всегда записываются с **полным разрешением**, даже если основное изображение усреднено по блокам: размер блока соответствует разрешению дисплея, и обе боковые панели отображают истинные значения индекса для каждого пикселя. Кроме того, они отображают больше информации, чем экранные версии — оба фиксируют окно растяжения _и_ истинные минимальные/максимальные значения данных, благодаря чему сохраненная легенда остаётся читаемой даже спустя несколько месяцев без необходимости открывать проект.

### Ход выполнения и результаты

Экспорт всего проекта занимает несколько минут, поэтому программа сообщает о ходе выполнения через канал реального времени, а не блокирует работу:

* Индикатор выполнения отображает `current / total` и файл, в который ведётся запись
* По завершении в панели отображается количество экспортированных изображений, количество пропущенных, а также путь к папке вывода
* Пропущенные изображения перечисляются с указанием причины (отображается до пяти, затем идет строка «+N more»). Обычной причиной является слой, не содержащий каналов, необходимых для данного индекса
* Если **ни одно** изображение в проекте не может использовать данный индекс, процесс завершается с сообщением об ошибке, а не оставляет пустую папку

Одновременно может выполняться только один экспорт в песочнице. Попытка запустить второй процесс, пока первый ещё выполняется, будет отклонена с чётким сообщением, чтобы избежать конфликта двух процессов при работе с одним и тем же файлом проекта.

### Сетка отображает завершённые запуски

Каждый завершённый запуск отображается в виде отдельной кнопки на панели инструментов [сетки изображений](image-grid.md) с надписью `<IndexName> <Index|LUT> <NNN>`. Именно так можно сравнивать запуски: дважды выполните экспорт с разными градиентами или пороговыми значениями, а затем переключайтесь между двумя кнопками в сетке.

## Пользовательские формулы индекса (Chloros+)

{% hint style="info" %}
**Где их создавать**: на боковой панели «Песочницы» или в**Настройках проекта** перед обработкой. Обе опции записывают данные в один и тот же список на уровне проекта.
{% endhint %}

1. Откройте калькулятор пользовательских формул из выпадающего списка формул индекса (требуется вход в систему с подходящей подпиской Chloros+)
2. Введите формулу, используя **символы диапазонов и слотов** `x`, `y`, `z`, `a`, `b`, `c` — это не названия диапазонов
3. Доступные операторы: `+`, `-`, `*`, `/`, `^` и `()` для группировки
4. Доступные функции: `sqrt()`, `log()`, `ln()`, `abs()`, `sign()`, `log1p()`, `log2()`
5. Назовите и сохраните её — она появится внизу раскрывающегося списка формул, и вы сможете привязать к ней слоты, перетаскивая кружки каналов, точно так же, как и в случае со встроенными пресетами

```

Modified NDVI with an offset:   (y-x)/(y+x+0.5)
Simple ratio:                   y/x
Three-band difference:          (y-x)/(y+x-z)
Squared ratio:                  (y/x)^2
```

{% hint style="warning" %}
**Пользовательские формулы доступны только в графическом интерфейсе.** Опция CLI/SDK `--indices` расширяет список 22 встроенных пресетов и автоматически игнорирует всё остальное, включая ваши пользовательские формулы. Чтобы применить пользовательскую формулу пакетно, настройте её в «Настройках проекта» и запустите обработку, либо воспользуйтесь функцией экспорта «Применить ко всем изображениям проекта» в Sandbox.
{% endhint %}

## Устранение неполадок

### «В этом слое нет каналов, необходимых для данного индекса»

Формула запрашивает положение канала, которого в текущем слое нет — например, индекс с тремя слотами в файле с одним или двумя каналами. Переключитесь на многополосный слой (отражательный или с удаленным байеровским фильтром) или выберите индекс, соответствующий фильтру вашей камеры.

### «Не удалось установить связь с бэкэндом обработки изображений»

Бэкенд не отвечает. Проверьте вкладку «Журнал»; если бэкэнд перезапускается, Sandbox восстановит работу самостоятельно, как только он возобновит работу.

### Изображение не изменилось при перетаскивании круга

Формула ещё не завершена. Незавершённая формула рассматривается как обычное состояние в процессе перетаскивания — ничего не рендерится, и об этом не выдаётся сообщение об ошибке. Заполните все поля, используемые формулой.

### Все изображение одного цвета

Вероятно, окно клипа находится далеко за пределами диапазона данных. Нажмите **AUTO**, чтобы привязать его к 2-му/98-му процентилю, или включите гистограмму**INDEX**, чтобы увидеть, где фактически находятся данные.

### Экспортированные цвета не совпадают с тем, что я видел

Они должны совпадать — путь экспорта намеренно зеркально отражает предварительный просмотр в реальном времени, включая альфа-канал в режиме обрезки, а усреднение по блокам применяется _после_ окрашивания точно так же, как это делает просмотрщик. Если они отличаются, проверьте, не изменился ли размер блока GSD между просмотром и экспортом.
