# Открытие изображения в полноэкранном режиме

<figure><img src="../.gitbook/assets/image (34).png" alt=""><figcaption><p>Изображение, открытое в полноэкранном режиме, с панелью выбора слоев в правом верхнем углу</p></figcaption></figure>

Программа просмотра изображений Chloros представляет собой полноэкранный интерфейс для просмотра, анализа и измерения ваших изображений. Именно здесь вы можете считывать **реальные значения пикселей** — DN по каждому каналу, процент отражения или яркость в Вт/м²/ср/нм — а не растянутый предварительный просмотр, отображаемый на экране.

## Доступ к просмотрщику изображений

### Из файлового браузера

1. Откройте вкладку **«Файловый браузер»** <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line">
2. Щелкните любую **миниатюру** в [сетке изображений](image-grid.md)
3. Изображение откроется в полноэкранном режиме на вкладке **Просмотрщик изображений**

Изображение откроется в том продукте, который был выбран в сетке. Если сетка настроена на `RAW (Reflectance)`, то именно на этом слое вы и окажетесь.

### Открытие боковой панели **Просмотрщика изображений**Щелкните значок**Просмотрщика изображений** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> на левой боковой панели, чтобы развернуть панель анализа. На ней сверху вниз расположены:

* название изображения и модель камеры
* кнопка **Экспорт/Сохранение изображений** (доступна только при активном индексе или LUT)
* флажки **Индекс**и**LUT**, а также панель настроек индекса — см. [Песочница «Индекс/LUT»](index-lut-sandbox.md)
* панель **Значения курсора**: считывание по каналам, гистограмма слоя и регулятор GSD***

## Навигация и масштабирование

### Просмотр изображений

* **Следующее изображение**: кнопка → или клавиша**→** (стрелка вправо)
* **Предыдущее изображение**: кнопка ← или клавиша**←** (стрелка влево)
* **Переход к конкретному изображению**: вернитесь к сетке и щелкните его миниатюру

Масштаб и панорамирование сохраняются при переходе между изображениями, поэтому вы можете просматривать набор изображений, оставаясь в одной и той же части кадра.

### Масштабирование

Масштабирование осуществляется с помощью **колесика мыши** с шагом 15 % и привязкой к курсору — точка под указателем остаётся под указателем. Диапазон ограничен размером изображения и окна: невозможно уменьшить масштаб ниже уровня «по размеру окна», а верхний предел определяется собственным разрешением изображения.

В полноэкранном просмотрщике нет специальных клавиш для масштабирования. (В сетке комбинации **Ctrl + `+` / `−`** изменяют размер миниатюр — это другой механизм управления.)

### Панорамирование при увеличении

Щелкните и удерживайте левую кнопку мыши над изображением, а затем перетащите курсор. Панорамирование ограничено, поэтому изображение нельзя вытащить за пределы экрана.

### Просмотр отдельных пикселей при высоком увеличении

Как только эффективное увеличение превышает **60×**, Chloros рисует выделенную рамку вокруг отдельного отображаемого пикселя под курсором и отображает плавающее значение рядом с ним.

«Эффективное» увеличение учитывает размер блока GSD: при размере блока 8 выделение появляется при увеличении 7,5×, а не 60×, поскольку один отображаемый пиксель уже соответствует 8 × 8 пикселям исходного изображения. При уменьшении масштаба ниже порогового значения выделение исчезает.

### Горячие клавиши

| Клавиша                             | Где       | Действие                              |
| ------------------------------- | ----------- | ----------------------------------- |
| **→**                           | Полный экран | Следующее изображение                          |
| **←**                           | Полный экран | Предыдущее изображение                      |
| **Ctrl + R**                    | Полный экран | Сброс индекса/песочницы LUT         |
| **Ctrl + `+`**/**Ctrl + `=`** | Сетка        | Увеличенные миниатюры (4 пикселя за нажатие)  |
| **Ctrl + `−`**                  | Сетка        | Меньшие миниатюры (4 пикселя за нажатие) |***

## Значения курсора

Наведите курсор на изображение, и на панели **Значения курсора** отобразятся значения всех каналов, расположенных под ним.

{% hint style="success" %}
**Это реальные значения файла.** Холст на экране представляет собой 8-битный растянутый предварительный просмотр и не может предоставить эти значения, поэтому Chloros берет образцы из фактического файла продукта для отображения. Именно поэтому 12-битный необработанный кадр отображает значения выше 255, а слой яркости типа float32 — физические единицы измерения.
{% endhint %}

### Значение столбцов

Панель адаптируется к просматриваемому слою:

| Просматриваемый слой              | Отображаемые столбцы    | Примечания                                                                                           |
| ---------------------------------- | ---------------- | ----------------------------------------------------------------------------------------------- |
| Коэффициент отражения                        | **DN**и**%** | Процент рассчитывается с учётом собственной шкалы данного файла — см. ниже                                      |
| Яркость                           | **Вт/м²/ср/нм**   | Физические значения типа «float»; столбец DN отсутствует, так как в данном случае значение DN не имеет смысла                           |
| Исходные данные / Без байеризации / Предварительный просмотр / JPG    | **DN**           | Целые цифровые значения                                                                         |
| Экспорт значений отражательной способности в формате 32-битовые данные отражательной способности в процентах | Только **%**       | Сохраненное число с плавающей запятой не является значением DN, поэтому при округлении до целого числа будет выведено бессмысленное значение `0` или `1` |

Каждая строка обозначена именем канала фильтра вашей камеры — `Red / Green / NIR` для RGN, `Orange / Cyan / NIR` для OCN, `NIR / Green / Blue` для NGB, `Red / Green / Blue` для RGB, а также однополосное название для RE, NIR и монохромных камер M3M. Каждая метка имеет цветную точку, соответствующую кругам каналов, используемым в редакторе формул индекса.

Сохраненные **индексы и LUT** представляют собой особый случай: они содержат компоненты цветовой карты, а не спектральные полосы, поэтому их строки обозначены как `Red / Green / Blue` (или `Index` для одноканального индексного файла), а не названиями фильтров камеры.

Когда индекс активен в песочнице, под каналами появляется дополнительная строка, отображающая **значение индекса** в месте нахождения курсора, с названием индекса и белой точкой, соответствующей его маркеру на гистограмме.

### Процент отражения использует собственную шкалу каждого файла

{% hint style="warning" %}
**Не следует считать, что 65535 = 100%.** Chloros сохраняет коэффициент отражения в разных масштабах в зависимости от того, какая камера его сгенерировала, и программа просмотра определяет правильный масштаб для каждого файла.
{% endhint %}

| Источник                  | DN, равный коэффициенту отражения 1,0 | Как он идентифицируется                                                                                                                               |
| ----------------------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LATTICE**(M3C / M3M) |**32768**                      | Тег XMP `Chloros:PixelScale=32768` записывается в каждый экспорт данных о коэффициенте отражения из LATTICE. Запас в 2× позволяет файлу передавать значения ρ выше 1,0 без обрезания |
| **Survey3**|**65535**                      | Отсутствует тег масштаба XMP Chloros — калибровка Survey3 записывает ρ × dtype-max и обрезает значения при 1,0                                                               |

Просмотрщик, песочница индекса/LUT и экспорт индекса все определяют масштаб с помощью одной и той же реализации, поэтому значение, которое вы считываете в точке курсора, совпадает со значением, использованным в вычислениях индекса.

Два важных следствия, о которых стоит знать:

* **32-битный процент**TIFF сохраняет значение DN/65535 в виде числа с плавающей запятой, а**8-битный** экспорт PNG/JPG сохраняет значение DN × 255/65535 — просмотрщик преобразует оба значения обратно перед выводом значения в процентах.
* Один случай не поддаётся восстановлению: **8-битный экспорт TIFF снимка с 8-битным исходным изображением** обрезается до диапазона 0–255 вместо перемасштабирования и намеренно не содержит метки масштаба. Для таких файлов панель выводит только значения DN, без столбца с процентами. Это честный ответ, а не ошибка.***

## Гистограмма слоя

Под строками курсора находится динамическая гистограмма просматриваемого слоя, состоящая из **256 интервалов**. По умолчанию она отображает одну сводную кривую, взвешенную по методу `(R + 2G + B) / 4` — тому же пространству измерений, которое используют гистограммы камеры LATTICE. Включение параметра**RGB** заменяет её кривыми по каждому каналу в цветах каналов, аддитивно смешанными так, чтобы перекрытия оставались разборчивыми. Монохромные слои всегда отображают одну кривую.

Горизонтальная ось имеет собственную систему единиц слоя:

| Слой       | Единица оси  | Максимальное значение оси                                               |
| ----------- | ---------- | ---------------------------------------------------------- |
| Отражательная способность | проценты    | 125% — запас по масштабу продукта допускает ρ выше 1,0           |
| Световая мощность    | Вт/м²/ср/нм | Собственный пик кадра, округлённый до двух значащих цифр |
| 8-битные данные | DN         | 255                                                        |
| 12-битные данные | DN         | 4095                                                       |
| 16-битные данные | DN         | 65535                                                      |

Когда ось настроена на DN и упирается в один из этих трёх верхних пределов, Chloros также определяет разрядность просматриваемого изображения.

Над гистограммой расположены три кнопки:

| Кнопка     | По умолчанию | Эффект                                                                                                                                                                                                                                                                                   |
| ---------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **КУРСОР** | Вкл.      | Рисует на гистограмме линии-маркеры в точках, соответствующих значениям, указанным в строках выше, чтобы вы могли увидеть, где пиксель под курсором находится в распределении кадра. В режиме RGB для каждого канала отображается по одному маркеру своего цвета; в остальных случаях — один белый маркер на суммарном значении |
| **ИНДЕКС**| Вкл.      | Появляется только при активном индексе. Переключает гистограмму с исходных полос на**распределение значений индекса**, при этом два порога клиппирования отображаются в виде оранжевых пунктирных линий, а значение индекса курсора — в виде белой линии                                                          |
| **RGB**| Выкл.     | Переключает отображение с совокупной кривой на кривые по каналам. На монохромном датчике эта кнопка имеет надпись**MONO** и отключена — отображается только один канал                                                                                                                                  |

Гистограмма вычисляется по **видимым блокам**, а не по исходным пикселям, находящимся за ними: при изменении размера блока GSD распределение пересчитывается, поэтому гистограмма, маркер курсора и отображаемое изображение всегда совпадают.***

## Размер блока GSD

В нижней части панели находится элемент управления **GSD (px)**: поле ввода числа, ползунок в диапазоне от**1 до 256**и кнопка**RESET**.

Он уменьшает детализацию _отображаемого_ изображения, усредняя блок исходных пикселей размером N × N в один отображаемый пиксель. `1` — это исходное разрешение.

* Это влияет на **полноэкранный просмотр, миниатюры сетки, показания курсора и обе гистограммы** — всё, что отображает изображение, использует одинаковое базовое разрешение.
* Это касается **только отображения**. Обработка и экспорт остаются без изменений. Единственное исключение сделано намеренно: экспорт из экспорт из [Index/LUT Sandbox](index-lut-sandbox.md) сохраняет то, что вы видите, поэтому он переносит текущий размер блока, и панель экспорта предупреждает вас, когда размер блока превышает 1.
* Это значение сохраняется **для каждого проекта** как `viewer_display.gsd_bin` в `project.json`, поэтому оно сохраняется при закрытии и повторном открытии.
* При размере блока более 1 курсор отображает значение блока, а не исходного пикселя — показанное значение представляет собой среднее значение блока под курсором.

{% hint style="info" %}
**Почему «размер блока», а не сантиметры на пиксель?** Для значения в см/пиксель требуется высота над землёй. EXIF-данные отдельного кадра содержат GPS-высоту над средним уровнем моря, а не над рельефом, на который был направлен объектив, поэтому Chloros не будет выводить расстояние до земли, которое невозможно достоверно определить. Размер блока в пикселях исходного изображения — это тот же запасной вариант, который используют инструменты облачного анализа MAPIR, когда расстояние до земли неизвестно.
{% endhint %}

## Типы изображений, которые можно просматривать

В раскрывающемся списке слоёв в правом верхнем углу просмотрщика перечислены все версии текущего изображения. То, какие записи отображаются, зависит от камеры и от того, что было обработано — см. [Слои изображения](image-layers.md) для полного списка и описания работы этого списка.

### Survey3

* **JPG** — файл предварительного просмотра, созданный самой камерой
* **RAW (Original)** — исходный файл `.RAW`, прошедший дебайеризацию для отображения, без коррекций
* **RAW (Target)** — кадр, идентифицированный как содержащий калибровочную мишень
* **RAW (отражательная способность)** — откалиброванный результат по отражательной способности (65535 = ρ 1,0)
* **С коррекцией виньетирования**/**Характеристика датчика** — некалиброванный резервный результат
* **С балансом белого** — продукт с балансом белого
* **RAW (`<INDEX>` Index)**и**`<INDEX>` LUT** — рассчитанные индексные изображения

### LATTICE

При съёмке с помощью LATTICE используется тот же выпадающий список с названиями уровней конвейера:

| Слой                 | Что он содержит                                                        |
| --------------------- | -------------------------------------------------------------------- |
| **RAW (оригинал)**    | Исходный необработанный кадр в том виде, в каком он был снят                                     |
| **RAW (без байеровской матрицы)**   | Линейное изображение без байеровской матрицы                                           |
| **RAW (Предварительный просмотр)**     | Предварительный просмотр на экране — растяжение в ложных цветах для мультиспектральных камер |
| **С балансом белого**    | Предварительный просмотр на экране для основных камер RGB (баланс белого + гамма)   |
| **RAW (Световое излучение)**    | Спектральное световое излучение в формате Float32, единицами Вт/м²/ср/нм                              |
| **RAW (Коэффициент отражения)** | Коэффициент отражения в формате uint16, 32768 = ρ 1,0                                    |

Сияние и коэффициент отражения доступны только в мультиспектральном режиме: ведущая камера RGB не поддерживает радиометрию по отдельным полосам, поэтому эти слои для неё не генерируются.

## Применение индексов и таблиц LUT

Применяйте мультиспектральные индексы и цветовые таблицы преобразования (LUT) с помощью боковой панели:

1. Откройте боковую панель **Просмотрщик изображений** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line">
2. Установите флажок **Индекс**

3. Выберите фильтр вашей камеры и формулу индекса, затем перетащите кружки каналов в соответствующие ячейки формулы
4. Добавьте таблицу преобразования (LUT) и выберите градиент, пороговые значения и режим обрезания
5. Просмотрите значения в месте нахождения курсора и сохраните результат с помощью **«Экспорт/Сохранить изображение(я)»**Полное руководство см. в [Песочнице «Индексы/LUT»](index-lut-sandbox.md).***

## Устранение неполадок

### Изображение не открывается

**Возможные причины**: файл был перемещён или удалён после импорта; продукт так и не был записан; недостаточно памяти для очень большого изображения.**Что делать**:

1. Убедитесь, что файл слоя по-прежнему существует в дереве выходных файлов проекта
2. Откройте файл во внешнем просмотрщике, чтобы убедиться, что он не повреждён
3. Закройте другие приложения, чтобы освободить память

### Изображение чёрное, белое или имеет ненормальные цвета

**Возможные причины**: у механизма растяжения изображения нет материала для работы (практически постоянный кадр); слой типа float32 с необычными значениями; индекс, не давший достоверных данных.**Что делать**:

1. Прочитайте значения курсора — если каждый канал равен нулю или близок к нулю, проблема заключается в данных, а не в отображении
2. Проверьте гистограмму: одиночный пик на одном из концов указывает на то, что кадр обрезан или пуст
3. Проверьте журнал обработки для запуска, в результате которого был сформирован слой

### Значения выглядят неверными

**Возможные причины**: вы находитесь не на том слое, о котором думаете; вы сравниваете процентное значение с необработанным значением DN; вы сравниваете файл LATTICE с файлом Survey3, используя один и тот же делитель.**Что делать**:

1. Убедитесь, что в раскрывающемся списке выбран нужный слой — единицы измерения на панели зависят от слоя
2. Для коэффициента отражения используйте столбец **%**, а не делите значение DN самостоятельно; если деление необходимо, используйте значение `Chloros:PixelScale` из этого файла (32768 для LATTICE, отсутствие значения означает 65535 для Survey3)
3. Верните размер блока GSD к значению 1 — при значении выше 1 вы считываете среднее значение по блоку, а не по пикселю
4. Убедитесь, что калибровка коэффициента отражения действительно была выполнена для данного кадра; некалиброванный резервный продукт (Sensor Response / Vignette Corrected) не является коэффициентом отражения
