# Слои изображения

Выпадающий список «Слои изображения» в программе просмотра изображений Chloros позволяет быстро переключаться между различными версиями одного и того же изображения — от исходных снимков до обработанных результатов по отраженному излучению и рассчитанных индексных изображений.

## Что такое слои изображения?

В Chloros **слои** относятся к различным результатам обработки, доступным для одного исходного изображения. При обработке изображений Chloros создает несколько версий:

* **Исходные изображения** (файлы JPG и RAW с вашей камеры)
* **Калиброванные по отражательной способности** результаты (если была включена калибровка отражения)
* **Целевые изображения** (если изображение содержит калибровочные мишени)
* **Индексные изображения** (NDVI, NDRE, GNDVI и т. д., если были настроены индексы)**Выпадающий список «Выбор слоя»** в правом верхнем углу просмотрщика изображений позволяет мгновенно переключаться между этими версиями, не выходя из просмотрщика.***

## Доступные типы слоев

### JPG

* Исходное изображение JPG для предварительного просмотра с вашей камеры
* Всегда доступно для всех изображений
* Необработанное, в том виде, в котором оно было снято камерой
* Загружается и отображается быстрее всего

**Когда просматривать:**

* Быстрый просмотр исходного снимка
* Проверка композиции и кадрирования изображения
* Проверка качества снимка перед обработкой

### RAW (исходный)

* Исходные данные датчика в формате RAW с вашей камеры
* Без дебайеризации и без применения постобработки
* Более высокая разрядность, чем у JPG (обычно 12- или 14-разрядные данные датчика)

**Когда просматривать:**

* Проверка качества исходных данных с датчика
* Проверка на наличие проблем с датчиком или артефактов
* Сравнение результатов до и после обработки

### RAW (Цель)

* Появляется только для изображений, в которых обнаружены калибровочные мишени
* Показывает исходное изображение в формате RAW с обнаруженной мишенью
* Используется для проверки успешности обнаружения мишени

**Когда просматривать:**

* Подтверждение правильного обнаружения калибровочных мишеней
* Проверка качества изображения мишени
* Устранение неполадок при калибровке

{% hint style="info" %}
**Слой мишени**: этот слой отображается в раскрывающемся списке только для изображений, содержащих калибровочные мишени. Для обычных снимков этот параметр недоступен.
{% endhint %}

### RAW (Отражение)

* Отраженное изображение с калибровкой
* С коррекцией виньетирования (если включено при обработке)
* Отражение откалибровано с использованием данных мишени (если включено)
* Многополосный TIFF со всеми каналами камеры
* Значения пикселей представляют процент отражения (при использовании процентного режима)
* Готов к обработке с помощью [Index/LUT Sandbox](index-lut-sandbox.md)

**Когда просматривать:**

* Проверка откалиброванных результатов
* Проверка качества калибровки
* Проверка значений пикселей на научную точность
* Сравнение с оригиналом для оценки эффектов калибровки

{% hint style="success" %}
**Рекомендуется**: Использовать слой RAW (Отражение) при проверке значений пикселей для научных измерений и анализа.
{% endhint %}

### RAW (NDVI Index)... и аналогичные

* Рассчитанное изображение растительного индекса (NDVI в данном примере)
* Название индекса меняется в зависимости от того, какой индекс был настроен во время обработки
* Примеры: RAW (NDVI Index), RAW (NDRE Index), RAW (GNDVI Index) и т. д.
* Однополосное изображение в оттенках серого, отображающее результаты расчета индекса
* Для каждого индекса, настроенного в настройках проекта, появляется один слой

**Возможные названия индексов:**

* RAW (NDVI Index)
* RAW (NDRE Index)
* RAW (GNDVI Index)
* RAW (OSAVI Index)
* RAW (EVI Index)
* RAW (SAVI Index)
* И многое другое... (см. [Формулы мультиспектральных индексов](../project-settings/multispectral-index-formulas.md))

**Когда просматривать:**

* Анализ результатов расчета индексов
* Проверка диапазонов значений индексов
* Выявление областей интереса
* Проверка индексных изображений перед использованием в ГИС или анализе

## Использование выбора слоев

### Открытие выпадающего меню

1. Откройте изображение в полноэкранном режиме (щелкните любую миниатюру в просмотрщике изображений)
2. Найдите **выпадающее меню слоев** в правом верхнем углу просмотрщика
3. В выпадающем меню отображается текущий выбранный слой (например, «JPG»)
4. Щелкните раскрывающийся список, чтобы увидеть все доступные слои

### Переключение слоев

1. Щелкните раскрывающийся список слоев, чтобы открыть список
2. Отобразятся все доступные слои для текущего изображения
3. Щелкните любое название слоя, чтобы переключиться на эту версию
4. Изображение обновляется немедленно, отображая выбранный слой

**Быстрое переключение:**

* Раскрывающийся список запоминает ваш последний выбор
* При переходе к следующему изображению Chloros пытается отобразить тот же тип слоя
* Если этот слой отсутствует на следующем изображении, по умолчанию используется JPG

### Доступность слоев

Не все слои доступны для каждого изображения:

**Всегда доступно:*** ✅ JPG (каждое изображение имеет предварительный просмотр в формате JPG)

**Доступно условно:**

* ⚠️ RAW (Оригинал) — только если изображение было снято в режиме RAW или RAW+JPG
* ⚠️ RAW (Цель) — только если изображение содержит обнаруженные калибровочные цели
* ⚠️ RAW (Отражение) — только после обработки с включенной калибровкой отражения
* ⚠️ RAW (\[Index] Индекс) — только после обработки с настроенными индексами

## Сохранение слоев

### Переход между изображениями

При переходе к другому изображению (с помощью клавиш со стрелками или щелчка по миниатюрам):**Настройки слоя сохраняются:**

* При просмотре «RAW (Отражение)» следующее изображение показывает «RAW (Отражение)» (если доступно)
* При просмотре «RAW (NDVI Index)» следующее изображение отображает «RAW (NDVI Index)» (если доступно)
* Если соответствующий слой отсутствует, по умолчанию используется формат JPG

**Пример рабочего процесса:**

1. Откройте изображение 1, переключитесь на RAW (NDVI Index)
2. Нажмите →, чтобы просмотреть изображение 2
3. Изображение 2 автоматически отобразит слой RAW (NDVI Index)
4. Продолжайте просмотр — все изображения отображают слой NDVI
5. Очень эффективно для просмотра результатов индексации по многим изображениям

***

## Типичные рабочие процессы

### Рабочий процесс 1: Сравнение «до» и «после»

**Цель**: Сравнить исходное изображение с откалиброванным

1. Откройте обработанное изображение в просмотрщике изображений
2. Выберите **RAW (Original)** из выпадающего списка
3. Обратите внимание на виньетирование и некалиброванные значения
4. Переключитесь на **RAW (Reflectance)** в раскрывающемся списке
5. Сравните — виньетирование удалено, значения откалиброваны

### Рабочий процесс 2: Просмотр индекса

**Цель**: Быстрый просмотр результатов NDVI по всему набору данных

1. Откройте первое обработанное изображение
2. Выберите **RAW (NDVI Index)** из выпадающего списка
3. Используйте клавишу со стрелкой → для перехода к следующему изображению
4. Слой NDVI сохраняется автоматически
5. Продолжайте просматривать все изображения, проверяя шаблоны NDVI
6. Переключитесь на **RAW (NDRE Index)** для сравнения

### Рабочий процесс 3: Проверка мишеней

**Цель**: Проверить, что все изображения мишеней были обнаружены правильно

1. Перейдите к изображению мишени
2. Выберите **RAW (Target)** из выпадающего списка
3. Убедитесь, что калибровочные мишени четко видны и обнаружены
4. Перейдите к следующему изображению цели
5. Повторите проверку для всех целей

### Рабочий процесс 4: Проверка значений пикселей

**Цель**: Проверить значения отражательной способности на научную точность

1. Откройте обработанное изображение
2. Выберите слой **RAW (Reflectance)**

3. Включите режим**Pixel Percent** (кнопка в правой верхней панели инструментов)
4. Наведите курсор на участки растительности
5. Убедитесь, что значения пикселей находятся в ожидаемых диапазонах (30–70% для NIR, 5–15% для Red)
6. Проверьте участки почвы и воды на наличие соответствующих значений

## Понимание значений пикселей по слоям

Разные слои показывают разные диапазоны значений пикселей:

### Слой JPG

* **Диапазон**: 0–255 (8-бит)
* **Значение**: Отображаемые значения, с гамма-коррекцией
* **Использование**: Только для визуального осмотра, не для научных измерений

### RAW (исходный)

* **Диапазон**: 0–65535 (16-бит)
* **Значение**: Необработанные цифровые данные датчика
* **Использование**: Проверка работоспособности датчика, не калиброванные данные

### RAW (Отражение)

* **Диапазон**: 0–65 535 (16-битный TIFF) или 0,0–1,0 (32-битный процент)
* **Значение**: Калиброванное отражение в процентах
* **Использование**: Научные измерения и анализ**Для 16-битного TIFF:**Разделить на 65 535, чтобы получить отражение в процентах**Для 32-битного процента:** Значения напрямую представляют проценты (0,5 = 50% отражения)

### RAW (индексные изображения)

* **Диапазон**: варьируется в зависимости от индекса (обычно от -1,0 до +1,0 для нормализованных индексов)
* **Значение**: результат расчета индекса
* **Примеры**:
  * NDVI: от -1 до +1 (растительность обычно от 0,4 до 0,9)
  * NDRE: от -1 до +1 (обнаружение стресса)
  * EVI: от 0 до 1 (улучшенная растительность)

## Советы и рекомендации

### Эффективное переключение слоев

* **Сокращения клавиатуры**: Хотя для слоев нет клавиш быстрого доступа, стрелки навигации (←/→) работают для всех слоев
* **Последовательные рабочие процессы**: Выберите один слой (например, NDVI) и просмотрите весь набор данных, прежде чем переключаться на другой
* **Быстрое сравнение**: переключайтесь между слоями «Original» и «Reflectance», чтобы проверить качество обработки

### Рекомендации по производительности

* **Формат JPG загружается быстрее всего**: используйте его для быстрой навигации по множеству изображений
* **Слои RAW загружаются медленнее**: более высокое разрешение и глубина цвета
* **Индексные слои**: скорость загрузки аналогична скорости загрузки слоев «Reflectance»
* **Первая загрузка происходит медленнее всего**: последующие просмотры одного и того же слоя кэшируются и загружаются быстрее

### Проверка качества

* **Всегда проверяйте RAW (оригинал)**: проверьте качество исходных данных, прежде чем доверять обработанным результатам
* **Сравнивайте слои**: используйте переключение слоев, чтобы убедиться, что обработка прошла правильно
* **Проверяйте диапазоны индекса**: используйте режим «Процент пикселей» со слоями индекса, чтобы убедиться, что значения разумны***

## Устранение неполадок

### Слой недоступен

**Проблема**: Ожидаемый слой не отображается в раскрывающемся списке**Возможные причины:**

* Изображение не было обработано (доступны только JPG и RAW (оригинал))
* Калибровка отражательной способности была отключена во время обработки
* Конкретный индекс не был настроен в настройках проекта
* Изображение является изображением только для целей (индексы для целей не генерируются)

**Решения:**

1. Убедитесь, что изображение было обработано (проверьте папку вывода на наличие обработанных файлов)
2. Проверьте настройки проекта, чтобы убедиться, что индексы были настроены
3. Повторите обработку с включенными нужными индексами

### Отображается неверный слой

**Проблема**: Изображение открывается в неожиданном слое**Причина**: Настройки слоя из предыдущего изображения были перенесены, но этот слой не существует на текущем изображении**Решение**: Chloros автоматически переключается на формат JPG, когда предпочтительный слой недоступен — это нормальное поведение

### Не видны калибровочные мишени

**Проблема**: Слой RAW (Target) не показывает обнаружение мишеней**Возможные причины:**

* Мишени не были обнаружены во время обработки
* Изображение фактически не содержит мишеней
* Слишком строгие настройки обнаружения мишеней

**Решения:**

1. Проверьте журнал отладки на наличие сообщений «Target found»
2. Убедитесь, что изображение действительно содержит видимые калибровочные мишени
3. Настройте параметры обнаружения мишеней в настройках проекта
4. См. [Выбор изображений мишеней](../processing-images-gui/choosing-target-images.md)

## Связанные функции

### Инструменты просмотра изображений

При просмотре любого слоя можно использовать:

* **Элементы управления масштабированием**: увеличение для просмотра деталей
* **Панорамирование**: щелкните и перетащите, чтобы перемещаться по увеличенному изображению
* **Просмотр значений пикселей**: просмотр значений в месте нахождения курсора
* **Стрелки навигации**: переход между изображениями с сохранением слоя
* **Режим «Процент пикселей»**: переключение между отображением в DN и процентах

См. [Открытие изображения в полноэкранном режиме](opening-an-image-full-screen.md) для получения полной документации по просмотрщику изображений.

### Песочница Index/LUT

Для интерактивного тестирования и визуализации индексов:

* **Расчет индекса в реальном времени**: тестируйте различные формулы индекса
* **Цветовое отображение LUT**: применяйте цветовые градиенты к индексам в оттенках серого
* **Экспорт визуализаций**: сохраняйте цветные изображения индексов

См. [Песочница Index/LUT](index-lut-sandbox.md) для получения подробной информации.
