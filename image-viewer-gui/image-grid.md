# Сетка изображений

После импорта изображений в проект вы увидите их, расположенные в виде сетки в основной области окна. В этой сетке вы выбираете, **какую версию каждого изображения вы просматриваете** — кнопки над ней позволяют одновременно переключать все миниатюры между исходными файлами и каждым обработанным результатом.

## Размер миниатюр

Используйте ползунок масштабирования в правом верхнем углу, чтобы настроить размер миниатюр изображений. Диапазон ползунка составляет от **64 пикселей до 1200 пикселей**.

* **Ctrl + колесико мыши** также позволяет масштабировать миниатюры.
* **Ctrl + `+`**/**Ctrl + `=`**и**Ctrl + `−`** изменяют размер на 4 пикселя при каждом нажатии. Диапазон значений, доступных с клавиатуры, ограничивается 64 пикселями в нижней части диапазона и в верхней части — тем размером, при котором в текущем окне в каждый ряд помещаются ровно две миниатюры.
* Выбранный размер сохраняется вместе с проектом (`UI → Grid thumbnail size` в `project.json`, по умолчанию `160`), поэтому при повторном открытии проекта он восстанавливается.

<figure><img src="../.gitbook/assets/chloros_grid_zoom.gif" alt=""><figcaption></figcaption></figure>*Разрешение* миниатюр — это настройка, отличная от *размера* миниатюр: см. **Отображение → Разрешение миниатюр изображений** в [Настройках проекта](../project-settings/project-settings.md) (по умолчанию 512 пикселей по длинной стороне). Размер определяет, насколько большой рисуется плитка; разрешение — сколько деталей загружается для её заполнения.***

## Панель инструментов сетки

Ряд кнопок над сеткой состоит из трёх групп (слева направо):

1. **По триггеру / По камере** — режим группировки. Отображается только для проектов, содержащих снимки LATTICE.
2. **Кнопки фильтрации камер** — по одной на каждую камеру LATTICE. Отображаются только в режиме «По камере».
3. **Кнопки режима экспорта/просмотра** — какой продукт отображается на каждой миниатюре.

Если окно слишком узкое, чтобы поместить все кнопки, группы сворачиваются справа налево в раскрывающиеся списки при наведении курсора: сначала сворачиваются кнопки экспорта/просмотра, затем — кнопки камер. В свернутой группе остается одна кнопка с надписью, обозначающей текущий активный выбор; при наведении курсора на неё полный набор кнопок выдвигается вниз. **Группы «По триггеру» и «По камере» никогда не сворачиваются.

## Кнопки просмотра экспорта

Эти кнопки переключают миниатюры в сетке между типами изображений. **Кнопка появляется, как только появляется продукт, названный ею** — что для исходных файлов означает сразу при импорте, а не после обработки. Chloros повторно сканирует продукты проекта во время выполнения задания, поэтому кнопки появляются в процессе обработки по мере того, как каждый продукт начинает записываться на диск.

### Базовая кнопка

Кнопка экспорта, расположенная крайней слева, имеет надпись, отражающую **то, что вы фактически импортировали**:

| Что вы импортировали | Название кнопки |
| --- | --- |
| Survey3 RAW+JPG | `JPG` |
| Снимки LATTICE с предварительным просмотром рядом с необработанным кадром | `PNG` или `TIFF`, в зависимости от того, какие из них отображаются в предварительном просмотре |
| Снимки LATTICE, где базовым файлом **является** исходный кадр | *нет кнопки* — `RAW (Original)` уже отображает этот файл |

В смешанном проекте надпись зависит от того, какое расширение используется в большинстве изображений.

### Кнопки продуктов

| Кнопка | Отображает | Когда появляется |
| --- | --- | --- |
| **Мишени** | Изображения с обнаруженными калибровочными мишенями | После запуска, в ходе которого были обнаружены мишени |
| **Отражательная способность** | Откалиброванные изображения отражательной способности | Только в проектах Survey3 — в проектах LATTICE вместо этого используется `RAW (Reflectance)`, поэтому в сетке никогда не отображаются две кнопки «Отражательная способность» |
| **С балансом белого** | Изображение с балансом белого (камеры RGB) | После обработки |
| **С коррекцией виньетирования** | Некалиброванный резервный вариант с коррекцией виньетирования | После сеанса, в котором не удалось применить калибровку отражательной способности и была включена *коррекция виньетирования* |
| **Характеристика датчика** | Некалиброванный резервный вариант с характеристикой датчика | То же самое, но с отключенной *коррекцией виньетирования* |
| **`RAW (<INDEX> Index)`** | По одной кнопке на каждый рассчитанный индекс | После запуска с настроенными индексами |
| **`<INDEX> LUT`** | Одна кнопка на каждый индекс с цветовой привязкой | После запуска с настроенной таблицей LUT |
| **`<Index> <Index\|LUT> <NNN>`** | Одна кнопка на каждый запуск экспорта [Index/LUT Sandbox](index-lut-sandbox.md) | В момент завершения экспорта из песочницы |

### Кнопки уровня LATTICE

Проекты, содержащие снимки LATTICE, добавляют следующие кнопки, обозначенные названием уровня, а не названием продукта:

| Кнопка | Уровень |
| --- | --- |
| **RAW (Оригинал)** | Исходный необработанный кадр в том виде, в котором он был импортирован |
| **RAW (Radiance)** | Спектральная яркость в формате Float32, Вт/м²/ср/нм |
| **RAW (Reflectance)** | Коэффициент отражения в формате uint16, 32768 = ρ 1,0 |

`RAW (Original)` доступен с момента импорта — он не требует обработки. Когда при импорте LATTICE отсутствует базовая кнопка (базовым файлом каждого снимка является его исходный кадр), сетка перемещается к первой доступной кнопке уровня, чтобы подсветка на панели инструментов соответствовала тому, что вы видите.

Двухуровневые экспорты Chloros **не имеют собственной кнопки сетки**:

* **Без байеризации** — в окне просмотра `RAW (Original)` изображение уже отображается без байеризации, поэтому вторая кнопка на визуально идентичном изображении была бы лишней. Продукт `RAW (Debayered)` по-прежнему записывается на диск и по-прежнему доступен для выбора в раскрывающемся списке полноэкранных слоёв.
* **Предварительный просмотр** — на камерах RGB предварительный просмотр регистрируется как слой `White Balanced`, у которого есть кнопка. На мультиспектральных камерах он зарегистрирован как `RAW (Preview)` и доступен из раскрывающегося списка полноэкранных слоев.

{% hint style="info" %}
Эти кнопки уровней отображаются только для проектов, которые действительно содержат кадры LATTICE. Survey3 — в таких проектах регистрируются некоторые из тех же внутренних имен слоёв, и кнопки для них отфильтровываются, так что сетка Survey3 сохраняет свой привычный набор `JPG / Targets / Reflectance`.
{% endhint %}

При нажатии на миниатюру сетки открывается полноэкранный [Просмотрщик изображений](opening-an-image-full-screen.md) для **того же продукта, который отображает сетка** — если сетка настроена на `Targets`, миниатюра открывает экспортированное целевое изображение.

## Группировка проекта LATTICE: по триггеру или по камере

Серийные съемки создают несколько изображений одного и того же момента, снятых разными модулями камер. Группировка определяет, как сетка их располагает. В обоих режимах отображаются сворачиваемые панели заголовков полной ширины; **каждая группа изначально развернута**, и Chloros запоминает те, которые вы сворачиваете. Состояние сворачивания отслеживается отдельно для каждого режима, поэтому сворачивание группы в режиме «По камере» не приводит к сворачиванию чего-либо в режиме «По триггеру».

### «По камере» (по умолчанию)

Одна группа на каждый модуль камеры. В заголовке отображаются модель и серийный номер камеры (`LATT-M3M — <serial>`), а также количество фотографий. Снимки внутри группы упорядочены в хронологическом порядке по дате съёмки.

В этом режиме на панели инструментов также появляется по одной **кнопке фильтрации по камере** для каждой камеры с надписью `MODEL (SERIAL)`. Все камеры изначально выделены; нажатие кнопки снимает выделение с этой камеры и удаляет её группу из сетки. Это быстрый способ просмотреть один диапазон данных за весь полёт.

### По триггеру

Одна группа на каждое событие съёмки — набор кадров, снятых всеми модулями при одном и том же срабатывании триггера. В заголовке отображается время съёмки, количество участвовавших камер и значок для каждой модели камеры в группе. Плитки внутри группы упорядочены по серийному номеру камеры, поэтому один и тот же диапазон находится в одном и том же столбце для каждого срабатывания триггера.

Изображения, не относящиеся к LATTICE, в смешанном проекте не группируются — они отображаются в виде обычных плиток после групп.

## Миниатюры в сетке соответствуют размеру блока GSD

Если вы установили размер блока **GSD (px)** на боковой панели вкладки «Изображение», миниатюры в сетке отображаются с тем же разрешением на местности — а не только в полноэкранном режиме. Размер блока, равный 8, означает, что каждый отображаемый пиксель представляет собой среднее значение блока из 8 × 8 исходных пикселей во всех местах приложения, где отображается изображение.

Поскольку ширина плитки изначально составляет всего несколько сотен пикселей, крупные размеры блоков перестают оказывать заметное влияние на сетку гораздо раньше, чем в полноэкранном режиме: кадр размером 4000 пикселей, нарисованный на плитке размером 160 пикселей, уже имеет соотношение примерно 25 исходных пикселей на один отображаемый пиксель. См. [Открытие изображения в полноэкранном режиме](opening-an-image-full-screen.md#gsd-block-size) для получения информации о самом элементе управления.
