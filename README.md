# Начало работы

<div data-full-width="false"><figure><img src=".gitbook/assets/chloros_logo_transparent.png" alt=""><figcaption></figcaption></figure></div>Chloros — это программное приложение от [MAPIR](https://www.mapir.camera), предназначенное для обработки мультиспектральных изображений, управления оборудованием MAPIR в режиме реального времени и записи данных с датчиков. Chloros версии 1.2.0 поддерживает всю линейку продуктов MAPIR:

* **Камеры Survey3** — преобразуют снимки в формате RAW+JPG в откалиброванные карты отражательной способности и индексов растительности. См. [Поддерживаемые камеры](supported-cameras.md).
* **Камеры LATTICE** — подключение мультиспектральных камерных модулей GigE в режиме реального времени, по отдельности или в виде синхронизированных массивов из нескольких камер: предварительный просмотр, съемка и обработка с получением откалиброванных продуктов яркости и отражательной способности. См. [раздел LATTICE](lattice/README.md).
* **Световые датчики DAQ** — спектральные датчики DAQ-U (USB), DAQ-M (Bluetooth) и DAQ-E (Ethernet): откалиброванные спектры в режиме реального времени, записи `.daq` и освещённость в нисходящем направлении для обработки данных отражательной способности. См. [раздел «DAQ»](daq/README.md).

{% hint style="success" %}
**Что нового в Chloros 1.2.0**: управление камерой и матрицей LATTICE в режиме реального времени, интеграция световых датчиков DAQ, режимы съёмки и регистраторы, полный конвейер радиометрической обработки LATTICE, автоматизация проектов из CLI/SDK и многое другое. Ознакомьтесь со списком нововведений ниже и [скачайте](download.md) журнал изменений.
{% endhint %}

## Что нового в Chloros 1.2.0

* **Управление камерами в режиме реального времени — новая вкладка «Камеры».** Подключайте камеры LATTICE по одной или в виде синхронизированных массивов из нескольких камер (синхронизация времени по протоколу PTP, съемка с аппаратным триггером) с наложением предварительного просмотра в реальном времени, гистограммами по отдельным полосам, интеллектуальной автоэкспозицией, калькулятором индекса в реальном времени и обновлениями прошивки камер прямо в приложении.
* **Датчики освещённости — новая вкладка «Датчики освещённости».** Подключайте датчики DAQ-U (USB), DAQ-M (Bluetooth) и DAQ-E (Ethernet); просматривайте откалиброванные спектры в реальном времени (Вт/м²/нм), записывайте файлы формата `.daq` в свой проект, выбирайте профили коррекции капа и обновляйте прошивку DAQ-E по сети.
* **Режимы съемки и устройства записи.** Однократная / непрерывная / интервальная съемка, а также режим «Самая быстрая съемка» (только в формате RAW); выбор для каждого проекта камер и типов экспорта, которые генерирует функция «Захватить всё»; матричные устройства записи для индексного видео мониторингового качества и серий RAW-кадров аналитического качества с возможностью автосборки видео в автономном режиме.
* **Конвейер обработки LATTICE.** Импорт папок с данными захвата LATTICE и разделение каждого необработанного кадра на следующие продукты: данные без дебайеризации, предварительный просмотр, яркость в формате float32 (Вт/м²/стр/нм) и коэффициент отражения с переключателями для каждого продукта. Значения отражательной способности могут быть получены с помощью калибровочной мишени внутри кадра или с помощью данных DAQ о нисходящем излучении; при экспорте применяется выравнивание массива; отсутствующая заводская калибровка загружается автоматически по серийному номеру камеры.
* **Проекты запоминают конфигурацию оборудования.** Подключённые камеры и датчики освещённости сохраняются вместе с проектом (`cameras.json` / `sensors.json`) и при повторном открытии проекта подключаются с сохраненными настройками. См. [GUI: Проекты](projects.md).
* **Улучшения в программе просмотра изображений.** Отображение пикселей/индексов курсора с правильным масштабированием коэффициента отражения для каждого файла, гистограммы слоёв, ползунок биннинга GSD, режимы сетки «На триггер» / «На камеру», просмотр продуктов LATTICE, а также экспорт «песочницы» индексов/LUT на диск.
* **CLI и SDK — значительно расширены.** Новые семейства команд `lattice`, `daq pool-*`, `project` и `time-sync`; новые опции `process` (`--input-level` — переключатели для отдельных продуктов, `--reflectance-source` — флаги выравнивания массивов); дескрипторы «smart-connect» для SDK (`connect_camera` / `connect_array` / `connect_daq_sensor`), которые автоматически запускают бэкенд; `open_project()` автоматизация; колесо SDK входит в состав установщиков и опубликовано на PyPI как `chloros-sdk`.
* **Честная семантика ошибок.** Запуск `chloros-cli process`, который запрашивал продукты, но не создал ни одного, теперь явно завершается с ошибкой и возвращает ненулевой код завершения; успешные запуски сообщают, сколько образов продуктов было создано.
* **Новая структура вывода.** Результаты сохраняются в папках `<project>/<camera>/<format>/<Product>_Images/` и сохраняют имя исходного файла — папка, а не суффикс имени файла, идентифицирует результат. См. [Форматы выходных изображений](output-image-formats.md).
* **Дополнительные входные данные, планы и языки.** Поддержка входных данных `.dng`; все 38 языков интерфейса полностью заполнены; аппаратные ограничения для каждого плана с бесплатным (без входа в систему) использованием до 4 камер и 2 датчиков освещенности.
* **Надёжность.** Функция «Остановить обработку» корректно завершает работу с подробной сводкой выполнения, в проектах с несколькими камерами экспортируются данные со всех камер, а при обновлении установщика вы больше не выходите из системы.***

Chloros доступен в 3 вариантах интерфейса:

## Chloros: Настольное приложение с графическим интерфейсом

Автономное отдельное окно со всеми функциями, включая вкладки «Камеры» и «Датчики освещенности» в режиме реального времени. _Только для Windows._

## [Chloros CLI: интерфейс командной строки](CLI.md)

Пакетная обработка из командной строки плюс команды в режиме реального времени `lattice`, `daq pool-*`, `project` и `time-sync`. Идеально подходит для автоматизации, создания скриптов и работы в режиме без графического интерфейса. Доступно на **Windows, Linux amd64 и Linux arm64 (NVIDIA Jetson)**. _Для доступа к CLI требуется платный тарифный план Chloros+._

## [Chloros API: Python SDK](api-python-sdk.md)

Программный интерфейс Python для автоматизации и настраиваемых рабочих процессов: обработка по полному конвейеру, сеансы работы с камерами/массивами в режиме реального времени, сеансы с датчиками DAQ и автоматизация на основе сохраненных проектов. Устанавливается вместе с пакетом desktop/CLI, а также публикуется как `pip install chloros-sdk`. Для доступа к _API требуется платный тарифный план Chloros+._

***

| Платформа | Графический интерфейс | CLI | Python SDK |

Инструкции по установке Linux см. в разделе [Linux и пограничные вычисления](linux/linux-overview.md).

## Начало работы за три шага

1. **Установка** — загрузите и запустите установщик для вашей платформы. См. [Загрузка](download.md).
2. **Войдите в систему (необязательно для графического интерфейса)** — графический интерфейс обрабатывает изображения бесплатно без учетной записи. [Chloros+ вход в систему](chloros+-login.md) открывает доступ к параллельной обработке, ускорение на GPU, более высокие ограничения по количеству устройств и доступ к CLI/SDK.
3. **Создайте свой первый проект** — откройте Chloros, создайте [Новый проект](projects.md), [добавьте свои изображения](processing-images-gui/adding-files-to-a-project.md) и [начните обработку](processing-images-gui/starting-the-processing.md). Чтобы вместо этого управлять реальным оборудованием, откройте вкладку «Камеры» или «Световые датчики» — см. [GUI: Навигация](navigation.md).***

## Chloros+

Хотя Chloros можно бесплатно использовать для большинства задач, вам может понадобиться больше возможностей. Именно в этом случае вам пригодится платная лицензия на Chloros+. С лицензией Chloros+ вы сможете разблокировать такие новые функции, как:

* **Многопоточная обработка**: значительно ускорьте обработку изображений в крупных проектах за счёт одновременной обработки изображений по конвейеру.
* **Ускорение на GPU (CUDA)**: воспользуйтесь преимуществами современных графических процессоров с большим объёмом видеопамяти для дальнейшего ускорения конвейера обработки изображений. Для достижения наилучших результатов мы рекомендуем 4 ГБ или более видеопамяти (VRAM).
* **Chloros+**[**CLI**](CLI.md)**Доступ**: запускайте Chloros+ из командной строки для автоматизации и интеграции в ваше собственное программное обеспечение. Доступно на любом платном тарифе; принудительно применяется на стороне сервера.
* **Chloros+**[**API**](api-python-sdk.md)**Доступ:** запустите Chloros+ из Python для программного управления, что обеспечит беспрепятственную интеграцию с вашими исследовательскими конвейерами, рабочими процессами анализа данных и пользовательскими приложениями. Доступно на любом платном тарифе; обеспечивается на стороне сервера.
* **Более высокие аппаратные ограничения**: подключайте больше камер и датчиков освещенности одновременно. Без входа в систему графический интерфейс подключает до 4 камер и 2 датчиков освещенности DAQ; платные тарифные планы повышают оба ограничения:

| Тариф | Камеры | Датчики освещенности DAQ |
| --- | --- | --- |
| Iron (бесплатный, без входа в систему) | 4 | 2 |
| Copper / Bronze | 6 | 3 |
| Silver | 10 | 6 |
| Gold | 20 | 12 |

* **Использование нескольких устройств**: каждая лицензия Chloros+ позволяет зарегистрировать 2 и более устройств. Используйте свою учётную запись MAPIR Cloud для управления зарегистрированными устройствами. Добавьте поддержку дополнительных устройств, обновив свою лицензию Chloros+.
* **Усовершенствованный метод дебайеризации с учетом текстур:** высококачественный метод дебайеризации с учетом контуров в сочетании с моделью шумоподавления на основе ИИ/машинного обучения, которая устраняет практически весь шум, возникающий при дебайеризации.
* **Пользовательские формулы мультиспектральных индексов:** вводите пользовательские мультиспектральные индексы в растровые калькуляторы Chloros как для обработки, так и для тестовой среды просмотра изображений.
* **Linux и периферийные вычисления:** запускайте Chloros на платформах Linux x86_64 и ARM64, включая NVIDIA Jetson, для полевой и периферийной обработки. См. [Обзор Linux](linux/linux-overview.md).
