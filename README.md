# Начало работы

<div data-full-width="false"><figure><img src=".gitbook/assets/chloros_logo_transparent.png" alt=""><figcaption></figcaption></figure></div>Chloros — это программное приложение от [MAPIR](https://www.mapir.camera) для обработки изображений и других данных с датчиков.

***{% hint style="success" %}**Что нового в Chloros 1.1.0**: Нативная поддержка Linux (amd64 и arm64), пограничные вычисления NVIDIA Jetson, динамическая адаптация вычислений, 4-поточный конвейер обработки, новые команды и опции CLI. См. [Скачать](download.md) для полного списка изменений.
{% endhint %}

Chloros доступен в 3 режимах работы:

## Chloros: Настольное приложение с графическим интерфейсом

Автономное отдельное окно со всеми функциями. _Только для Windows._

## [Chloros CLI: Интерфейс командной строки](CLI.md)

Пакетная обработка из командной строки. Идеально подходит для автоматизации, написания скриптов и работы в режиме без интерфейса. Доступно на **Windows, Linux amd64 и Linux arm64 (NVIDIA Jetson)**. _Для доступа к CLI требуется лицензия Chloros+._

## [Chloros API: Python SDK](api-python-sdk.md)

Программный интерфейс Python для автоматизации и настраиваемых рабочих процессов. Идеально подходит для исследовательских конвейеров, интеграции с существующими приложениями Python и создания пользовательских инструментов. Доступно на **всех платформах** через `pip install chloros-sdk`. _Для доступа к API требуется лицензия Chloros+._***

## Поддерживаемые платформы

| Платформа | GUI | CLI | Python SDK |
| --- | --- | --- | --- |
| **Windows 10/11** | Да | Да | Да |
| **Linux amd64 (x86_64)** | Нет | Да | Да |
| **Linux arm64 (NVIDIA Jetson)** | Нет | Да | Да |

Инструкции по установке Linux см. в разделе [Linux и пограничные вычисления](linux/linux-overview.md).

## Chloros+

Хотя Chloros можно бесплатно использовать для большинства задач, вам может понадобиться больше возможностей. Именно в этом случае вам пригодится платная лицензия на Chloros+. С лицензией Chloros+ вы сможете разблокировать такие новые функции, как:

* **Многопоточная обработка**: значительно ускорьте обработку изображений в крупных проектах за счет одновременной обработки изображений по конвейеру.
* **Ускорение на GPU (CUDA)**: воспользуйтесь преимуществами современных вариантов с большим объемом памяти GPU, чтобы еще больше ускорить конвейер обработки изображений. Для достижения наилучших результатов мы рекомендуем 4 ГБ или более видеопамяти.
* **Chloros+**[**CLI**](CLI.md)**Доступ**: запускайте Chloros+ из командной строки для автоматизации и интеграции в ваше собственное программное обеспечение.
* **Chloros+**[**API**](api-python-sdk.md)**Доступ:** запустите Chloros+ из Python для программного управления, что обеспечит бесшовную интеграцию с вашими исследовательскими конвейерами, рабочими процессами анализа данных и пользовательскими приложениями.
* **Использование на нескольких устройствах**: каждая лицензия Chloros+ позволяет зарегистрировать 2 и более устройств. Используйте свою учетную запись MAPIR Cloud для управления зарегистрированными устройствами. Добавьте поддержку дополнительных устройств, обновив свою лицензию Chloros+.
* **Усовершенствованный метод дебайеризации с учетом текстуры:** высококачественный алгоритм дебайеризации с учетом краев в сочетании с моделью шумоподавления на основе ИИ/машинного обучения, которая устраняет практически весь шум дебайеризации. 
* **Пользовательские формулы мультиспектральных индексов:** введите пользовательские мультиспектральные индексы в растровые калькуляторы Chloros как для обработки, так и для песочницы просмотра изображений.
* **Linux и пограничная вычислительная техника:** запускайте Chloros на платформах Linux x86\_64 и ARM64, включая NVIDIA Jetson, для полевой и пограничной обработки. См. [Обзор Linux](linux/linux-overview.md).
