# Обзор Linux

Chloros 1.3.0 обеспечивает встроенную поддержку Linux для **CLI**и**Python SDK** — обработку мультиспектральных изображений в режиме без графического интерфейса, а также управление камерами LATTICE и световыми датчиками DAQ в режиме реального времени — на рабочих станциях, серверах и периферийных устройствах NVIDIA Jetson под управлением Linux.

{% hint style="info" %}
**В Linux отсутствует графический интерфейс пользователя (GUI).**Графический интерфейс Chloros Desktop доступен только для Windows. Пользователи Linux взаимодействуют с Chloros через [CLI](../CLI.md) и [Python SDK](../api-python-sdk.md). `.deb` действительно добавляет пункт**Chloros CLI** в меню приложений — он просто запускает эмулятор терминала, в котором работает `chloros-cli`.
{% endhint %}

## Поддерживаемые архитектуры

| Архитектура | Описание | Пакет |
| --- | --- | --- |
| **amd64 (x86_64)** | Стандартные процессоры для настольных компьютеров и серверов (Intel, AMD) | `chloros_<version>_amd64.deb` |
| **arm64 (aarch64)** | Процессоры ARM — семейство NVIDIA Jetson Orin (JetPack 6) | `chloros_<version>_arm64_jp6.deb` |

## Поддерживаемые дистрибутивы Linux

* **Ubuntu 22.04 LTS или новее** (amd64)
* **Debian 12 или новее** (amd64)
* **NVIDIA JetPack 6** (arm64 — платформы Jetson Orin)***

## Что получают пользователи Linux

* **Chloros CLI** — полнофункциональный интерфейс командной строки для пакетной обработки, автоматизации и написания скриптов
* **Chloros Python SDK** — программный интерфейс на Python для исследовательских конвейеров и пользовательских инструментов, устанавливаемый с помощью `.deb` для системы `python3` (колесо, соответствующее версии для virtualenvs, находится в `/usr/lib/chloros/sdk/`; PyPI предназначено для машин без пакета Chloros)
* **Управление камерами LATTICE** — обнаружение, подключение, настройка и съемка с камер LATTICE и синхронизированных массивов из нескольких камер через `chloros-cli lattice` и SDK; `.deb` включает среду выполнения Arena SDK, необходимую для работы камер
* **Управление световыми датчиками DAQ** — подключение датчиков DAQ-U/M/E, потоковая передача откалиброванных спектров и запись файлов `.daq` с помощью `chloros-cli daq pool-*` и SDK
* **Синхронизация времени по PTP** — бэкенд Chloros запускает главный сервер PTP, к которому подключаются камеры LATTICE и датчики DAQ-E в качестве подчиненных устройств; проверяйте его с помощью `chloros-cli time-sync` и поддерживайте его работу в фоновом режиме с помощью модуля systemd `chloros-backend@<user>.service` (см. [Установка в Linux](linux-installation.md#always-on-ptp-for-headless-hosts))
* **Автоматизация проектов** — запускайте сохраненные проекты в фоновом режиме с помощью `chloros-cli project` и модуля SDK `open_project`
* **Ускорение на GPU** — обработка с ускорением CUDA на графических процессорах NVIDIA (настольные графические процессоры на amd64 и графический процессор Jetson с JetPack 6)
* **Динамическая адаптация вычислений** — автоматическое определение аппаратного обеспечения и выбор стратегии обработки, с возможностью переопределения с помощью `CHLOROS_STRATEGY` в качестве экспертного «запасного выхода»
* **Все функции обработки** — тот же конвейер, что и в Windows: калибровка, коррекция виньетирования, индексы растительности и все форматы экспорта
* **Возможности Chloros+** — многопоточная (конвейерная) обработка, дебайеризатор с учетом текстур (на графическом процессоре с поддержкой CUDA) и настраиваемые индексы при использовании платного тарифного плана Chloros+

## Чего не получают пользователи Linux

* **Графический интерфейс пользователя** — нет графического интерфейса; всё взаимодействие осуществляется через CLI или Python SDK
* **Просмотрщик изображений** — нет интерактивного просмотрщика изображений, просмотра в виде сетки или маркеров на карте
* **Визуальное управление проектами** — проекты создаются и управляются с помощью команд CLI и вызовов SDK (само оборудование — камеры, датчики, устройства захвата — по-прежнему полностью управляется из терминала)***

## Требования к лицензии

Для доступа к CLI и SDK требуется **платный тариф Chloros+ — Copper или выше**(Copper, Bronze, Silver, Gold). Бесплатный тариф**Iron** не предоставляет доступа к CLI/SDK. Это ограничение обеспечивается на уровне бэкенда, а не только в CLI:

| Ситуация | Ответ бэкенда |
| --- | --- |
| Не вошёл в систему | `401` с `error_code: AUTH_REQUIRED` |
| Вошёл в систему на бесплатном тарифе «Iron» | `403` с `error_code: PLAN_UPGRADE_REQUIRED` |

`chloros-cli status` работает на любом тарифе — это единственный маршрут, не подпадающий под ограничение, — поэтому причина отказа всегда видна.

## Начало работы на Linux

1. **Установите Chloros** — см. [Установка на Linux](linux-installation.md) для установки `.deb`
2. **Проверьте** — команда `chloros-cli --version` выводит `Chloros CLI 1.3.0`; команда `chloros-cli selftest` запускает 7-этапную диагностику
3. **Проверьте Python SDK** — `.deb` устанавливает его: `python3 -c "import chloros_sdk; print(chloros_sdk.__version__)"` (в virtualenv — `pip install /usr/lib/chloros/sdk/chloros_sdk-*.whl`)
4. **Войдите в систему** — `chloros-cli login your@email.com 'your-password'` (один раз на каждом компьютере; при обновлении пакета данные входа сохраняются, а при удалении пакета они стираются)
5. **Обработайте свой первый набор данных** — `chloros-cli process ~/datasets/flight001`

Для NVIDIA Jetson см. специальное [Руководство по NVIDIA Jetson](nvidia-jetson-guide.md), где описаны настройка для конкретной платформы, тепловые характеристики и развертывание в полевых условиях.
