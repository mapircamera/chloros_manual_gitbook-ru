# Обзор Linux

Chloros 1.2.0 обеспечивает встроенную поддержку Linux для **CLI**и**Python SDK** — обработку мультиспектральных изображений без монитора, а также управление камерой LATTICE и световым датчиком DAQ в режиме реального времени — на рабочих станциях, серверах и периферийных устройствах NVIDIA Jetson.

{% hint style="info" %}
**На Linux нет настольного графического интерфейса.**Настольный графический интерфейс Chloros доступен только на Windows. Пользователи Linux взаимодействуют с Chloros через [CLI](../CLI.md) и [Python SDK](../api-python-sdk.md). `.deb` действительно добавляет**Chloros CLI** в меню вашего приложения — он просто открывает эмулятор терминала, в котором запущен `chloros-cli`.
{% endhint %}

***

| --- | --- | --- | --- | --- |
| **Графический интерфейс для настольных ПК** | Да | Н/Д | Нет | Нет |
| **CLI** (`chloros-cli`) | Да | Да | Да | Да |
| **Python SDK** (`chloros-sdk`) | Да | Да | Да | Да |
| **Конвейер обработки изображений** | Да | Да | Да | Да |
| **Управление камерами LATTICE (в режиме реального времени)** | Да (вкладка «Камеры») | Да (`chloros-cli lattice`, SDK) | Да | Да |
| **Датчики освещенности DAQ (в режиме реального времени)** | Да (вкладка «Датчики освещенности») | Да (`chloros-cli daq pool-*`, SDK) | Да | Да |
| **Синхронизация времени PTP (хост является главным сервером)** | Да | Да (`chloros-cli time-sync`) | Да | Да |
| **Ускорение на GPU (CUDA)** | Да | Да | Да | Да (JetPack 6) |
| **Дебайеринг с учетом текстур** | Да (Chloros+) | Да (Chloros+) | Да (Chloros+) | Да (Chloros+) |
| **Динамическая адаптация вычислений** | Да | Да | Да | Да |
| **Бэкенд как системная служба** (`chloros-backend.service`) | Нет | Нет | Да (по выбору) | Да (по выбору) |
| **Программа обновления без переустановки** (`chloros-cli update`) | Нет (запустите установщик) | Нет (запустите установщик) | Да | Да |***

## Поддерживаемые архитектуры

| Архитектура | Описание | Пакет |
| --- | --- | --- |
| **amd64 (x86_64)** | Стандартные процессоры для настольных компьютеров и серверов (Intel, AMD) | `chloros_<version>_amd64.deb` |
| **arm64 (aarch64)** | Процессоры ARM — семейство NVIDIA Jetson Orin | `chloros_<version>_arm64_jp6.deb` (сборка JetPack 6) |

## Поддерживаемые дистрибутивы Linux

* **Ubuntu 22.04 LTS или более поздние версии** (amd64)
* **Debian 12 или более поздние версии** (amd64)
* **NVIDIA JetPack 6** (arm64 — платформы Jetson Orin)***

## Что получают пользователи Linux

* **Chloros CLI** — полный интерфейс командной строки для пакетной обработки, автоматизации и создания скриптов
* **Chloros Python SDK** — программный интерфейс Python для исследовательских конвейеров и пользовательских инструментов (устанавливается из PyPI, а также входит в состав `.deb` в виде колеса, соответствующего версии)
* **Управление камерами LATTICE** — обнаружение, подключение, настройка и съемка с камер LATTICE и синхронизированных массивов из нескольких камер с помощью `chloros-cli lattice` и SDK; `.deb` включает среду выполнения Arena SDK, необходимую для работы камер
* **Управление световыми датчиками DAQ** — подключение датчиков DAQ-U/M/E, потоковая передача откалиброванных спектров и запись файлов `.daq` с помощью `chloros-cli daq pool-*` и SDK
* **Синхронизация времени по PTP** — бэкенд Chloros запускает PTP-грандмастер, к которому подключаются камеры LATTICE и датчики DAQ-E в качестве ведомых устройств; проверьте его с помощью `chloros-cli time-sync`, и обеспечьте его работу в фоновом режиме с помощью модуля systemd `chloros-backend.service` (см. [Установка Linux](linux-installation.md#always-on-ptp-for-headless-hosts))
* **Автоматизация проектов** — запускайте сохраненные проекты в режиме без интерфейса с помощью `chloros-cli project` и модуля `open_project`, входящего в состав SDK
* **Ускорение на GPU** — обработка с ускорением CUDA на графических процессорах NVIDIA (настольных и Jetson)
* **Динамическая адаптация вычислений** — автоматическое определение аппаратного обеспечения и выбор стратегии обработки, с возможностью переопределения с помощью параметра `CHLOROS_STRATEGY` в качестве экспертного «аварийного выхода»
* **Все функции обработки** — тот же конвейер, что и у Windows: калибровка, коррекция виньетирования, индексы растительности и все форматы экспорта
* **Функции Chloros+** — многопоточная (конвейерная) обработка, дебайеризация с учетом текстур и настраиваемые индексы при использовании платного тарифного плана Chloros+

## Чего не получают пользователи Linux

* **Графический интерфейс пользователя** — нет графического интерфейса; все взаимодействие осуществляется через CLI или Python SDK
* **Просмотрщик изображений** — нет интерактивного просмотрщика изображений, просмотра в виде сетки или маркеров на карте
* **Визуальное управление проектами** — проекты создаются и управляются с помощью команд CLI и вызовов SDK (само оборудование — камеры, датчики, устройства захвата — по-прежнему полностью управляется с терминала)***

## Требования к лицензии

Для доступа к CLI и SDK требуется **платный тарифный план Chloros+ — Copper или выше**(Copper, Bronze, Silver, Gold). Бесплатный тарифный план**«Iron»** не предоставляет доступа к функциям CLI/SDK. Это ограничение обеспечивается на серверной стороне, а не только на уровне CLI:

| Ситуация | Ответ бэкенда |
| --- | --- |
| Не вошёл в систему | `401` с `error_code: AUTH_REQUIRED` |
| Вошёл в систему на бесплатном уровне Iron | `403` с `error_code: PLAN_UPGRADE_REQUIRED` |

`chloros-cli status` работает на любом тарифе — это единственный маршрут, не подпадающий под ограничение шлюза, — поэтому причина отказа всегда видна.

## Начало работы с Linux

1. **Установите Chloros** — см. [Установка Linux](linux-installation.md) для установки `.deb`
2. **Проверьте** — `chloros-cli --version` выводит на печать `Chloros CLI 1.2.0`; `chloros-cli selftest` запускает 7-этапную диагностику
3. **Установите Python и SDK** (необязательно) — `pip install chloros-sdk`
4. **Войдите в систему** — `chloros-cli login your@email.com 'your-password'` (один раз на каждое устройство и повторно после каждого обновления пакета)
5. **Обработайте свой первый набор данных** — `chloros-cli process ~/datasets/flight001`

Для NVIDIA Jetson см. специальное [руководство по NVIDIA Jetson](nvidia-jetson-guide.md), в котором описаны настройка для конкретной платформы, тепловые характеристики и развертывание в полевых условиях.
