# Обзор Linux

В версии Chloros 1.1.0 реализована встроенная поддержка Linux для **CLI**и**Python SDK**, что позволяет осуществлять обработку многоспектральных изображений в режиме без монитора на рабочих станциях, серверах и периферийных устройствах NVIDIA Jetson.

{% hint style="info" %}
**На Linux нет графического интерфейса.** Графический интерфейс Chloros Desktop доступен только на Windows. Пользователи Linux взаимодействуют с Chloros через [CLI](../CLI.md) и [Python SDK](../api-python-sdk.md).
{% endhint %}

***

## Матрица поддержки платформ

| Функция | Windows (GUI) | Windows (CLI/SDK) | Linux amd64 (CLI/SDK) | Linux arm64 / Jetson (CLI/SDK) |
| --- | --- | --- | --- | --- |
| **Графический интерфейс для настольных ПК** | Да | Н/Д | Нет | Нет |
| **CLI** | Да | Да | Да | Да |
| **Python SDK** | Да | Да | Да | Да |
| **Ускорение на GPU (CUDA)** | Да | Да | Да | Да (JetPack 6) |
| **Дебайеринг с учетом текстур** | Да (Chloros+) | Да (Chloros+) | Да (Chloros+) | Да (Chloros+) |
| **Динамическая адаптация вычислений** | Да | Да | Да | Да |***

## Поддерживаемые архитектуры

| Архитектура | Описание | Метод установки |
| --- | --- | --- |
| **amd64 (x86_64)** | Стандартные процессоры для настольных компьютеров/серверов (Intel, AMD) | Пакет `.deb` |
| **arm64 (aarch64)** | Процессоры на базе ARM, в первую очередь NVIDIA Jetson | Пакет `.deb` (JetPack 6) |

## Поддерживаемые дистрибутивы Linux

* **Ubuntu 20.04+** (amd64)
* **Debian 11+** (amd64)
* **NVIDIA JetPack 6** (arm64 — платформы Jetson)***

## Что получают пользователи Linux

* **Chloros CLI** — Полный интерфейс командной строки для пакетной обработки, автоматизации и написания скриптов
* **Chloros Python SDK** — программный интерфейс Python (`pip install chloros-sdk`) для интеграции в исследовательские конвейеры и пользовательские инструменты
* **Ускорение на GPU** — обработка с ускорением CUDA на графических процессорах NVIDIA (настольные ПК и Jetson)
* **Динамическая адаптация вычислений** — автоматическое определение аппаратного обеспечения и оптимизация стратегии обработки
* **Все функции обработки** — тот же конвейер мультиспектральной обработки, что и в Windows (калибровка, коррекция виньетирования, индексы растительности, все форматы экспорта)
* **Функции Chloros+** — многопоточная обработка, дебайеринг с учетом текстур, пользовательские индексы (с лицензией Chloros+)

## Чего не получают пользователи Linux

* **Графический интерфейс** — Нет графического интерфейса; все взаимодействие осуществляется через CLI или Python SDK
* **Просмотрщик изображений** — нет интерактивного просмотрщика изображений, просмотра в виде сетки или маркеров на карте
* **Визуальное управление проектами** — управление проектами осуществляется с помощью команд CLI и вызовов SDK***

## Начало работы с Linux

1. **Установка Chloros** — См. [Установка Linux](linux-installation.md) для установки пакета `.deb`
2. **Установите Python SDK** (необязательно) — `pip install chloros-sdk`
3. **Активируйте лицензию** — `chloros-cli login your@email.com 'password'`
4. **Обработайте свой первый набор данных** — `chloros-cli process ~/datasets/flight001`

Пользователям NVIDIA Jetson рекомендуется ознакомиться со специальным [руководством по NVIDIA Jetson](nvidia-jetson-guide.md), где приведены инструкции по настройке и оптимизации для данной платформы.
