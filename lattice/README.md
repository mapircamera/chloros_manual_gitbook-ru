# Камеры LATTICE

LATTICE — это модульная мультиспектральная система камер от MAPIR, предназначенная для съемки в сельском хозяйстве и научных целях. Каждая камера LATTICE построена на базе датчика Sony IMX265 с глобальным затвором (**3,1 Мп, размер пикселя 3,45 мкм**) и подключается по сети Ethernet как устройство**GigE Vision**.

Chloros 1.2.0 управляет камерами LATTICE в режиме реального времени — обнаружение, предварительный просмотр, съёмка и синхронизированные массивы из нескольких камер — с трёх интерфейсов:

| Интерфейс    | Где                                                          | Платформы                                                |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| Графический интерфейс | Вкладка **«Камеры»** на боковой панели Chloros                         | Windows 10/11 x64                                        |
| CLI        | Семейство команд `chloros-cli lattice`                           | Windows 10/11 x64, Linux x86_64, Linux aarch64 (Jetson) |
| Python SDK | `chloros_sdk.connect_camera()` / `chloros_sdk.connect_array()` | Windows 10/11 x64, Linux x86_64, Linux aarch64 (Jetson) |

> **Ищете оборудование?**Камерные модули, объективы, фильтры и диапазоны, рамки и крепления, кабели, PoE и проводка триггера описаны в [**руководстве пользователя LATTICE**](https://mapir.gitbook.io/lattice-camera). В этой главе рассматривается управление камерами с помощью Chloros.

Записи LATTICE представляют собой стандартные файлы формата `.tif`/`.tiff`, и Chloros всегда обрабатывает их, начиная с необработанных данных. См. [Справочник по CLI](../reference/cli-reference.md) и [Справочник по SDK](../reference/sdk-reference.md) для ознакомления с полным набором команд и интерфейсом API.

## Две конфигурации датчиков

| Конфигурация | Датчик       | Фильтр                                | Что передает одна камера                                          |
| ------------- | ------------ | ------------------------------------- | ----------------------------------------------------------------- |
| **M3C**| Цветной по Байеру | тройной полосовой фильтр                |**Три откалиброванных диапазона за одну экспозицию**                 |
| **M3M**| Монохромный   | одиночный узкополосный интерференционный фильтр |**Один откалиброванный диапазон**; для получения индексов объединяйте несколько камер M3M |

Поскольку камера M3M является монохромной и оснащена одним фильтром, для каждого диапазона выполняется отдельная экспозиция. Камера M3C охватывает все три своих диапазона за одну экспозицию датчика.

## Строки модели и именование

Каждая камера хранит свой идентификатор в GenICam `DeviceUserID` в виде строки модели:

```
<sensor>-<lens>-F<filter>       e.g.  M3C-L41-FRGN,  M3M-L87-F450
```

Chloros отображает её с префиксом `LATT-` (например, `LATT-M3M-L87-F450`). Эта же строка `LATT-…` записывается в тег EXIF `Model` при каждом экспорте и используется в качестве имени папки вывода камеры в обработанных проектах.

| Компонент | Значения                                                   | Значение                                                                                            |
| --------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Датчик    | `M3C` / `M3M`                                            | Цветная матрица Байера / монохромная                                                                          |
| Объектив      | `L41` / `L87`                                            | Число обозначает **горизонтальный угол обзора в градусах**: L41 = узкий (41°), L87 = широкий (87°)    |
| Фильтр    | `FRGB` / `FRGN` / `FOCN` / `FNGB` (M3C) или `F<nm>` (M3M) | См. [Фильтры и спектральные полосы](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands) |

Строка модели определяет все последующие настройки: Chloros определяет профиль датчика, расположение диапазонов и заводскую калибровку на основе `DeviceUserID` + `DeviceSerialNumber`. Настройки для каждой камеры отдельно не требуются — см. [Подключение камер](connecting.md).

## Фильтры и полосы

Центра полос, границы FWHM и полный каталог M3M из 23 SKU являются техническими характеристиками продукта, поэтому они приведены в руководстве по аппаратному обеспечению: [**Фильтры и спектральные полосы**](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands).

Что важно с точки зрения программного обеспечения: код фильтра в строке модели определяет, какие продукты может создавать Chloros. Камеры с фильтром RGB (`FRGB`) выдают только продукты с устраненным эффектом Бейера и продукты предварительного просмотра — значения яркости и отражательной способности по отдельным полосам не имеют смысла для широкополосного датчика, поэтому Chloros пропускает их и сообщает об этом. Каждый другой фильтр формирует полную цепочку «излучение → отражательная способность → индекс».

## Краткий обзор радиометрической калибровки

Каждая камера LATTICE проходит индивидуальную калибровку на заводе по цепочке, прослеживаемой до NIST, и поставляется с сертификатом для каждой конкретной камеры. Что именно охватывает калибровка, как она проводится и какую точность можно указывать, описано в руководстве по аппаратному обеспечению: [**Заводская радиометрическая калибровка**](https://mapir.gitbook.io/lattice-camera/calibration/factory-radiometric-calibration).

Что касается программного обеспечения, важно, что Chloros определяет правильную калибровку при подключении камеры и фиксирует примененные коэффициенты в каждом экспорте — см. [Подключение камер](connecting.md).
