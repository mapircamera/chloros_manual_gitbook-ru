# Камеры LATTICE

LATTICE — это модульная мультиспектральная система камер компании MAPIR, предназначенная для съемки в сельском хозяйстве и научных целях. Каждая камера LATTICE построена на базе датчика Sony IMX265 с глобальным затвором (**3,1 Мп, размер пикселя 3,45 мкм**) и подключается по сети Ethernet как устройство**GigE Vision**.

Chloros 1.3.0 управляет камерами LATTICE в режиме реального времени — обнаружение, предварительный просмотр, съемка и синхронизированные массивы из нескольких камер — с трех интерфейсов:

| Интерфейс    | Где                                                          | Платформы                                                |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| Графический интерфейс | Вкладка **«Камеры»** на боковой панели Chloros                         | Windows 10/11 x64                                        |
| CLI        | Семейство команд `chloros-cli lattice`                           | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (Jetson) |
| Python SDK | `chloros_sdk.connect_camera()` / `chloros_sdk.connect_array()` | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (Jetson) |

> **Ищете оборудование?**Камерные модули, объективы, фильтры и диапазоны, рамки и крепления, кабели, PoE и проводка триггера описаны в [**руководстве пользователя LATTICE**](https://mapir.gitbook.io/lattice-camera). В этой главе рассматривается управление камерами из Chloros.

Записи LATTICE представляют собой стандартные файлы формата `.tif`/`.tiff`, и Chloros всегда обрабатывает их, начиная с исходных данных. Полный список команд и интерфейс API см. в [Справочнике по CLI](../reference/cli-reference.md) и [Справочнике по SDK](../reference/sdk-reference.md).

## Две конфигурации датчиков

| Конфигурация | Датчик       | Фильтр                                | Что передаёт одна камера                                          |
| ------------- | ------------ | ------------------------------------- | ----------------------------------------------------------------- |
| **M3C**| Цветная матрица Байера | тройной полосовой фильтр                |**Три откалиброванных диапазона за одну экспозицию**                 |
| **M3M**| Монохромная   | одиночный узкополосный интерференционный фильтр |**Один откалиброванный диапазон**; объединение нескольких камер M3M для получения индексов |

Поскольку камера M3M является монохромной и оснащена одним фильтром, для каждого диапазона выполняется отдельная экспозиция. Камера M3C охватывает все три своих диапазона за одну экспозицию датчика.

## Строки модели и именование

Каждая камера хранит свой идентификатор в GenICam `DeviceUserID` в виде строки модели:

```
<sensor>-<lens>-F<filter>       e.g.  M3C-L41-FRGN,  M3M-L87-F450
```

Chloros отображает её с префиксом `LATT-` (например, `LATT-M3M-L87-F450`). Та же строка `LATT-…` записывается в тег EXIF `Model` при каждом экспорте и используется в качестве имени выходной папки камеры в обработанных проектах.

| Компонент | Значения                                                   | Значение                                                                                            |
| --------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Датчик    | `M3C` / `M3M`                                            | Цветная матрица Байера / монохромная                                                                          |
| Объектив      | `L41` / `L87`                                            | Число обозначает **горизонтальный угол обзора в градусах**: L41 = узкий (41°), L87 = широкий (87°)    |
| Фильтр    | `FRGB` / `FRGN` / `FOCN` / `FNGB` (M3C) или `F<nm>` (M3M) | См. [Фильтры и спектральные полосы](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands) |

Строка модели определяет все последующие действия: Chloros определяет профиль датчика, расположение полос и заводскую калибровку на основе `DeviceUserID` + `DeviceSerialNumber`. Настройки для каждой камеры отдельно не требуются — см. [Подключение камер](connecting.md).

## Фильтры и спектральные полосы

Центральные частоты полос, ширина на пол-высоты (FWHM) и полный каталог M3M из 23 артикулов являются техническими характеристиками продукта, поэтому они приведены в руководстве по аппаратному обеспечению: [**Фильтры и спектральные полосы**](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands).

Что важно с точки зрения программного обеспечения: код фильтра в строке модели определяет, какие продукты может формировать Chloros. Камеры с RGB-фильтрами (`FRGB`) выдают только данные после дебайеризации и предварительный просмотр — значения яркости и отражательной способности по отдельным полосам не имеют смысла для широкополосного датчика, поэтому Chloros пропускает их и сообщает об этом. Любой другой фильтр генерирует полную цепочку: яркость → отражательная способность → индекс.

## Краткий обзор радиометрической калибровки

Каждая камера LATTICE проходит индивидуальную калибровку на заводе по цепочке, прослеживаемой до NIST, и поставляется с сертификатом для каждой конкретной камеры. Что именно охватывает эта калибровка, как проводятся измерения и какую точность можно указывать, описано в руководстве по аппаратному обеспечению: [**Заводская радиометрическая калибровка**](https://mapir.gitbook.io/lattice-camera/calibration/factory-radiometric-calibration).

Что касается программного обеспечения, важно, чтобы Chloros определял правильную калибровку при подключении камеры и фиксировал примененные коэффициенты при каждом экспорте — см. [Подключение камер](connecting.md).
