# Подключение камер

<figure><img src="../.gitbook/assets/image (37).png" alt=""><figcaption><p>Вкладка «Камеры» до подключения камер</p></figcaption></figure>Chloros автоматически обнаруживает камеры LATTICE по каналу связи — на вкладке «Камеры» графического интерфейса, из `chloros-cli lattice` или из Python SDK. Строка модели камеры определяет все последующие действия: Chloros определяет профиль датчика, расположение полос и заводскую калибровку на основе параметров камеры `DeviceUserID` + `DeviceSerialNumber`, поэтому **настройка каждой камеры отдельно не требуется**.

Перед подключением убедитесь, что на хост-сети выполнены соответствующие настройки — локальная адресация канала, поддержка джамбо-фреймов, а для массивов — настройки буфера приёма сетевой карты. Это настройки на уровне оборудования, описанные в руководстве LATTICE: [**Настройка сети**](https://mapir.gitbook.io/lattice-camera/setup/network-setup).

## Подключение через графический интерфейс

Откройте вкладку **Камеры**на боковой панели Chloros (вкладки, относящиеся к оборудованию, появляются после завершения запуска бэкэнда) или воспользуйтесь главным меню →**Подключиться к камере**. Оба способа открывают диалоговое окно**Подключить камеру(ы)**.

### Диалоговое окно «Подключить камеру(ы)»

Сразу после открытия диалоговое окно начинает сканировать сеть («Сканирование сети...») и выводит список всех найденных камер. В каждой строке отображаются **модель**камеры (например, `LATT-M3M-L41-F550`),**серийный номер**и**IP-адрес**.

* **Щелкните по строке, чтобы выбрать её**(зелёная подсветка). Вы можете выбрать**несколько камер** и подключить их за один раз — Chloros подключает их по очереди.
* Строки с меткой **«Подключено»** уже подключены и не могут быть выбраны повторно.
* Строки с меткой **«В массиве»** относятся к подключенному в данный момент массиву камер. Сначала отключите массив, чтобы использовать эту камеру в автономном режиме.
* **Подключить** — подключает выбранную(ые) камеру(ы); на кнопке отображается количество, например «Подключить (3)», если выбрано более одной камеры.
* **Повторить сканирование** — запускает поиск заново.
* **Закрыть** — закрывает диалоговое окно.
* Если сканирование завершилось без результатов, в диалоговом окне отобразится сообщение **«В сети не найдено камер»** — см. раздел [Устранение неполадок](connecting.md#troubleshooting) ниже.

<figure><img src="../.gitbook/assets/image (38).png" alt=""><figcaption><p>Диалоговое окно «Подключить камеру(ы)» — показано здесь в случае отсутствия камер в сети</p></figcaption></figure>### Первое подключение: загрузка пакета калибровки

**При первом**подключении данной камеры к компьютеру Chloros загружает заводской пакет калибровки камеры (\~3,8 МБ) непосредственно с самой камеры по интерфейсу GigE. Пока выполняется эта операция, в диалоговом окне отображается зелёная панель**«Загрузка данных калибровки с камеры»**с индикатором прогресса для каждого серийного номера — ожидайте, что на каждую камеру уйдёт примерно**70 секунд**. Пакет кэшируется на хосте, поэтому при последующих подключениях той же камеры загрузка полностью пропускается (и панель не отображается).

### Анализ системы

Кнопка **«Анализ системы»** в диалоговом окне проверяет хост и сеть (во время выполнения отображается надпись «Анализ...») и формирует диагностический отчёт:

* **Хост** — ядра ЦП и оперативная память; название графического процессора и объем памяти, либо «GPU: не обнаружено».
* **Сетевые интерфейсы** — название каждого сетевого адаптера, скорость соединения, MTU (с пометкой «jumbo», если активна), состояние (активно/неактивно) и указание на то, подключен ли он к USB-шине.
* **Камеры**— серийный номер, модель, IP-адрес и**на каком сетевом адаптере подключена каждая камера**.
* **Производительность** — текущее и идеальное количество кадров в секунду (fps) для каждой камеры с учётом формата пикселей; при превышении идеального значения над текущим отображается зелёная строка «Потенциал: возможно улучшение в N раз».
* **Предупреждения и пронумерованные рекомендации** — или сообщение «Система работает нормально для текущего количества камер», если исправлять нечего.

Запускайте эту функцию при непредвиденном поведении обнаружения или потоковой передачи — она выявляет большинство проблем со стороны сетевых карт (неправильный MTU, камера на неправильном интерфейсе, ограничения USB-адаптера) без выхода из диалогового окна.

### Подключение массива

Чтобы подключить две или более камер в виде **синхронизированного массива**, воспользуйтесь мастером подключения массива (**«Подключить массив камер»**): он пошагово проведет вас через выбор главного/подчиненного устройства (данные предварительно заполняются с помощью пробника подключения GPIO), выбор режима отображения (отдельные или объединенные плитки) и настройки массива с динамическим прогнозом достижимой частоты кадров (fps) и пропускной способности кабеля перед подтверждением действий. Мастер и рабочие процессы массива описаны в разделе «Мультикамерные массивы» данного руководства; аналогом для CLI является «Рабочий процесс первого подключения камеры LATTICE» в [Справочнике по CLI](../reference/cli-reference.md).

## Подключение с CLI и SDK

Для доступа к CLI и SDK требуется платный тарифный план Chloros+ и авторизация; это проверяется на стороне сервера (`401 AUTH_REQUIRED` при отсутствии входа в систему, `403 PLAN_UPGRADE_REQUIRED` на бесплатном тарифе).

```bash
# List cameras on the network (vendor, model, serial, IP, MAC)
chloros-cli lattice info

# Single-camera smoke test: capture one frame (saves every applicable export type)
chloros-cli lattice capture -o output/

# Connect a synchronized array — same smart-prep flow as the GUI
chloros-cli lattice array-connect --serials 213800234,214000533
```

```python
import chloros_sdk

# Persistent live-camera session through the backend
with chloros_sdk.connect_camera("213800234") as cam:
    ...

# Array session (smart-prep: network probe, tier auto-pick, PTP, AE seeding, trigger config)
with chloros_sdk.connect_array(["213800234", "214000533"]) as array:
    ...
```

Полные сигнатуры, параметры и рабочие процессы захвата: [CLI Справочник](../reference/cli-reference.md) § `chloros-cli lattice`, [Справочник SDK](../reference/sdk-reference.md) § `connect_camera()` / `connect_array()`.

## Как происходит калибровка при подключении

Каждая камера LATTICE имеет свой заводской пакет калибровки **встроенный в камеру**, а Chloros также проверяет облако MAPIR при подключении камеры:

| Ситуация   | Что использует Chloros                                                                                                                                                                                                          |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Онлайн**|**Самая новая калибровка, опубликованная для данного серийного номера** — копия из облака имеет приоритет над копией на камере. Таким образом, камера, которая была перекалибрована или обновлена с помощью MAPIR, обновляется автоматически; никаких действий со стороны пользователя не требуется. |
| **Офлайн**|**Пакет, установленный на камере**, в исходном виде. Полностью автономные рабочие процессы продолжают функционировать; они просто не используют более новые калибровки до тех пор, пока камера не подключится к сети хотя бы один раз (или не будет перепрошита до заводских настроек).                                                  |

Во время съёмки фактически применяемые коэффициенты **зафиксируются в метаданных XMP каждого изображения**. Последующее обновление калибровки никогда не изменяет без уведомления уже снятые изображения — при повторной обработке старого снимка используются коэффициенты, зафиксированные в его XMP, а не самые последние на сегодняшний день.

## Устранение неполадок

* **&quot;«Камеры в сети не найдены»**— проверьте настройки локальной сети в разделе [Настройка сети](https://mapir.gitbook.io/lattice-camera/setup/network-setup): статический IP-адрес сетевой карты хоста — `169.254.x.x/16`, камеры должны находиться на одном сегменте сети, использование DHCP или шлюза не предполагается. Затем воспользуйтесь функцией**«Анализ системы»**в диалоговом окне подключения, чтобы проверить, на каком сетевом адаптере видна (или не видна) каждая камера. После любой замены кабелей или смены сетевого адаптера выполните**повторное сканирование**.
* **Ранее работавшая установка отказывается подключаться** (панели массива с кодами ошибок `FRAMES WILL DROP` / `Reduce ROI to enable`) — обновление драйвера сетевой карты незаметно сбросило настройки кольца приёма. Примените их заново или запустите команду `chloros-cli lattice network --fix` из терминала с правами администратора; см. раздел [Настройка сети](https://mapir.gitbook.io/lattice-camera/setup/network-setup).
* **Камера отображает сообщение «In Array»** — она входит в подключенный массив. Отключите массив, чтобы использовать камеру в автономном режиме.
