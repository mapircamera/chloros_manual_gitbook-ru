# Подключение камер

<figure><img src="../.gitbook/assets/image (37).png" alt=""><figcaption><p>Вкладка «Камеры» до подключения камер</p></figcaption></figure>

Chloros автоматически обнаруживает камеры LATTICE в сети — через вкладку «Камеры» графического интерфейса, через `chloros-cli lattice` или через Python SDK. Строка модели камеры определяет все последующие действия: Chloros определяет профиль датчика, расположение полос и заводскую калибровку на основе файлов `DeviceUserID` и `DeviceSerialNumber` камеры, поэтому **настраивать каждую камеру отдельно не требуется**.

Перед подключением убедитесь, что настраивана сеть хоста — локальная адресация канала, джамбо-фреймы и, для массивов, настройки буфера приёма сетевой карты. Это настройка на стороне оборудования, описанная в руководстве LATTICE: [**Настройка сети**](https://mapir.gitbook.io/lattice-camera/setup/network-setup).

## Подключение через графический интерфейс

Откройте вкладку **Камеры** на боковой панели Chloros (вкладки, относящиеся к оборудованию, появляются после завершения запуска бэкэнда) или воспользуйтесь главным меню → **Подключиться к камере**. Оба способа открывают диалоговое окно**Подключить камеру(ы)**.

### Диалоговое окно «Подключить камеру(ы)»

Сразу после открытия диалоговое окно начинает сканировать сеть («Сканирование сети...») и выводит список всех найденных камер. В каждой строке отображаются **модель**камеры (например, `LATT-M3M-L41-F550`),**серийный номер**и**IP-адрес**.

* **Щелкните строку, чтобы выбрать её**(зелёная подсветка). Вы можете выбрать**несколько камер** и подключить их за один раз — программа Chloros подключает их по очереди.
* Строки с меткой **«Подключено»** уже подключены и не могут быть выбраны повторно.
* Строки с меткой **«В массиве»** относятся к подключенному в данный момент массиву камер. Сначала отключите массив, чтобы использовать эту камеру в автономном режиме.
* **Подключить** — подключает выбранные камеры; на кнопке отображается количество, например «Подключить (3)», если выбрано более одной камеры.
* **Повторить сканирование** — запускает поиск заново.
* **Закрыть** — закрывает диалоговое окно.
* Если сканирование завершилось без результатов, в диалоговом окне отобразится сообщение **«Камеры в сети не найдены»** — см. раздел [Устранение неполадок](connecting.md#troubleshooting) ниже.

### Первое подключение: загрузка пакета калибровки

**При первом** подключении данной камеры к компьютеру Chloros загружает заводской пакет калибровки камеры (\~3,8 МБ) непосредственно с самой камеры по интерфейсу GigE. Пока идет загрузка, в диалоговом окне отображается зелёная панель **«Загрузка данных калибровки с камеры»**с индикатором прогресса для каждого серийного номера — ожидайте примерно**70 секунд** на каждую камеру. При подключении более шести камер строки прогресса прокручиваются внутри панели. Пакет кэшируется на хосте, поэтому при последующих подключениях той же камеры загрузка полностью пропускается (и панель не отображается).

### Анализ системы

Кнопка **«Анализ системы»** в диалоговом окне проверяет хост и сеть (во время работы отображается надпись «Анализ...») и формирует диагностический отчет:

* **Хост** — ядра ЦП и оперативная память; название и объем памяти графического процессора или «GPU: не обнаружено».
* **Сетевые интерфейсы** — название каждого сетевого адаптера, скорость соединения, MTU (с пометкой «jumbo», если эта функция активна), состояние (активный/неактивный) и указание на то, подключен ли он к USB-шине.
* **Камеры**— серийный номер, модель, IP-адрес и**на каком сетевом адаптере подключена каждая камера**.
* **Производительность** — текущее и идеальное количество кадров в секунду (fps) на камеру для данного формата пикселей; если идеальное значение превышает текущее, отображается зелёная строка «Потенциал: возможно улучшение в N раз».
* **Предупреждения и пронумерованные рекомендации** — или сообщение «Система работает нормально для текущего количества камер», если исправлять нечего.

Запускайте эту функцию при непредвиденном поведении обнаружения или потоковой передачи — она выявляет большинство проблем со стороны сетевых карт (неправильный MTU, камера на неправильном интерфейсе, ограничения USB-адаптера) без выхода из диалогового окна.

### Подключение массива

Чтобы подключить две или более камер в виде **синхронизированного массива**, воспользуйтесь мастером подключения массива (**«Подключить массив камер»**): он проведет вас через выбор главной и подчиненной камер (предварительно заполненный с помощью проверки синхронизационного кабеля — любая подключенная камера может быть главной, а камера RGB `-FRGB` выбирается автоматически при подключении), выбор режима отображения (отдельные или объединенные плитки), а также сцену настроек массива с динамическим отображением достижимых значений fps и пропускной способности кабеля перед подтверждением. Мастер и рабочие процессы массива описаны в разделе «Мультикамерные массивы» данного руководства; эквивалентом в CLI является «Рабочий процесс первого подключения камеры LATTICE» в [Справочнике по CLI](../reference/cli-reference.md).

## Подключение через CLI и SDK
Для доступа через

CLI и SDK требуется платный тарифный план Chloros+ и авторизация; это требование обеспечивается на стороне сервера (`401 AUTH_REQUIRED` при отсутствии авторизации, `403 PLAN_UPGRADE_REQUIRED` на бесплатном тарифном плане).

```bash
# List cameras on the network (vendor, model, serial, IP, MAC)
chloros-cli lattice info

# Single-camera smoke test: capture one frame (saves every applicable export type)
chloros-cli lattice capture -o output/

# Connect a synchronized array — same smart-prep flow as the GUI
chloros-cli lattice array-connect --serials 213800234,214000533
```

```python
import chloros_sdk

# Persistent live-camera session through the backend
with chloros_sdk.connect_camera("213800234") as cam:
    ...

# Array session (smart-prep: network probe, tier auto-pick, PTP, AE seeding, trigger config)
with chloros_sdk.connect_array(["213800234", "214000533"]) as array:
    ...
```

Полный список сигнатур, опций и рабочих процессов сбора данных: [Справочник по CLI](../reference/cli-reference.md) § `chloros-cli lattice`, [Справочник по SDK](../reference/sdk-reference.md) § `connect_camera()` / `connect_array()`.

## Как происходит калибровка при подключении

Каждая камера LATTICE имеет свой заводской пакет калибровки **встроенный в камеру**, а Chloros также проверяет облако MAPIR при подключении камеры:

| Ситуация   | Что использует Chloros                                                                                                                                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Онлайн**|**Самая новая калибровка, опубликованная для данного серийного номера** — копия из облака имеет приоритет над копией, хранящейся в камере. Таким образом, камера, которая была перекалибрована или обновлена MAPIR, обновляется автоматически; никаких действий со стороны пользователя не требуется. |
| **В автономном режиме**|**Пакет, установленный на камере**, в исходном виде. Полностью автономные рабочие процессы продолжают функционировать; они просто не используют более новые калибровки до тех пор, пока камера не подключится к сети хотя бы один раз (или не будет перепрошита до заводских настроек).                                                  |

Во время съемки фактически применяемые коэффициенты **зафиксированы в метаданных XMP каждого изображения**. Последующее обновление калибровки никогда не изменяет без уведомления уже снятые изображения — при повторной обработке старого снимка используются коэффициенты, зафиксированные в его XMP, а не самые новые на сегодняшний день.

## Устранение неполадок

* **"«Камеры в сети не найдены»**— проверьте настройки локальной сети в разделе [Настройка сети](https://mapir.gitbook.io/lattice-camera/setup/network-setup): статический IP-адрес сетевой карты хоста `169.254.x.x/16`, камеры должны находиться на одном сегменте сети, использование DHCP или шлюза не предполагается. Затем воспользуйтесь функцией**«Анализ системы»**в диалоговом окне подключения, чтобы проверить, на каком сетевом адаптере видна (или не видна) каждая камера. После любой замены кабелей или сетевых адаптеров выполните**повторное сканирование**.
* **Ранее работавшая установка отказывается подключаться** (панели массива с кодами ошибок `FRAMES WILL DROP` / `Reduce ROI to enable`) — обновление драйвера сетевой карты незаметно сбросило настройки кольца приёма. Примените их заново или запустите команду `chloros-cli lattice network --fix` из терминала с правами администратора; см. раздел [Настройка сети](https://mapir.gitbook.io/lattice-camera/setup/network-setup).
* **Камера отображается как «In Array»** — она входит в подключенный массив. Отключите массив, чтобы использовать камеру в автономном режиме.
