# Настройки камер

Вкладка **«Камеры»** представляет собой панель управления в режиме реального времени от Chloros для камер LATTICE: основная область просмотра, в которой каждая подключенная камера отображается в виде «живой» плитки, и боковая панель, переключающаяся между тремя страницами — **списком камер**,**панелью настроек**(настройки для отдельной камеры, массива или захвата — по одной за раз) и**калькулятор индекса**. На этой странице описаны все элементы управления в списке камер, панели настроек отдельных камер и панели настроек массива. Режимы захвата, выбор типа экспорта и рабочий процесс «Захват всего» описаны на сопутствующей странице [Настройки и режимы захвата](capture.md).

Вкладка «Камеры» появляется в боковой панели, как только бэкенд Chloros готов к работе. Все элементы управления, описанные ниже, взаимодействуют с локальным бэкендом через `127.0.0.1:5000`; изменения сразу же применяются к камере в режиме реального времени, если не указано иное.

## Типы камер, используемые на этой странице

Элементы управления отображаются или скрываются в зависимости от того, какой тип камеры выбран. В руководстве повсеместно используются следующие термины:

| Термин | Значение | Каналы фильтра |
| --- | --- | --- |
| **RGB-камера** | LATTICE M3C с фильтром FRGB (модель содержит `-FRGB`) | Red / Green / Blue |
| **Мультиспектральная камера Байера** | LATTICE M3C с фильтрами FRGN, FOCN или FNGB | FRGN: Red / Green / NIR · FOCN: Orange / Cyan / NIR · FNGB: NIR / Green / Blue |
| **Моно (M3M)** | LATTICE M3M — один узкополосный фильтр, одна откалиброванная полоса | Однополосная |
| **Элемент массива** | Камера, подключенная в составе синхронизированного массива (объединенное или раздельное отображение) | В соответствии со своим фильтром |

Камеры RGB проходят фотометрическую обработку (баланс белого, цветовые профили, гамма); мультиспектральные и монохромные камеры проходят радиометрическую цепочку и пропускают фотометрические настройки. Элементы массива передают настройки на уровне потока (формат пикселей, разрешение, биннинг, триггер, частота кадров) массиву — эти строки становятся доступными только для чтения в панели настроек отдельной камеры и перемещаются в панель настроек массива.

### Верхняя панель

| Элемент управления | Функция |
| --- | --- |
| **Переключение режима просмотра**| Переключает между**режимом сетки**(все плитки в виде ячеек) и**режимом списка**(строки во всю ширину: каждая объединенная матрица представляет собой одну составную строку, каждый элемент**отдельной** матрицы — отдельную строку со своим собственным потоком и таблицей калибровочных мишеней, а затем ОДНА автономная камера — активная — ниже). Всплывающие подсказки: «Переключиться в режим сетки» / «Переключиться в режим списка». |
| **Блокировка сетки**(замок) | По умолчанию**заблокировано** — плитки зафиксированы на месте. Разблокируйте, чтобы перетаскивать плитки в любое место (промежутки сохраняются). Сетка автоматически повторно блокируется каждый раз, когда подключается новая камера. Всплывающие подсказки: «Разблокировать сетку (включить перетаскивание плиток)» / «Заблокировать сетку (зафиксировать плитки на месте)». |
| Ползунок **Масштаб трансляции** | Размер плитки — от 60 пикселей до полной ширины контейнера. Ячейки сохраняют соотношение сторон 4:3. При ширине ячейки менее 200 пикселей наложения с названием и частотой кадров скрываются, чтобы плитка оставалась чистой. |

### Плитки потока

Каждая камера отображает составную плитку в режиме реального времени; камера может дополнительно показывать три плитки в оттенках серого с **разделением по каналам** (см. [Разделение по каналам](#display-overlays-drawn-over-the-live-feed)), а массивы отображают комбинированную плитку. Активная плитка имеет кольцо выбора цвета камеры (или массива).

При наведении курсора на плитку появляется кнопка закрытия **X**:

* Закрытие **композитной** плитки при сохраненных разделениях каналов просто скрывает композитную плитку.
* Закрытие **последней видимой плитки автономной камеры** отключает эту камеру.
* **Плитки с разделением каналов, входящие в массив, никогда не отключают** камеру — они лишь скрывают её.

Если сетка разблокирована, перетащите любую плитку в любое гнездо; макет сохраняется вместе с проектом.

### Строки камер

Каждая строка камеры отображает рамку с цветовой маркировкой (пользовательский цвет камеры), метку «CAM» — с синей буквой **M**(главная) или зелёную**S** (подчинённая) для элементов массива — и отображаемое имя. Имя по умолчанию — `LATTICE-MODEL (serial)`; его можно переименовать в панели настроек камеры. Кнопки строки:

| Кнопка | Эффект |
| --- | --- |
| **Глаз**| Включение/выключение видимости. Скрытые камеры исчезают из сетки и**исключаются из функции «Захват всего»**. |
| **Шестеренка** | Открыть панель настроек для каждой камеры (следующий раздел). |
| **Пауза / Воспроизведение**| Заморозить предварительный просмотр**только на экране** — захват на сервере продолжается. Приостановленные камеры не могут осуществлять захват. |
| **X** | Отключить. Пользовательский интерфейс обновляется немедленно (в идеале); само отключение на сервере может занять 10–30 с. |

### Строки массива

В строке массива отображается значок «ARRAY» цвета массива, название массива (его можно переименовать в настройках массива) и кнопка **DAQ · включить/выключить**—**включена**, когда на уровне массива установлен датчик освещенности *или* у любого участника массива есть датчик на уровне отдельной камеры; в его всплывающей подсказке точно указано, какой датчик подаёт сигнал на что. Камеры-участницы перечислены с отступом ниже в отдельных строках. Кнопки строки массива: **глаз**(скрывает/отображает ВСЕ элементы одновременно),**шестеренка**(панель настроек массива),**X**(отключение всего массива).

Статус датчика освещенности (DLS), используемый в строках массива и на панели настроек массива, имеет четыре состояния:**выключено**,**ожидание**(спектра ещё нет),**активно**(спектр поступил в течение последних 3 с) и**устарело** — свежего спектра не поступало в течение 3 с, но последнее значение *все ещё используется* (показания DAQ никогда не истекают на пути захвата).

Пока вы не измените порядок, в списке сначала отображаются массивы, затем автономные камеры, причём камеры (и элементы каждого массива) расположены в **порядке камер**: M3C (Байер) перед M3M (монохромная); среди M3C — FRGB, FRGN, FOCN, затем FNGB; M3M — по длине волны фильтра, начиная с самой низкой. По умолчанию сетка выстраивается в том же порядке. Вы можете перетаскивать отдельные камеры и целые группы матриц друг за другом на боковой панели, чтобы изменить порядок списка; элементы матрицы нельзя перетаскивать независимо друг от друга.

### Гистограмма в реальном времени

В верхней части панели находится гистограмма яркости в реальном времени, вычисляемая на основе предварительного просмотра в формате JPEG с частотой ~8 Гц. Среднее значение взвешено по методу Байера — (R+2G+B)/4 — для соответствия собственной системе экспозамера камеры.

* **Оранжевая (Orange) пунктирная линия**= цель автоэкспозиции.**Перетащите её по горизонтали, чтобы изменить цель** — при отпускании отправляется одна команда, а перетаскивание переключает режим цели автоэкспозиции в ручной.
* **Зелёная (Green) сплошная линия** = фактическое среднее значение яркости (то, что в данный момент обеспечивает автоэкспозиция).
* **Кнопка RGB** (вверху справа): переключает наложение гистограмм по отдельным полосам, окрашенных в соответствии с фильтром камеры (например, в режиме FRGN: серый — NIR, зелёный — красный). На монохромных (M3M) камерах кнопка имеет надпись «MONO» и отключена — в монохромном режиме всегда отображается однополосная гистограмма яркости.
* Метки по оси X соответствуют разрядности датчика текущего формата пикселей: 0..255, 0..1023, 0..4095 или 0..65535.

#### Таблица калибровочной мишени

Таблица предназначена **только для просмотра результатов проверки** («только для проверки — не изменяет калибровку»). В заголовке указаны серийный номер камеры, фильтр, номер мишени и размер маркера в пикселях; в таблице по одной строке на каждую панель:

* **Панель**, затем по одному столбцу на каждую полосу с значением панели — камера Байера отображает свои три полосы по названию и длине волны (например, FRGN: Red 660 нм / Green 550 нм / NIR 850 нм); **монохромная (M3M) камера отображает свою единственную полосу** (например, `F750`) и не имеет столбцов NDVI.
* **Sat** — доля насыщенных пикселей панели (янтарный цвет — от 1 %, красный — от 5 %).
* **NDVI Meas**,**NDVI Theo** (эталонный NDVI по отражательной способности панели) и **Δ**— только для мультиспектральных камер Байера. Небольшая пометка после «NDVI Meas» указывает, на основе чего был рассчитан измеренный NDVI:**ρ**(отражательная способность — имеется показание датчика освещенности),**L**(излучательная способность — показания датчика освещенности отсутствуют) или**DN**(исходные значения камеры). Только**ρ**-NDVI сопоставим с NDVI Theo: для L и DN столбец Δ затенен, и об этом говорится в примечании («Нет показаний датчика освещённости: NDVI рассчитан на основе излучения, поэтому Δ не является проверкой калибровки» / «NDVI рассчитан на основе исходных значений камеры, поэтому Δ не является проверкой калибровки»). При использовании ρ значение Δ отображается зелёным, если оно меньше 0,02, жёлтым — если меньше 0,05, в остальных случаях — красным.

| **Сглаживание AE** | 0,5–40, шаг 0,1 | 8,0 | Все | Демпфирование AE. Всплывающая подсказка: «Чем ниже — тем быстрее реагирует автоэкспозиция (может пульсировать при высокой частоте кадров). Чем выше — тем плавнее и медленнее». {% hint style="info" %}
**Требования к освещённости для мультиспектральных камер Bayer (RGN / OCN / NGB):** сцена должна быть достаточно освещена во всех трёх каналах, иначе калибровка не будет работать правильно — одна экспозиция датчика охватывает все три спектра. Используйте датчик освещённости DAQ для измерения освещённости или переключитесь в полностью монохромный режим (M3M), чтобы каждая полоса получала свою собственную экспозицию. Если при съёмке это требование нарушается, Chloros обнаруживает это и предупреждает вас (уведомление об ограничении при размикшировании). В режиме реального времени в плитке с разделением по каналам отображается надпись **«Данные полосы с низкой достоверностью · N%»**, если функция unmix ограничила эту полосу на 25 % или более её пикселей.
{% endhint %}

{% hint style="info" %}
**Как функция автоматической экспозиции распределяет время экспозиции и коэффициент усиления (1.3.0)**. При автоматическом усилении (Gain on Auto) Chloros удерживает усиление на уровне 0 дБ до тех пор, пока экспозиция не достигнет максимально допустимого значения (верхний предел AE, период срабатывания массива или верхний предел экспозиции DAQ); только после этого усиление увеличивается. В массиве приоритет имеет частота срабатывания: система автоматической экспозиции заполняет период, определяемый этой частотой, а затем повышает усиление, поэтому затемнение сцены больше не снижает частоту срабатывания в режиме «Авто» (в версии 1.2.0 это происходило). **Ручная**экспозиция на одном из элементов массива, продолжительность которой превышает период срабатывания, замедляет частоту срабатывания массива, чтобы приспособиться к ней; частота автотриггера восстанавливается, как только все элементы массива, которые её замедлили, вернутся в режим автоматической экспозиции. Если параметры**«Экспозиция»**и**«Целевая яркость AE»** установлены в режим «Авто», а датчик освещённости DAQ предоставляет показания, экспозиция каждой камеры фиксируется после стабилизации автоматической экспозиции, пока измеренная освещённость остаётся в пределах примерно ±25 %; более значительное и продолжительное изменение освещенности, перезапуск настроек (например, изменение области интереса) или ваше собственное изменение экспозиции приводят к его повторной активации.
{% endhint %}

{% hint style="info" %}
**Как работает автоэкспозиция (версия 1.3.0).**

* При ручной экспозиции коэффициент усиления остается в режиме «Авто», пока вы не измените его значение.
* Небольшие пересветы не затемняют сцену: зеркальные блики, занимающие до 1 % кадра, игнорируются, а на панелях известной калибровочной мишени — до 0,5 % панели.
* Предельное значение экспозиции DAQ применяется только при наличии калибровочной мишени в поле зрения; если панели не видно, камера выставляет экспозицию для сцены.
* Экспозиция остается стабильной при постоянном освещении и стабилизируется в течение нескольких секунд после значительного изменения освещенности. Пересвет больше не ограничивает экспозицию навсегда, а при смене области интереса (ROI) экспозиция настраивается заново.
* Целевой уровень яркости не выходит за пределы диапазона камерыдосягаемости, поэтому возвращающийся свет не вызывает бликов в кадре.
* Камера, автоэкспозиция которой перестает реагировать при ярком солнечном свете, удерживается на уровне, соответствующем освещённости, считываемой датчиком освещённости или, при его отсутствии, собственными кадрами камеры, и отпускается при изменении освещения. Затемнённый или закрытый датчик освещённости не влияет на этот процесс.
{% endhint %}

(автономные камеры) | Решатель с замкнутым выражением использует спектр DLS и скалярные величины из пакета калибровки камеры, чтобы довести самую яркую полосу до состояния, близкого к насыщению, при этом сохраняя самую тёмную полосу выше минимального уровня SNR — одна запись экспозиции на каждое решение, без цикла стабилизации. Предназначено для таймлапса с солнечным питанием, где каждый кадр должен быть правильно экспонирован. Бэкенд незаметно переключается на реактивную автоэкспозицию (AE), если показания DLS устарели или отсутствуют, либо пакет калибровки не загружен. |
| **Сглаживание (α)** | 0,05–1,0, шаг 0,05 | 0,3 | Сглаживание последовательных прогнозных решений (чем ниже, тем плавнее). |
| **Отражательная способность сцены**| Кнопка**«Перекалибровать ρ»** | — | Пересчитывает коэффициент отражательной способности сцены, используемый алгоритмом решения. |

{% hint style="info" %}
**При использовании массива камер прогнозирующий автоэкспозиция по умолчанию отключается** — для массивов камер интеллектуальная автоэкспозиция Chloros в сочетании с автоэкспозицией на стороне камеры управляют экспозицией (с защитой от перенасыщения), а оценка отражательной способности одной сценыоценка отражательной способности не является безопасной при смешанных сценах. Здесь вы можете повторно включить её для каждой камеры, если вам конкретно требуется радиометрическая экспозиция на основе DLS.
{% endhint %}

**Ограничение экспозиции на основе данных сбора данных (DAQ) и автоэкспозиция с фиксацией падающего света.** Независимо от состояния вышеуказанного флажка, когда датчик освещённости DAQ назначен на RGB-камеру, Chloros вычисляет — на основе измеренной абсолютной интенсивности нисходящего излучения — максимальное значение экспозиции × коэффициент усиления, при котором поверхность с отражательной способностью 100 % остаётся ниже уровня клиппинга, и применяет его в качестве **предел**для автоматической экспозиции. Начиная с версии 1.3.0 этот предел применяется только тогда, когда калибровочная мишень находится в поле зрения этой камеры (попадает в кадр в течение последних 10 с); если мишени в поле зрения нет, вместо этого работает обычная автоэкспозиция камеры со своей собственной защитой от пересвета, благодаря чему остальная часть сцены не остается темнее, чем это необходимо. Пока верхний предел активен, камера работает в режиме**фиксации падающего света**: она работает в режиме открытого контура с экспозицией, заданной по измеренному падающему свету, при усилении 0 дБ — экспозиция зависит от измеренного света, а не от содержания сцены. Поскольку верхний предел может только сократить выдержку, он сам по себе не может вызвать обрезание. Начиная с версии 1.3.0 верхний предел рассчитывается с использованием собственной константы экспозиции камеры из её пакета калибровки (среднее значение по парку используется только в том случае, если в пакете отсутствует собственное значение). Верхний предел отключается автоматически — и возобновляется обычная автоэкспозиция сцены — всякий раз, когда в поле зрения отсутствует калибровочная мишень, показания DAQ отсутствуют, устарели (>30 с), тёмные или если ≥15 % кадра подвергается клиппингу при зафиксированной экспозиции (что означает, что датчик и камера воспринимают разную освещённость). Переключателя в графическом интерфейсе пользователя нет; это стандартное поведение, когда к RGB-камере подключён DAQ.

#### Редактор области интереса (ROI)

Новое в версии 1.3.0. Строка кадрирования ROI и карта под ней работают совместно:

* **ROI включено / ROI выключено**—**немедленно**включает или выключает кадрирование датчика (камеры на короткое время перезапускаются; на плитке массива отображается надпись «Применение настроек…»).**Выкл.**считывает данные со всего датчика и**запоминает вашу область кадрирования**— поля продолжают её отображать;**Вкл.** применяет её снова. Включение области интереса без заданной области кадрирования приводит к применению центрированной области кадрирования половинного размера («Область кадрирования не была задана, поэтому была применена центрированная область кадрирования половинного размера. Настройте её с помощью полей»).
* **Выбор**— рисует область выреза на карте: перетащите курсор по ней или щелкните два противоположных угла (Esc отменяет действие). Прямоугольник фиксируется в полях W/H/X/Y, привязываясь к настройкам выше; ничего не применяется, пока вы не нажмете**Применить**, поэтому сначала можно точно настроить его с помощью стрелок в полях. Один прямоугольник на каждое нажатие кнопки «Выбрать».
* **Карта**показывает кадрирование на всем сенсоре, поэтому вы можете снова расширить его: «Полный сенсор, в реальном времени», пока камеры считывают полный сенсор, или «Полнокадровый снимок от {время}. Камеры считывают только вырезанную область», пока они работают в режиме кадрирования. Если массив всегда передавал только кадрированные данные, на карте отображается надпись «Полнокадрового просмотра пока нет: этот массив передавал только кадрированные данные»» с кнопкой**Показать полный кадр**, которая отключает область интереса (ROI). Метка кадра `W×H @ X,Y` располагается за пределами рамки (над ней или под ней, если рамка касается верхнего края) как на карте, так и на плитке реального времени.
* **Применить**фиксирует настройки полей: кадр включает область интереса (ROI); полный кадр (после**Сброса**) оставляет её выключённой, при этом предыдущий кадр сохраняется в памяти; область интереса, которая выключена и чьи поля всё ещё отображают запомненный кадр, остаётся выключённой при применении других изменений (формат, биннинг, частота).
* **В выровненной матрице окно кадрирования каждого элемента размещается в соответствии с выравниванием**, поэтому каждая камера кадрирует один и тот же участок сцены. Матрица, кадрированная до выравнивания, сначала выравнивается по полному сенсору (кадрирование снимается, выравнивание выполняется, а затем кадрирование восстанавливается с окнами для каждой камеры).
* После изменения кадрирования автоматическая экспозиция перенастраивается в соответствии с новым кадрированием. При кадрировании экспозиция элемента массива может продолжаться до окончания периода срабатывания.
* Состояние включения/выключения области интереса (ROI) и запомненная область кадрирования сохраняются вместе с проектом.

### Выравнивание (совместная регистрация)

Показано как для **объединённых, так и для отдельных массивов** (в версии 1.2.0 это отображалось только для объединённых массивов); заголовок группы гласит «Выравнивание».

* Плитка **Остаточная погрешность**: «RMS x.xx px» — зелёный цвет при значении менее 1 пикселя, жёлтый — при значении до 3 пикселей, красный — в остальных случаях или при сбое любой камеры; «нет профиля» перед первым вычислением.

* Таблица по камерам: камера (последние 4 символа серийного номера + фильтр), погрешность репроекции в пикселях с количеством совпадений («ref» для ведущей камеры) и нормализованный показатель кросс-корреляции перекрытия относительно минимального порога прохождения 0,35.
* **Перекалибровать выравнивание** (с надписью «Калибровать выравнивание» до первого профиля) — повторно запускает совместную регистрацию на новых кадрах.
* **Флажок «Автоэкспонировать камеры для выравнивания»** (по умолчанию установлен) — временно увеличивает яркость темных или плоских камер (сначала экспозиция, затем коэффициент усиления), чтобы у них появилась текстура для сопоставления, а затем восстанавливает автоэкспозицию.

Chloros**автоматически выравнивает каждый массив после подключения в обоих режимах отображения, как только автоматическая экспозиция элементов стабилизируется (попытки продолжаются до 5 минут); комбинированный предварительный просмотр также выравнивается при открытии. Отдельный массив не имеет составной плитки, поэтому в этом разделе опрашивается состояние выравнивания и запускается сама функция «Перекалибровать». Выполняйте перекалибровку, если изменились фокус или глубина сцены. Выравнивание**по замыслу действует только в течение сеанса** — оно никогда не сохраняется в профиле, поскольку зависит от текущего расстояния до сцены. Захваты по-прежнему можно экспортировать с пиксельной регистрацией (см. [Выравниваемые экспорты](capture.md#per-array-controls)).

### Интеллектуальная коррекция виньетирования

* Флажок **«Включить коррекцию»**— применяет оценку виньетирования для каждой камеры к радиометрической цепочке (в режиме реального времени**и** при экспорте).
* **Калибровка по текущему виду**— сначала наведите массив на однородную мишень (плоскую панель, стену или небо); каждая камера выравнивается индивидуально, и в отчёте о состоянии отображается прирост плоскостности «n/N камер · −x,x %». Нажатие кнопки**Очистить** удаляет оценку.
* Статус: «Калибровано», «Не калибровано» или «Частично калибровано — запустить заново», если оценки только некоторых камер по-прежнему применимы при их текущем кадрировании (например, после того, как функция «Перекалибровать» сдвинула окно кадрирования одной из камер) — запустите «Калибровку» снова.
* Выполните точную настройку для каждой камеры с помощью ползунка **«Виньетирование»** в [Live Preview](#live-preview).

### Предварительный просмотр в реальном времени

* Флажок **Гистограмма**+ ползунок ширины (0,10–0,90 кадра) — полоса гистограммы на потоке сразу на плитке каждого участника (включая плитки с разделёнными каналами), а также [Наложение гистограммы](#display-overlays-drawn-over-the-live-feed), настроенное для всей матрицы. Оно отображается как включённое, если у всех участников оно уже есть. На**отдельной** матрице это единственная строка в группе.
* *Только для комбинированных матриц:* **Индекс**: флажок «Включить» + значок шестеренки — открывает общий [калькулятор индекса](#index-calculator-pane) с полосами, построенными на основе данных**всех** камер-участников. Строка предварительного просмотра выражения ниже показывает текущее выражение («Выражение не задано — откройте калькулятор, чтобы создать его»), обновляемое каждую секунду.
* *Только в комбинированном режиме:* выпадающий список **Разрешение рендеринга**(те же пресеты, что и для отдельных камер, по умолчанию 720p): высота потока в режиме реального времени**и** размер сохраненного композитного экспорта. Примечание в панели: «Предварительный просмотр + размер сохраненного композита. Изображения с отдельных камер всегда экспортируются в полном разрешении».

### Слои отображения *(только в режиме объединения)** Флажок **Включить** (по умолчанию отключен — главная камера отображается напрямую; включен = многослойный композит).
* **Выпадающие списки**«Передний план»**/**«Фон»**: каждая камера-участник (по имени) или**«Индекс»**. Когда для параметра «Передний план» выбран «Индекс», пиксели за пределами минимального/максимального значений LUT отображают слой «Фон».

### Разделенный вид *(только в комбинированном режиме)*

**«Показать камеры-участников»**— кнопка**«Разделить / Скрыть камеры участников»**, которая добавляет прямую трансляцию с каждой камеры участника в виде отдельных ячеек сетки рядом с композитным изображением. Ячейки считывают данные из существующего буфера кадров массива (дополнительное подключение камер не требуется). Только в режиме сетки; сохраняется для каждого массива вместе с проектом.

### Возможности

Панель только для чтения, обновляемая каждые 5 с:

* **Метка уровня**: «Одновременная съемка» (зелёный) · «Одновременная съемка (последовательная передача FTD)» (зелёный) · «Поэтапная съемка (смещение 100 мс)» (жёлтый) · «Конфигурация слишком велика» (красный).
* **Состояние кадра**: «x,xx % незавершено» — зелёный при значении менее 1 %, жёлтый при значении менее 5 %, красный при значении 5 % и более.
* **Строка соединения**: «NIC {mbps} Мбит/с — устойчивая пропускная способность {MB/s} МБ/с».

Это бюджет пропускной способности массива в режиме реального времени. Информацию о базовых показателях fps и модели сети, а также о том, что следует изменить, когда уровень становится жёлтым или красным, см. в разделе [Массивы с несколькими камерами](arrays.md) и в [Справочнике по CLI](../reference/cli-reference.md).

## Панель «Калькулятор индекса»

Третья страница боковой панели, общая для настроек индекса отдельных камер и для массива в целом (поочередно — заголовок гласит «Калькулятор индекса — <camera name="">» или «Калькулятор индекса — <array name="">»). На ней отображается список диапазонов (фильтр камерыестественные полосы или все полосы по всем камерам в массиве), текущее выражение и конфигурацию LUT (вкл./выкл., уровень — по умолчанию 7 ступеней, мин. — по умолчанию 0,2, макс. — по умолчанию 1), а также гистограмму индекса в реальном времени. Кнопка **Применить** фиксирует выражение; изменения LUT применяются в режиме реального времени к предварительному просмотру.

## Настройки для отдельной камеры и настройки, управляемые массивом

Краткое руководство о том, что находится где, когда камера является элементом массива:

| Управляется массивом (только для чтения на панели камеры) | По-прежнему для отдельной камеры внутри массива |
| --- | --- |
| Формат пикселей, разрешение, биннинг | Автоэкспозиция (экспозиция, коэффициент усиления, целевое значение, сглаживание, область интереса) |
| Режим/источник срабатывания, частота кадров | Шумоподавление, резкость, виньетирование |
| | Ориентация (зеркальное отражение/поворот), наложения на экране (настройки массива → «Live Preview» одновременно устанавливает гистограмму на всех камерах-членах), точечный экспонометр |
| | Индекс (массивы с отдельным отображением), привязка к датчику освещенности |

Другие общие настройки:

* **Объединённое или раздельное отображение** выбирается при подключении массива: объединённое = одна выровненная составная плитка (потоки с элементов доступны только через «Разделённый вид»); раздельное = каждый элемент отображает свою собственную синхронизированную плитку. Камера никогда не показывает одновременно как отдельный поток, так и плитку массива.
* **Автоматическое повторное подключение**: при открытии сохраненного проекта восстанавливаются камеры и массивы, а все сохраненные настройки повторно применяются к бэкенду до возобновления потоков.
* **Управление захватом**: скрытые или приостановленные камеры исключаются из режима «Захват всего»; массив полностью блокируется только тогда, когда ВСЕ элементы массива скрыты или приостановлены. См. [Настройки и режимы захвата](capture.md).

## Как сохраняются настройки

Состояние вкладки «Камера» сохраняется **вместе с проектом**, а не в браузере:

* Каждое реактивное изменение создаёт моментальный снимок камер и массивов в файле проекта `cameras.json` (с задержкой 500 мс).
